ライブラリバグ情報および使用上の注意
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
< HMD ライブラリ libhmd の追加 > 
- PlayStation library release 4.2以前では LIBGS, LIBGTE の一部として
  提供されていた HMD 関連は、 LIBHMD という形で分離・独立しました。
  これに伴い、LIBGS, LIBGTE のライブラリ、ヘッダファイルからは HMD 
  関連の関数、宣言が削除されています。HMD ライブラリ (LIBHMD)、libhmd.h 
  を併せてご使用くださるようお願いいたします。
  また、環境マップについては「β版」としてのご提供になります。これは、
  将来のリリースにおいて互換性を保たない形でのフォーマット変更の可能性が
  あるためです。β版のプリミティブについては、現時点では SCE による正式
  サポート対象では無いため、タイトル作成にご利用になる場合、貴社のご判断
  にて行われますようお願いいたします。

< printver の追加 >
- バージョン確認のために利用されていた pkver で、バージョンを表示できな
  いファイルが多数発見されていたため、今回新たに printver を追加しました。

< pkver の削除 >
- 上記の理由により、pkver を削除しました。

< バグ情報 >
- PadInitMtap() で初期化を行ったとき、まれにマウスを認識しないことがあり
  ます。認識させるためにはマウスを抜き差ししてください。

- 拡張サウンドライブラリ(libsnd)において、現在ノイズの発音が正しく機能
  しません。ノイズを使用する際は基本サウンドライブラリ(libspu)をご使用
  ください。この不具合は次期リリースで対応予定です。

- BreakDraw() で OT を中断し、ContinueDraw() で別の OT を割り込ませ、
  描画を再開しようとしたときに、割り込ませる OT の最後にあるパケットが実
  行されないという不具合があります。割り込ませる OT の最後は、NULL 
  パケット（サイズが 0 のパケット）にしてお使いください。
  この不具合は、次期リリースで対応予定です。

ここに記載されている会社名、製品名は、各社の登録商標または商標です。

< ライブラリのバグフィクス >
- DsRead() を使用した時、リード終了後に発行される pause プリミティブに
  より sync callback が呼ばれることがありましたが、このタイミングでは
  sync callback は呼ばれないよう修正しました。

- ふたが開いている時には、DsGetDiskType() は DslStatShellOpen を返さない
  という不具合を修正しました。

- CdPlay(), DsPlay() 使用時、指定したトラックが再生されずにスキップ
  してしまうという不具合を修正しました。

- DsRead() のパケットがキューに入りきらなかった時に、次回からの
  DsRead() が必ずエラーになるという不具合を修正しました。

- DsCommand(), DsPacket() がコマンドを登録したのにも関わらずエラーを
  返す事があるという不具合を修正しました。

- DslGetlocL, DslGetlocP プリミティブコマンドを、10, 30, 50分台のセクタ
 リード中に使用した際、DslDiskError になるという不具合を修正しました。

- DsRead(), DsSearchFile() 等を頻繁に呼び出していると、データの読み込み
  ができなくなるという不具合を修正しました。

- DsPlay() 使用時、複数トラックを指定しても最初の 1 曲しか再生されないと
  いう不具合を修正しました。

  バッファの内容が異常になるという不具合を修正しました。
