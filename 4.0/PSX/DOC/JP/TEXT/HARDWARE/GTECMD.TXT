[リミッタ]
        演算処理の一部において、演算結果やレジスタ中のデータ値が特定の上限値
        と下限値の間にクリッピングされます。つまり下限値より小さいデータは下
        限値に、上限値よりも大きいデータは上限値にそれぞれ変換されます。また、
        変換の発生はFLAGレジスタ中の範囲外データ検出フラグに反映されます。こ
        の機能を「リミッタ」と呼びます。
        各リミッタの使用と当ドキュメントにおける指定記号を下表に示します。
        
        +-----+--------+----------+------+------+-----------------------+
        |指定  リミッタ 範囲外検出 下限   上限   備考                   |
        |記号           ビット                                          |
        +-----+--------+----------+------+------+-----------------------+
        |A1S   A1       24         -2^15  2^15-1                        |
        |A2S   A2       23         -2^15  2^15-1                        |
        |A3S   A3       22         -2^15  2^15-1                        |
        |A1U   A1       24         0      2^15-1                        |
        |A2U   A2       23         0      2^15-1                        |
        |A3U   A3       22         0      2^15-1                        |
        |A1C   A1       24         0 or   2^15-1 引数limにより下限値決定|
        |                          -2^15                                |
        |A2C   A3       23         0 or   2^15-1 引数limにより下限値決定|
        |                          -2^15                                |
        |A3C   A3       22         0 or   2^15-1 引数limにより下限値決定|
        |                          -2^15                                |
        |B1    B1       21         0      2^8-1                         |
        |B2    B2       20         0      2^8-1                         |
        |B3    B3       19         0      2^8-1                         |
        |C     C        18         0      2^16-1                        |
        |D1    D1       14         -2^10  2^10-1                        |
        |D2    D2       13         -2^10  2^10-1                        |
        |E     E        12         0      2^12-1                        |
        +-----+--------+----------+------+------+-----------------------+
        
[演算エラー検出]
        オーバーフローとアンダーフローの検出は特定の演算操作に対してのみ行わ
        れます。当ドキュメントでは検出対象演算の右に、演算テスト結果フラグ番
        号を＜と＞ではさんで記載しています。
        
[凡例]
        
        +--------------+---+-------------------------+
        |文字属性       例  内容                     |
        +--------------+---+-------------------------+
        |アンダーライン VAL 中間値                   |
        |                   （対応するレジスタなし） |
        |強調文字       OBJ 32ビット値               |
        +--------------+---+-------------------------+
        
        +----------+----------------------------------------------+
        |記号       意味                                          |
        +----------+----------------------------------------------+
        |limX()     リミッタ適用 Ｘはリミッタ指定記号             |
        |<-         FIFO型データ転送                              |
        |           例：a <- b <- c <- d;は以下と等価。           |
        |               a = b;                                    |
        |               b = c;                                    |
        |               c = d;                                    |
        |^          べき乗                                        |
        |           例：a^bは「aのb乗」                           |
        |==         引数値条件                                    |
        |n=0,1,2 {} nを0,1,2と変化させながら{}中の処理を３回反復。|
        |(a.b.c)    固定小数点数                                  |
        |           符号部aビット、整数部bビット、小数部cビット   |
        |(-.b.-)    bビットバイナリデータ                         |
        |<n>        オーバー・アンダーフローテスト対象演算        |
        |           テスト結果はFLAGレジスタ中の積和テストフラグ  |
        |           n番へ反映される。                             |
        +----------+----------------------------------------------+
        
[記述例]
        （Ａ）
        (1.15.0)  A = B;
        →(1.15.0)形式固定小数点数に対してA=Bを実行。
        
        （Ｂ）
        (1.15.0) IR0 = limX(SSX);
        リミッタ：
        +----+-----+------+
        |記号 下限  上限  |
        +----+-----+------+
        |limX -2^15 2^15-1|
        +----+-----+------+
        →32ビット値SSXをXで指定されるリミッタで丸めて、その結果得られた(1.12.
        0)形式固定小数点数をIR1へ代入する。
        
        （Ｃ）
        n=0,1,2{
        (1.3.12)L1n
            = limA(LL1n);
        }
        →(1.3.12)形式固定小数点数に対して
        L10=limA(LL10); 
        L11=limA(LL11);
        L12=limA(LL12);
        を実行。
        
        （Ｄ）
        sf==0      sf==1
        (1.31.0) (1.19.12) A = B;
        →BをAへ代入。ただしsfが0ならば小数部なしの、sfが1ならば小数部12ビッ
        トの、32ビット符号付き固定小数点数に変換。

[機能]
        座標変換＆透視変換
        
[演算]
        (1.31.12)  SSX = TRX + R11*VX0 + R12*VY0 + R13*VZ0; <1>
        (1.31.12)  SSY = TRY + R21*VX0 + R22*VY0 + R23*VZ0; <2>
        (1.31.12)  SSZ = TRZ + R31*VX0 + R32*VY0 + R33*VZ0; <3>

        (1.15. 0)  IR2 = limA2S(SSY);
        (1.15. 0)  IR3 = limA3S(SSZ);
        (0.16. 0)  SZx(0) <- SZ0(1) <- SZ1(2) <- SZ2(3) <- limC(SSZ);
        (1.27.16)  SX = OFX + IR1*(H/SZ); <4>
        (1.27.16)  SY = OFY + IR2*(H/SZ); <4>
        (1.19.24)  P = DQB + DQA*(H/SZ); <4>

        (1.15. 0)  SX0 <- SX1 <- SX2 <- limD1(SX);
        (1.15. 0)  SY0 <- SY1 <- SY2 <- limD2(SY);
        (1. 7.24)  MAC0 = P;
        (1.31. 0)  MAC1 = SSX;
        (1.31. 0)  MAC2 = SSY;
        (1.31. 0)  MAC3 = SSZ;
