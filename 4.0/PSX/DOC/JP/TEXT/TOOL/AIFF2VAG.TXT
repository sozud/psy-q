                                                   PlayStation Data Converter

aiff2vag
---------


 1 概要

    Audio Interchange File Format (以下 AIFF) 形式、Windows WAV(以下WAV) 形式
    のデータもしくは 16 bit ストレート PCM データ(ヘッダ無し)を PlayStation 
    の波形データファイルに変換します。
    ここでは、1996/Jul/25付けの Version 2.1 に関する内容を記述しています。

 2 使い方


    aiff2vag [options] aiff-files...

      引数としてAIFF 形式、WAV形式または 16bit ストレート PCM 形式のファイル
      を与えると、PS の圧縮波形データファイルである VAG ファイル (*.VAG) を生
      成します。複数のファイルを与え、一度に変換することも可能です。ファイル
      の拡張子 「.aif」 は省略可能です。

 3 オプション


    -1

      ループありの波形データを、エンコード時に強制的にループ無し音源としてエ
      ンコードします。

    -L

      ループ無しの波形データを、エンコード時に強制的にループ有り音源としてエ
      ンコードします。

    -R fs

      16bit ストレート PCM 入力時に、そのデータのサンプリングレートを指定しま
      す。fs は Hz 単位です。

    -E

      エンディアン(バイト列順序)コンバートをしません。

 4 制約

    現バージョンは以下の制約を持っています。
    
         ・16bit 非圧縮データのみに対応しています。4bit、8bit、圧縮形式のデー
           タには対応していません。
         ・モノラルデータのみに対応しています。ステレオソースをコンバートする
           際には、チェンネルを分割してからコンバートしてください。
