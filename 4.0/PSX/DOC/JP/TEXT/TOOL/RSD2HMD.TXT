                                                   PlayStation Data Converter

rsd2hmd
--------


 1 概要

    RSD フォーマットファイルを、HMD フォーマットに変換します。
    ここでは、Version 1.0に関する内容を記述しています。

 2 使い方


    rsd2hmd [options] RSD-file

    
    RSD フォーマットのファイルを、HMD フォーマットに変換します。出力される 
    HMD ファイルは、入力 RSD ファイルから拡張子を取り除いた名前に ".hmd" をつ
    けたファイル名になります。

 3 オプション


    -o output-file

      出力ファイル名を指定します。デフォルトは入力ファイルの拡張子を".hmd"に
      変換したものを現在のディレクトリに生成します。

    -s X

      指定された倍率でオブジェクトを拡大・縮小します。

    -bin2cl file-name

      出力したHMDデータを16進表記で表したものを指定されたファイルに出力します。

    -ni

      イメージデータをHMDに出力しません。

 4 備考

         ・使用されるRSDファイル、及びTIMファイルは同一ディレクトリに存在しな
           くてはなりません。別ディレクトリに存在する場合は、その相対パスある
           いは絶対パスを指定して下さい。
         ・出力されるHMDファイルはRSDファイル中に示される情報を全て含みます。
           連結情報や、COORDINATE情報など含みたくない情報が存在する場合は、
           RSDファイル中でファイル指定をしないか、あるいはコメントアウトして
           おいて下さい。
         ・出力ファイル名が既に存在する場合、その内容は上書きされます。警告な
           どは出力しませんので、ご注意ください。
         ・本プログラムはRSDフォーマットの以下のバージョンに対応しています。そ
           の他のバージョンのRSDファイルは使用することができませんので、あら
           かじめご了承下さい。
        
              RSDファイル      version 3.0
              PLYファイル      version 3.0
              MATファイル      version 3.0
              GRPファイル      version 3.0
              (rsd2hmd version 1.0ではGRPファイルは使用しないため、versionは
        問いません)
              MSHファイル      version 1.0
              PVTファイル      version 1.0
              CODファイル      version 1.0
              OGPファイル      version 1.0
              MOTファイル      version 1.0
