                                                   PlayStation Data Converter

dxf2rsd
--------


 1 概要

    DXFファイルをPlayStationの3Dモデルデータファイルに変換します。
    DOS版とSGI版があります。ここでは、1996/Apr/25付けの Version 2.81 に関する
    内容を記述しています。

 2 使い方


    dxf2rsd [options] DXF-files ...

      DXFファイル名を引数として与えると、以下の４つのファイルを生成します。
      
         ・RSDファイル(*.rsd)
         ・ポリゴンファイル(*.ply)
         ・マテリアルファイル(*.mat)
         ・グループファイル(*.grp)
      
      引数にワイルドカードが使用できます。複数のファイルを与え一度に変換する
      ことも可能です。ファイル名の".dxf"は省略可能です。

 3 オプション


    -o output-file

      出力RSD名を指定します。拡張子は取り除かれます。デフォルトは入力ファイル
      名の拡張子を除いたものです。

    -col r g b

      モデル全体の色をRGB(それぞれ0-255)で指定します。デフォルトではグレイ
      (200 200 200)に設定されます。

    -cf color-file

      カラーテーブルファイルを指定します。

    -cl

      未定義カラーのリストを標準出力に出力します。また同色のポリゴンを整理し
      てMATファイルに出力します。デフォルトはOFFです。(例2参照)

    -info

      入力DXFファイルの情報を表示します。おおよその大きさやポリゴン数を知るこ
      とができます。変換は行いません。

    -max n-poly

      変換できる最大のポリゴン数を設定します。デフォルトは10000です。

    -quad または -quad1

      4頂点3DFACEに対して、三角分割を行いません。これにより、モデル全体のポリ
      ゴン数を減少させることが可能です。デフォルトはOFFです。

    -quad2 (threshold)

      隣接する2つの三角形を１つの四角形に合成します。引数を指定すると、2つの
      三角形の向き(法線ベクトル)のぶれを角度で設定でき、その角度以下の三角形
      同士を合成します。
      引数が0.0のとき正確に同じ法線ベクトルを持つ場合のみ合成され、10.0のとき
      10度の差まで許されることになります。0.0から90.0の間の小数を指定してくだ
      さい。デフォルトは1.0です。(例4参照)

    -quad3

      三角形に対して、第3頂点と第4頂点が等しい四角形として生成します。これに
      よりすべて四角形にすることができます。

    -s または -g

      スムーズ(グーロー)シェーディングを行ないます。デフォルトはOFFです。

    -e distance

      引数で与えられた距離を半径とする球内に存在するすべての頂点を同じとみな
      します。これにより、頂点数、ポリゴン数を削減することが可能です。なお、
      距離の計算は、-scで拡大縮小されたあとに行なわれます。

    -r

      同じ法線ベクトルを生成しないようにして、法線数を削減します。フラットシ
      ェーディングの場合に有効です。デフォルトはOFFです。(例3参照)

    -n

      法線を作成しません。光源計算を行なわない場合に指定します。デフォルトは
      OFFです。

    -sc factor

      モデルの拡大縮小を行ないます。引数で倍率を指定します。デフォルトは1.0で
      す。

    -t x y z

      モデルを移動させます。引数で移動量を指定します。デフォルトは(0.0, 0.0, 
      0.0)です。

    -auto

      モデルを原点付近に移動し適当な大きさ（１辺1000の立方体に収まるよう）に
      拡大縮小します。デフォルトはOFFです。

    -back

      全ポリゴンの法線の向きを逆にします。デフォルトはOFFです。

    -both

      全ポリゴンを両面ポリゴンとして生成します。デフォルトはOFFです。

    -dup

      全ポリゴンに対して表裏それぞれにポリゴンを生成します。ポリゴン数は2倍に
      なります。デフォルトはOFFです。

    -nopl

      POLYLINEを無視し3DFACEのみ変換します。デフォルトはOFFです。

    -Y-Z, -Y+Z, +Y-Z, +Y+Z, -Z-Y, -Z+Y, +Z-Y, +Z+Y

      座標系の変換方法を指定します。モデラの座標系を正面から見た場合の、手前
      と上の座標軸とその向きを指定します。例えば"-Y+Z"は、手前がＹ軸の負、上
      がＺ軸の正であることを示します。ここで座標系とはDXFのものであって、必ず
      しもモデラの画面とは一致しません。デフォルトは"-Y+Z"です。dxf2rsdはこれ
      をPlayStationの座標系(-Z-Y)に変換します。 (PSの座標系は、手前がＺ軸の負、
      上がＹ軸の負です。)

    -v

      変換に関する詳細な情報を標準出力に出力します。(例1参照)

 4 前バージョン(ver.2.8)からの主な変更点

         ・メモリ関連のバグを除きました(DOS版)。

 5 制約

    現バージョンは以下の制約を持っています。
    
         ・ASCII形式のDXFファイルにのみ対応しています。
         ・DXFエンティティのうち、3DFACEおよびPOLYLINEにのみ対応しています。
         ・大きなPOLYLINEは変換できない場合があります。できるだけモデラで
           3DFACE (三角形または四角形)に変換した上でDXFファイルを生成してくだ
           さい。
         ・４頂点が同一平面上にない四角形に対しては正しく表示されない場合があ
           ります。
         ・変換可能な最大ポリゴン数は、生成する頂点数、法線数の影響を受けます。
           目安として、DOS版の場合で5000ポリゴン程度とお考え下さい。

 6 補足

         ・3DFACE、POLYLINEは、ともにDXFのポリゴン表現の形式です。3DFACEは４つ
           の頂点でひとつのポリゴン(三角形また四角形)を表現します。一方、
           POLYLINEは連結線分で複数のポリゴンを表します。3DFACEはデータが大き
           くなりがちですが、互換性に優れています。これに対し、POLYLINEはデー
           タは小さくなりますが、表現の自由度が大きく、異なるモデラ間でのデー
           タ交換がうまくできないことがあります。
         ・3DFACEはRSDに直接変換できますが、POLYLINEはまず三角分割を行なわなく
           てはなりません。この分割は一般に高価で、うまくいかない場合がありま
           す("Fail to triangulate!"のエラーメッセージが出ます)。さらに三角分
           割が無事終了した場合でも、POLYLINEでは、一部ポリゴンの向きが反転し
           てしまうことがあります。
         ・ただし、3D Studioなどが生成するPOLYLINEはPOLYFACE MESHと呼ばれるも
           ので、これは3DFACEと等価な表現方法のため、変換に問題はありません。
         ・実機上で１つのオブジェクトとして動かすための現実的な数は最大2000ポ
           リゴン程度です。これを目安にモデルデータを作成してください。
         ・ポリゴン数が多くて、フラットシェーディングでは変換できない場合でも、
           グーローを指定すれば変換できる場合があります。
         ・Y-Z座標軸を交換したり、各軸の正負を入れ替えると、そのたびにポリゴン
           の表裏が反転します。
         ・モデラによっては、3DFACEで出力しても、ポリゴンの表裏が反転している
           ことがあります。全体が反転している場合は座標系を変える(+Y+Zなど)か、
           -backオプションを御使用ください。一部だけ表裏が逆になっている場合、
           モデラでその面を反転させる必要があります。
         ・市販の3Dモデラの出力するDXFが、dxf2rsdで「変換可能である」ための十
           分条件は、そのモデラが、すべて3DFACEのDXFを出力でき、かつ、ポリゴ
           ン毎に表裏の反転ができることです。これらの条件を満たしていなくても
           変換可能なものもあります。また、他のモデラで一度DXFを読み、保存す
           ることで、直接は変換できないものでも、変換可能になることがあります。
         ・データが大きく、すべての法線を生成できない場合、-nオプションが生成
           されたものとして法線なしのRSDを生成します。
         ・-rオプションは、グーローシェーディングを行なう場合は無効です。また、
           -rオプションを指定すると、法線数や順序が変わるため、法線MIMeを行な
           う場合には使用できません。
         ・-quad2で2つの三角形を四角形に合成すると、Zソートが起こる場合があり
           ます。
         ・-quad2を指定して合成される２つの三角形は、モデラで互いに違う色を指
           定してDXFとして出力すると、その部分だけ-quad2を無効にすることがで
           きます。その場合は、dxf2rsd -quad2 -cl のように、-clオプションも同
           時に指定してください。

    例2（-clオプション）

      モデラで行った着色情報をRSDに反映させることができます。これには「-cl」
      オプションを用います。これにより、ポリゴンが「適当に」色付けされます。
      「適当に」とは、モデラ上での色とは異なるものの、同じ色であった部分には
      同じ色を割り当てることを示しています。これはDXFにはRGB値ではなく「色番
      号」しか保持されないためです。その後、MATファイルをテキストエディタで編
      集するか、次のようにカラーテーブルファイルを作って、色を指定することが
      可能です。
        
        C:\> dxf2rsd -cl foo > foo.cl		カラーテーブルファイルの生成
        C:\> type foo.cl			生成された色番号ファイルを見る
        	183
        	40
        	253
        	0
        	8
        
      ここで、各色番号に割り当てたい色を、テキストエディタを用いて、色番号に
      続けてRGB値（各０～255）で記入します。
        
        C:\> vz foo.cl				ファイルを編集
        C:\> type foo.cl			編集後のファイルを表示
        	183	100 100 200
        	40	 58  20  43
        	253	 10 100  10
        	0	212  20 100
        	8	  0 128 126
        
      続いて、-cf オプションを指定して再びdxf2rsdを起動します。
        
        C:\> dxf2rsd -cf foo.cl foo		dxf2rsd を起動
        
      新たに生成されたRSDは、カラーテーブルファイル通りに色が割り当てられたも
      のになります。

    例3 大きなデータの変換

      詳細過ぎるデータがあるとき、「-e」オプションを用いて、いくつかの頂点を
      ひとつにすることができます。下の例は、距離が100以下の２頂点を同一とみな
      すことで、頂点数ならびにポリゴン数、法線数を削減しています（拡大を行な
      った後のスケールを基に距離が計算されることに注意）。
      データにも依存しますが、適当な距離を設定することにより、ほとんど形を変
      えずにデータ量を減らすことができます。
      さらに、「-r」オプションを指定すれば、法線数も削減できます。
        
        C:\> dxf2rsd -v -e 100 -sc 1000 big.dxf
        =================================================
        Input DXF file:big.dxf
        
          [DXF] SIZE    : 134628 lines
                VERTEX  : 18982
                POLYGON : 8618 (estimate)
                          3-poly     : 1746
                          4-poly     : 3436
                RANGE  x: -1.644 ... +1.545
                       y: -2.352 ... +0.000		スケールが小さいので
                       z: -3.649 ... +3.993
                SCALE   : 1000.000			1000倍する
                MATERIAL:    0
        
          [RSD] VERTEX  : 1208
                POLYGON : 2708 (68% reduced)		ポリゴン数は約3割に
                          triangles  : 2708
                RANGE  x: -1643.811 ... +1545.072
                       y: -2352.365 ... +0.000
                       z: -3649.154 ... +3992.687
                MATERIAL:    0
                NORMAL  : 2708
        
          Output files  : big.[rsd, ply, mat, grp]
    
      さらに、-rオプションを指定すれば、法線数も削減できます。

    例4 四角形の合成

      -quad2オプションを指定すると、隣接する二つの三角形を四角形に合成するこ
      とができます。次の例では、二つの三角形の間の角度が5度以下のものを四角形
      に変換することによって、ポリゴン数を半分近くまで削減しています。
        
        C:\> dxf2rsd -v -quad2 5.0 earth
        =================================================
          Input DXF file : earth.dxf
        
          [DXF] SIZE    : 88158 lines
                VERTEX  : 8811
                POLYGON : 2937 (estimate)
                          3-poly     : 2937		もとは3角形2937個
                RANGE  x: -4.000 ... +3.986
                       y: -3.997 ... +3.997
                       z: -4.000 ... +4.000
                MATERIAL:    0
        
          [RSD] VERTEX  : 2231
                POLYGON : 1686				全部で1686ポリゴン
                          triangles  :   43		2502個の3角形が合成され
                          quadrangles: 1251		1251個の4角形になった
                MATERIAL:    0
                NORMAL  : 1686 (quad2 < 4.9870)
        
          Output files  : earth.[rsd, ply, mat, grp]
    
      図中
                NORMAL  : 1686 (quad2 < 4.9870)
        
      の「4.9870」は、許容角度(この場合5.0)のうちで、実際に変換された最も大き
      な角度を示しています。従って、「-quad2 4.986」などを指定して再び実行す
      ると、合成される四角形の数は若干少なくなります。
