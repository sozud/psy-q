                                                   PlayStation Data Converter

timpos
-------


 1 概要

    PlayStationの画像データファイルであるTIMファイル中に記されたイメージやカ
    ラーテーブルのVRAMアドレスを変更します。
    DOS版とSGI版があります。ここでは、1996/May/1付けの Version 1.1 に関する内
    容を記述しています。

 2 使い方


    timpos [options] input-file image-x image-y [clut-x clut-y]

      引数で与えられたTIMファイルに対して、イメージおよびカラーテーブル(CLUT)
      がVRAM上のどのアドレスに配置されるかを設定します。与えるアドレスはイメ
      ージおよびCLUTそれぞれの左上の座標値です。なお、VRAM空間は横1024 x 縦
      512 です。
      
      CLUTアドレスのみを引数で与えることはできません。イメージアドレスも指定
      してください。イメージアドレスとして負の数を与えればそのアドレスは変更
      されません。
    
      例）
        timpos test.tim -1 -1 0 500 (CLUTアドレスのみ変更)
    
      また、CLUTアドレスとして負の数を与えると、CLUTなしのTIMファイルが生成さ
      れます。CLUTアドレスを変更しない場合は、イメージアドレスのみ指定してく
      ださい。
    
      例）
        timpos test.tim 640 0 （イメージアドレスのみ変更）
        timpos test.tim 640 0 -1 0 （CLUTなしのTIMを生成）
    
      引数のTIMファイル名の".tim"は省略可能です。

 3 オプション


    -o output-file

      出力ファイル名を指定します。デフォルトでは入力ファイルに上書きされます。

    -v

      入力ファイルおよび変換に関する情報を標準出力に出力します。このオプショ
      ンとともにTIMファイルのみを与えれば現在の配置情報を知ることができます。

 4 前バージョン(ver.1.0)からの変更点

         ・CLUTアドレスとして負の数を指定した場合に、CLUTなしのTIMファイルを生
           成するようになりました。

 5 注意

         ・CLUTなしTIMファイルをCLUTありに変換することはできません。
