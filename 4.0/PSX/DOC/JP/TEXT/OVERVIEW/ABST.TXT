                                                 Library Overview Release 4.0

<PlayStation OS> 概要
======================

  PlayStationには、柔軟で強力なOSが搭載されています。このOSを利用することによ
  り、PlayStationの能力を最大限に引き出し、かつ、これを自在に制御するアプリケ
  ーションを開発することができます。

 1 <PlayStation OS>とは
------------------------

    <PlayStation OS>は、PlayStationのCPUとして搭載されているR3000をターゲット
    に開発された、きわめて新しいコンセプトを持つオペレーティングシステムです。
    プログラム開発の効率は、そのマシンに搭載されているOSが提供する環境、サー
    ビスに大きく依存します。十分に高速なCPUと周辺デバイスが保証されてさえいれ
    ば、OSの提供するサービスをうまく利用し開発を進めて行くことで、ハードウェ
    アの能力を限界まで引き出す方法を考察するといったことに時間をとられる必要
    はなく、集中してプログラミングに取り組むことができます。
    <PlayStation OS>の設計コンセプトは、「ゲームプログラム開発者のために」「
    割り込み駆動のプログラムを快適に動作させる環境を提供」することにあります。
    このコンセプトに基づき、<PlayStation OS>のカーネルは、R3000および
    PlayStationハードウェアを制御するサービス（サブルーチン）の集合体として提
    供されます。
    さらに、各サービスはすべてC言語の関数として提供されます。C言語を用いるこ
    とにより、ソースコードの視認性、保守性の向上を図れるだけでなく、ブロック
    構造記述、および関数呼び出しの容易さなどの特長を活かし、プログラミングを
    より平易に行なうことが可能になります。

 2 <PlayStation OS>の特徴
--------------------------

    <PlayStation OS>には、その設計コンセプトを実現する、数々の特長があります。

  2.1 C言語によるプログラミング

    R3000 CPUの制御、PlayStationハードウェア群の制御など、ほとんどのサービス
    はC言語の関数として提供されます。よって、プログラミングは一貫してC言語で
    行うことができます。

  2.2 R3000の機能を簡単に利用可能

    R3000での割り込み処理手続きは複雑であると言われていますが、<PlayStation 
    OS>ではこれをOSが代行処理する「ディスパッチャー」システムを採用し、平易な
    インターフェイスを提供しています。もちろん、ディスパッチに伴うオーバーヘ
    ッドは最小限に抑えています。
    さらに、通常のOSでは公開されないようなネイティブ・レベルでの使い方もサポ
    ートしています。これにより、チップの能力を最大限に引き出し、より高度なチ
    ューニングを行うことができます。もちろん、すべてC言語により制御できますの
    で、難解なR3000のアセンブラを修得する必要はありません。

  2.3 軽量・小型・パフォーマンス重視

    せっかくの高速ゲームも、OSが鈍重であっては、その足を引っ張ることになりか
    ねません。アプリケーションのパフォーマンス重視のため、<PlayStation OS>の
    メモリ常駐サイズを64Kバイトと最小限のレベルに抑え、CPU占有時間も最小限と
    なるよう設計されています。また、OSのシステムテーブルも公開され、OSの拡張、
    内部データの取得といった点にも配慮がなされています。
    さらに<PlayStation OS>では、より一層の高速化を図るべく、一般のOSにみられ
    る禁止事項のチェックをも敢えてカットしています。これらのチェックは、アプ
    リケーションが責任を持って行う必要があります。従って、本来禁止されている
    操作を行ってしまう危険性もありますが、注意深くプログラミングすることによ
    り、OS内部の機能を利用した、よりハイレベルなチューニングを可能にしていま
    す。

  2.4 ハードウェアのすべての機能を提供

    これまで、ビデオゲーム機のハードウェア制御と言えば、これを解析し、アセン
    ブラにより隅々まで神経を行き届かせる必要がありました。<PlayStation OS>で
    はこういった負担を軽減するため、ハードウェアのすべての機能をC言語の関数と
    して提供しています。各関数のオーバーヘッドは最小限に抑えられています。

  2.5 シングル／マルチタスクの選択が可能

    <PlayStation OS>は、基本的に複数の処理を非同期に行うことのできるマルチタ
    スクOSです。マルチタスク制御は、比較的遅いデバイスであるCD-ROMの制御、あ
    るいはBGMの演奏などに適しています。
    また、従来型のプログラミング、すなわちシングルタスクに慣れた方のために、
    マルチタスクを利用するかどうかを選択可能としています。OS起動直後はシング
    ルタスク・モードであり、ここで設定を行うことにより、動作モードを選択する
    ことが可能です。

  2.6 ファイルシステムのデバイスドライバ化

    <PlayStation OS>では、ファイルシステムのデバイスドライバ化という、これま
    でにない仕組みが採用されています。デバイスを自由に着脱し、複数のファイル
    システムを共存させることが可能です。これにより、開発効率をより一層高める
    ことができます。

 3 OSの起動／操作
------------------

    <PlayStation OS>は「ゲームプログラム開発者のための環境」を提供するOSです。
    従ってユーザがこれを直接操作するためのインターフェースは基本的に装備され
    ていません（デバッグ環境下でのデバッグモニタを除く）。ユーザインターフェ
    ースは、アプリケーションの責任において提供する必要があります。

  3.1 OSの起動

    まず、ROMの特定番地にジャンプし、接続されているハードウェア（CD-ROMドライ
    ブなど）のチェックを行ないます。
    次にCD-ROMドライブ中のディスク種別判定を行ないます。ディスクが適したもの
    であれば、システム設定ファイル（system.cnf）を検索し、これに従って起動し
    ます。
    また、ディスクが入っていない場合は、CDプレーヤーとメモリカード管理のふた
    つの機能を備えたROM常駐プログラム「OSD」（On Screen Display）が起動されま
    す。

  3.3 システム設定ファイル(system.cnf)

    ここに<PlayStation>システムの設定、起動するアプリケーション等を記述します。
    パラメータは、行頭から「＜キーワード＞ = ＜内容＞」の形式で記述します。記
    述はすべて1バイト英数字、大文字で行ない、等号の両端には半角空白が必要です。
    小文字は使用できません。また、数値は16進表記です。ファイル内に同一パラメ
    ータが複数存在する場合は、最初に見つかった内容が優先されます。
    記述可能なパラメータは次のとおりです。

        表 1 システム設定ファイルのキーワード一覧
    +----------+----------------------------------------------------------+
    |キーワード 内容                                                      |
    |BOOT       起動するファイル名を指定。デフォルトはcdrom:PSX.EXE;1     |
    |           例：BOOT = cdrom:PSXAPP.EXE;1                             |
    |TCB        タスク管理ブロック要素数を指定。デフォルトは4。           |
    |           例：TCB = 5                                               |
    |EVENT      イベント管理ブロック要素数を指定。デフォルトは16。        |
    |           例：EVENT = 5                                             |
    |STACK      BOOTで指定したファイルが起動される時のスタックポインタ値。|
    |           デフォルトは0x801ff00。例：STACK = 800ffff0               |
    +----------+----------------------------------------------------------+
