シリアル入出力ライブラリ（libsio）
===================================

  PlayStationとＰＣを接続し、その間での標準入出力のサービスを提供します。デバ
  ッグ情報をＰＣに出力することでデバッグの支援を行えます。細かい通信処理も可
  能です。

 1 概要
--------

    「シリアル入出力ライブラリ」は、 PlayStationの通信コネクタとＰＣのRS232C
    ポートを通信ケーブルDTL-H3050で接続して標準入出力の機能を提供します。
    
    通常デバッキングステーションの標準出力は、NULLとなっているため、デバッグ
    のための情報を得ることができません。本ライブラリを用いることで、標準出力
    をＰＳの通信ポートに割り当てることができるようになり、そこに通信ケーブル
    DTL-H3050を接続することで、RS232cの入出力が可能となります。
    また、BIOSを利用することにより、さらに細かい通信処理も可能となります。
    

  1.1 ライブラリファイル

    標準入出力ライブラリのファイル名は「libsio.lib」です。
    各サービスを呼び出すプログラムは、必ずこれをリンクする必要があります。

  1.2 インクルードヘッダ

    シリアル入出力ライブラリを使うためにはヘッダファイル「libsio.h」が必要で
    す。

        表 1
    +------------------+----------+
    |内容               ファイル名|
    |インクルードヘッダ libsio.h  |
    |ライブラリ         libsio.lib|
    +------------------+----------+
    

 2 ドライバとBIOS
------------------

    シリアル入出力ライブラリは「シリアル入出力ドライバ」と「シリアル入出力
    BIOS」から構成されています。

  2.1 シリアル入出力ドライバ

    シリアル入出力ドライバはC言語標準の手順による標準入出力を提供します。
    ドライバを組み込むだけで容易に通信ポートに標準入出力を割り当てることがで
    きます。
    ＰＣおよびモデム等との複雑な通信を行う場合には、BIOSを利用します。

  2.2 組み込みと削除

    シリアル入出力ドライバの組み込みはAddSIO()にて行ないます。同じく削除は
    DelSIO()で行ないます。

  2.3 BIOS

    シリアル入出力BIOSはC言語標準の関数仕様ではカバーできない詳細なドライバの
    制御と情報取得機能を提供します。インタフェース関数	は_sio_control()です。
    通常、標準入出力にはライブラリ等からデバッグデータが出力されていますので、
    ＰＣとのデータ通信等を行おうとした場合に予期せぬデータが出力されます。
    それを回避するためには、ドライバを組み込まずに標準入出力をNULLにしたたま
    まBIOSを用いて通信を
    行うことが必要となります。
    なお、BIOSはシリアル入出力ドライバを組み込まない状態で稼働します。
    _sio_control()が提供する機能を次に示します。
    
        形式	long _sio_control(cmd, arg, param)
        		unsigned long cmd;
        		unsigned long arg;
        		unsigned long param;
        
        引数	cmd	コマンド
        		arg	サブコマンド
        		param	引数
    

        表 2 コマンド一覧
    +---+---+------------------------------------------------+
    |cmd arg 機能                                            |
    |0   0   ステータスレジスタの値を返す。                  |
    |    1   コントロールレジスタの値を返す。                |
    |    2   モードレジスタの値を返す。                      |
    |    3   通信速度（bps単位）を返す。                     |
    |    4   １バイト読み込む                                |
    |1   0   システム予約                                    |
    |    1   paramの値をコントロールレジスタに設定する。     |
    |    2   paramの値をモードレジスタに設定する。           |
    |    3   paramの値を通信速度（bps単位）として設定する。  |
    |    4   １バイト書き込む                                |
    |2   0   ドライバをリセットする。                        |
    |    1   ドライバステータスエラー関連ビットをクリアする。|
    +---+---+------------------------------------------------+
    

        表 3 ステータスレジスタ
    +-----+---------+------------------------+
    |bit             内容                    |
    |31-10           不定                    |
    |9     SR_IRQ    1:割り込みon            |
    |8     SR_CTS    1:CTSがon               |
    |7     SR_DSR    1:DSRがon               |
    |6               不定                    |
    |5     SR_FE     1:フレームエラー発生    |
    |4     SR_OE     1:オーバーランエラー発生|
    |3     SR_PERROR 1:パリティエラー発生    |
    |2     SR_TXU    1:送信データなし        |
    |1     SR_RXRDY  1:受信データ読みとり可能|
    |0     SR_TXRDY  1:送信データ書き込み可能|
    +-----+---------+------------------------+
    

        表 4コントロールレジスタ
    +-----+---------+--------------------------------+
    |bit             内容                            |
    |31-13           不定                            |
    |12    CR_DSRIEN 1:DSR割り込み許可               |
    |11    CR_RXIEN  1:受信割り込み許可              |
    |10    CR_TXIEN  1:送信割り込み許可              |
    |9,8             0固定                           |
    |7               不定                            |
    |6     CR_INTRST 1:SIO1リセット                  |
    |5     CR_RTS    1:RTSがon                       |
    |4     CR_ERRRST 1:割り込みとエラーフラグのクリア|
    |3               不定                            |
    |2     CR_RXEN   1:受信を許可                    |
    |1     CR_DTR    1:DTRがon                       |
    |0     CR_TXEN   1:送信を許可                    |
    +-----+---------+--------------------------------+
    

        表 5 モードレジスタ
    +----+----------+-----------------------+
    |bit             内容                   |
    |31-8            不定                   |
    |7,6             ストップビット長       |
    |     MR_SB_01   01：1                  |
    |     MR_SB_10   10：1.5                |
    |     MR_SB_11   11：2                  |
    |5    MR_P_EVEN  パリテェ２  1：奇 0：偶|
    |4    MR_PEN     パリティ１  1：あり    |
    |3,2             キャラクタ長           |
    |     MR_CHLEN_5 00：5ビット            |
    |     MR_CHLEN_& 01：6                  |
    |     MR_CHLEN_7 10：7                  |
    |     MR_CHLEN_8 11：8                  |
    |1               常に1                  |
    |0               常に0                  |
    +----+----------+-----------------------+
    

  2.4 通信仕様

    通信仕様は次に示す設定から任意に選択することができます。

        表 6 通信仕様
    +----------------+----------------------------------+
    |項目             設定値                            |
    |キャラクタ長     5,6,7,8ビット                     |
    |ストップビット   0,1,1.5,2ビット                   |
    |パリティチェック なし、偶、奇                      |
    |通信速度         1～2073600bps（2073600の約数のみ）|
    +----------------+----------------------------------+

    |キャラクタ長     8ビット|
