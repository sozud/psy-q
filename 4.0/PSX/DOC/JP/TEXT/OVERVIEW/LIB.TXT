                                                 Library Overview Release 4.0

 PlayStationライブラリの構成
=============================

  PlayStationライブラリには、<PlayStation OS>とのアプリケーションインターフェ
  イス(API)を提供するカーネルライブラリを始めとし、さまざまなライブラリが用意
  されています。ここでは、これらのライブラリの構成形態について簡単にご紹介し
  ます。
    

 1 PlayStationライブラリの構成
-------------------------------

    PlayStationのライブラリには、<PlayStation OS>との関係を基準にして、低レベ
    ルライブラリ、高レベルライブラリの２種類があり、これが２層構造を形成して
    います。プログラマはどちらのレベルのライブラリでも目的に応じて使いわける
    ことができ、また同時に２つのレベルのライブラリを使うこともできます。
        
        図 1 PlayStationライブラリの構造

    以下、各ライブラリについて、その概要をご紹介いたします。

  1.1 カーネルライブラリ（libapi）

    アプリケーションと<PlayStation OS>とのインタフェース(API)を提供するライブ
    ラリです。

  1.2 周辺機器ライブラリ（libetc）

    コントローラなどの周辺機器や低レベルの割り込み処理のためのコールバックの
    制御を行なうためのライブラリです。

  1.3 CD-ROMライブラリ（libcd）

    CD-ROMドライブから画像や音声データ、およびプログラムを読み出したり、DA（
    デジタルオーディオ）やXAサウンド再生などを行なうためのライブラリです。
    ファイル名をキーとした高速なディスクアクセスや、データの読みだしと処理を
    同時に行なう「ストリーミング」技法を支援する関数も含まれています。

  1.4 拡張CD-ROMライブラリ（libds）

    CD-ROMライブラリのカーネルに新しいインターフェイスを構築するライブラリで
    す。従来のライブラリに置き換わる形で用意されています。
    これまでと同等の機能を実現し、さらにエラー時のリカバリーをシステムで行う
    などCD-ROMの確実なコントロールに重点が置かれています。

  1.5 基本グラフィックスライブラリ（libgpu）

    描画エンジンへのコマンドを作成し、コマンドリストに登録するためのライブラ
    リです。ここで扱われるデータはスプライト、ポリゴン、ラインなどの基本的な
    ものです。

  1.6 基本ジオメトリライブラリ（libgte）

    GTE（ジオメトリ計算エンジン）の制御を行なうためのライブラリです。ここで扱
    われるデータは行列、頂点などの基本的なものです。

  1.7 拡張グラフィックスライブラリ（libgs）

    libgpu、libgteを使って３次元グラフィックスシステムを構築したものがlibgsで
    す。ここで扱われるデータはオブジェクト、バックグラウンド面などのより大き
    な単位となります。

  1.8 基本サウンドライブラリ（libspu）

    SPU（サウンド再生処理プロセッサ）を制御するためのライブラリです。

  1.9 拡張サウンドライブラリ（libsnd）

    あらかじめ譜面データとして記録しておいた発音シーケンスをバックグラウンド
    演奏するライブラリです。

  1.10 データ処理ライブラリ（libpress）

    画像及び音声データを圧縮（エンコード）、伸長（デコード）するためのライブ
    ラリです。

  1.11 メモリカードライブラリ（libcard）

    リセットやパワーオフ後もデータを保存するためのメモリカードを制御するライ
    ブラリです。メモリカードファイルシステムドライバも含んでいます。

  1.12 メモリカード簡易レベルライブラリ（libmcrd）

    PlayStationに実装されたメモリカードを簡易なインターフェイスにより使用する
    ためのものです。

  1.13 対戦ケーブルライブラリ（libcomb）

    対戦ケーブルによる<PlayStation>間の通信を行なうためのライブラリです。ブロ
    ックサイズ8バイトの通信ドライバを含んでいます。

  1.14 シリアル入出力ライブラリ（libsio）

    デバッギングステーション上で、標準入出力をSIO1に設定するためのライブラリ
    です。

  1.15 マルチタップライブラリ（libtap）

    オプション周辺機器であるマルチタップを介して3～8組のコントローラ・メモリ
    カードにアクセスするためのライブラリです。

  1.16 ガンライブラリ（libgun）

    コントローラコネクタに接続することが可能なライトペン型入力機器にアクセス
    するためのライブラリです。

  1.17 C標準ライブラリ（libc/libc2）

    C標準ライブラリのサブセットです。文字関数、メモリ操作関数、文字クラステス
    ト、非局所ジャンプ、そしてユーティリティ関数の一部を含んでいます。
    libcはROM中に本体プログラムを持つコンパクトなライブラリ、libc2はライブラ
    リ内に本体プログラムを持つ高速ライブラリです。

  1.18 数学ライブラリ（libmath）

    ソフトウェアによる浮動小数点数演算パッケージを含むANSI/IEEE754準拠の数学
    関数ライブラリです。

  1.19 GTEインラインマクロライブラリ（dmpsx）

    GTEを高速に制御するためのマクロライブラリです。関数呼出しを使用しないため
    命令キャッシュのミスが少なくなり高速に動作します。使用にはdmpsxが必要です。

 2 データフォーマット
----------------------

    ライブラリは、PlayStation専用グラフィックスアーティストツールならびにサウ
    ンドアーティストツールが供給する各種データフォーマットを解釈することがで
    きます。詳細については別章をご参照ください。
