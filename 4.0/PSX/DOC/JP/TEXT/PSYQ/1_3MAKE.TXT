                                                     Psy-Q Programmer's Guide

 1 MAKE ユーティリティ PSYMAKE
===============================

  PSYMAKE は、コンピュータプログラムの構築及び再構築を自動化する MS-DOS 用汎
  用MAKE ユーティリティです。PSYMAKE は PSYMAKE は、プログラムの構築手順、依
  存関係を記述した「MAKE ファイル」に基づき、再構築が必要なシステムの要素のみ
  を再構築します。プログラムが再構築を必要とするかどうかは、ターゲットファイ
  ルのタイムスタンプ、及びプログラムが依存するソースファイルによって定義され
  ます。一般に、ソースファイルが１つでもターゲットファイルよりも新しい場合、
  ターゲットファイルは再構築されます。PSYMAKE を利用することにより、複雑な 
  DOS コマンドをいちいち入力する必要がなく、プログラム開発をスムースに進行さ
  せることが可能となります。

 1 書式
--------

    PSYMAKE を実行するには、MS-DOS のプロンプトから次のように入力します。
    
        psymake [/option] [target]
    
    オプションは"/"（スラッシュ）に続けて指定します。複数指定する場合はスペー
    スで区切ります。
    オプションに続き、ターゲットを指定します。ターゲットが指定されていない場
    合、MAKE ファイル中の最初のターゲットが構築されます。
    MAKE ファイル名はデフォルトでは"MAKEFILE.MAK"となっています。MAKE ファイ
    ルは、"/f"オプションで指定することができます。
    以下、オプション及び各種ファイルについて解説していきます。

 2 オプション
--------------

    オプションは"/"（スラッシュ）に続けて指定します。複数指定する場合はスペー
    スで区切ります。
    オプションには次のものがあります。

    ・すべてをビルド(/b)

      "/b"を指定すると、ファイルのタイムスタンプを無視して、すべてを構築しま
      す。

    例

        psymake /b all

    ・マクロ定義(/d <name=string>)

      "/d"に続きシンボル name とその文字列 string を"="（イコール）で結んで指
      定します。"/d"と name の間はスペースで区切ります。

    例

        psymake /d Creator=Me all

    ・MAKE ファイル名指定(/f <filename>)

      "/f"に続き、MAKE ファイル名 filename をスペースで区切って指定します。
      デフォルトの MAKE ファイルは"MAKEFILE.MAK"です。また、filename に拡張子
      が指定されていない場合、拡張子は".MAK"であるとみなします。

    例

        psymake /f test.mak all

    ・エラー無視(/i)

      "/i"を指定すると、常にエラー状態を無視します。

    例

        psymake /i all

    ・クワイエットモード(/q)

      "/q"を指定すると、クワイエットモードとなり、コマンド実行前にコマンドを
      表示しません。

    例

        psymake /q all

    ・コマンドを実行しない(/x)

      "/x"を指定すると、コマンドを実行せず、表示のみを行ないます。

    例

        psymake /x all

 3 MAKE ファイル
-----------------

    MAKE ファイルは一連のコマンドから成り、「依存」として知られている明白な規
    則、及び「暗黙の規則」により制御されます。
    ターゲットファイルを構築する必要がある場合、PSYMAKE は、まずそのファイル
    の依存規則を検索します。依存規則が見つからない場合は、PSYMAKE は、暗黙の
    規則を使ってターゲットファイルを構築します。

  3.1 依存

    依存関係は次のように記述します。
        targetfile: [sourcefiles]
        	[command
        	...
        	command]
    ターゲットファイル targetfile は行頭から記述し、最後に":"（コロン）を付加
    し、その後ろにソースファイル sourcefiles を記述します。ソースファイルはス
    ペースで区切って複数指定することができます。
    続いてターゲットを構築するために実行するコマンド command を記述します。コ
    マンドはすべて、行頭にスペースまたはタブを入れ、実行順に１行ずつ記述しま
    す。
    各フィールドの関係と、動作は次のようになっています。
         ・１行目で、targetfile のファイルが、sourcefile として指定されたファ
           イルに依存することを表わしています。
         ・ソースファイルが１つでもターゲットファイルより新しかったり、ターゲ
           ットファイルが存在しない場合は、PSYMAKE は、ターゲットファイルを再
           構築するために続くコマンド command を実行します。
         ・ソースファイルが指定されていない場合は、ターゲットファイルが常に再
           構築されます。
         ・ソースファイルが１つも存在しない場合は、PSYMAKE は、現在のターゲッ
           トファイルを構築するコマンドを実行する前に、まずソースファイルを構
           築しようとします。
         ・ただし、PSYMAKE が必要なファイルを構築する方法を定義する規則を見つ
           けられない場合、動作は中止され、エラーが報告されます。

  3.2 依存の例

    例えば、次のように記述します。

    例

        main.cpe:main.s inc1.h inc2.h
        	asmpsx main,main
    この例では、main.cpe が、ファイル main.s、inc1.h 及び inc2.h に依存するこ
    とを表わしています。これらのファイルのいずれかが、main.cpe より新しかった
    り、あるいは main.cpe が存在しない場合は、main.cpe を作成または更新するた
    めに、コマンド"asmpsx main,main"が実行されます。
    また、次の例では main.cpe を構築するために、２つのコマンドが実行されます。

    例

        main.cpe:main.s inc1.h inc2.h
        	asmpsx /l main,main,main
        	psylink main,main

  3.3 暗黙の規則

    ターゲットファイルを構築するコマンドが指定されていない場合、PSYMAKE は、
    ターゲットファイルの構築方法を定義する、暗黙の規則を検索します。
    暗黙の規則は、ある種類のファイルを別の種類から作成する方法、たとえば、
    .ASM ファイルを.EXE ファイルに変換する方法を定義した一般規則です。
    暗黙の規則は以下のような形式をとります。
        .<target extension>.<source extension>:
        	command
        	[...
        	command]
    target extension に、ターゲットファイルの拡張子を、source extension にそ
    のファイルの元となるファイルの拡張子を指定します。
    続いて、その下の行に、ターゲットとなる拡張子を持つファイルを構築するため
    に実行されるコマンドを、少なくとも１つ指定します。

    例

        .bin.s:
        	asmpsx /p $*,$*
    この例では、拡張子.Ｓのファイルから、拡張子.BIN のファイルを、asmpsx コマ
    ンドで作成します。なお、コマンド行にある代用文字"$*"については、後述の「
    定義済みマクロ」の項を参照してください。

  3.4 コマンドの実行

    PSYMAKE は以下の順でコマンドを検索し、実行します。

    (1)カレントディレクトリ


    (2)PATH で指定されたディレクトリ

    指定されたコマンドが EXE または COM ファイルでない場合や、BAT ファイルの
    場合、PSYMAKE は、そのコマンド／バッチファイルを実行するために 
    COMMAND.COM を呼び出します。これにより、CD 及び DEL といったコマンドを使
    用することができます。

  3.5 コマンドプリフィックス

    依存、または暗黙の規則で指定するコマンドには、以下のプリフィックスを使用
    することもできます。
    
    +--------------+----------------------------------------------+
    |プリフィックス 機能                                          |
    |@              コマンドを表示しません。                      |
    |               例: @psylink test.obj,test.cpe                |
    |-number        終了ステータスが number で指定した数を超えると|
    |               PSYMAKE はアボートします。                    |
    |               例: -10psylink test.obj,test.cpe              |
    +--------------+----------------------------------------------+
    通常、"/q"オプションが指定されていなければ、PSYMAKE は、実行するコマンド
    を表示します。これを抑制したい場合は、実行するコマンドの先頭に"@"を付加し
    てください。
    また、実行するコマンドに"-"または"-number"のれも指定されておらず、"/i"オ
    プションが指定されていない場合、コマンドが０以外のエラーコードを返すと 
    PSYMAKE はアボートします。

  3.6 マクロ

    マクロは、１つのテキストと等価なシンボルです。マクロは使用時に割り当てら
    れたテキストの内容に展開されます。
    マクロは以下の形式をとります。
        name=text
    マクロ名 name と、その内容を示す text を"="（イコール）で結びます。"="の
    前後にスペースを入れることはできません。大文字・小文字は区別されます。
    マクロは、任意の時点で再定義することができます。マクロ定義が他のマクロを
    参照している場合は、使用時に展開されます。
    また、規則で使われているマクロは、すぐに展開されます。

    例

        FLAGS=/p/s
        ...
        .bin.s:
        	asmpsx $(FLAGS) /p $*,$*
    この例では、asmpsx コマンド行にある"$(FLAGS)"は、"/p/s"に置き換えられます。

  3.7 定義済みマクロ

    定義済みマクロはすべて"$"（ドルマーク）で始まり、依存及び暗黙の規則のコマ
    ンド行で、ファイル名に代えて使用することができます。
    +------+--------------------------------------------------------+
    |マクロ 内容                                                    |
    |$d     定義済みテストマクロ。                                  |
    |       例: !if $d(MODEL)                                       |
    |       # MODEL が定義されている場合                            |
    |$*     パスの付いたベースファイル名（例: C:\PSYQ\TEST）を示す。|
    |$<     パスの付いたファイル名（例: \PSYQ\TEST.s）を示す。      |
    |$:     パスのみ（例: \PSYQ）を示す。                           |
    |$.     パスのないファイル名（例: TEST.s）を示す。              |
    |$&     パスのないベースファイル名（例: TEST）を示す。          |
    +------+--------------------------------------------------------+

  3.8 ディレクティブ

    以下のディレクティブが使用できます。
    +---------------------+-------------------------------------------------+
    |ディレクティブ        内容                                             |
    |!if <expression>      if、elseif、else、及びendif の間で、条件付き     |
    |!elseif <expression>  処理を行なうことができます。                     |
    |!else                 式 expression がゼロでない場合は真、ゼロの場合に |
    |!endif                偽となります。                                   |
    |                      例: !if DEBUG                                    |
    |                          ....                                         |
    |                          !else                                        |
    |                          .....                                        |
    |                          !endif                                       |
    |!error <message>      メッセージ message を表示し、中断します。        |
    |!undef <macro>        マクロ名 macro の定義を取り消します。            |
    +---------------------+-------------------------------------------------+

  3.9 式

    式は 32 ビットまで評価され、以下の要素から成っています。
    +-----------+------------------------------------------------------+
    |要素        内容                                                  |
    |10 進の定数 10 進数の定数、例えば１、10、1234 など                |
    |16 進数     16 進数、例えば $FF00、$123abc など                   |
    |単項        -、~、!                                               |
    |２項(※)    +、-、*、／、%、>、<、&、｜、^、&&、∥、>、<、>=、<=、|
    |            ==（または=）、!=（または <>）                        |
    +-----------+------------------------------------------------------+
    ※これらの演算子は、Ｃ言語の場合と同じ意味をもっていますが、"="及び"<>"は、
    より便利にするために追加されました。

  3.10 値の割り当て

    マクロ名には、計算された値を割り当てることができます。これを行なうには、
    マクロ名と内容を"=="（イコール２つ）で結びます。

    例

        NUMFILES==$(NUMFILES)+1
    これにより、まず右辺を評価して 10 進のアスキー文字列に変換し、その結果が
    左辺（マクロ名）に割り当てられます。
    上の例で、NUMFILES が"42"であるとすると、割り当てられる値は"43"になります。
    また、定義されていないマクロ名は、式中では"0"に、他の場所では null 文字列
    に変換されます。
    なお、マクロと内容を"="（イコール１つ）で結んだ場合は、計算は行なわれませ
    んので注意してください。次の例では、NUMFILE の値は"42+1"という文字列にな
    ります。

    例

        NUMFILE=$(NUMFILES)+1

  3.11 コメント

    コメントは、"#"（ハッシュマーク）に続いて記述します。

    例

        main.exe: main.asm	# main.exe only depends
        # on main.asm
        # whole line comment

  3.12 行の分割

    コマンドが長すぎて１行に収まらない場合、行末に"\"を付加することにより、複
    数行に分けて記述することができます。

    例

        main.exe: main.asm i1.h i2.h \
        	  i3.h i4.h
