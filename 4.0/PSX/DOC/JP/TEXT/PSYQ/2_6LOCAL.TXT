                                                     Psy-Q Programmer's Guide

 1 ローカルラベル
==================

  プログラムが進歩するにつれ、ユニークで、かつ明示的なラベル名を探すことがま
  すます困難になってきています。ローカルラベルを用いれば、意味のあるラベル名
  を再使用することができますので、このような状態を緩和することが可能です。

 1 文法及び適応範囲（スコープ）
--------------------------------


  1.1 言語オプション文法

    ローカルラベルには、ローカルラベル開始記号が付いています。デフォルトの開
    始記号は"@"です。が、OPT ディレクティブで l オプションを使うか、ASMPSX で
    "/l<c>"オプションを指定することにより、他の文字を開始記号とすることも可能
    です。
    ローカルラベル名は、一般のラベル規則に従って設定する必要があります。また、
    ローカルラベルは、マクロの展開によりスコープが解除されることはありません。

  1.2 適応範囲（スコープ）

    ローカルラベルが有効となるコード領域を「スコープ」と呼びます。この領域の
    外であれば、同じラベル名を再度使用することができます。ローカルラベルのス
    コープを定義するには、次の３つの方法があります
    
          (a) ２つの非ローカルラベルの間が、暗黙のスコープとなります。OPT ディ
              レクティブあるいは ASMPSX のオプションでｄオプションが指定され
              ている場合を除き、変数を設定したり、代入を行なったり、RS 値を定
              義したりすることにより、現在のローカルラベルのスコープが解除さ
              れることはありません。
          (b) スコープは、一般に、MODULE 及び MODEND により定義することができ
              ます。
          (c) マクロ内にローカルなラベル（あるいは他のシンボルタイプ）を定義す
              るには、LOCAL ディレクティブが使用できます。
      
    次の例は、ローカルラベルの、自己完結型のサブルーチン内での「プレースマー
    カ」としての典型的な使用法を示したものです。スコープは、非ローカルラベル 
    Plot2 及び Plot3 で定義されています。SET ステートメントがルーチンのスコー
    プを解除することはありません。ラベル@chk1 及び@ret は再使用可能です。

    例

        plot2	lb	r3,loc(a0)
        	...
        	subiu	r3,r0,-83
        	bge	r3,@chk1
        	addiu	r3,r0,168
        	j	@ret
        	subiu	r3,r0,83
        	...
        	jal	lcolour
        	addu	r2,r0,r3
        SetX	set	x+1
        @ret	jr	ra
        	...
        	jr	ra
    また、次の例では、最後の分岐が@chk1 のスコープ外にあるため、エラーを引き
    起こします。

    例

        plot2	...
        	bge	r3,@chk1
        	...
        	bra	setplot
        @chk1	...
        	...
        setplot	set	x+1
        	j	@chk1

 2 ディレクティブ
------------------

    
=============================================================================
MODULE、MODEND                                               [ディレクティブ]
=============================================================================
        
[書式]
        MODULE
        ...
        ...
        MODEND
        
[解説]
        MODULE ステートメントの次から、MODEND ステートメントまで（MODEND を含
        む）のコードを、ひとつのモジュールとみなします。モジュール内で定義さ
        れたローカルラベルは再使用することができますが、モジュールのスコープ
        外から参照することはできません。また、他の場所で定義されたローカルラ
        ベルを、現在のモジュール内から参照することもできません。
        
[参照]
        LOCAL
        
[備考]
        モジュールは入れ子にすることができます。
        MODULE ステートメント自身は非ローカルラベルであり、現在アクティブなデ
        フォルトスコープを解除します。
        マクロにモジュールを入れることができます。また、マクロをモジュールに
        入れることもできます。モジュールにあるローカルラベルは、そのモジュー
        ル内の任意の場所に存在するマクロから参照することができます。マクロ内
        にあるモジュールは、そのマクロにおいてローカルなラベルを提供します。
        
[例]
        Strat	module
        	add	r1,r0,r0
        	j	@lab1
        	...
        @Lab1	addi	r4,r0,-1
        	beq	r4,r0,@SetTact
        	...
        	jr	ra
        @SetTact	Module
        	lw	r5,Tatic2(a0)
        	...
        @lab1	lw	r6,8(a0)
        	...
        	beq	r5,r0,@lab1
        	jr	ra	
        	modend
        	modend

=============================================================================
 LOCAL                                                       [ディレクティブ]
=============================================================================
        
[書式]
        LOCAL 	<symbol>[,symbol]...
        
[解説]
        symbol で指定されたシンボルをそのマクロ内でのみ有効なローカルラベルと
        します。symbol は複数指定することができ、この場合、コンマで区切ります。
        
[参照]
        MODULE
        
[備考]
        LOCAL 命令は、そのオペランドを構成するシンボルの型を特定しません。従
        ってシンボルは、代入、文字列代入、または他のタイプとして、またはラベ
        ルとして使用することができます。
        
[例]
        doorpos	macro
        	local	m_door1,m_door2,doorw
        	jal	doorw
        	jal	doorw
        m_door1		equ	door_start*\1
        m_door2		equ	door_fin*\2
        doorw	...
        	endm
