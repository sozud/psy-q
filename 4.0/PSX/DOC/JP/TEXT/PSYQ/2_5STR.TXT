                                                     Psy-Q Programmer's Guide

 1 文字列操作関数
==================

  マクロ構造を拡張するため、ASMPSX アセンブラは、文字列の操作のための強力な関
  数を提供しています。これらの関数により、文字列を比較したり、テキストを調べ
  たり、サブセットを作成したりすることができます。

 1 文字列操作関数
------------------

    
=============================================================================
STRLEN                                                       [文字列操作関数]
=============================================================================
        
[書式]
        STRLEN(string)
        
[解説]
        テキスト string の長さを返します。
        
[参照]
        STRCMP
        
[備考]
        STRLEN は、オペランドの任意の位置で使用可能です。
        
[例]
        次の例では文字列数がループの回数として使用されています。
        Nummov	macro
        	rept	strlen(\1)
        	lw	r3,(a0)
        	endr
        	endm
        	...
        	Nummov	"12345"

=============================================================================
 STRCMP                                                      [文字列操作関数]
=============================================================================
        
[書式]
        STRCMP(stringl,string2)
        
[解説]
        文字列 strings1 と string2 を比較し、これが同じ場合は真を、異なる場合
        は偽を返す。
        
[参照]
        STRLEN
        
[備考]
        比較は、文字列の先頭の位置を１として行なわれます。
        
[例]
        Vers	equ	"Acs"
        	...
        	if	strcmp("\Vers","Sales")
        	lw	r3,Sallnd(a0)
        	else
        	if
        	lw	r3,Aclnd(a0)
        	else
        	if	strcmp("\Vers","Test")
        	lw	r3,Tstlnd(a0)
        	endif
        	endif
        	endif

=============================================================================
 INSTR                                                       [文字列操作関数]
=============================================================================
        
[書式]
        INSTR([start,]string,sub-string)
        
[解説]
        文字列 string 中に文字列 sub-string が現われる位置を返します。string 
        が sub-string を含んでいない場合は０が返されます。
        start で検索開始位置を指定することもできます。
        
[参照]
        SUBSTR
        
[備考]
        返される値は比較対象となる文字列の先頭を１とした位置です。
        
[例]
        Mess	equs	"Demo for Sales Dept"
        	...
        	if	instr("\Mess","Sales")
        	lw	r3,Sallnd(a0)
        	else
        	lw	r3,Aclnd(a0)
        	endif

=============================================================================
 SUBSTR                                                      [文字列操作関数]
=============================================================================
        
[書式]
        <symbol name>	SUBSTR	[start],[end],<string>
        
[解説]
        文字列 string を symbol name に代入します。
        start で開始位置を、end で終了位置を指定し、その間の部分文字列を代入
        することもできます。start が省略された場合、開始位置は文字列の先頭、
        end が省略された場合、終了位置は文字列の末尾となります。
        
[参照]
        INSTR, EQUS
        
[備考]
        位置は対象となる文字列の先頭を１とした値を指定します。
        
[例]

    例１

        Message		equs	"A short Sample String"
        Part1	substr	9,14,"\Message"
        Part2	substr	16,,"\Message"
        Part3	substr	,7,"\Message"
        Part4	substr	,,"\Message"
        
        例１では、Part1 は"Sample"、Part2 は"String"、Part3 は"A Short"となり
        ます。また、Part4 への代入は、オリジナル文字列の全部を指定する EQUS 
        に相当します。

    例２

        cbb	macro	string
        lc	=	0
        	rept	strlen(\string)
        cc	substr	lc+1,lc+1,\string
        	db	'\cc'^($A5+lc)
        lc	=   	lc+1
        	endr
        	endm
