                                                     Psy-Q Programmer's Guide

 1 統合コンパイラ CCPSX.EXE
============================

  Psy-Qでは、GNU C、GNU C++をベースとする、統合コンパイラCCPSXを提供していま
  す。CCPSX は、ファイルの拡張子に基づき、これに合ったツールを自動的に呼び出
  しオブジェクト、実行ファイルを作成しますので、これを利用することにより、プ
  ログラム開発をより効率的に進めることができます。

 1 環境変数
------------

    CCPSX を利用するには、各ツールがどのディレクトリに格納されているかを、以
    下の環境変数で指定する必要があります。
    
    +--------------+----------------------------------------------------+
    |環境変数       設定する内容                                        |
    |COMPILER_PATH  GNU Ｃコンパイラ (CPPPSX.EXE、CC1PSX.EXE、          |
    |               CPLUSPSX.EXE)などが格納されているディレクトリ。     |
    |PSYQ_PATH      PSYLINK.EXE など、Psy-Q の各種ツールが格納されている|
    |               ディレクトリ。                                      |
    |C_INCLUDE_PATH ヘッダファイルが格納されているディレクトリ。        |
    |LIBRARY_PATH   PlayStation ライブラリが格納されているディレクトリ。|
    |TMPDIR         テンポラリファイルを作成するディレクトリ。          |
    |GO32TMP        GO32 用テンポラリディレクトリ                       |
    +--------------+----------------------------------------------------+
    
    これらの環境変数は、AUTOEXEC.BAT で指定し、PC の起動時に自動的に設定され
    るようにしてください。なお、ディレクトリの区切り記号には、"\"ではなく"/"
    （スラッシュ）を用いるようにしてください。

    例 標準的な設定

        set COMPILER_PATH=c:/compiler
        set PSYQ_PATH=c:/psyq
        set C_INCLUDE_PATH=c:/psx/include
        set LIBRARY_PATH=c:/psx/lib
        set TMPDIR=c:/tmp
        set GO32TMP=c:/tmp

 2 ファイルの拡張子と動作
--------------------------

    CCPSX は、その対象とされたファイルの拡張子に基づき、次のような形でツール
    を呼び出し、コンパイル、リンク等を行ない、実行ファイルを作成します。また、
    オプションを指定することにより、プリプロセス、リンク、アセンブル、コンパ
    イルの各段階任意の位置で処理を停止させることも可能です。
    なお、認識不可能な拡張子を持つファイルはすべてオブジェクトとして扱われ、
    リンカが呼び出されますのでご注意ください。
    
    +------+---------------------------------------------------------+
    |拡張子 呼び出すツールとその順                                   |
    |.C     Ｃプリプロセッサ → Ｃコンパイラ → アセンブラ → リンカ |
    |.I     Ｃコンパイラ → アセンブラ → リンカ                     |
    |.CC    Ｃプリプロセッサ → C++コンパイラ → アセンブラ → リンカ|
    |.CPP   Ｃプリプロセッサ → C++コンパイラ → アセンブラ → リンカ|
    |.II    C++コンパイラ → アセンブラ → リンカ                    |
    |.IPP   C++コンパイラ → アセンブラ → リンカ                    |
    |.ASM   Ｃプリプロセッサ → アセンブラ → リンカ                 |
    |.S     アセンブラ → リンカ                                     |
    |その他 リンカ                                                   |
    +------+---------------------------------------------------------+

 3 書式
--------

    CCPSX を実行するには、MS-DOS のプロンプトから次のように入力します。
        ccpsx  [-option]  <source file> [source file]...
    オプションは"-"（マイナス記号）に続けて指定します。複数指定する場合はスペ
    ースで区切ります。また、オプションに続き、ソースファイル名をスペースで区
    切って指定します。
    例えば、test.c をコンパイルし、オブジェクトファイル (test.obj) を作成する
    には次のように指定します。

    例

        ccpsx -c test.c
    さらに、test.c をコンパイルし、実行ファイル test.cpe を作成するには次のよ
    うに指定します。なお、"-o"の次の"test.cpe"は、"-o"オプションの引数（出力
    ファイル名）で、ソースファイル名ではありません。

    例

        ccpsx -o test.cpe test.c
    また、ソースファイルを複数指定し、これをすべてコンパイルすることも可能で
    す。ファイルはスペースで区切って指定します。この例では、test1.c、test2.c、
    test3.c をコンパイルし、それぞれのファイルに対応した OBJ ファイルを作成す
    るように指示しています。

    例

        ccpsx -c test1.c test2.c test3.c
    オプションにはこの他にもさまざまなものがあります。これについては以下で解
    説していきます。

 4 オプション
--------------

    オプションは"-"（マイナス記号）に続けて指定します。複数指定する場合はスペ
    ースで区切ります。また、オプションでは大文字、小文字は区別されます。例え
    ば "-O" と "-o" は全く別の意味となりますのでご注意ください。

  4.1 動作制御オプション

    CCPSX の動作を制御するオプションとして、次のものがあります。

    ・プリプロセスのみを実行 (-E)

      "-E"を指定すると、プリプロセスのみを行ない、コンパイル、リンクは行なわ
      れません。出力ファイル名が指定されていない場合、結果は画面 (stdout) に
      表示されます。

    例

        ccpsx -E test.c

    ・コンパイルまでを実行、アセンブラコード出力 (-S)

      "-S"を指定すると、コンパイルが終わったところで処理を停止します。リンク
      は行なわれません。ソースファイルとしてＣファイルが指定された場合、アセ
      ンブラファイルを作成します。出力ファイル名が指定されていない場合、入力
      ファイル名の拡張子を".S"に置き換えたファイルに出力します。

    例

        ccpsx -S test.c

    ・コンバイルまでを実行、オブジェクトファイル出力 (-c)

      "-c"を指定すると、コンパイル、アセンブルを実行し、オブジェクトファイル
      を作成します。リンクは行なわれません。出力ファイル名が指定されていない
      場合、入力ファイル名の拡張子を".OBJ"に置き換えて出力します。

    例

        ccpsx -c test.c
    また、上記オプションの何れもが指定されていない場合、CCPSX はリンカを呼び、
    実行ファイルを作成します。出力ファイル名が指定されていない場合、A.OUT と
    なります。

  4.2 言語オプション

    Ｃの「方言」を制御するオプションとして、次のものがあります。

    ・ANSI 対応 (-ansi)

      "-ansi"を指定すると、すべての ANSI 標準のＣプログラムをサポートするよう
      になります。

    例

        ccpsx -ansi test.c

  4.3 デバッグ情報生成

    デバッグ情報を生成するオプションとして、次のものがあります。

    ・デバッグ情報生成 (-g)

      "-g"を指定すると、デバッグ情報を生成し、実行ファイルに埋め込みます。ソ
      ースレベルデバッグを実行する際には、これを必ず指定してください。

    例

        ccpsx -g test.c -o test.cpe

  4.4 最適化オプション

    コードを最適化するオプションとして、次のものがあります。
    なお、最適化オプション("-O")とデバッグ情報生成オプション("-g")を同時に指
    定すると、デバッグが正常に実行できなくなりますのでご注意ください。

    ・最適化しない (-O0)

      "-O0"を指定すると、最適化を行ないません。これはデフォルトの設定で、通常、
      あらためて指定する必要はありません。

    ・標準レベルの最適化 (-O、-O1)

      "-O"または"-O1"を指定すると、標準レベルの最適化を実行します。

    例

        ccpsx -O test.c

    ・高レベルの最適化 (-O2、-O3)

      "-O2"または"-O3"を指定すると、高レベルの最適化を行ないます。

    例

        ccpsx -O2 test.c

    ・グローバルポインタ参照 (-G[num])

      グローバルポインタ(GP)を用いて参照されるデータ項目の
      最大サイズをバイト単位で指定します。デフォルトは num = 8 です。
      num = 0 と指定すると、GPを用いたデータ参照は行われません。
      主にオーバレイ処理（ダイナミックにCDからプログラムを読み込んで
      実行させる）をしたい場合等に使用します。

    例

        ccpsx -O2 -G0 -c test.c  

  4.5 一般的なオプション

    CCPSX 全体を制御する一般的なオプションとして、次のものがあります。

    ・警告メッセージの抑制 (-W)

      "-W"を指定すると、コンパイラ及びプリブロセッサの警告メッセージを抑制し
      ます。

    例

        ccpsx -W test.c

    ・マクロ定義 (-D<NAME>、-D<NAME=VALUE>)

      "-D"に続き、定義したいマクロ NAME、またはマクロ NAME とその値 VALUE を
      "="（イコール）で結んで指定します。

    例 マクロ DEBUG を指定

        ccpsx -DDEBUG test.c

    例 マクロ DEBUG を１に指定

        ccpsx -DDEBUG=1 test.c

    ・マクロ定義解除 (-U<NAME>)

      "-U"に続き、定義を解除したいマクロ NAME を指定します。

    例 マクロ DEBUG を解除

        ccpsx -UDEBUG test.c

    ・詳細情報表示 (-v)

      "-v"を指定すると、CCPSX が各ツールをどのように起動しているかの情報を表
      示します。

    例

        ccpsx -v test.c

    ・漢字対応 (-kanji)

      "-kanji"を指定すると、Ｃコンパイラが２バイトコード（漢字）を正しく処理
      するようになります。ソースコード中に漢字を含む文字列がある場合は必ず指
      定してください。

    例

        ccpsx -kanji test.c

  4.6 アセンブラ(ASPSX)オプション


    ・グループ名指定 ( -Wa,s[name] )

      このモジュールをnameという名前のグループとして定義します。
      主にオーバレイモジュールのコンパイル時に使用します。

    例

        ccpsx -O3 -G0 -Wa,stest1 -c test.c

    0除算チェックルーチンを生成しない ( -Wa,0 )

      割り算を含むコードをアセンブルする際、ASPSXは、0除算のチェックを行うル
      ーチンをデフォルトで生成しています。"-Wa,0"を指定すると、0除算チェック
      ルーチンを生成しません。これにより若干プログラムサイズを節約できます。

    例

        ccpsx -c -Wa,0 main.c

  4.7 リンカオプション

    PSY-Q リンカを制御するオプションとして、次のものがあります。

    ・標準ライブラリをリンクしない (-nostdlib)

      "-nostdlib"を指定すると、PlayStation の標準ライブラリ (libgs、libgte、
      libgpu、libetc、libapi、libsn) をリンクしません。標準ライブラリは 
      \PSYQ\PSYQ.INIで定義されています。

    例

        ccpsx -nostdlib test.c

    ・ライブラリの指定 (-l <libname>)

      "-l"に続き、リンクしたいライブラリ libname をスペースで区切って指定しま
      す。ライブラリアンを用いてオリジナルのライブラリを作成した場合に利用し
      ます。

    例

        ccpsx -l mylib.lib test.c

    ・ORG アドレスの指定 (-Xo$<address>)

      "-Xo"に続き、ORG アドレス address を先頭に "$" を追加し、 16 進数で指定
      します。デフォルトのアドレスは０です。

    例

        ccpsx -Xo$80040000 test.c

    ・デバッグモードの指定 (-Xd)

      "-Xd"を指定すると、デバッグモードとなり、リンクのみを行ないます。

    例

        ccpsx -Xd test.c
    
    また、PSY-Q リンカ (PSYLINK) がサポートするオプションは、"-X"に続けて指定
    することにより、基本的にすべて利用することができます。

    例 バイナリコードを出力する（PSYLINK の"/p"オプションの"p"を指定）

        ccpsx -Xp test.c
    
    なお、リンカはプログラムのエントリポイントとして常に__SN_ENTRY_POINT を設
    定します。このマクロは libsn.lib で定義されています。

  4.8 出力ファイル名の指定

    出力ファイル名を指定するオプションとして、次のものがあります。

    ・出力ファイル名の指定 (-o <filename>)

      "-o"に続き、出力ファイル名 filename をスペースで区切って指定すると、指
      定したファイルに結果を出力することができます。例えば次のように指定する
      と、test.c から実行ファイル test.cpe が作成されます。

    例

        ccpsx test.c -o test.cpe
    ただし、"-o"で指定できるファイルは１つのみですので、実行ファイルを作成す
    る場合を除き、複数のファイルをコンパイルする際に用いるのは無意味となりま
    す。
    例えば、次のようにソースファイルを複数指定し、かつ、リンクを実行しないオ
    プションを指定した場合、ファイルは上書きされ、常に最後に指定されたファイ
    ルのコンパイル結果が出力されることになります（test.cpe には常に test3.c 
    のコンパイル結果=オブジェクトが出力されてしまいます）。

    例

        ccpsx -c -o test.cpe test1.c test2.c test3.c

  4.9 シンボルファイル名の指定

    シンボルファイルを出力させるには、"-o"オプションの引数として、出力ファイ
    ル名に続き、シンボルファイル名を","（コンマ）で区切って指定します。
    次の例では、実行ファイルとして test.cpe を、シンボルファイルとして 
    test.sym を出力しています。

    例

        ccpsx test.c -o test.cpe,test.sym

  4.10 マップファイル名の指定

    マップファイルを出力させるには、"-o"オプションで出力ファイル、シンボルフ
    ァイルを指定し、これに続き、マップファイル名を","（コンマ）で区切って指定
    します。
    次の例では、実行ファイルとして test.cpe を、シンボルファイルとして 
    test.sym を、そしてマップファイルとして test.map を出力しています。

    例

        ccpsx test.c -o test.cpe,test.sym,test.map

 5 応答ファイルの利用
----------------------

    ソースファイルやオプションの指定が多い場合、DOS の制限により、コマンド行
    にこれが入り切らなくなる場合があります。この場合、「応答ファイル」を作成
    し、これを CCPSX の引数に指定することにより、この制限を回避することができ
    ます。
    応答ファイルを利用するには、次のように、ファイル名の先頭に"@"（アットマー
    ク）を指定します。
    
        ccpsx @<filename>
    
    例えば、応答ファイルとして test.cnf を作成し、これを用いる場合は次のよう
    になります。

    例

        ccpsx @test.cnf
    応答ファイルには、CCPSX に指定するオプション、ソースファイルをそのまま記
    述します。

    例 test.cnf の内容

        -Xo$80040000 -kanji main.c polygon.c screen.c buffer.c event.c enemy.c 
        stage.c padctrl.c file.c
