                                                     Psy-Q Programmer's Guide

 1 一般ディレクティブ
======================

  ASMPSX は、多種多様な関数、ディレクティブを提供しています。

 1 代入ディレクティブ
----------------------

    代入ディレクティブは、シンボルに対して値を代入するために使用します。値は、
    定数、変数または文字列のいずれかとなります。
    
=============================================================================
EQU                                                      [代入ディレクティブ]
=============================================================================
        
[書式]
        <symbol name> EQU <expression>
        
[解説]
        式 expression の結果を定数値として symbole name に代入します。
        式には前方参照を含めることが可能です。指定されている内容が評価できな
        い場合、式は保存され、後にこれを参照したときに置換されます。
        ただし、

    例

        List	equ	Lastentry-Firstentry
        の例において Firstentry、Lastentry がいまだ定義されていない場合、
        
        dw  List+2
        は、
        dw  (Lastentry-Firstentry)+2
        として扱われます。代入された式は、暗黙のうちにカッコで括られます。
        
[参照]
        SET、EQUS
        
[備考]
        オプションを指定することにより、ASMPSX 実行時に代入を実行することがで
        きます。これはテストモードのような条件付きアセンブルを実行する際に便
        利です。
        
        EQU でシンボルに代入した値は不変です。二次的代入をしようとすると、エ
        ラーが発生します。しかし、現在値を、既存するシンボルに再代入すること
        は可能です。これは、マスターセグメントによりすでに使われている定数を、
        補助コード内で再定義するときよく用いられます。
[例]
        Length	equ	4
        Width	equ	8
        Depth	equ	12
        Volume	equ	Length"Width"Depth
        DmaHigh	equ	$ffff8609
        DmaMid	equ	DmaHigh+2

=============================================================================
 SET                                                     [代入ディレクティブ]
=============================================================================
        
[書式]
        <symbol name> SET <expression>
        <symbol name>  =  <expression>
        
[解説]
        式 expression の結果を変数として symbole name に代入します。SET によ
        り代入された値は、随時、再代入できます。
        "SET"及び"="は等価で、どちらを使用しても構いません。
        
[参照]
        EQU
        
[備考]
        SET の代入式に前方参照を含めることはできません。指定されている内容が
        評価できない場合、エラーが発生します。
        シンボルが定義される前に使用されている場合は、ASMPSX は警告を発し、ア
        センブラの仮パスで決定された値が代入されます。
        SET で指定するシンボルはオペランドの形式を想定しません。従って、エラ
        ーを引き起こす可能性のある、相対開始位置を持つコード（例えば SECTION 
        構成）ではなく、マクロのような場所でのローカル値の設定に適しています。
[例]
        Loopcount	set	0
        GrandTotal	=	SubTotalA+SubTotalB
        xdim	set	Bsize<<SC
        cbb	macro	string
        lc	=	0
        	rept	strlen(＼string)
        cc	substr 	lc+1,lc+1,＼string
        	db 	'＼cc'^($A5+lc)
        lc	=	lc+1
        	endr
        	endm

=============================================================================
 EQUS                                                    [代入ディレクティブ]
=============================================================================
        
[書式]
        <symbol name>	EQUS	"text"
        <symbol name>	EQUS	'text'
        <symbol name>	EQUS	<other symbol name>
        
[解説]
        テキストまたは文字列変数 text を symbole name に代入します。
        text はダブルクォートあるいはシングルクォートで括って指定します。
        文字列にダブルクォートを含める必要がある場合は、文字列全体をシングル
        クォートで括るか、ダブルクォートを２つ記述してください。
        同様に文字列にシングルクォートを含める必要がある場合は、文字列全体を
        ダブルクォートで括るか、シングルクォートを２つ記述してください。

    例

        Sinquote	equs	'What"s the point?'
        Singquot2	equs	"What's the point?"
        Doubquote	equs	"Say ""Hello""and go"
        Doubquote	equs	'Say "Hello" and  go'
        
        また、デリミタ（ダブルクォート、シングルクォート）が省略された場合、
        アセンブラは、オペランドを以前定義した文字列変数 other symbole name 
        であると仮定し、その値を symbole name に代入します。
        
[参照]
        EQU、SET
        
[備考]
        ポイントブラケット、"{"、"}" は、マクロで使用される特殊デリミタです。
        詳しくは MACRO ディレクティブの項を参照してください。
        EQUS により定義したシンボルは、別の文字列の一部とすることを含め、コー
        ドの任意の場所に記述することができます。
        周囲の文字列と混同される恐れがある場合は、シンボルの前、そして必要に
        応じ、シンボルの後にバックスラシュ＼または通貨記号￥を付加する必要が
        あります。

    例１

        z	equs	"123"
        	...
        	dw	z + 4		（123 + ４に変換されます）

    例２

        z	equs	"123"
        	...
        	dw	number\z\a	（number123a に変換されます）

    例３

        SA	equs	'StartAddress'
        	...
        	dw	\SA\4 		（StartAddress4 に変換されます）
        
[例]
        Program	equs	"Psy-Q v 1.2"
        Qtex	equs	"What's the score?"
        	db	"Remember to assemble &
        		＼_filename",0

=============================================================================
 R                                                       [代入ディレクティブ]
=============================================================================
        
[書式]
        <symbol name>	R<size>	<count>
        
[解説]
        _RS 変数の値を symbol name に代入し、rs カウンタを、size の指定に基づ
        き、バイト、ハーフ
        ワードあるいはワード単位で count 分だけ進めます。
        size に指定できるのは次のいずれかです。
        
        +----+-------------------------+
        |記号 単位                     |
        |b    バイト                   |
        |h    ハーフワード（16 ビット）|
        |w    ワード（32 ビット）      |
        +----+-------------------------+
        
[参照]
        RSSET、RSRESET
        
[備考]
        この命令と RSSET、RSRESET は共に、ASMPSX 変数 _RS に従い動作します。
        _RS 変数には現行オフセットが入っています。
        自動偶数配置オプション (AE) が指定されている場合、ハーフワード及びワ
        ード単位のＲ命令は、_RS 変数が次のワード境界に揃えられているかどうか
        を確認します。
        
[例]
        rsreset
        Icon_no	 rb	 1
        Dropcode rh	 1
        Actcode	 rh	 1
        Actname	 rb	 10
        Objpos	 rw	 1
        Artlen	 rb	 0
        この例では、最初の５つの RS のそれぞれが代入された後、_RS ポインタが
        進められます。従って各のシンボルが示す値は次のようになります。
        なお、最後の rb は、_RS ポインタを進めません。count に０を指定するこ
        とは、_RS 変数の EQUATE と等価であるためです。
        
        +--------+---------------------------------------------------------+
        |シンボル 値                                                       |
        |Icon_no  0 (RSRESET により０に設定されます）                      |
        |Dropcode 1                                                        |
        |Actcode  4 (自動偶数配置が指定されている場合、ポインタは偶数境界に|
        |         進められます)                                            |
        |Actname  6                                                        |
        |Objpos   16                                                       |
        |Artlen   20                                                       |
        +--------+---------------------------------------------------------+

=============================================================================
 RSSET                                                   [代入ディレクティブ]
=============================================================================
        
[書式]
        RSSET	<value>
        
[解説]
        指定値 value を_RS 変数に代入します。
        
[参照]
        RSRESET
[備考]
        このディレクティブは、通常、オフセットが、０以外の値で始まるときに使
        われます。

=============================================================================
 RSRESET                                                 [代入ディレクティブ]
=============================================================================
        
[書式]
        RSRESET [value]
        
[解説]
        _RS 変数を０（または value）に設定します。
        _RS カウンタを新たなデータ構造の開始時に初期化する一般的な方法です。
        
[参照]
        R、RSSET
        
[備考]
        オプショナルパラメータ value は、他のアセンブラとの互換性のために用意
        されています。これが指定された場合、RSRESET は、RESET ディレクティブ
        のように動作します。

 2 データの定義
----------------

        データ及びリザーブスペースを定義するためのディレクティブとして、以下
        のものがあります。
        
=============================================================================
D                                                              [データの定義]
=============================================================================
        
[書式]
        <symbol name>	D<size>	<expression>,<expression>...
        
[解説]
        この命令は、オペランドの式 expression を評価し、その結果を、size パラ
        メータにより指定されたフォーマットで、symbol name に代入します。式は、
        数値、文字列またはシンボルとなります。
        size に指定できるのはいずれかです。
        
        +----+-------------------------+
        |記号 単位                     |
        |b    バイト                   |
        |h    ハーフワード（16 ビット）|
        |w    ワード（32 ビット）      |
        +----+-------------------------+
        
        式が文字列の場合、これにダブルクォートを含める必要がある場合は、文字
        列全体をシングルクォートで括るか、ダブルクォートを２つ記述してくださ
        い。
        同様に文字列にシングルクォートを含める必要がある場合は、文字列全体を
        ダブルクォートで括るか、シングルクォートを２つ記述してください。
        また、デリミタ（ダブルクォート、シングルクォート）が省略された場合、
        アセンブラは、オペランドを以前定義した文字列変数であると仮定し、その
        値を symbole name に代入します。
        
[参照]
        DCB
        
[備考]
        自動偶数配置オプション (AE) が指定されている場合、ハーフワード及びワ
        ード単位のＤ命令は、プログラムカウンタが次のワード境界に揃えられてい
        るかどうかを確認します。
        アセンブラが、範囲外のパラメータを検出すると、ASMPSX は、エラーを発生
        します。下記のステートメントは、エラーの原因となります。
        db	257
        db	-129
        dh	66000
        dh	-33000
[例]
        Hexvals		dh	$80d,$a08,0,$80d,0
        Coords		dh	-15,46
        Pointers	dw	StartMarker,EndMarker
        ErrorMes	db	"File Error",0

=============================================================================
 DC                                                            [データの定義]
=============================================================================
        
[書式]
        DC<size>	<length>,<value>
        
[解説]
        value から成る、length 長のメモリのブロックを size 単位で生成します。
        size に指定できるのは次の何れかです。
        
        +----+-------------------------+
        |記号 単位                     |
        |b    バイト                   |
        |h    ハーフワード（16 ビット）|
        |w    ワード（32 ビット）      |
        +----+-------------------------+
        
[参照]
        DB
        
[備考]
        自動偶数配置オプション (AE) が指定されている場合、ハーフワード及びワ
        ード単位の DC 命令は、プログラムカウンタが次のワード境界に揃えられて
        いるかどうかを確認します。
        
[例]
        dcb	256,$7F	（$7F から成る 256 バイトのメモリブロックを生成）
        dch	64,$FF  （$FF から成る 64 ハーフワードのメモリブロックを生成）

=============================================================================
 DS                                                            [データの定義]
=============================================================================
        
[書式]
        <symbol name>	DS<size>	<length>
        
[解説]
        length 長のメモリブロックを size 単位で生成し、これを symbol name に
        割り当て、０で初期化します。
        size に指定できるのは次のいずれかです。
        
        +----+-------------------------+
        |記号 単位                     |
        |b    バイト                   |
        |h    ハーフワード（16 ビット）|
        |w    ワード（32 ビット）      |
        +----+-------------------------+
        
[参照]
        DC、DCB
        
[備考]
        自動偶数配置オプション (AE) が指定されている場合、ハーフワード及びワ
        ード単位の DS 命令は、プログラムカウンタが次のワード境界に揃えられて
        いるかどうかを確認します。
        BSS 属性のあるグループ／セクションにメモリを割り当てるために使われる
        場合、予約領域は初期化されません。
        
[例]
        List	dsh	64	（64 ハーフワードの領域を予約し、０で初期化します）
        Buffer	dsb	1024	（1024 バイトの領域を予約し、０で初期化します）

=============================================================================
 HEX                                                           [データの定義]
=============================================================================
        
[書式]
        <symbol name>	HEX	<hexlist>
        
[解説]
        hexlist で指定された符号無し 16 進ニブルペアの値をバイト単位で symbol
         name に代入します。
        
[参照]
        INCBIN
        
[備考]
        HEX として格納されているデータは、読みづらく、メモリ効率も悪く、アセ
        ンブラにとって余計な作業の原因となります。従って、HEX ステートメント
        は、比較的小さなデータ定義に限って使用することをお勧めします。大量の
        データを読み込むには、そのデータをファイルに格納し、ランタイム時にバ
        イナリファイルとして INCLUDE することをお勧めします。
        
[例]
        HexString	hex	100204FF0128
        この例は
        HexString	db	$10,$02,$04,$FF,$01,$28
        と等価です。

=============================================================================
 DATASIZE、DATA                                                [データの定義]
=============================================================================
        
[書式]
        DATASIZE	<size>
        DATA		<value>,<value>
        
[解説]
        これらの命令を一緒に使うことにより、プログラマは、値を１～256 バイト
        長（8～2048 ビット）に定義することができます。DATA アイテムのサイズは、
        まず、DATA SIZE で定義しなければなりません。
        value は 16 進または 10 進の数値文字列で、オプションとしてマイナス符
        号を付加することができます。
        
[参照]
        IEEE32、IEEE64
        
[備考]
        DATA で指定された value の値が、DATASIZE により指定されたサイズ内に収
        まらない場合、ASMPSX はエラーを発生します。
        
[例]
        datasize	8
        ...
        data		$123456789ABCDEF0
        data		-1,$FFFFFFFFFFFF

=============================================================================
 IEEE32、IEEE64                                                [データの定義]
=============================================================================
        
[書式]
        IEEE32	<fp.value>
        IEEE64	<fp.value>
        
[解説]
        32 ビット及び 64 ビット浮動小数点数字を IEEE フォーマットに定義します。
        
[参照]
        DATA、DATASIZE
        
[例]
        ieee32	1.23,34e10
        ieee64	123456.7654321e-2

 3 プログラム実行の制御
------------------------

        プログラムカウンタの状態を変更し、アセンブラの実行を制御するディレク
        ティブとして、以下のものがあります。
        
=============================================================================
ORG                                                    [プログラム実行の制御]
=============================================================================
        
[書式]
        ORG	<address>[,parameter]
        
[解説]
        ORG 命令は、アセンブラに、ターゲットマシンのコードの位置を知らせます。
        address は、以前に定義したシンボル、あるいは 16 進／10 進の数値です。
        オプションとして、数値の先頭に"?"を付加したり、コンマに続いてマシン依
        存の数値パラメータを指定することができます。
        
[参照]
        OBJ、OBJEND、GROUP、SECTION
        
[備考]
        リンクファイルを出力する場合、ORG 命令は使用してはいけません。
        プログラムが SECTION ディレクティブを含む場合、指定できる ORG は１つ
        のみです。また、ORG ディレクティブはすべての SECTION ディレクティブよ
        り前になければなりません。SECTION を利用しない場合は、複数の ORG を指
        定することができます。
        オペランド (address) の前にクエスチョンマークを付加することにより、プ
        ログラムが必要とする RAM 容量を指定することができます。ただし、この機
        能は、OS がメモリを割り当てるマシンでのみ利用可能です。
        
[例]
        	org	$100
        Begin	lw	r2,8(a0)
        Program	equ	$4000
        ...
        	org	Program

=============================================================================
 CNOP                                                  [プログラム実行の制御]
=============================================================================
        
[書式]
        CNOP	<offset>,<size boundary>
        
[解説]
        プログラムカウンタを指定したサイズ境界 size boundary から、指定したオ
        フセット offset に再設定します。
        
[備考]
        SECTION ディレクティブを含むコードでは、ASMPSX は、プログラムカウンタ
        をそのセクション用にすでに設定されているアラインメントよりも大きなサ
        イズ境界に再設定することはできません。
        従って、バイト単位で配置されたセクションに、サイズ境界に２を指定した 
        CNOP ステートメントを記述することはできません。
        
[例]
        この例ではプログラムカウンタを次のハーフワード境界の上方の 512 バイト
        に設定します。
        
        	section	prime
        Firstoff=	512
        Firstsize=	2
        ...
        	cnop	Firstoff,Firstsize

=============================================================================
 OBJ、OBJEND                                           [プログラム実行の制御]
=============================================================================
        
[書式]
        OBJ	<address>
        OBJEND
        
[解説]
        OBJ は、これに続くコードを、それがあたかも指定したアドレス address に
        あるかのように、アセンブルします。ただしそのコードは、直前のコードに
        続いて表示されます。
        OBJEND は、この処理を打ち切り、ORG で指定されたアドレス値に戻ります。
        
[参照]
        ORG
        
[備考]
        OBJ-OBJEND 構成は、１つのアドレスでアセンブルしなければならないコード
        に便利です（例えば ROM カートリッジ内）。しかし、コピーされた後は、別
        のアドレスで実行されます。
        OBJ-OBJEND で区切られたコードブロックは、入れ子にはできません。
        
[例]
        org	$100
        dw	*
        dw	*
        obj	$200
        dw	*
        dw	*
        objend
        dw	*
        dw	*
        上記コードは、下記のような、アドレス$100 で始まるワードのシーケンスを
        生成します。
        $100
        $104
        $200
        $204
        $110
        $114

 4 ファイルのインクルード
--------------------------

        ほとんどのプログラムのソースコードは、あまりにも大きいため、単一ファ
        イルとして取り扱うことができません。通常、プログラムは、アセンブル処
        理中に一緒に呼び出される補助ファイルで構成されています。
        ここでは、別個のソースファイルを収集し、これを制御するためのディレク
        ティブについて解説します。また、INCLUDE したファイルからアセンブルさ
        れるコードの制御を助ける演算子についても解説します。
        
=============================================================================
INCLUDE                                              [ファイルのインクルード]
=============================================================================
        
[書式]
        INCLUDE	<filename>
        
[解説]
        現在のファイルの処理を再開する前に、別のソースファイル filename を読
        み込んで処理します。
        filename は、ドライブ及びパスを含む、ソースファイルの名前です。
        filename は、クォーテーションで囲むこともできます。
        
[参照]
        INCBIN
        
[備考]
        ファイルの INCLUDE を入れ子にすることができます。（INCLUDEしたファイ
        ル内に INCLUDE を指定できます。
        ASMPSX 実行時に"/j"オプションを指定し、INCLUDE されるファイルの探索パ
        スを指定することができます。
        パス名にはバックスラッシュが含まれていますが、これは EQUS ディレクテ
        ィブによって定義されたシンボルと混同される恐れがあります。これを回避
        するには、バックスラッシュは２個指定するか、バックスラッシュの代わり
        にスラッシュを用いてください。

    例

        include	d:\\source\\levels.s
        include	d:/source/levels.s
[例]
        		section	short1
        codestart	j	entrypoint
        		db	 _hours,_minutes
        		db	_day,_month
        		db	_year
        		include	vars1.s
        		section	short2
        		include	vars2.s
        		section	code
        		include	graph1.s
        		include	graph2.s
        		include	maths.s
        		include	trees.s
        		include	tactics.s
        entrypoint	li	t0,8
        		lw	a0,fred
        		...

=============================================================================
 INCBIN                                              [ファイルのインクルード]
=============================================================================
        
[書式]
        <symbol name>	INCBIN	<filename>[,start,length]
        
[解説]
        現在のファイル処理を再開する前に、別のバイナリファイル filename を読
        み込み、処理します。
        filename は、ドライブ及びパスを含む、ソースファイルの名前です。
        filename は、クォーテーションで囲むこともできます。
        start、length は任意の値で、これにより指定したファイルの特定の部分を
        選択してインクルードすることが可能となります。これらを省略した場合の
        動作は次の通りです。
         ・start が省略されると、ファイルの始めから読み込みを開始します。
         ・length が省略されると、ファイルの終わりまでを読み込みます。
         ・start 及び length の両方が省略されると、ファイル全体を読み込みます。
[参照]
        INCLUDE、HEX
        
[備考]
        INCBIN により、大量のバイナリデータを別々のファイルに保存し、アセンブ
        ル時にメインプログラムに読み込むことができます。こうしたデータは大抵
        の場合、文字列や座標値です。アセンブラには、受信データのタイプ及びレ
        イアウトに関する情報は一切引き渡されません。従って、INCBIN データのラ
        ベル付け及び修正は、プログラマの責任となります。
        ASMPSX 実行時に"/j"オプションを指定し、INCLUDE されるファイルの探索パ
        スを指定することができます。
        パス名にはバックスラッシュが含まれていますが、これは EQUS ディレクテ
        ィブによって定義されたシンボルと混同される恐れがあります。これを回避
        するには、バックスラッシュは２個指定するか、バックスラッシュではなく
        スラッシュを用いてください。

    例

        include	d:\\source\\levels.s
        include	d:/source/levels.s
        
[例]
        Charmove	incbin	"d:\source\charmov.bin"

=============================================================================
 REF                                                 [ファイルのインクルード]
=============================================================================
        
[書式]
        [~]REF(symbol)
        
[解説]
        REF は特殊演算子で、これにより、プログラマは INCLUDE すべきコードのセ
        グメントを決めることができます。
        REF は、カッコ中のシンボル symbol が前もって参照されている場合に TRUE
         となります。
        また、"~"（チルド）は NOT を表わし、任意に指定することができます。
        
[例]
        Links ルーチンは、同ルーチンへの参照がすでに行なわれている場合、アセ
        ンブルされます。
        	if	ref(Links)
        Links	lw	r1,8(a0)
        	...
        	jr	ra
        	endif

=============================================================================
 DEF                                                 [ファイルのインクルード]
=============================================================================
        
[書式]
        [~]DEF(symbol)
        
[解説]
        REF 演算子と同様に、DEF は特殊機能です。これにより、プログラマはすで
        に INCLUDE されたコードのセグメントを判定することができます。
        DEF は、カッコ中のシンボル symbol が前もって定義されている場合に TRUE
         となります。
        また、"~"（チルド）は NOT を表わし、任意に指定することができます。
        
[例]
        アドレス代入部は、load_addr がまだ定義されていない場合、アセンブルさ
        れます。
        		if	~def(load_addr)
        load_addr	equ	$1000
        exec_addr	equ	$1000
        reloc_addr	equ	$80000-$300
        		endc

 5 アセンブルの制御
--------------------

        コードのセクションを選択したり、繰り返しを実行するなど、アセンブラを
        制御するためのディテクティブとして、以下のものがあります。
        
=============================================================================
END                                                        [アセンブルの制御]
=============================================================================
        
[書式]
        END     [address]
        
[解説]
        END 命令は、アセンブラにそのソースコードのアセンブルを中止するよう伝
        えます。
        address にはプログラムの最初のアドレスを指定します。
        
[参照]
        REGS
        
[備考]
        このディテクティブは、おおむね装飾的なものです。というのも、アセンブ
        ラは処理すべきコードがなくなると、処理を中止するからです。
        
[例]
        startrel	lw	t0,(a0)
        		addu	r3,r2,r1
        		...
        		jr	ra
        		end

=============================================================================
 IF, ELSE, ELSEIF, ENDIF, ENDC                             [アセンブルの制御]
=============================================================================
        
[書式]
        IF	[~]<expression>
        ELSE
        ELSEIF	[~]<expression>
        ENDIF
        ENDC
        
[解説]
        これらの条件命令により、アセンブルするコードを選択することができます。
        式 expression の前に、NOT を表わす"~"（チルド）を付加することも可能で
        す。ただし、式の意味を保護するためのカッコを慎重に扱う必要があります。
        
[参照]
        CASE
        
[備考]
        ENDC 及び ENDIF は等価で、どちらを使用しても構いません。
        ELSEIF 命令が式なしで使われる場合は、ELSE 命令と同じように動作します。
        
[例]
        		if	Sim_CD
        sec _dir	equ	2
        		elseif	Real_CD
        sec_dir		equ	1
        		else
        sec_dir		equ	3
        		endif
        		if	~usesquare
        round		macro  
        		addu	＼1,＼2,＼3
        		endm
        		elseif
        round		macro
        		endm
        		endc
        ldimm		macro	dest,imm
        	if 	(＼imm > -32568) & (＼imm < 32768)
        			addiu	＼dest,r0,＼imm
        		else
        			lui	＼dest,(＼imm) >> 16
        			if	(＼imm) & $ffff
        		ori	＼dest,＼dest,(＼imm) & $ffff
        			endif
        		endif
        		endm

=============================================================================
 CASE、ENDCASE                                             [アセンブルの制御]
=============================================================================
        
[書式]
        	CASE	<expression>
        =<expression>[,expression]
        =?
        	ENDCASE
        
[解説]
        CASE 命令は、複数の条件から選択を行なう場合に使用します。
        expression には、評価される式を指定します。
        "="の後の引数 expression が真の場合、それに続くコードがアセンブルされ
        ます。
        前に真となるケースがない場合は、"=?"のケースが選択されます。 
        
[参照]
        IF
        
[備考]
        "=?"ケースがなく、既存のケースが異常の場合、ケース定義されたコードは
        アセンブルされません。
        
[例]
        下記は、IF を CASE に置き換えたものです。
        Target	equ	Sony-1
        	...
        	case	Target
        =Sony-1
        sec_dir	equ	2
        =Sony-2
        sec_dir	equ	1
        =?	db	 "New Version",0
        sec_dir	equ	3
        	endcase

=============================================================================
 REPT、ENDR                                                [アセンブルの制御]
=============================================================================
        
[書式]
        REPT	<count>
        ...
        ENDR
        
[解説]
        REPT 及び ENDR ステートメント間のコードを繰り返します。繰り返しの回数
        は count の値で決まります。
        
[参照]
        DO、WHILE
        
[備考]
        マクロ内では、REPT は頻繁に NARG 機能と関連付けられます。
        
[例]
        rept	12
        dh	0,0,0,0
        endr
        cbb	macro	string
        lc	=	0
        	rept	strlen(＼string)
        cc	substr	lc+1,lc+1,＼string
        	db	"＼cc"^($A5+lc)
        lc	=	lc+1
        	endr
        	endm

=============================================================================
 WHILE、ENDW                                               [アセンブルの制御]
=============================================================================
        
[書式]
        WHILE	<expression>
        ...
        ENDOW
        
[解説]
        オペランドの式 expression が真である限り、WHILE 及び ENDW ステートメ
        ント間のコードを繰り返します。
        
[参照]
        REPT、DO
        
[備考]
        WHILE 式にある文字列代入は、WHILE ループが最初に検出されたときに１回
        だけ行なわれます。従って次の例は正しく動作しません。

    例

        s	equs	 "X"
        	while	strlen("\s")<4
        	db	 "\s",0
        s	equs	"\s\x"
        	endw
        これを避けるには、次のようにループを回る度に変数を設定し、ループが継
        続することを示してください。

    例

        s	equs	"X"
        looping	=	-1
        	while	looping
        	db	"\s",0
        s	equs	"\s\x"
        looping	=	strlen("\s")<4
        	endw
        
[例]
        MultP	equ	16
        	...
        Indic	=	MultP
        	while	Indic>1
        	lw	r1,term(a0)
        	...
        Indc	=	Indic-1
        	endw

=============================================================================
 DO、UNTIL                                                 [アセンブルの制御]
=============================================================================
        
[書式]
        DO
        ...
        UNTIL	<expression>
        
[解説]
        DO 及び UNTIL ステートメント間のコードを、指定した式 expression が真
        になるまで、繰り返します。
        
[参照]
        REPT、WHILE
        
[備考]
        WHILE 命令とは対象的に、UNTIL 式の文字列代入は、ループを回る度に再評
        価されます。
        
[例]
        MultP	equ	16
        	...
        Indic	=	MultP
        	do
        	lw	r1,term(a0)
        	...
        Indic	=	Indic-1
        	until	Indic <= 1

 6 ターゲット関連
------------------

        ターゲットマシンの最初のパラメータを指定するディレクティブとして、次
        のものがあります。
        
=============================================================================
REGS                                                         [ターゲット関連]
=============================================================================
        
[書式]
        REGS	<regcode=expression>[,<regcode=expression>]
        
[解説]
        レジスタ regcode に式 expression を代入します。regcode には、"r1"、
        "PC"のようなレジスタのニーモニック名を指定します。
        CPE ファイルが作成されるか、オブジェクトコードがターゲットに出力され
        ると、REGS ディレクティブは、コードの実行開始時にレジスタの内容を設定
        します。
        
[備考]
        ターゲットに固有なリロケータブルコードまたはバイナリコードに対しては
        使用できません。
        
[例]
        regs	t0=$1234
        regs	pc=entrypoint
