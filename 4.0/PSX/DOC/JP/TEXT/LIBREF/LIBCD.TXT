CdlATV                                                               [構造体]
=============================================================================
                                                       オーディオアッテネータ
        
[構造]
        typedef struct {
        		u_char val0;
        		u_char val1;
        		u_char val2;
        		u_char val3;
        } CdlATV;
        
[メンバ]
        val0		CD (L) → SPU (L) への減衰量
        val1		CD (L) → SPU (R) への減衰量
        val2		CD (R) → SPU (R) への減衰量
        val3		CD (R) → SPU (L) への減衰量
        
[解説]
        CDの音量を設定するための構造体。
        CDの音量はCD-DAおよびCD-XAの音量のことである。
        val0～val3の値は最小音量0から最大音量128を設定する。
        通常のステレオの音量を調整するためにはval0にＬチャンネル、val1にＲチ
        ャンネルの音量を指定しval1、val3には0を指定する。
        
[関連項目]
        CdMix()

CdComstr                                                               [関数]
=============================================================================
                         コマンドのコードに対応する文字列を得る（デバッグ用）
        
[形式]
        char *CdComstr (
        u_char com 
        )
        
[引数]
        com		コマンド終了コード
        
[解説]
        デバッグ用。処理状態コードから対応する文字列を得る。例えばコードに応
        じて以下のような文字列を得る。
         
        +--------------+-----------+
        |コマンドコード 文字列     |
        |CdlNop         CdlNop     |
        |CdlSetloc      CdlSetLoc  |
        |CdlPlay        CdlPlay    |
        |CdlForward     CdlForward |
        |CdlBackward    CdlBackward|
        +--------------+-----------+
        
[返り値]
        文字列の先頭ポインタ

CdControl                                                              [関数]
=============================================================================
                               CD-ROMサブシステムにプリミティブコマンドを発行
        
[形式]
        int CdControl (
        u_char com, 
        u_char *param, 
        u_char *resrult 
        ）
        
[引数]
        com		コマンドコード
        param		コマンドに対する引数
        result		返り値（8byte）
        
[解説]
        CD-ROMサブシステムにプリミティブコマンドを発行する。プリミティブコマ
        ンドには、それぞれ対応するコマンドコードが以下のように割り当てられて
        いる。
         
        +------------+------+------+------------------------------------+
        |シンボル     コード タイプ 内容                                |
        |CdlNop       0x01   B      NOP（No Operation）                 |
        |CdlSetloc    0x02   B      シークのターゲット位置を設定        |
        |CdlPlay      0x03   B      CD-DA演奏開始                       |
        |CdlForward   0x04   B      早送り                              |
        |CdlBackward  0x05   B      巻き戻し                            |
        |CdlReadN     0x06   B      データリード開始（リトライつき）    |
        |CdlStanby    0x07   N      ディスクを回転させた状態で待機      |
        |CdlStop      0x08   N      ディスクの回転を停止                |
        |CdlPause     0x09   N      現在位置で一時停止                  |
        |CdlMute      0x0b   B      CD-DAミュート                       |
        |CdlDemute    0x0c   B      ミュート解除                        |
        |CdlSetfilter 0x0d   B      再生ADPCMセクタを選択               |
        |CdlSetmode   0x0e   B      基本モード設定                      |
        |CdlGetparam  0x0f   B      CDサブシステムの現在のmodeを獲得    |
        |CdlGetlocL   0x10   B      論理位置獲得（データセクタ）        |
        |CdlGetlocP   0x11   B      物理位置獲得（オーディオセクタ）    |
        |CdlSeekL     0x15   N      論理シーク（データセクタシーク）    |
        |CdlSeekP     0x16   N      物理シーク（オーディオセクタシーク）|
        |CdlReadS     0x1b   B      データリード開始（リトライなし）    |
        +------------+------+------+------------------------------------+
         			B: Blocking, N: Non-Blocking operation
        
        プリミティブコマンドは処理の終了を待ってリターンするブロックコマンド、
        終了をまたずにリターンするノンブロックコマンドの２つのタイプがある。
        
[返り値]
        発行に成功すれば1を、失敗すれば0を返す。
        
[備考]
        paramを指定しないコマンドには0を指定する。resultに0を指定すると返り値
        をもどさない。ノンブロック関数であるため、実際の転送の終了はCdSync()
        で検出する必要がある。
        
[関連項目]
        CdControlB(),CdControlF()

CdControlF                                                             [関数]
=============================================================================
                     CD-ROMサブシステムにプリミティブコマンドを発行（高速型）
        
[形式]
        int CdControlF (
        u_char com, 
        u_char *param
        )
        
[引数]
        com		コマンドコード（CdControl()参照）
        param		コマンドに対する引数
        
[解説]
        CD-ROMサブシステムにプリミティブコマンドを発行する。サブシステムに対
        する一切のハンドシェークを行なわない。そのためエラーハンドリングはも
        ちろんのこと、エラー検出までもプログラマの責任で行う必要がある。
        
[返り値]
        発行に成功すれば1を、失敗すれば0を返す。
        
[備考]
        paramを指定しないコマンドには0を指定する。サブシステムに対してコマン
        ドの受け付け(ACK)さえも待たないため高速。現在は、必ず1を返すため返り
        値は意味を持たない。
        
[関連項目]
        CdControl(),CdControlB()

CdDataCallback                                                         [関数]
=============================================================================
                                      CdGetSector終了のコールバック関数を定義
        
[形式]
        int CdDataCallback (
        CdlCB func 
        )
        
[引数]
        func		コールバック関数
        
[解説]
        CdGetSector()終了時に呼ばれるコールバックを定義する。リードが終了した
        時にfuncが呼び出される。funcに0を指定した場合は、コールバックは発生し
        ない。ただしCdGetSector()は関数からリターンした時点で転送は終了してい
        るため、コールバックを設定することは無意味である。
        
[返り値]
        以前に設定されたコールバックのアドレス
        
[備考]
        func内では以降の描画終了割り込みはマスクされる。従ってfuncは必要な処
        理を終了したらすみやかにリターンする必要がある。CdlCBは以下のコールバ
        ック関数の型を表す。
        typedef void ( *CdlCB )( u_char, u_char* )
        
[関連項目]
        CdGetSector(),CdDataSync()

CdDataSync                                                             [関数]

[形式]
        int CdDataSync (
        int mode
        )
        
[引数]
        mode		0: 転送の終了を待つ
         		1: 現在の状態を調べて即座にリターンする
        
[解説]

[返り値]

[関連項目]
        CdGetSector(),CdDataCallback()

CdDiskReady                                                            [関数]
=============================================================================
                                                       Cdの状態をチェックする
        
[形式]
        int CdDiskReady (
        int mode
        )
        
[引数]
        mode		チェックモード（0: ブロック型、1: ノンブロック型）
        
[解説]
        CDの状態をチェックし、コマンドが発行できるかどうかを調べる。CDのカバ
        ーを閉めた直後は、数秒間コマンドが発行できない状態が続くが、これをチ
        ェックする。ブロック型は安定していない場合は安定するまでホールドして
        リターンする。ノンブロック型の場合はステータスを見てリターンする。
        
[返り値]
         
        +----------------+------------------------------------------------+
        |返り値           意味                                            |
        |CdlComplete      コマンドを発行できる状態にある                  |
        |CdlDiskError     ブロック型：ディスクが入っていないか不良ディスク|
        |                 ノンブロック型：まだ安定していない、            |
        |                 もしくはディスクが入っていない、                |
        |                 もしくは不良ディスク                            |
        |CdlStatShellOpen プレイヤーのふたが開いている                    |
        +----------------+------------------------------------------------+
        
        
[備考]
        CDの交換などでプレイヤーがカバーを閉めた直後は、この関数を使用してCD
        の安定を待つ必要がある。その後CdGetDiskType()でCDのフォーマットを確認
        してからコマンドを発行する。
        ブロック型をコールした場合、関数がリターンするまでに最大で以下の時間
        を要する。
        
        デバッギングステーション
        		CD-R		最大約１２秒
        		CD-DA		最大約１２秒
        		ディスクなし	約５秒
        PlayStation
        		Black CD	最大約３秒
        		CD-DA		最大約５秒
        		ディスクなし	約５秒
        
        ノンブロック型の場合は、ステータスを見てすぐにリターンするが、CDが安
        定していない状態と、ディスクなしの状態を区別できない。よって、上記の
        時間を参考にしてプログラム側でタイムアウトを管理する必要がある。
        ※この関数はDTL-H2000では正常に動作しない。

=============================================================================

[形式]

[引数]

CdGetDiskType                                                          [関数]
=============================================================================
                                                      CD のフォーマットを得る
        
[形式]
        int CdGetDiskType ( void )
        
[引数]
        なし
        
[解説]
        CDのフォーマットを得る。検出可能なフォーマットは現在CD-ROMフォーマッ
        トのみ。
        
[返り値]
         
        +----------------+------------------------------+
        |返り値           意味                          |
        |CdlCdromFormat   CD-ROMフォーマット            |
        |CdlOtherFormat   他のフォーマット              |
        |CdlStatShellOpen プレイヤーのカバーが開いている|
        |CdlStatNoDisk    CDが入っていない              |
        +----------------+------------------------------+
        
[備考]
        デバッギングステーションではPlayStationディスク（ブラックディスク）、
        CD-Rおよび一般のCD-ROM （ISO9600フォーマットのもの）がCD-ROMとして認
        識されるが、PlayStation（実機）ではPlayStationディスクのみCD-ROMとし
        て認識される。CD-DAは常にOtherFormatと認識される。CDの交換などプレイ
        ヤーのカバーが閉じられた直後にこの関数を使用する場合は、その前に
        CdDiskReady()を呼んでCDサブシステムが安定したことを確認する。
        ※この関数は、DTL-H2000では正常に動作しない。

CdGetSector                                                            [関数]
=============================================================================
                               セクタバッファのデータをメインメモリへ転送する
[形式]
        int CdGetSector (
        void *madr, 
        int size
        )
        
[引数]
        madr		転送先メインメモリアドレス
        size		転送サイズ（ロングワード）
        
[解説]
        セクタバッファ上のセクタデータをメインメモリ上に転送する。転送終了ま
        でブロックする。
        
[返り値]
        発行に成功すれば1を、失敗すれば0を返す。
        
[備考]
        セクタサイズはモードによって異なる。転送は複数回にわけて異なるメモリ
        領域へ転送することもできる。セクタバッファのポインタはCdReady割込みに
        よって先頭にセットされるため、セクタデータがバッファに準備されてから、
        次のセクタデータが上書きされる前（次のCdReady割込みが発生する前）に読
        み出さないと、以前のセクタデータは失われる。
        本関数はDMAの終了を待ってリターンするため、関数のリターン時には転送は
        終了している。
        
        なお、現在のCdGetSector()ではReadyコールバックによってバッファの読み
        込みポインタがリセットされるため、ポインタを更新するためのダミーのデ
        ータ転送は不要。
        
[関連項目]
        CdGetSector2()

CdGetSector2                                                           [関数]
=============================================================================
             セクタバッファのデータをメインメモリに転送する（ノンブロック型）
[形式]
        int CdGetSector2 (
        void* madr,
        int size
        )
        
[引数]
        madr		転送先メインメモリアドレス
        size		転送サイズ（ロングワード）
        
[解説]
        セクタバッファ上のデータをメインメモリ上に転送する。転送はサイクルス
        チールモードで行われるため、転送中に割込みが入ることができる。本関数
        は転送を開始してリターンするノンブロック型であるため、転送の終了は
        CdDataSync()もしくはCdDataCallback()で監視する必要がある。
        なお、サイクルスチールモードでの転送中は、割込みは入ることができるが
        普通のプログラムはデータバスを使用できないため、バスを通してメモリな
        どにアクセスする命令があるとその時点で処理がブロックされる。
        
[返り値]
        実行に成功すれば１を、失敗すれば０を返す。
        
[備考]
        サイクルスチールモードでのデータ転送は、ブロックモード（CdGetSector()
        で使用されるモード）に比べて時間がかかる。
        
        なお、現在のCdGetSector2()ではReadyコールバックによってバッファの読み
        込みポインタがリセットされるため、ポインタを更新するためのダミーのデ
        ータ転送は不要。
        
[関連項目]
        CdDataCallback(),CdDataSync(),CdGetSector()

CdPlay                                                                 [関数]

        int *tracks,
        int offset
        )

        mode		モード
        tracks		演奏するトラックを指定した配列。0で終端していること
        offset		演奏を開始するtracksのインデックス
        
[解説]
        配列tracksで指定された複数のトラックをバックグラウンドに順に演奏する。
        配列の最後のトラックまで演奏したらモードに応じて繰り返し演奏するか、
        演奏を終了する。
        modeに指定できる値は次の通り。
         
        +----+------------------------------------------------------------+
        |mode 内容                                                        |
        |0    演奏を停止する。                                            |
        |1    tracksで指定されたトラックを順に演奏し、指定されたトラックを|
        |     すべて演奏したら、演奏を停止する。                          |
        |2    tracksで指定されたトラックを順に演奏し、指定されたトラックを|
        |     すべて演奏したら、最初に戻って繰り返し演奏する。            |
        |3    現在の演奏中のトラックに対応するtracksのインデックスを返す。|
        +----+------------------------------------------------------------+
        
[返り値]
        現在演奏中のトラック。これはトラック番号ではなく配列tracksのインデッ
        クスが返される。-1が返された場合は、演奏は終了していることを表す。
        
[備考]
        演奏はトラック単位で行われ、トラックの途中からの演奏や停止はできない。

CdReadCallback                                                         [関数]
=============================================================================
                                                CdRead コールバック関数を定義
        
[形式]
        CdlCB CdReadCallback (
        CdlCB func 
        )
        
[引数]
        func		コールバック関数
        
[解説]
        CdRead()終了時に呼ばれるコールバックを定義する。リードが終了した時に
        funcが呼び出される。funcに0を指定した場合は、コールバックは発生しない。
        CdlCBは以下のコールバック関数の型を表す
        typedef void ( *CdlCB )( u_char, u_char* )

        ステータスには以下のものがある。
        
        	CdlComplete		CdRead()の実行が終了した
        	CdlDiskError		CdRead()の実行が異常終了した

        resultは8byteである。
        char result[ 8 ];
        resultの先頭には ステータスが入りそれ以降は直近に発行されたコマンドに
        よって内容が異なる。
        
[返り値]
        以前に設定されたコールバックのアドレス
        
[備考]
        func内では以降の描画終了割り込みはマスクされる。従ってfuncは必要な処
        理を終了したらすみやかにリターンする必要がある。
        
[関連項目]
        CdRead(),CdReadSync()
