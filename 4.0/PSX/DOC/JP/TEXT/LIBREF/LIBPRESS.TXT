DECDCTENV                                                            [構造体]
=============================================================================
                                                             DCT デコード環境
        
[構造]
        typedef struct {
        		u_char	iq_y[64];
        		u_char	iq_c[64];
        		short	dct[64];
        } DECDCTENV;
        
[メンバ]
        iq_y		輝度成分量子化テーブル
        iq_c		色差成分量子化テーブル
        dct		システム予約
        
[解説]
        DCT デコードのパラメータを設定する。
        デフォールトの iq_y, iq_c 両テーブルの値は同じで、以下の通り。
        
        u_char iq_y[64] = {
         	 2, 16, 19, 22, 26, 27, 29, 34,
         	16, 16, 22, 24, 27, 29, 34, 37,
         	19, 22, 26, 27, 29, 34, 34, 38,
         	22, 22, 26, 27, 29, 34, 37, 40,
         	22, 26, 27, 29, 32, 35, 40, 48,
         	26, 27, 29, 32, 35, 40, 48, 58,
         	26, 27, 29, 34, 38, 46, 56, 69,
         	27, 29, 35, 38, 46, 56, 69, 83
        };
        
        注意：テーブル中の各値は、小数部４ビットの固定小数点表現である。
        
[備考]
        iq_y, iq_c はジグザグスキャン順序で並べられていることに注意。

=============================================================================
                                                  SPUエンコード環境属性構造体
        
[構造]
        typedef struct {
        		short	*src;
        		short	*dest;
        		long	size;
        		long	loop_start;
        		char	loop;
        		char	byte_swap;
        		char	proceed;
        		char	pad4;
        } ENCSPUENV;
        
[メンバ]
        src		16-bit ストレート PCM データアドレス
        dest		PlayStation オリジナル波形データ
        size		16-bit ストレート PCM データサイズ (単位:byte)
        loop_start	PCM データのループスタートポイント (単位:byte)
        loop		ループ波形生成指定
        byte_swap	PCM データの endian 指定
        proceed		一括/分割エンコード指定
[解説]
        EncSPU() のための SPU エンコード環境属性を指定する。
         
[備考]
        使用法の詳細はEncSPU() を参照。

DecDCTin                                                               [関数]
=============================================================================
                                       ランレベルを画像処理サブシステムに送信
        
[形式]
        void DecDCTin (
        u_long *buf, 
        int mode
        )
        
[引数]
        buf		入力ランレベル
        mode		デコードモード
        
[解説]
        ランレベル buf 以下をダイレクトカラー画像に解凍する。
        解凍結果は、DecDCTout()で取り出す。
        デコードモードは mode の下位２ビットで指定する。
         
        +-----+---------------------+
        |bit 0 出力モード           |
        |0     16bitダイレクトカラー|
        |1     24bitダイレクトカラー|
        +-----+---------------------+
         
        +-----+---+
        |bit 1 STP|
        |0     0  |
        |1     1  |
        +-----+---+
        
        出力のピクセルの深さは、24bit/16bitのどちらかを選択できる。
        16bitモードの場合、解凍後のピクセルの15bit目(STPビット）は、mode の
        bit1で設定できる。
        
[返り値]
        なし
        
[備考]
        DecDCTin()で解凍された結果生じる画像の幅・高さに関する情報は、ランレ
        ベルやビットストリームには保持されていない。これらのパラメータは、よ
        り上位の階層のデータ形式(STRフォーマットなど）で定義される。
        送受信のデッドロックを防止するために、送信したランレベルに対応するサ
        イズのデータはDecDCTout()によって必ず受信しなくてはならない。
        しかし、その際に一回のDecDCTin()で送信したデータを複数回のDecDCTout()
        で読み出してもよいし、その逆もできる。
        DecDCTin()はノンブロック関数であるため、実際の転送の終了は
        DecDCTinSync()で検出する必要がある。DecDCTin()の終了をまたずに、次の
        DecDCTin()を実行すると２回目の送信は１回目の送信が終了するまでブロッ
        クされる。

DecDCTinCallback                                                       [関数]
=============================================================================
                                       送信終了時に呼ばれるコールバックを設定
        
[形式]
        int DecDCTinCallback (
        void (*func)()
        ) 
        
[引数]
        func		コールバック関数のアドレス
        
[解説]
        送信終了時に呼ばれるコールバック func を設定する。
        コールバックが設定されると、送信の終了時に関数 func が呼び出される。
        func に0を指定した場合は、コールバックは発生しない。
        
[返り値]
        なし
        
[備考]
        func 内では以降の送信終了割り込みはマスクされる。従って func は必要な
        処理を終了したらすみやかにリターンする必要がある。

DecDCTout                                                              [関数]
=============================================================================
                             画像処理サブシステムからデコードデータを受けとる
        
[形式]
        void DecDCTout (
        u_long *buf, 
        int size
        )
        
[引数]
        buf		解凍後画像データ
        size		受信するデータサイズ（ロングワード）
        
[解説]
        ランレベルを解凍し size ワード分の結果を buf 以下に格納する。
        解凍データのフォーマットは、DecDCTin()の引数によって24bit/16bitいずれ
        かになる。
        サイズ size は全解凍データサイズと等しいか小さい値を指定する。
        全解凍データより小さい値を指定した場合は、送受信のデッドロックを防止
        するために、続くDecDCToutで残りのデータをすべて読み出す必要がある。
        解凍画像は、マクロブロック（16x16矩形領域）単位で出力される。
        データサイズはマクロブロックサイズ（16bitモードならば16x16x2 = 
        512byte = 128 word, 24bitモードならば、16x16x3 = 768 byte = 192 word)
        単位で指定する必要がある。
        
[返り値]
        なし
        
[備考]
        DecDCTout()はノンブロック関数であるため、実際の転送の終了は
        DecDCToutSync()で検出する必要がある。DecDCTout()の終了をまたずに、次
        のDecDCTout()を実行すると２回目の送信は１回目の送信が終了するまでブロ
        ックされる。

DecDCTvlc                                                              [関数]
=============================================================================
                                                            VLCの解凍を行なう
        
[形式]
        int DecDCTvlc (
        u_long *bs, 
        u_long *buf
        )
        
[引数]
        bs		入力ビットストリーム
        buf		出力ランレベル
        
[解説]
        ビットストリーム bs を解凍し、中間形式であるランレベルを buf 以下に生
        成する。
        解凍後のランレベルの大きさは、DecDCTBufSize() で取得できる。
        ランレベルが DecDCTvlcSize() で指定された値を越えると、DecDCTvlc() は
        一旦処理を中断し制御をアプリケーションに戻す。
        中断したVLCデコードは、DecDCTvlc(0, 0) を実行することで再開できる。
        
[返り値]
         
        +------+----------------------------------------+
        |返り値 意味                                    |
        |0      全ビットストリームのデコードが終了      |
        |1      未デコードのビットストリームを残して復帰|
        |-1     デコード失敗                            |
        +------+----------------------------------------+
        
[備考]
        ブロック関数。DecDCTin()を実行する前に必ずDecDCTvlc()で一旦ビットスト
        リームをランレベルに変換しておく必要がある。
        途中結果のランレベルをDecDCTin()に入力として与えることはできない。
        将来DecDCTvlc2に置き換えられる｡

DecDCTvlc2                                                             [関数]
=============================================================================
                                                            VLCの解凍を行なう
        
[形式]
        int DecDCTvlc2(
        u_long *bs, 
        u_long *buf, 
        DECDCTTAB *table
        )
        
[引数]
        bs		入力ビットストリーム
        buf		出力ランレベル
        table		VLC テーブル
[解説]
        ビットストリーム bs を table に従って解凍し、中間形式であるランレベル
        を buf 以下に生成する。解凍後のランレベルの大きさは、DecDCTBufSize() 
        で取得できる。ランレベルが DecDCTvlcSize2() で指定された値を越えると、
        DecDCTvlc2() は一旦処理を中断し制御をアプリケーションに戻す。中断した
        VLCデコードは、DecDCTvlc2(0, 0, table)を実行することで再開できる。
[返り値]
         
        +------+----------------------------------------+
        |返り値 意味                                    |
        |0      全ビットストリームのデコードが終了      |
        |1      未デコードのビットストリームを残して復帰|
        |-1     デコード失敗                            |
        +------+----------------------------------------+
[備考]
        ブロック関数。DecDCTin()を実行する前に必ずDecDCTvlc2()で一旦ビットス
        トリームをランレベルに変換しておく必要がある。
        途中結果のランレベルをDecDCTin()に入力として与えることはできない。
        VLCテーブルはあらかじめDecDCTBuild() で解凍しておくこと。

DecDCTvlcBuild                                                         [関数]
=============================================================================
                                                        VLCテーブルを生成する
[形式]
        void DecDCTvlcBuild (
        DECDCTTAB table
        )
        
[引数]
        mode		VLC バッファ
        
[解説]
        DecDCTvlc2() で使用する VLC テーブルを生成する。
        生成されるサイズは sizeof(DECDCTTAB) であらかじめ知ることができる。 
        構造体DECDCTTABに関しては、libpress.hを参照のこと。
        
[返り値]
        なし
        
[備考]
        VLCテーブルは、圧縮された（4KB) 形式で保持され、ムービー再生時にのみ
        これをワーク領域に解いて (64KB)解凍に使用される。
        この場合は、ムービー再生時でのメモリ削減にはならないが、ムービー未使
        用時には不必要なテーブル領域を削減することができる。
        
[関連項目]
        DecDCTvlc2()

EncSPU                                                                 [関数]
=============================================================================
                                                 波形データのエンコードを行う
        
[形式]
        long EncSPU (
        ENCSPUENV *es_env
        )
        
[引数]
        es_env		SPU エンコード環境属性
        
[解説]
        SPU エンコード環境属性 es_env.src に指定された 16-bit ストレート PCM 
        データを PlayStation オリジナル波形データ (VAG, ヘッダ情報なし) にエ
        ンコードしてメンバes_env.dest に返す。
        
        es_env.sizeには 16-bit ストレート PCM データのサイズをバイト単位で指
        定する。
        ループ波形を作成する際にはes_env.loopにENCSPU_ENCODE_LOOPを指定し、
        es_env.loop_startに es_env.src内の PCM データのループスタートポイント
        をバイト単位で指定する。ループ波形でない場合にはes_env.loopに 
        ENCSPU_ENCODE_NO_LOOPを指定する。
        PCMデータの endian により、es_env.byte_swapに 
        ENCSPU_ENCODE_ENDIAN_BIG (16-bit big endian) あるいは 
        ENCSPU_ENCODE_ENDIAN_LITTLE (16-bit little endian) を指定する。
        es_env.proceedには一括/分割エンコード指定を行う。
        
        +----------------------+------------------+
        |es_env.proceed         エンコード指定    |
        |ENCSPU_ENCODE_WHOLE    一括エンコード    |
        |ENCSPU_ENCODE_START    分割エンコード開始|
        |ENCSPU_ENCODE_CONTINUE 分割エンコード継続|
        |ENCSPU_ENCODE_END      分割エンコード終了|
        +----------------------+------------------+
        
        es_env.proceedが ENCSPU_ENCODE_WHOLE以外の場合は、領域を分割する形、
        すなわち ENCSPU_ENCODE_STARTで先頭ブロックを含む領域のエンコード、
        ENCSPU_ENCODE_CONTINUEで中間領域の継続したエンコード、
        ENCSPU_ENCODE_ENDで最終ブロックを含む部分のエンコードを、 es_env.src 
        からes_env.size で指定した領域だけ行う。
        
[返り値]
        es_env.dest に作成されたエンコード後の PlayStation オリジナル波形デー
        タのサイズ。
        エンコード後の PlayStation オリジナル波形データのサイズエラーがあった
        場合は ENCSPU_ENCODE_ERROR を返す
        
[備考]
        loop に ENCSPU_ENCODE_NO_LOOP に指定した場合、loop_start は無視される。
