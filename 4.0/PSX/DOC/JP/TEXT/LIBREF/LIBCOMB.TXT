_comb_control                                                          [関数]
=============================================================================
                                                   対戦ケーブルドライバの制御
        
[形式]
        long _comb_control (
        unsigned long cmd,
        unsigned long arg,
        unsigned long param
        )
        
[引数]
        cmd		コマンド
        arg		サブコマンド
        param		引数
        
[解説]
        対戦ケーブルドライバの詳細な制御を行います。
        ※詳細はoverview/comb.docの「ＢＩＯＳ」を参照してください。
        
[返り値]
        各コマンド／サブコマンドによる、それぞれの値を返します。

ChangeClearSIO                                                         [関数]
=============================================================================
                              ドライバ内で拡張 SIO からの割り込みをクリアする
        
[形式]
        void ChangeClearSIO ( 
        long val 
        )
        
[引数]
        val		割り込み要因クリアフラグ
        
[解説]
        val に非 0を指定するとドライバ内で拡張 SIO からの割り込みをクリアしま
        す。他の拡張 SIO ドライバと共存する場合にのみ使用します。
        
[返り値]
        なし
