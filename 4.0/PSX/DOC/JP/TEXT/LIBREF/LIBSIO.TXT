_sio_control                                                           [関数]
=============================================================================
                                                                      SIOBIOS
        
[形式]
        long _sio_control( 
        unsigned long cmd
        unsigned long arg
        unsigned long param 
        )
        
[引数]
        cmd		コマンド
        arg		サブコマンド
        param		引数
        
[解説]
        SIOドライバ制御および情報取得。
        ＰＣとの細かい通信処理に利用する。
        ライブラリ等の標準出力によるデバッグデータを抑制したい場合に利用する。
        
[返り値]
        備考参照
        
[備考]

        表 1 コマンド一覧
        +---+---+------------------------------------------------+
        |cmd arg 機能                                            |
        |0   0   ステータスレジスタの値を返す。                  |
        |    1   コントロールレジスタの値を返す。                |
        |    2   モードレジスタの値を返す。                      |
        |    3   通信速度（bps単位）を返す。                     |
        |    4   １バイト読み込む                                |
        |1   0   システム予約                                    |
        |    1   paramの値をコントロールレジスタに設定する。     |
        |    2   paramの値をモードレジスタに設定する。           |
        |    3   paramの値を通信速度（bps単位）として設定する。  |
        |    4   １バイト書き込む                                |
        |2   0   ドライバをリセットする。                        |
        |    1   ドライバステータスエラー関連ビットをクリアする。|
        +---+---+------------------------------------------------+
        

        表 2 ステータスレジスタ
        +-----+---------+------------------------+
        |bit             内容                    |
        |31-10           不定                    |
        |9     SR_IRQ    1:割り込みon            |
        |8     SR_CTS    1:CTSがon               |
        |7     SR_DSR    1:DSRがon               |
        |6               不定                    |
        |5     SR_FE     1:フレームエラー発生    |
        |4     SR_OE     1:オーバーランエラー発生|
        |3     SR_PERROR 1:パリティエラー発生    |
        |2     SR_TXU    1:送信データなし        |
        |1     SR_RXRDY  1:受信データ読みとり可能|
        |0     SR_TXRDY  1:送信データ書き込み可能|
        +-----+---------+------------------------+
        

        表 3 コントロールレジスタ
        +-----+---------+--------------------------------+
        |bit             内容                            |
        |31-13           不定                            |
        |12    CR_DSRIEN 1:DSR割り込み許可               |
        |11    CR_RXIEN  1:受信割り込み許可              |
        |10    CR_TXIEN  1:送信割り込み許可              |
        |9,8             0固定                           |
        |7               不定                            |
        |6     CR_INTRST 1:SIO1リセット                  |
        |5     CR_RTS    1:RTSがon                       |
        |4     CR_ERRRST 1:割り込みとエラーフラグのクリア|
        |3               不定                            |
        |2     CR_RXEN   1:受信を許可                    |
        |1     CR_DTR    1:DTRがon                       |
        |0     CR_TXEN   1:送信を許可                    |
        +-----+---------+--------------------------------+
        

        表 4 モードレジスタ
        +----+----------+-----------------------+
        |bit             内容                   |
        |31-8            不定                   |
        |7,6             ストップビット長       |
        |     MR_SB_01   01：1                  |
        |     MR_SB_10   10：1.5                |
        |     MR_SB_11   11：2                  |
        |5    MR_P_EVEN  パリテェ２  1：奇 0：偶|
        |4    MR_PEN     パリティ１  1：あり    |
        |3,2             キャラクタ長           |
        |     MR_CHLEN_5 00：5ビット            |
        |     MR_CHLEN_& 01：6                  |
        |     MR_CHLEN_7 10：7                  |
        |     MR_CHLEN_8 11：8                  |
        |1               常に1                  |
        |0               常に0                  |
        +----+----------+-----------------------+

Sio1Callback                                                           [関数]
=============================================================================
                                        SIO割り込みコールバック関数を設定する
        
[形式]
        int Sio1Callback( 
        void (* func)() 
        )
        
[引数]
        func		コールバック関数
        
[解説]
        _sio_control(1, 1, param)で設定された割り込み要因(CR_DSRIEN, CR_RXIEN,
         CR_TXIEN)により割り込みが発生した場合に、関数funcが呼び出される。
        funcに 0を指定した場合は、コールバックは発生しない。 
        
[返り値]
        なし
        
[備考]
        割り込み発生時には、_sio_control(2,1,0)または_sio_control(1,1, 
        CR_ERRRST)を用いて割り込みフラグをクリアする必要がある。割り込みフラ
        グがクリアされていない状態では、次のSIO割り込みは発生しない。
