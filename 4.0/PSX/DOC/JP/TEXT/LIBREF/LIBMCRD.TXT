=============================================================================
MemCardAccept                                                          [関数]
=============================================================================
                                                           カードの状態を取得
[形式]
        long MemCardAccept (
        long chan
        )
        
[引数]
        chan	ポート番号 + カード番号
        	ポート番号(Ａポート:0x00、Ｂポート:0x10)
        	カード番号(通常 0)
        
[解説]
        chanで指定したメモリカードの接続をテストし、接続されている場合はさら
        に詳細な情報を取得する。
        新規カードの場合は _card_clear(), _card_load()を実行し、以降のファイ
        ルアクセス関数を使用可能にする。
        MemCardOpen() などファイルアクセス関数の使用に先立って実行する必要が
        ある。カードが入れ替わらない限り反復して実行する必要はない。
        関数自体は非同期処理のため直ちに終了する。多重の処理登録は行なえない。
        処理の完了はMemCardSync() または完了コールバックにより確認する。
        所用時間は最大 76VSYNC。カードが存在しない場合は約4VSYNC。
        取得結果はMemCardSync() または完了コールバックの result 値として通知
        される。
        新規カード(McErrNewCard)の検出は１回のみで、２回目以降はMcErrNone が
        返る。
        
        result値
        +----+-----------------+--------------------------------+
        |値   マクロ            状態                            |
        |0x00 McErrNone         接続されている                  |
        |0x01 McErrCardNotExist 接続されていない                |
        |0x02 McErrCardInvalid  不良カード                      |
        |0x03 McErrNewCard      新規カード（カードが交換された）|
        |0x04 McErrNotFormat    フォーマットされていない        |
        +----+-----------------+--------------------------------+
        
[返り値]
        処理登録に成功すると 1を、以外は 0を返す。
        
[備考]
        非同期関数, 所要時間 4～76VSYNC
        
[関連項目]
        MemCardOpen(), MemCardReadFile(), MemCardWriteFile()

MemCardCallback                                                        [関数]
=============================================================================
                                                     完了コールバック関数定義
[形式]
        MemCB MemCardCallback (
        MemCB func
        )
        
[引数]
        func		コールバック関数
        
[解説]
        非同期関数の終了時に呼ばれるコールバックを定義する。
        非同期関数が終了した時に func が呼び出される。
        func に 0を指定した場合は、コールバックは発生しない。
        
        MemCBは以下のコールバック関数の型を表す
        	typedef void (*MemCB)( unsigned long cmds, unsigned long result )
        
        	cmds		終了した非同期関数
        	result		非同期関数の実行結果
        
        cmds値
        +----+---------------+----------------+
        |値   マクロ          関数            |
        |0x01 McFuncExist     MemCardExist    |
        |0x02 McFuncAccept    MemCardAccept   |
        |0x03 McFuncReadFile  MemCardReadFile |
        |0x04 McFuncWriteFile MemCardWriteFile|
        |0x05 McFuncReadData  MemCardReadData |
        |0x06 McFuncWriteData MemCardWriteData|
        +----+---------------+----------------+
        result値は各関数の項目を参照
        
[返り値]
        以前に設定されたコールバックのアドレス
        
[備考]
        同期関数, 即時終了する
        
[関連項目]
        MemCardAccept(), MemCardExit(), MemCardReadFile(),MemCardWriteFile(),
         MemCardReadData(), MemCardWriteData()

MemCardExist                                                           [関数]
=============================================================================
                                                       カードの接続状態を取得
[形式]
        long MemCardExist (
        long chan
        )
        
[引数]
        chan		ポート番号 + カード番号
        		ポート番号(Ａポート:0x00、Ｂポート:0x10)
        		カード番号(通常 0)
        
[解説]
        chanで指定したメモリカードの接続をテストする。
        MemCardAccept() と異なり、カードの存在のみのテストを行うため所要時間
        が少なくなっている。
        従って、未フォーマットの確認など、より詳細なカード情報が必要な場合は
        MemCardAccept() を実行する必要がある。
        また、カードが交換された場合も、MemCardOpen() などファイルアクセス関
        数の使用に先立ってMemCardAccept() を実行する必要がある。
        関数自体は非同期処理のため直ちに終了する。多重の処理登録は行なえない。
        処理の完了はMemCardSync() または完了コールバックにより確認する。
        所用時間は約4VSYNC。
        取得結果はMemCardSync() または完了コールバックの result 値として通知
        される。
        新規カード(McErrNewCard)の検出は、MemCardAccept() を行わない限り、何
        度も通知される。
        
        result値
        +----+-----------------+--------------------------------+
        |値   マクロ            状態                            |
        |0x00 McErrNone         接続されている                  |
        |0x01 McErrCardNotExist 接続されていない                |
        |0x02 McErrCardInvalid  不良カード                      |
        |0x03 McErrNewCard      新規カード（カードが交換された）|
        +----+-----------------+--------------------------------+
        
[返り値]
        処理登録に成功すると 1を、以外は 0を返す。
        
[備考]
        非同期関数, 所要時間 約 4VSYNC
        
[関連項目]
        MemCardAccept()

MemCardGetDirentry                                                     [関数]
=============================================================================
                                         メモリカードのディレクトリ情報を取得
[形式]
        long MemCardGetDirentry (
        long chan,
        char* name,
        struct DIRENTRY* dir,
        long* files,
        long ofs,
        long max
        )
        
[引数]
        chan		ポート番号 + カード番号
        		ポート番号(Ａポート:0x00、Ｂポート:0x10)
        		カード番号(通常 0)
        name		検索するファイル名( ワイルドカード指定 )
        dir		検索できたファイルに関する情報を格納するバッファ
        files		検索されたファイル数を格納するバッファ
        ofs		エントリのオフセット
        		検索されたファイル群の先頭から、いくつスキップして、バ
        		ッファに格納するかを指定する。( 0～14 )
        max		バッファに格納する最大エントリ数
        
[解説]
        ファイル名パターン name に該当するファイルを検索し、それに関する情報
        を dir に格納し、総検索数を files へ格納する。
        格納バッファはユーザアプリ側で用意する。
        
[返り値]
        result値
        +----+-----------------+------------------------+
        |値   マクロ            状態                    |
        |0x00 McErrNone         正常終了                |
        |0x01 McErrCardNotExist カードが接続されていない|
        |0x02 McErrCardInvalid  不良カード              |
        |0x04 McErrNotFormat    フォーマットされていない|
        +----+-----------------+------------------------+
        
[備考]
        同期関数
        ブロッキング時間: 正常終了の時は1～2VSYNC、それ以外は4～76VSYNC。
        ファイル名パターンにはワイルドカード文字として?（任意の1文字）*（任意
        長のすべての文字列）を使うことができる。*以降の文字指定は無視される。
        
[関連項目]
        DIRENTRY

MemCardInit                                                            [関数]
=============================================================================
                                                 メモリカードシステムの初期化
[形式]
        void MemCardInit (
        long val
        
[引数]
        val		ROM内のコントローラルーチン使用(0:なし、1:使用する)
        
[解説]
        メモリカードシステムを初期化する。以降MemCardStart()でシステムを稼働
        状態にすると、MemCardで始まる各関数が使用可能となる。
        ２重に実行してはならない。
        処理完了に60～70VSYNCを要する。libtap,libgunを利用する場合は、引数を0
        にする。InitPAD、InitGUN()、InitTAP()よりも後に実行すること。
        
[返り値]
        なし
        
[備考]
        同期関数, ブロッキング時間60～70VSYNC。クリティカルセクションには入ら
        ない。
        
[関連項目]
        MemCardEnd(), MemCardStart(), MemCardStop()

MemCardOpen                                                            [関数]
=============================================================================
                                                               ファイルを開く
[形式]
        long MemCardOpen (
        long chan,
        char* file,
        long flag
        )
        
[引数]
        chan		ポート番号 + カード番号
        		ポート番号(Ａポート:0x00、Ｂポート:0x10)
        		カード番号(通常 0)
        file		ファイル名
        flag		オープン形式指定
        		(リードオープン: O_RDONLY、ライトオープン: O_WRONLY)
        
[解説]
        指定形式でメモリカード上のファイルをオープンし、MemCardReadData(),
        MemCardWriteData() を使用可能とする。
        形式の併用( O_RDONLY|O_WRONLY )はできない。
        複数ファイルのオープンはできない。
        
[返り値]
        
        +----+-----------------+------------------------+
        |値   マクロ            状態                    |
        |0x00 McErrNone         正常終了                |
        |0x01 McErrCardNotExist カードが接続されていない|
        |0x02 McErrCardInvalid  不良カード              |
        |0z04 McErrNotFormat    フォーマットされていない|
        |0x05 McErrFileNotExist ファイルが見つからない  |
        +----+-----------------+------------------------+
        
[備考]
        同期関数
        ブロッキング時間: 正常終了のときは即時終了する、それ以外は4～76VSYNC。
        
[関連項目]
        MemCardReadData(), MemCardWriteData(), MemCardClose()

MemCardReadData                                                        [関数]
=============================================================================
                                             メモリカードからデータを読み込む
[形式]
        long MemCardReadData (
        long chan,
        unsigned long* adrs,
        long offset,
        long bytes
        )
        
[引数]
        chan		ポート番号 + カード番号
        		ポート番号(Ａポート:0x00、Ｂポート:0x10)
        		カード番号(通常 0)
        adrs		読み込むメインメモリアドレス
        offset		ファイルの先頭を 0とした読み込みオフセットバイト数
        bytes		読み込むバイト数(128の倍数)
        
[解説]
        メモリカード上のファイルからデータを読み込む。
        MemCardOpen() によって事前にファイルをオープンしておく必要がある。
        関数自体は非同期処理のため直ちに終了する。多重の処理登録は行なえない。

        実行結果はMemCardSync() または完了コールバックの result 値として通知
        される。
        bytesは128単位で指定する。128単位でない数値を指定した場合、処理登録は
        行われず、戻り値に 0を返し終了する。
        
        result値
        +----+-----------------+--------------------------------+
        |値   マクロ            状態                            |
        |0x00 McErrNone         正常終了                        |
        |0x01 McErrCardNotExist カードが接続されていない        |
        |0x02 McErrCardInvalid  通信エラー発生                  |
        |0x03 McErrNewCard      新規カード（カードが交換された）|
        +----+-----------------+--------------------------------+
        
[返り値]
        処理登録に成功すると 1を、以外は 0を返す。
        
[備考]
        非同期関数, 所要時間 オーバーヘッド 約1VSYNC ＋ 1ブロック(8192バイト
        )	あたり約130VSYNC
        
[関連項目]
        MemCardOpen()

MemCardSync                                                            [関数]
=============================================================================
                                                       非同期関数の終了を待つ
[形式]
        long MemCardSync (
        long mode,
        unsigned long* cmds,
        unsigned long* result
        )
        
[引数]
        mode		0: 非同期関数の終了を待つ
        		1: 現在の状態を調べて即座にリターンする
        cmds		終了した非同期関数
        result		非同期関数の実行結果
        
[解説]
        MemCardAccept(), MemCardReadFile()などの非同期関数の終了を待つ。
        cmdsには終了した非同期関数のコード番号が入る。
        
        cmds値
        +----+---------------+----------------+
        |値   マクロ          関数            |
        |0x01 McFuncExist     MemCardExist    |
        |0x02 McFuncAccept    MemCardAccept   |
        |0x03 McFuncReadFile  MemCardReadFile |
        |0x04 McFuncWriteFile MemCardWriteFile|
        |0x05 McFuncReadData  MemCardReadData |
        |0x06 McFuncWriteData MemCardWriteData|
        +----+---------------+----------------+
        result値は各関数の項目を参照
        
[返り値]
        
        +------+------------+
        |返り値 内容        |
        |0      処理中      |
        |1      終了        |
        |-1     登録処理なし|
        +------+------------+
        
[備考]
        同期関数, modeが 1の場合は即時終了する、 0の場合は各非同期関数の所要
        時間に準ずる。
        
[関連項目]
        MemCardAccept(), MemCardExit(), MemCardReadFile(),MemCardWriteFile(),
         MemCardReadData(), MemCardWriteData()

        bytesは128単位で指定する。128単位でない数値を指定した場合、処理登録は
        行われず、戻り値に 0を返し終了する。
        
        result値
        +----+-----------------+--------------------------------+
        |値   マクロ            状態                            |
        |0x00 McErrNone         正常終了                        |
        |0x01 McErrCardNotExist カードが接続されていない        |
        |0x02 McErrCardInvalid  通信エラー発生                  |
        |0x03 McErrNewCard      新規カード（カードが交換された）|
        +----+-----------------+--------------------------------+
        
[返り値]
        処理登録に成功すると 1を、以外は 0を返す。
        
[備考]
        非同期関数, 所要時間 オーバーヘッド 約1VSYNC ＋ 1ブロック(8192バイト)
        あたり約130VSYNC
        
[関連項目]
        MemCardOpen()
        

=============================================================================
MemCardWriteFile                                                       [関数]
=============================================================================
                                             メモリカードへファイルを書き込む
[形式]
        long MemCardWriteFile (
        long chan,
        char* file
        unsigned long* adrs,
        long offset,
        long bytes
        )
        
[引数]
        chan		ポート番号 + カード番号
        		ポート番号(Ａポート:0x00、Ｂポート:0x10)
        		カード番号(通常 0)
        file		ファイル名
        adrs		書き込むデータのあるメインメモリアドレス
        offset		ファイルの先頭を 0とした書き込みオフセットバイト数
        bytes		書き込むバイト数(128の倍数)
        
[解説]
        メモリカードにファイルを書き込む。
        新規ファイルの場合はMemCardCreateFile() で事前にファイルを作成してお
        く必要がある。
        関数自体は非同期処理のため直ちに終了する。多重の処理登録は行なえない。
        処理の完了はMemCardSync() または完了コールバックにより確認する。
        実行結果はMemCardSync() または完了コールバックの result 値として通知
        される。
        bytesは128単位で指定する。128単位でない数値を指定した場合、処理登録は
        行われず、戻り値に 0を返し終了する。
        
        result値
        +----+-----------------+--------------------------------+
        |値   マクロ            状態                            |
        |0x00 McErrNone         正常終了                        |
        |0x01 McErrCardNotExist カードが接続されていない        |
        |0x02 McErrCardInvalid  通信エラー発生                  |
        |0x03 McErrNewCard      新規カード（カードが交換された）|
        |0x05 McErrFileNotExist ファイルが見つからない          |
        +----+-----------------+--------------------------------+
        
[返り値]
        処理登録に成功すると 1を、以外は 0を返す。
        
[備考]
        非同期関数, 所要時間 オーバーヘッド 約4VSYNC ＋ 1ブロック(8192バイト)
        あたり約130VSYNC
        
[関連項目]
        MemCardCreateFile()
