DisableTAP                                                             [関数]
=============================================================================
                                             コントローラとの通信を中断する。
        
[形式]
        void DisableTAP ( void )
        
[引数]
        なし
        
[解説]
        コントローラとの通信を一時中断する。
        StopTAP()は、Vsync割り込みにより起動されているコントローラのハンドラ
        を削除するが、
        この関数は、単にフラグの操作だけでコントローラの通信をスキップする。
        
[返り値]
        なし
        
[備考]
        通常コントローラはVsyncの割り込みで通信を行うが、1/60secより長いタイ
        ミングでしかコントローラの状態を必要としない場合に利用される。
        
[関連項目]
        EnableTAP()

[形式]

[関連項目]
        DisableTAP()

InitTAP                                                                [関数]
=============================================================================
                                                         コントローラの初期化
        
[形式]
        void InitTAP (
        char *bufA,
        long  lenA,
        char *bugB,
        long  lenB
        )
        
[引数]
        bufA, bufB	受信データバッファ
        lenA, lenB	受信データバッファ長（バイト単位）
        
[解説]
        コントローラの受信データバッファを登録する。
        InitPAD(),InitGUN()との併用はできません。
        
[返り値]
        なし
        
[備考]
        受信バッファに格納されるデータ形式は以下の通りです。
         
        +------+------------------------------------+
        |バイト 内容                                |
        |0      受信結果  0x00:成功、0xff:失敗      |
        |1      上位4ビット：端末種別               |
        |        0x1:マウス                         |
        |        0x2:16ボタンアナログ               |
        |        0x3:ガンコントローラ               |
        |        0x4:16ボタン                       |
        |        0x5:アナログジョイスティック       |
        |        0x8:マルチタップ                   |
        |       下位4ビット：受信データバイト数／２ |
        +------+------------------------------------+
        	マウス
        +------+----------------------------------+
        |3      ボタン状態  1:リリース、0:プッシュ|
        |       第2ビット：右、  第3ビット：左    |
        |4      移動量  X方向 (-128～127)         |
        |5      移動量  Y方向 (-128～127)         |
        |6      移動量  Z方向 (-128～127)         |
        |7,8, - 移動量  ?方向 (-128～127)         |
        +------+----------------------------------+
        	16ボタンアナログ、アナログジョイスティック
        +---------+----------------------------------+
        |2,3       ボタン状態  1:リリース、0:プッシュ|
        |4,5,6,7,- アナログチャネル値                |
        +---------+----------------------------------+
        	ガンコントローラ、16ボタン
        +---+----------------------------------+
        |2,3 ボタン状態  1:リリース、0:プッシュ|
        +---+----------------------------------+
        	マルチタップの受信データ構造
        +-----+------------------------------------------+
        |0     受信結果 0x00:成功、0xff：失敗            |
        |1     0x80固定                                  |
        |2     コネクタ＃１ 受信結果  0:成功、0xff：失敗 |
        |3     同上 (端末種別<<4)｜(受信データバイト数/2)|
        |4-9   同上 受信データ                           |
        |10    コネクタ＃２ 受信結果  0:成功、0xff：失敗 |
        |11    同上 (端末種別<<4)｜(受信データバイト数/2)|
        |12-17 同上 受信データ                           |
        |18    コネクタ＃３ 受信結果  0:成功、0xff：失敗 |
        |19    同上 (端末種別<<4)｜(受信データバイト数/2)|
        |20-25 同上 受信データ                           |
        |26    コネクタ＃４ 受信結果  0:成功、0xff：失敗 |
        |27    同上 (端末種別<<4)｜(受信データバイト数/2)|
        |28-33 同上 受信データ                           |
        +-----+------------------------------------------+
        
        バッファの第1バイトの上位4ビットは端末種別、下位4ビットは端末からの受
        信データ（バッファの第3バイト以降に格納される。）のバイト数の半分の値、
        となります。ボタンやチャネルなどの物理的な配置や対応は各端末のドキュ
        メントを参照してください。
        
        *既存端末の型
        標準コントローラは16ボタン型端末です。
        弊社から商品化されているマウスは、XとYの２方向だけをサポートするマウ
        ス型端末。また株式会社ナムコ様の「ネジコン」は、4チャネル、つまりバッ
        ファ第1バイトの下位4ビットが3（（ボタン分2バイト＋4チャネル分4バイト）
        ÷２ ）、の16ボタンアナログ型端末です。
        
[関連項目]
        StartTAP(), StopTAP()

SendTAP                                                                [関数]
=============================================================================
                                                         コントローラの初期化
        
[形式]
        void SendTAP (
        char *bufA,
        long  lenA,
        char *bugB,
        long  lenB
        )
        
[引数]
        bufA, bufB	送信データバッファ
        lenA, lenB	送信データバッファ長（バイト単位）
        
[解説]
        コントローラの送信データバッファを登録する。
        垂直同期割り込み毎のコントローラとの通信時にバッファにセットされたタ
        ーゲットデバイスＩＤおよびデータが送信される。
        
        +------+-----------------------------------------------------+
        |バイト 内容                                                 |
        |０     バッファのデータが有効か無効かを指定するフラグ       |
        |       0x00で無効、0x01で有効。その他の値での動作は未定義。 |
        |１     コントローラＡのターゲットデバイスＩＤ               |
        |       (上位２ビットを利用、他のビットはシステム予約)       |
        |２～6  コントローラＡへの送信データ                         |
        |７     コントローラＢのターゲットデバイスＩＤ               |
        |8～12  コントローラＢへの送信データ                         |
        |13     コントローラＣのターゲットデバイスＩＤ               |
        |14～18 コントローラＣへの送信データ                         |
        |19     コントローラＤのターゲットデバイスＩＤ               |
        |20～24 コントローラＤへの送信データ                         |
        +------+-----------------------------------------------------+
        
        
[返り値]
        なし
        
[備考]
        振動装置搭載の新型アナログコントローラにおけるバッファ設定と注意事項
        は以下のとおり。
        
        +----------------------------+---------------------------------+
        |バイト                       内容                             |
        |ターゲットデバイスＩＤ       上位2bit：0x01                   |
        |                             下位6bit：動作未定義（振動装置） |
        |送信データ（第１バイト）     bit0:1 = 振動ON、 0 = 振動OFF    |
        |                             その他(bit7～1)：動作未定義      |
        |送信データ（第２バイト以降） 常に0x00。その他：動作未定義     |
        +----------------------------+---------------------------------+
         
        
        注意事項：
        振動装置へのオン操作はコントローラとの通信が行われ、次にコントローラ
        との通信が行われるまでの１垂直同期期間の間のみ有効。装置を動作させる
        期間中、垂直同期割り込み毎に送信データバッファにターゲットデバイスＩ
        Ｄおよび振動オンをセットしかつバッファを有効状態にし続けること。ター
        ゲットデバイスＩＤは上位２ビットが01のときに有効となるが、他のビット
        はシステム予約となっており、すべて0として下さい。また、送信データ第１
        バイトも下位１ビットが1のとき有効となり、他のビットは、0として下さい。

StartTAP                                                               [関数]
=============================================================================
                                                 コントローラの読みとりを開始
        
[形式]
        long StartTAP ( void )
        
[引数]
        なし
        
[解説]
        垂直帰線区間割り込みをトリガとして行なわれるコントローラの読みとりを
        開始する。
        
[返り値]
        成功すると1を、失敗すると0を返す
        
[備考]
        割り込みを許可した状態で返る。
        
[関連項目]
        InitTAP()
