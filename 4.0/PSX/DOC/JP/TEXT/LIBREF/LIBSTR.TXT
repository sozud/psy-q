ストリーミング ライブラリ (libcd)

 1 構造体
----------

=============================================================================
StHEADER                                                             [構造体]
=============================================================================
                                           ストリーミングフォーマットのヘッダ
        
[構造]
        typedef struct {
        		u_short id;
        		u_short type;
        		u_short secCount;
        		u_short nSectors;
        		u_long frameCount;
        		u_long frameSize;
        		u_short width;
        		u_short height;
        } StHEADER;
        
[メンバ]
        id		システム予約
        type		データタイプ（常に 0x0160)
        secCount	１フレーム中でのセクタオフセット
        nSectors	１フレームを構成するセクタ数
        frameCount	動画の絶対フレーム番号
        frameSize	動画データのサイズ（long word単位）
        width		動画の横サイズ
        height		動画の縦サイズ
        
[解説]
        動画セクタの header部分を記述したストラクチャ。
        StGetNext()でとってきたヘッダ部をこのストラクチャにキャストすると 構
        造体のメンバを通じて それぞれの情報にアクセスできる。
        
        それぞれの情報の詳細は STRセクタヘッダ 及び MDEC動画セクタヘッダ を参
        照のこと。

StCdInterrupt                                                          [関数]
=============================================================================
                                      CDROMからの割り込みハンドラ（内部関数）
        
[形式]
        void StCdInterrupt ( void )
        
[引数]
        なし
        
[解説]
        この関数は通常はStSetStream(),StStartEmulate()でCDROMの割り込みにフッ
        クされるため、ユーザプログラムで呼ぶ必要はない。
        ただし mode bit 1の２４ビットモードにすると割り込みでは、StCdInter 
        Flagがセットされるだけなのでユーザプログラムでこの関数を呼ぶ必要があ
        る。
        
[返り値]
        なし

StClearRing                                                            [関数]
=============================================================================
                                               リングバッファをフラッシュする
        
[形式]
        void StClearRing ( void )
        
[引数]
        なし
        
[解説]
        リングバッファをフラッシュする。トラックジャンプをする時などリングバ
        ッファをフラッシュすることで余計なフレームが出てしまうのを防ぐために
        有効。

StFreeRing                                                             [関数]
=============================================================================
                                                     リングバッファを解放する
        
[形式]
        unsigned long StFreeRing (
        unsigned long *base
        ）
[引数]
        base		解放する１FRAMEのユーザデータ領域の先頭アドレス
        
[解説]
        StGetNext()で取り出された領域はロックされる。StFreeRing()はこのロック
        された領域を解放する。
        解放する領域は base をユーザ領域の先頭アドレスとして与えられる１FRAME
        分の領域である。連動してセクタヘッダ領域も解放される。
        StGetNext()でロックした領域は使い終わったならば解放しないとリングバッ
        ファすぐあふれストリーミングは止まってしまう。
        
[返り値]
        解放に成功すると０失敗すると（例えばロックしていないのに解放しようと
        した）１を返す

StGetBackloc                                                           [関数]
=============================================================================
                     コマ落ち防止のためアクセスを行う場合のロケーションを得る
        
[形式]
        int StGetBackloc (
        CdlLOC *loc,
        )
        
[引数]
        loc		アクセスポイント
        
[解説]
        現在リングバッファに貯められている最新のロケーション情報とフレームID
        を返す。ここで得られるロケーション情報はリングバッファ溢れによるコマ
        飛ばしを抑制するためのアクセスを行う場合にアクセスのロケーションとし
        て使用される。
        使用例は \psx\sample\cd\movie\tuto3.c
        
        ただしStModeStream2モードの時のみ有効
        
[返り値]
        ストリーミング再開後にとるべき最初のフレームID
        StModeStream2モードでない場合エラーとして－１が返る
        
[備考]
        アクセスによるコマ落ち防止はXAオーディオを使用していない場合のみ可能

StGetNext                                                              [関数]
=============================================================================
                                                  １FRAME分のデータをとり出す
        
[形式]
        unsigned long StGetNext (
        unsigned long **addr,
        unsigned long **header
        )
        
[引数]
        addr		とり出された１FRAME分のデータのユーザデータ領域の先頭アドレス
        header 		とり出された１FRAME分のデータのセクタヘッダ領域の先頭アドレス
        
[解説]
        リングバッファにある１FRAME分のデータをとり出す。
        StGetNext()は呼ばれると次の１FRAME分のデータが、リングバッファ上に用
        意されていればユーザデータとセクタヘッダの先頭アドレスを引数にいれ０
        を返す。
        もし次の１FRAMEのデータが準備できないときは１を返す。
        とり出された領域はStFreeRing()が呼ばれるまでロックされるため新たなデ
        ータで壊されることはない。
        とり出された領域はアドレス的に連続でありデータの途中でリングバッファ
        の折り返りはない。
        
[返り値]
        １FRAME分のデータがリングバッファより取り出せれば０を用意されてなけれ
        ば１を返す
        
[関連項目]
        StFreeRing()

StNextStatus                                                           [関数]
=============================================================================
                                                     次のフレームの状態を返す
        
[形式]
        unsigned short StNextStatus (
        unsigned long **addr,
        unsigned long **header
        )
        
[引数]
        addr		次に取り出されるユーザデータ領域の先頭アドレス
        header		次に取り出されるデータのセクタヘッダ領域の先頭アドレス
        
[解説]
        リングバッファにある次の１フレームのステータスを得る。この関数を呼ん
        でも内部状態は変化しない。
        
        ステータスは以下の通り
         
        +----------+-----------------------------------------------+
        |ステータス 内容                                           |
        |StFREE     次のフレームはリングバッファ上にない           |
        |StCOMPLETE 次のフレームはリングバッファ上にそろった       |
        |StBUSY     次のフレームはリングバッファ上にそろいつつある |
        |StLOCK     次のフレームは処理中（つまりStGetNext()で      |
        |           引き上げているが、まだStFreeRing()していない） |
        +----------+-----------------------------------------------+
        
[返り値]
        次のフレームのステイタス

StRingStatus                                                           [関数]
=============================================================================
                                                   リングバッファの状態を返す
        
[形式]
        void StRingStatus (
        short *free_sectors,
        short *over_sectors
        )
        
[引数]
        free_sectors	リングバッファ上の未使用セクタ数を返す
        over_sectors	CDROMのデータを読み込んでいるセクタ位置と現在処理
        		しているセクタ位置の差分が返される
        
[解説]
        リングバッファの状態を引数で与えられる二つの変数に値を返すことでリポ
        ートする。
        
        第一引数の free_sectors はリングバッファ上でまだデータが入っていない
        未使用領域のセクタ数を返す。この値が大きいほどリングバッファに余裕が
        ある。
        
        第二引数の over_sectors はCDROMからデータを読み込んでいるセクタ位置か
        ら現在処理中のセクタ位置の差分である。この値が大きいほどリングバッフ
        ァ上に処理していないデータが多く存在することになる。
        
        free_sectors と over_sectors とを足すとリングバッファのサイズとほぼ等
        しくなる。感ぜんに一致しない場合があるのはリングバッファの最後の方は
        １フレーム分のデータが入りきらない場合途中で折り返すからである。
        
[返り値]
        なし

StSetChannel                                                           [関数]
=============================================================================
                                         ストリーミングのチャンネルを指定する
        
[形式]
        int StSetChannel (
        u_long ch
        ）
        
[引数]
        ch		ストリーミングチャンネル
        
[解説]
        ストリーミングライブラリにはSTRデータの一部だけを選択して再生するとい
        う機能がある。選択するデータはチャンネルにより識別される。
        チャンネルはSTRデータに入っておりオーサリングレベルでおこなわれる。
        StSetChannelはストリーミングで再生するチャンネルを設定する。
        チャンネルは、0から31までである。
        
[返り値]
        チャンネルが設定できれば０が返り失敗すれば１が返る

StSetEmulate                                                           [関数]
=============================================================================
                 ストリーミングのエミュレーションのためのパラメータを設定する
        
[形式]
        void StStartEmulate (
        unsigned long *addr,
        unsigned long mode,
        unsigned long start_frame,
        insigned long end_frame,
        int (*func1)(),
        int (*func2)()
        )
        
[引数]
        addr		エミュレーションデータの先頭アドレス
         		その他の引数はStSetStream()と同じ
        
[解説]
        エミュレーションのためのパラメータを設定する。
        エミュレーションとはメモリーにCDROMのデータを入れておき、実際のCDから
        はデータレディのタイミングだけをもらって、CDROMからではなくメモリーか
        らデータをひっぱってきてストリーミングを再生する機能である。
        もちろんメモリ容量には限りがあるため再生時間は数秒に限られるがCDROMエ
        ミュレータを使うよりも容易にエミュレーションをすることができる。
        あらかじめ addr にSTRフォーマットのデータをロードしておく必要がある。
        
[返り値]
        なし
        
[関連項目]
        StSetStream()

StSetMask                                                              [関数]
=============================================================================
                                       ストリーミングの再生をコントロールする
        
[形式]
        void StSetMask (
        u_long mask,
        u_long start,
        u_long end
        )
        
[引数]
        mask		ストリーミングを再生するかしないかのスイッチ
         		0:再生状態、1:停止状態
        start		StSetStream()のstart_frame
        end		StSetStream()のend_frame
        
[解説]
        ストリーミング再生を瞬間的に止めたり再開させたりするには、CDROMをポー
        ズしていてはメカ的なタイムラグがあり不可能である。
        StSetMask()を使えば mask の値をライブラリに設定することで、瞬間的にス
        トリーミング再生のON/OFFができる。
        start,end はStSetStream()のトリガフレームの値を再設定するものである。
        
[返り値]
        なし
        
[関連項目]
        StSetStream()

StSetRing                                                              [関数]
=============================================================================
                                                     リングバッファを設定する
        
[形式]
        void StSetRing (
        unsigned long  *ring_addr;
        unsigned long  ring_size
        )
        
[引数]
        ring_addr	リングバッファの先頭アドレス
        ring_size	リングバッファの大きさ（セクタ単位）
        
[解説]
        リングバッファを設定する。ring_addr で先頭アドレスを ring_size で大き
        さを設定する。
        ただし現状サポートされているCDROMのセクタはフォーム１のみ。よって１セ
        クタのデータ領域は2048byteである。領域の確保はメインプログラムで行な
        う。
        ストリーミングライブラリを使うには必ず最初に１回呼ぶ必要がある。
        
[返り値]
        なし
        
[関連項目]
        StUnSetRing()

StSetStream                                                            [関数]
=============================================================================
                                         ストリーミングのパラメータを設定する
        
[形式]
        void StSetStream (
        unsigned long mode,
        unsigned long start_frame,
        unsigned long end_frame,
        int (*func1)(),
        int (*func2)()
        )
        
[引数]
        mode		モードの設定
         		色モード指定 (16bit mode: 0、24bit mode:1)
        start_frame 	ストリーミングをスタートさせるFRAME
         		0 を指定するとフレーム番号にかかわらずスタート。
        end_frame	ストリーミングを終了するFRAME
         		0 を指定するとリングバッファの最後までデータが入ると自動的に終了、
        		十分大きな数を指定するとCDROMのデータの最後まで再生して終了。
        func1		1FRAME分のデータができる毎にコールバックされる関数のアドレス。
        		0 を指定するとコールバックされない。
        func2		ストリーミングが終了するとコールバックされる関数のアドレス。
        		0 を指定するとコールバックされない。
        
[解説]
        StSetStream()はストリーミングのためのパラメータをセットする。
        start_frame, end_frame で指定する frame 番号はSTRデータに書かれている
         frame 番号である。
        start_frame はストリーミングを再生させるトリガをかけるフレームのこと
        である。
        ストリーミングライブラリはこのトリガフレームがこない限り再生を始めな
        い。
        よってストリーミングデータの途中から再生をしたい場合は start_frame も
        １ではなく適正な値にセットしなければならない。
        ストリーミングのスタートポイントを厳密に定めなくてもよいならば0を指定
        することでどのフレームがきても再生するようにできる。
        end_frame は０を設定するとリングバッファに入り切る最大のFRAMEが入った
        ところで終了するのでリングバッファを大きくとり、メモリーから再生する
        時に便利。
        
[返り値]
        なし
        
[備考]
        ストリーミングのアプリケーションを正常にexitするにはストリーミングの
        終了は end_frame で指定しない方が望ましい。
        end_frame には0xffffffffを設定しておきアプリケーションのループ中で最
        適なexitポイントをコーディングすべきである。

StUnSetRing                                                            [関数]
=============================================================================
                             ストリーミングライブラリで使う割り込みを解放する
        
[形式]
        void StUnSetRing ( void )
        
[引数]
        なし
        
[解説]
        StSetRing()でフックされた2つの割り込み関数をはずし初期状態に戻す。
        2つの割り込み関数とは
                 CdDataCallback
                 CdReadyCallback
        のことである。
        ストリーミングを終了し ストリーミングライブラリを使用しない他のプログ
        ラムに移行する場合はこの関数を呼んで、割り込みのフックを初期状態に戻
        す必要がある。
        
[返り値]
        なし
        
[関連項目]
        StSetRing(),StSetStream()
