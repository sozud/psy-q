DslATV                                                               [構造体]
=============================================================================
                                                       オーディオアッテネータ
[構造]
        typedef struct {
        	u_char val0;
        	u_char val1;
        	u_char val2;
        	u_char val3;
        } DslATV;
        
[メンバ]
        val0		CD (L) → SPU (L) への減衰量
        val1		CD (L) → SPU (R) への減衰量
        val2		CD (R) → SPU (R) への減衰量
        val3		CD (R) → SPU (L) への減衰量
        
[解説]
        CDの音量を設定するための構造体。CDの音量はCD-DAおよびCD-XAの音量のこ
        とである。val0～val3の値は最小音量０から最大音量１２８を設定する。
        通常のステレオの音量を調整するためにはval0にＬチャンネル、val2にＲチ
        ャンネルの音量を指定し、val1、val3には０を指定する。
        
[備考]
        
[関連項目]

DsCommand                                                              [関数]
=============================================================================
                               プリミティブコマンドをコマンドキューに登録する
[形式]
        int DsCommand (
        u_char com,
        u_char* param,
        DslCB cbsync,
        int count
        )
        
[引数]
        com		コマンドコード
        param		コマンドに対する引数（u_char[ 4 ]）
        cbsync		コールバック関数のポインタ
        count		リトライ回数（0：リトライなし、-1：無限リトライ）
        
[解説]
        プリミティブコマンドをコマンドキューに登録する。登録されたコマンドは、
        実行可能であれば即座に実行されるが、既に他のコマンドが実行されている
        場合は登録のみ行われる。コマンドは全てバックグラウンドで実行される。
        コマンドの実行が失敗した場合はcountの回数だけリトライされ、count回リ
        トライしても成功しなかった場合はエラーとなる。count=0はリトライなしで、
        count=-1は無限回リトライである。
        コールバック関数は各コマンド毎に設定が可能で、コマンドが終了した（エ
        ラーになった）場合にキックされる。また、DsSync()によってコマンドの実
        行状況を獲得することができる。
        
[返り値]
        コマンドの発行が成功した場合はコマンドID（>0）が返される。失敗した場
        合は０。
        
[備考]
        
[関連項目]
        DsSync()

DsFlush                                                                [関数]
=============================================================================
                                               コマンドキューをフラッシュする
[形式]
        void DsFlush ( void )
        
[引数]
        なし
        
[解説]
        コマンドキューに登録されている全てのコマンドを削除する。実行中のコマ
        ンドがある場合、実行は最後まで行われるが結果は保存されずコールバック
        関数も呼び出されない。
        
[返り値]
        なし
        
[備考]
        関数呼びだし時に実行中のコマンドがある場合、そのコマンドは最後まで実
        行されるため、以降のコマンドの実行は待たされる（キューに登録される）。
        
[関連項目]

DsGetDiskType                                                          [関数]
=============================================================================
                                                               CDの種類を得る
[形式]
        int DsGetDiskType ( void )
        
[引数]
        なし
        
[解説]
        現在セットされているCDの種類を得る。得られる種類はPlayStation用ディス
        ク（ブラックディスク）かそれ以外のCDの２通り。
        本関数は、システムステータス（DsSystemStatus()で得られるステータス）
        がDslReadyになるまで処理をブロックする。
        
[返り値]
        DslCdromFormat		PlayStation用ディスク
        DslOtherFormat		それ以外のCD
        DslStatNoDisk		CDがセットされていない
        DslStatShellOpen	CDのカバーが開いている
        
[備考]
        デバッギングステーションでは、ISO9660規格のCD（CD-Rを含む）を
        DslCdromFormatと認識する。また、本関数はDTL-H2000およびDTL-H5000では
        正常に動作しない。
        
[関連項目]

DsGetSector                                                            [関数]
=============================================================================
                               セクタバッファのデータをメインメモリへ転送する
[形式]
        int DsGetSector (
        void* madr, 
        int size
        )
        
[引数]
        madr		転送先メインメモリアドレス
        size		転送サイズ（ロングワード）
        
[解説]
        セクタバッファ上のセクタデータをメインメモリ上に転送する。関数の実行
        は転送終了までブロックする。
        
[返り値]
        発行に成功すれば１を、失敗すれば０を返す。
        
[備考]
        セクタサイズはモードによって異なる。セクタバッファのデータは複数回に
        わけて異なるメモリ領域へ転送することもできる。セクタデータがバッファ
        に準備されてから、次のセクタデータが上書きされる前に読み出さないと、
        以前のセクタデータは失われる。
        関数のリターン時には転送は終了している。
        
[関連項目]
        DsDataCallback(),DsDataSync(),DsGetSector2()
        

=============================================================================
DsGetSector2                                                           [関数]
=============================================================================
             セクタバッファのデータをメインメモリに転送する（ノンブロック型）
[形式]
        int DsGetSector2 (
        void* madr,
        int size
        )
        
[引数]
        madr		転送先メインメモリアドレス
        size		転送サイズ（ロングワード）
        
[解説]
        セクタバッファ上のデータをメインメモリ上に転送する。転送はサイクルス
        チールモードで行われるため、転送中に割込みが入ることができる。本関数
        は転送を開始してリターンするノンブロック型であるため、転送の終了は
        DsDataSync()もしくはDsDataCallback()で監視する必要がある。
        なお、サイクルスチールモードでの転送中は、割込みは入ることができるが
        普通のプログラムはデータバスを使用できないため、バスを通してメモリな
        どにアクセスする命令があるとその時点で処理がブロックされる。
        
[返り値]
        実行に成功すれば１を、失敗すれば０を返す。
        
[備考]
        サイクルスチールモードでのデータ転送は、ブロックモード（DsGetSector()
        で使用されるモード）に比べて時間がかかる。
        
[関連項目]
        DsDataCallback(),DsDataSync(),DsGetSector()

DsPacket                                                               [関数]
=============================================================================
                                           一連のコマンド列をキューに登録する
[形式]
        int DsPacket (
        u_char mode,
        DslLOC* pos,
        u_char com,
        DslCB* cbsync,
        int count
        )
        
[引数]
        mode		動作モード
        pos		ターゲットポジション
        com		最後に実行されるコマンド
        cbsync		コマンドがすべて終了したときにキックされるコールバック関数
        count		リトライ回数（0：リトライなし、-1：無限リトライ）
        
[解説]
        データリード（再生）に関する一連のコマンドをキューに登録する。キュー
        に登録されるコマンドは以下の通り。
        
        DslPause
        DslSetmode		mode
        DslSetloc		pos
        comで指定されたコマンド
        
        comには以下のコマンドを指定することができる。
        
         ・DslPlay
         ・DslReadN
         ・DslReadS
         ・DslSeekP
         ・DslSeekL
        
        DslPlay、DslReadN、DslReadSを指定した場合はデータリード（再生）まで実
        行される。
        DslSeekP、DslSeekLを指定した場合は、シーク実行後にポーズ状態で終了す
        る。
        
        一連のコマンドのいずれかがエラーになった場合は、先頭のコマンドからリ
        トライされる。リトライする回数はcountで指定する。count=0の場合はリト
        ライなし、count=-1の場合は無限回リトライされる。count回リトライしても
        成功しなかった場合はエラーとなる。
        一連のコマンドが全て成功するかエラーとなった場合は、cbsyncで指定され
        たコールバック関数がキックされる。また、DsSync()によって実行状況を獲
        得することができる。
        
[返り値]
        登録した場合はコマンドID（>0）が返される。失敗した場合は０。
        
[備考]
        キューに一連のコマンドを登録するだけの空きがない場合はエラーとなる。
        
[関連項目]
        DsCommand()

DsPlay                                                                 [関数]
=============================================================================
                                                      CD-DAトラックを再生する
[形式]
        int DsPlay (
        int mode,
        int* tracks,
        int offset
        )
        
[引数]
        mode		モード
        tracks		演奏するトラックを指定した配列。０で終端していること
        offset		演奏を開始するtracksのインデックス
        
[解説]
        配列tracksで指定された複数のトラックをバックグラウンドに順に演奏する。
        配列の最後のトラックまで演奏したらモードに応じて繰り返し演奏するか、
        演奏を終了する。
        modeに指定できる値は次の通り。
         
        +----+------------------------------------------------------------+
        |mode 内容                                                        |
        |0    演奏を停止する。                                            |
        |1    tracksで指定されたトラックを順に演奏し、指定されたトラックを|
        |     すべて演奏したら、演奏を停止する。                          |
        |2    tracksで指定されたトラックを順に演奏し、指定されたトラックを|
        |     すべて演奏したら、最初に戻って繰り返し演奏する。            |
        |3    現在の演奏中のトラックに対応するtracksのインデックスを返す。|
        +----+------------------------------------------------------------+
        
[返り値]
        現在演奏中のトラック。これはトラック番号ではなく配列tracksのインデッ
        クスが返される。-1が返された場合は、演奏は終了していることを表す。
        
[備考]
        演奏はトラック単位で行われ、トラックの途中からの演奏や停止はできない。
        
[関連項目]

DsRead                                                                 [関数]
=============================================================================
                                                             データを読み込む
[形式]
        int DsRead (
        DslLOC* pos,
        int sectors,
        u_long* buf,
        int mode
        )
        
[引数]
        pos		データの開始位置
        sectors		読み込むセクタ数
        buf		データを格納するバッファの先頭アドレス
        mode		データを読み込む際の動作モード
        
[解説]
        CDのデータをメインメモリに読み込む。読み込みはセクタ単位で行われるた
        め、bufの大きさは１セクタ＝２０４８バイト（５１２ワード）の倍数でなけ
        ればならない。
        データの読み込み処理は関数の実行終了後バックグラウンドで行われる。関
        数の実行の成功がデータの読み出しの成功ではないことに注意。
        
[返り値]

DsStartReadySystem                                                     [関数]
=============================================================================
                                                 簡易レディシステムを開始する
[形式]
        int DsStartReadySystem (
        DslRCB func,
        int count
        )
        
[引数]
        func		コールバック関数のポインタ
        count		リトライ回数（-1：無限リトライ）
        
[解説]
        簡易レディシステムを開始する。簡易レディシステムが開始されると、
        DslDiskErrorが発生した場合に最後に発行されたコマンドによってリトライ
        が行われる。リトライの回数はcountで指定する。count=-1の場合は無限回リ
        トライとなる。リトライ回数はシステムスタート時からの総回数である。
        funcで指定されたコールバック関数は、通常はデータリードが成功したとき
        のみキックされる。エラーでキックされるのは、カバーが開けられた場合か
        リトライ回数を超えてエラーが発生した場合に限られる。
        
        リトライが行われた場合、再リードされるポジションはライブラリによって
        決定されるが、コールバック関数は前回呼び出された次のセクタからキック
        される。よって、コールバック関数の中でリトライを意識する必要はない。
        
[返り値]
        1：		成功
        0：		失敗（既にシステムが開始されている）
        
[備考]
        本関数は必ず対応するデータリード（再生）コマンドのコールバック内で実
        行する。それ以外の場所で実行した場合、エラーハンドリングシステムが破
        壊されることがある。
        
[関連項目]
        DsEndReadySystem()

DsSync                                                                 [関数]
=============================================================================
                                         プリミティブコマンドの終了を監視する
[形式]
        int DsSync (
        int id,
        u_char* result
        )
        
[引数]
        id		コマンドID
        result		結果格納バッファのポインタ（u_char[ 8 ]）
        
[解説]
        プリミティブコマンドの終了を監視する。呼び出された時点でのコマンドID
        に対応するコマンドの実行状況を返す。resultの値はDslCompleteもしくは

        	DslDiskError：	コマンドの実行は失敗した
        	DslNoIntr：	まだ実行されていない
        	DslNoResult：	実行は終了したが結果は既に抹消されている
        
[備考]
        コマンドの実行結果はある程度の個数まで保存されているが、それ以前のも
        のについては抹消される。保存される結果の最大数はマクロ定数
        DslMaxRESULTSに定義されている。
        
[関連項目]
