 1 関数

=============================================================================
InitGUN                                                                [関数]
=============================================================================
                                                             ガンを初期化する
        
[形式]
        void InitGUN ( 
        char *bufA, *bugB,
        long  lenA, lenB
        char *buf0,
        char *buf1,
        long len
        )
        
[引数]
        bufA, bufB	コントローラ受信データバッファ
        lenA, lenB	コントローラ受信データバッファ長（バイト単位）
        buf0,buf1	水平・垂直位置受信バッファ(バッファのサイズは、len*4+2 バイト必要)
        len		ガンによる１ Vsyncあたりの割り込み数(最大20)
        
[解説]
        コントローラの受信データバッファおよび水平・垂直位置受信バッファを登
        録する。
        ガンによる割り込みをトリガーとした、垂直および水平位置の取り込みをお
        こなう。
        InitPAD(),InitTAP()との併用はできません。
        ライブラリのバージョン4.0から、ガンの精度を上げるために割り込み処理内
        部でDMAと割り込みをブロックしています。1Vsyncあたりの割り込みの数を大
        きく設定しますと１回あたり1Hsyncの時間を消費しますので、この値は小さ
        めに設定してください。
        水平方向のカウンタの値は、システムクロックの値を返していますので、ピ
        クセル値を得るためには、水平方向の解像度に応じて下記の係数を乗算して
        ください。

        表1 システムクロック-ピクセルクロック変換表
        +------+--------------+--------+
        |モード 水平方向解像度 係数    |
        |NTSC:  256            0.158532|
        |       320            0.198166|
        |       384            0.226475|
        |       512            0.317065|
        |       640            0.396332|
        |PAL:   256            0.157086|
        |       320            0.196358|
        |       384            0.224409|
        |       512            0.314173|
        |       640            0.392717|
        +------+--------------+--------+
         [ピクセル値] = [係数]×[システムクロック値]＋[オフセット]
        	
        
[関連項目]
        InitPAD(),SelectGUN(),StartGUN(),StopGUN(),RemoveGUN()

RemoveGUN                                                              [関数]
=============================================================================
                                                               ガンを選択する
        
[形式]
        void RemoveGUN (
        )
        
[解説]
        InitGUN()で登録したガンドライバを取り除く。
        
[関連項目]
        InitGUN(),StartGUN(),StopGUN(),SelectGUN(),RemoveGUN()
        

=============================================================================
SelectGUN                                                              [関数]
=============================================================================
                                                               ガンを選択する
        
[形式]
        void SelectGUN (
        int ch,
        unsigned char mask
        )
        
[引数]
        ch		ガンのチャネル（0 または 1）
        mask		割り込みマスクの設定（0:割り込み禁止、1:割り込み許可）
        
[解説]
        ガンに対して割り込みマスクのオンオフを知らせる。
        同時に２つ以上のマスクの解除はできない。
        
[関連項目]
        InitGUN(),StartGUN(),StopGUN(),SelectGUN(),RemoveGUN()

=============================================================================
StartGUN                                                               [関数]
=============================================================================
                                                 コントローラの読みとりを開始
        
[形式]
        long StartGUN ( void )
        
[引数]
        なし
        
[解説]
        垂直帰線区間割り込みをトリガとして行なわれるコントローラの読みとりを
        開始する。
        
[返り値]
        成功すると1を、失敗すると0を返す
        
[備考]
        割り込みを許可した状態で返る。
        
[関連項目]
        InitGUN(),StopGUN(),SelectGUN(),RemoveGUN()

=============================================================================
StopGUN                                                                [関数]
=============================================================================
                                                 コントローラの読みとりを停止
        
[形式]
        void StopGUN ( void )
        
[引数]
        なし
        
[解説]
        コントローラの読みとりを停止する。割り込みは禁止しない。
        
[返り値]
        なし
        
[関連項目]
        InitGUN(),StartGUN(),SelectGUN(),RemoveGUN()
