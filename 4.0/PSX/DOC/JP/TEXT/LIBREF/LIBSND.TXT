=============================================================================
_SsFCALL                                                             [構造体]
=============================================================================
                        SsSeqOpenJ(), SsSepOpenJ() で参照する関数テーブルの型
        
[構造]
        typedef struct {
        		void (*noteon)();
        		void (*programchange)();
        		void (*pitchbend)();
        		void (*metaevent)();
        		void (*control[13])();
        		void (*ccentry[20])();
        } _SsFCALL;
        
[メンバ]
        それぞれの要素は 下位関数へのポインタ
        
        noteon			MIDI status data
        programchange
        pitchbend
        metaevent
        control
        ccentry
         
        control 第一配列		MIDI status data の control change の各イベント
        	CC_NUMBER		Control Changeを使う際に指定
        	CC_BANKCHANGE		Control Change 1番(Bank Change)
        	CC_DATAENTRY		Control Change 6番(Data Entry)
        	CC_MAINVOL		Control Change 7番(Main Volume)
        	CC_PANPOT		Control Change 10番(Pan Pot)
        	CC_EXPRESSION		Control Change 11番(Expression)
        	CC_DAMPER		Control Change 64番(Damper pedal)
        	CC_NRPN1		Control Change 98番(NRPN)
        	CC_NRPN2		Control Change 99番(NRPN)
        	CC_RPN1			Control Change 100番(RPN)
        	CC_RPN2			Control Change 101番(RPN)
        	CC_EXTERNAL		Control Change 91番(External Effect Depth)
        	CC_RESETALL		Control Change 121番(Reset All)
        
        ccentry 第一配列		nrpn, rpn data のentry イベント
         			各イベントの詳細は、概要をご覧ください。
        	DE_PRIORITY		priority
        	DE_MODE			mode
        	DE_LIMITL		limit low
        	DE_LIMITH		limit high
        	DE_ADSR_AR_L		ADSR (AR-L)
        	DE_ADSR_AR_E		ADSR (AR-E)
        	DE_ADSR_DR		ADSR (DR)
        	DE_ADSR_SL		ADSR(SL)
        	DE_ADSR_SR_L		ADSR(SR-L)
        	DE_ADSR_SR_E		ADSR(SR-E)
        	DE_ADSR_RR_L		ADSR(RR-L)
        	DE_ADSR_RR_E		ADSR(RR-E)
        	DE_ADSR_SR		ADSR(SR)
        	DE_VIB_TIME		vibrate time (no support)
        	DE_PORTA_DEPTH		portamento depth (no support)
        	DE_REV_TYPE		reverb type
        	DE_REV_DEPTH		reverb depth
        	DE_ECHO_FB		echo feed back
        	DE_ECHO_DELAY		echo feed delay
        	DE_DELAY		delay time
        
[解説]
        SsSeqPlay(), SsSepPlay()は MIDI の status data を解析して下位関数を呼
        び出している。この下位関数はかなりの数にのぼり、1 つのアプリケーショ
        ンでは全ての下位関数を使わない場合がほとんどである。これらの下位関数
        群は、SsSeqOpen(), SsSepOpen() を CALL することでセットされる。
        
        そこで、不要な下位関数をリンクしないことでコードを小さくするために 
        SsSeqOpenJ(),SsSepOpenJ()という、それぞれSsSeqOpen(),SsSepOpen()コン
        パチで下位関数をジャンプテーブル化し、必要な関数群をユーザが設定出来
        るようにした。
        
        _SsFCALLは、この関数テーブルを定義した構造体である。それぞれの要素に
        適切な下位関数のポインタを入れることで、その関数はリンクされる。逆に
        ポインタを入れず extern宣言もしないことでリンクを切ることができる。た
        だしポインタのない関数が呼ばれた場合は、BUS ERRORが発生するので注意が
        必要である。これは下位関数の頭に dmy をつけたダミー関数を設定すること
        で回避することが出来る。
        
[関連項目]
        SsSeqOpen(), SsSepOpen(), SsSeqOpenJ(), SsSepOpenJ()

VabHdr                                                               [構造体]
=============================================================================
                                                                 バンクヘッダ
        
[構造]
        struct VabHdr {
        		long form;
        		long ver;
        		long id;
        		unsighned long fsize;
        		unsigned short reserved0;
        		unsigned short ps;
        		unsigned short ts;
        		unsigned short vs;
        		unsigned char mvol;
        		unsigned char pan;
        		unsigned char attr1;
        		unsigned char attr2;
        		unsigned long reserved1;
        };
        
[メンバ]
        form		フォーマットネーム (常に VABp)
        ver		フォーマットバージョン番号
        id		バンク (VAB) 番号
        fsize		バンクファイルサイズ
        reserved0	システム予約
        ps		バンクに含まれる全プログラム数
        ts		バンクに含まれる全 VAG 属性セット数
        vs		バンクにまれる VAG 数
        mvol		マスタボリューム
        pan		マスタパンレベル
        attr1		ユーザ定義可能なバンク属性１
        attr2		ユーザ定義可能なバンク属性２
        
[解説]
        VAB バンクヘッダは、実行時に扱われる音源データセットのファイルサイズ、
        含まれる音源の数などの情報が含まれている。
        
        SsVabOpenHead()およびSsVabTransBody() 関数が呼ばれたときにシステムに
        読み込まれ、SPUのローカルメモリに波形データが展開される。また、ボイス
        アロケーション時にボリューム設定やパンニング設定などが参照される。
        
        VAB、プログラム、VAG の各ヘッダ情報は、ユーザが実行時に変更することも
        可能で、変更した属性値は次のキーオン時からボイスアロケーションに反映
        される。

VagAtr                                                               [構造体]
=============================================================================
                                                                   波形ヘッダ
        
[構造]
        struct VagAtr {
        		unsigned char prior;
        		unsigned char mode;
        		unsigned char vol;
        		unsigned char pan;
        		unsigned char center;
        		unsigned char shift;
        		unsigned char min;
        		unsigned char max;
        		unsigned char vibW;
        		unsigned char vibT;
        		unsigned char porW;
        		unsigned char porT;
        		unsigned char pbmin;
        		unsigned char pbmax;
        		unsigned char reserved1;
        		unsigned short reserved2;
        		unsigned short adsr1;
        		unsigned short adsr2;
        		short prog;
        		short vag;
        		short reserved [4];
        };
        
[メンバ]
        prior		優先度（0～15）
        mode		音源モード
        vol		ボリューム（0～127, 0:min, 127:max）
        pan		パンポット (0～127, 0:left,63:center,127:right)
        center		センターノート (0～127)
        shift		ピッチ補整（0～99, cent 単位）
        min		最小ノートリミット
        max		最大ノートリミット
        vibW		ビブラート幅（0 ～ 127, 127 で一オクターブ）
        vibT		ビブラートの１周期の時間（tick 単位）
        porW		ポルタメント幅
        porT		ポルタメント持続時間（tick 単位）
        pbmin		最小ピッチベンドリミット
        pbmax		最大ピッチベンドリミット
        reseaved1	システム予約
        reseaved2	システム予約
        adsr1		ADSR 設定値 (その１)
        adsr2		ADSR 設定値 (その２)
        prog		この VAG 属性が含まれる親プログラム
        vag		この VAG 属性が利用する VAG の ID 番号
        reserved [0..3]	システム予約

_SsContBankChange                                                      [関数]
=============================================================================
                                             SsSeqOpen(SsSepOpen)の下位関数群
        
[形式]
        void _SsContBankChange(
        short num1, 
        short num2
        )
        
[引数]
        num1		SEQ/SEP アクセスナンバー
        num2		SEP データ内の SEQ ナンバー

        _SsSetControlChange と併せてこの下位関数を呼び出す必要がある。

        SsSeqOpenJ(), SsSepOpenJ()

SsSeqCalledTbyT                                                        [関数]
=============================================================================
                             1Tick毎に呼ばれ、SEQ/SEPデータを解釈し演奏を行う
        
[形式]
        void SsSeqCalledTbyT (void)
        
[引数]
        なし
        
[解説]
        1 Tick毎にこの関数が呼ばれ、SEQ / SEPデータを解釈し演奏を行う。
        TickはSsSetTickMode() によって設定されるが、このTickはSEQ / SEPデータ
        で指定されている速度、及び分解能には依存せず、単にサウンドシステム内
        部の分解能を規定する。
        SsSetTickMode() での指定で、tick_modeがSS_TICK60, SS_TICK120,
        SS_TICK240,及び任意の分解能の指定を行った場合は、 SS_NOTICKを指定した
        場合はユーザ・プログラム側で垂直帰線（Vsync()）のタイミング（1/60秒間
        隔{NTSC}あるいは 1/50秒間隔{PAL}）あるいは指定した間隔（SS_NOTICKと「
        ビットor」で指定した間隔）でこの関数を呼び出す必要がある。SS_NOTICK以
        外を指定した場合は指定された分解能でサウンドシステム側がこの関数を呼
        び出す。
        SsSetTickCallback() で Tick Callback関数が指定された場合で SEQ/SEPデ
        ータを解釈し、演奏を行わせたい場合には、指定したTick Callback関数の中
        でこの関数を呼び出す必要がある。
        
[返り値]
        なし
        
[関連項目]
        SsSetTickMode(), SsSetTickCallback()

[形式]
        typedef void (*SsSeqMarkCallbackProc)(short, short, short);

        short access_num,

        SsMarkCallbackProc proc
        )
        
[引数]
        access_num	SEQ/SEPアクセスナンバー
        seq_num		SEPデータ内のSEQナンバー

        /* Callback関数定義*/
        SsMarkCallbackProc proc (short ac_no, short tr_no,short data)

         	:
        }
        /* SEQをオープン*/
        short seq_a_num = SsSeqOpen (addr, vab_id);
        /* Callback関数をセット*/
        SsSetMarkCallback (seq_a_num, 0, (SsMarkCallbackProc) proc);

SsSetTableSize                                                         [関数]
=============================================================================
                                          SEQ/SEPデータ属性テーブル領域の指定
        
[形式]
        void SsSetTableSize (
        char *table,
        short s_max,
        short t_max
        )
        
[引数]
        table		SEQ/SEPデータ属性テーブル領域変数
        s_max		オープンするSEQ/SEPデータの最大数
        t_max		SEPに含まれるSEQ数
        
[解説]
        SEQ/SEPデータの属性テーブルの領域をライブラリ側に指定する。ライブラリ

        用して table の領域を確保する。

        1回のみ呼ばれるように設定する。複数回呼ばれた際の動作は不定である。

=============================================================================
SsSetTickMode                                                          [関数]
=============================================================================
                                                             Tickの設定を行う
        
[形式]
        void SsSetTickMode (
        long tick_mode
        )
        
[引数]
        tick_mode		Tickモード
        
[解説]
        Tick の分解能を設定する。SsSeqOpen() またはSsSepOpen() が呼ばれる前、
        かつSsStart() の前に設定を行なうこと。なお、複数回呼ばれた際の動作は
        保証しない。
        Tick ModeはSEQ/SEPデータで指定されている速度、及び分解能には依存せず、
        単にサウンドシステム内部の分解能を規定する。
        Tick Modeの中で、SS_TICK50, SS_TICK60, SS_TICKVSYNC はSetVideoMode()
        の指定によりその動作が異なる(以下個別のTickModeの項を参照)。
         
        +-+------------------------+---------------------------------------+
        |  tick_mode                動作                                   |
        |1 SS_TICK50                Tick = 1/50秒                          |
        |                           (SsSeqCalledTbyT() 自動呼び出し)       |
        |2 SS_TICK60                Tick = 1/60秒                          |
        |                           (SsSeqCalledTbyT() 自動呼び出し)       |
        |3 SS_TICKVSYNC             Tick =垂直帰線の分解能                 |
        |                           (SsSeqCalledTbyT() 自動呼び出し)       |
        |4 SS_TICK120               Tick = 1/120秒                         |
        |                           (SsSeqCalledTbyT() 自動呼び出し)       |
        |5 SS_TICK240               Tick = 1/240秒                         |
        |                           (SsSeqCalledTbyT() 自動呼び出し)       |
        |6 SS_NOTICK                Tick 6= 1/60秒                         |
        |                           (SsSeqCallTbyT() は自動では呼ばれない) |
        |7 任意の分解能             Tick = (1/tick_mode)秒                 |
        |                           (SsSeqCalledTbyT() 自動呼び出し)       |
        |8 (任意の分解能|SS_NOTICK) Tick =(1/tick_mode)秒                  |
        |                           (SsSeqCallTbyT() は自動では呼ばれない) |
        +-+------------------------+---------------------------------------+
        
        1. tick_mode = SS_TICK50
                1/50秒が1 Tickとなり、この分解能でSEQファイルが解釈され演奏さ
                れる。
                SetVideoMode()で指定したモードがMODE_PALの場合はOSのルートカ
                ウンタ管理サービスRCntCNT3をこの分解能で利用し、よって、PALの
                垂直帰線のタイミング(1/50秒)が1 Tickとなり、この分解能でSEQフ
                ァイルが解釈され演奏される。
                MODE_NTSCの場合はOSのルートカウンタ管理サービスRCntCNT2でこの
                分解能を生成してSEQファイルが解釈され演奏される。よって、プロ
                グラム中でRCntCNT2はこの分解能以外では使用できない。
        
        2. tick_mode = SS_TICK60
                1/60秒が1 Tickとなり、この分解能でSEQファイルが解釈され演奏さ
                れる。
                SetVideoMode()で指定したモードがMODE_NTSCの場合はOSのルートカ
                ウンタ管理サービスRCntCNT3をこの分解能で利用し、よって、NTSC
                の垂直帰線のタイミング(1/60秒)が1 Tickとなり、この分解能でSEQ
                ファイルが解釈され演奏される。
                MODE_PALの場合はOSのルートカウンタ管理サービスRCntCNT2でこの
                分解能を生成してSEQファイルが解釈され演奏される。よって、プロ
                グラム中でRCntCNT2はこの分解能以外では使用できない。
        
        3. tick_mode = SS_TICKVSYNC
                垂直帰線のタイミングが1 Tickとなり、この分解能でSEQファイルが
                解釈され演奏される。
                SetVideoMode()で指定したモードがMODE_NTSCの場合はNTSCの垂直帰
                線のタイミング(1/60秒)が分解能となり、指定したモードが
                MODE_PALの場合はPALの垂直帰線のタイミング(1/50秒)が分解能とな
                り、SEQファイルが解釈され演奏される。
                どちらもOSのルートカウンタ管理サービスRCntCNT3をこの分解能の
                ために利用する。
        
        4. tick_mode = SS_TICK120
                1/120秒が1 Tickとなり、この分解能でSEQファイルが解釈され演奏
                される。
                ただし、この場合OSのルートカウンタ管理サービスRCntCNT2をこの
                分解能で利用するため、プログラム中でRCntCNT2はこの分解能以外
                では使用できない。
        
        5. tick_mode = SS_TICK240
                1/240秒が1 Tickとなり、この分解能でSEQファイルが解釈され演奏
                される。
                ただし、この場合OSのルートカウンタ管理サービスRCntCNT2をこの
                分解能で利用するため、プログラム中でRCntCNT2はこの分解能以外
                では使用できない。
        
        6. tick_mode = SS_NOTICK
                垂直帰線のタイミング(1/60秒)が1 Tickとなり、この分解能でSEQフ
                ァイルが解釈され演奏される。
                ただしTick Callback 関数は自動では呼ばれないため、ユーザ・プ
                ログラムの中で垂直帰線のタイミングでTick Callback関数（例えば
                SsSeqCalledTbyT ()）を呼ぶ必要がある。
        
        7. tick_mode =任意の分解能
                60～240の間で任意の値を引数に設定することにより、1Tickを(1/
                tick_mode)秒に設定し、この分解能でSEQファイルが解釈され演奏さ
                れる。
                ただし、この場合OSのルートカウンタ管理サービスRCntCNT2をこの
                分解能で利用するため、プログラム中ではRCntCNT2をこの分解能以
                外では使用できない。
        
        8. tick_mode = (任意の分解能|SS_NOTICK)
                60～240の間で任意の値を引数に設定することにより、1Tickを(1/
                tick_mode)秒に設定し、この分解能でSEQファイルが解釈され演奏さ
                れる。
                ただし、引数にSS_NOTICKとの「ビットor」を指定していることによ
                りTick Callback 関数は自動では呼ばれないため、ユーザはプログ
                ラムの中で指定したタイミングでTick Callback関数（例えば
                SsSeqCalledTbyT()）を呼ぶ必要がある。
        
[返り値]
        なし
        
[関連項目]
        SsStart(), SsSeqCalledTbyT(), SetVideoMode(), SsSetTickCallback()

SsUtSetReverbType                                                      [関数]

        )

[解説]
        リバーブタイプを設定する。
         
        +--------------------+--------------+----------+--------+
        |type                 モード         Delay time Feedback|
        |SS_REV_TYPE_OFF      off            ×         ×      |
        |SS_REV_TYPE_ROOM     ルーム         ×         ×      |
        |SS_REV_TYPE_STUDIO_A スタジオ(小)   ×         ×      |
        |SS_REV_TYPE_STUDIO_B スタジオ(中)   ×         ×      |
        |SS_REV_TYPE_STUDIO_C スタジオ(大)   ×         ×      |
        |SS_REV_TYPE_HALL     ホール         ×         ×      |
        |SS_REV_TYPE_SPACE    スペースエコー ×         ×      |
        |SS_REV_TYPE_ECHO     エコー         ○         ○      |
        |SS_REV_TYPE_DELAY    ディレイ       ○         ○      |
        |SS_REV_TYPE_PIPE     パイプエコー   ×         ×      |
        +--------------------+--------------+----------+--------+

        SsUtSetReverbType(SS_REV...);

        SsUtSetReverbDepth(64,64);
        
        番号とタイプの対応は上記の通り。

        設定が正しく行なわれなかった場合は-1を返す。

        SsVabTransBody(), SsVabTransBodyPartly()

=============================================================================
SsVabOpenHeadSticky                                                    [関数]
=============================================================================
                                  音源ヘッダリストを認識する(.VB転送番地指定)
        
[形式]
        short SsVabOpenHeadSticky (
        unsigned char *addr,
        short vabid,
        unsigned long sbaddr
        )
        
[引数]
        addr		VABデータのメインメモリ内の先頭アドレス
        vabid		希望するVABIDあるいは-1
        sbaddr		VabBody(.VB)をサウンドバッファに転送する際のサウンド
        		バッファ内の先頭アドレス
        
[解説]
        メインメモリ上の音源ヘッダリストを認識する。
        メインメモリ上のテーブルをサウンドライブラリで利用可能な状態にする。
        VABIDを指定してオープンする。VABIDが-1の場合、空いているVABID(0～15)
        を探し、割り付ける。
        sbaddr にはVabBody(.VB)をサウンドバッファに転送する際のサウンドバッフ
        ァ内の先頭アドレスを0x1010～0x7ffffの範囲で指定する。その際、.VBのサ
        イズを考慮し、リバーブワークエリアのとる領域には転送されないようアド
        レスを指定しなければならない。
        後に呼ばれるSsVabTransBody(), SsVabTransBodyPartly() では、sbaddr か
        らVabBodyを転送する。
        本関数を使う場合は、サウンドバッファのメモリ管理の整合性が取れなくな
        るため、他のVAB(.VH)をオープンする際にSsVabOpenHead() は使用できない。
        全て本関数で.VHのオープンを行う。
        
[返り値]
        VAB識別番号
        失敗したら-1を返す。
        
[関連項目]
        SsVabOpenHead(), SsVabTransBody(), SsVabTransBodyPartly()

SsVabTransBodyPartly                                                   [関数]
=============================================================================
                                                     音源データを分割転送する
        
[形式]
        short SsVabTransBodyPartly (
        unsigned char *addr,
        unsigned long bufsize,
        short vabid
        )
        
[引数]
        addr		分割転送のためのバッファの先頭アドレス
        bufsize		バッファの大きさ
        vabid		VABID
        
[解説]
        SsVabOpenHead() でヘッダリストを認識させたメインメモリ上の音源データ
        (VABボディ)をSPUサウンドバッファへ転送を開始する。
        addr から始まる大きさ bufsize の領域に音源データ(VABボディ)の1部分を
        逐次コピーしつつ連続的にSsVabTransBodyPartly() を呼ぶことにより、メイ
        ンメモリ上の限られた領域の使用のみで、サウンドバッファ内において連続
        した領域に転送が行える。
        転送の連続性を確保するため、各転送においてSsVabTransBodyPartly() の呼
        びだし後、SsVabTransCompleted() により転送が終了しているかを確認する
        必要がある。
        
[返り値]
        SsVabOpenHead() より受け継がれた音源データ(VABボディ)の大きさが全て転
        送できていない場合は-2が、失敗した場合は -1が、成功すると与えられた 
        vabid を返す。
        
[関連項目]
        SsVabOpenHead(), SsVabTransBody()

        short SsVabTransCompleted (

        )

=============================================================================
SsVabTransfer                                                          [関数]
=============================================================================
                                                   音源データを認識、転送する
        
[形式]
        short SsVabTransfer (
        unsigned char *vh_addr,
        unsigned char *vb_addr, 
        short vabid,
        short i_flag
        )
        
[引数]
        vh_addr		VHデータの先頭アドレス
        vb_addr		VBデータの先頭アドレス
        vabid		VAB認識番号
        i_flag		= SS_IMMEDIATE ...すぐ返り値(VAB認識番号)を返す
        		= SS_WAIT_COMPLETED ... 転送が終了するまで待つ
        
[解説]
        vh_addrで指定された音源ヘッダリスト (VH データ) を認識し、vb_addrで指
        定された音源データ(VBデータ) をSPUサウンドバッファへ転送する。vabidに
        VAB認識番号を指定する。vabidが -1の場合、空いているVAB認識番号 (0-15)
         を探して割り付ける。i_flagにて本関数が転送終了するまで待つか、転送開
        始後すぐに抜ける（その後SsVabTransCompletedでチェックする）かを指定す
        る。
        
[返り値]
        VAB識別番号
        失敗した場合には、その要因によって以下の値を返す。
        	-1	VAB ID割り当て不可能or VH異常
        	-2	VB異常
        	-3以上	その他の異常
        
[関連項目]
        SsVabOpenHead(), SsVabTransBodyPartly(), SsVabTransCompleted()

SsVoKeyOff                                                             [関数]
=============================================================================
                                                                   キー・オフ
        
[形式]
        void SsVoKeyOff (
        long vab_pro,
        long pitch
        )
        
[引数]
        vab_pro		VABデータid，プログラム番号
        pitch		ピッチ
        
[解説]
        vab_pro の下位16 bit中、上位8 bitはvab_id、下位8 bitはプログラム番号
        を指定する。
        pitch の下位16 bit中、上位8 bitは、MIDI規格の鍵番号を指定し、さらに細
        かいピッチを指定したい場合は pitch の下位8 bitに1/128半音単位で指定す
        る。
        この vab_pro と pitch で指定された音をキーオフする。
        
[返り値]
        なし
        
[関連項目]
        SsVoKeyOn()
