bmp2tim

↑1 概要

WindowsイメージデータをPlayStationの画像データファイルに変換します。
ここでは、1994/Apr/27付けのVersion 2.1に関する内容を記述しています。

↑2 使い方

bmp2tim [options] BMP-files ...

Windows3.0のBMP形式のイメージデータファイルを与えると、PlayStationのテクスチャファイルであるTIMファイル(*.tim)を生成します。引数にワイルドカードが使用できます。複数のファイルを与え一度に変換することも可能です。ファイル名の".bmp"は省略可能です。

↑3 オプション

-o output-file

出力ファイル名を指定します。デフォルトでは入力ファイルの拡張子を".tim"に変換したものを現在のディレクトリに生成します。

-org x y

VRAM上でのイメージの原点を指定します。デフォルトは(0, 0)です。

-plt x y

VRAM上でのカラーパレット(CLUT)の位置を指定します。x yどちらかに負の数を指定すると、4または8bitのTIMであってもCLUTを生成しません。デフォルトは(0, 480)です。

-t

(0 0 0)以外の色に対して、透明制御ビットをONにします。(0 0 0)以外の色が半透明色になります。デフォルトでは、すべての色は不透明になります。

-b

(0 0 0)に対して、透明制御ビットをOFFにします。(0 0 0)は透明になります。デフォルトでは、(0 0 0)は黒として表示されます。

-v

変換に関する詳細な情報を表示します。

↑4 前バージョンからの主な変更点

  • CLUTなしのTIMファイルを生成できるようになりました(-pltオプション)。

↑5 制約

現バージョンは以下の制約を持っています。
  • BMP圧縮形式には対応していません。
  • 白黒(1bit)BMPには対応していません。
