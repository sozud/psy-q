tmd2pmd

↑1 概要

TMD フォーマットのモデリングデータを、PMD フォーマットに変換します。
DOS版とSGI版があります。ここでは、1995/Oct/16付けの Version 1.14 に関する内容を記述しています。

↑2 使い方

tmd2pmd [options] TMD-files ...

PlayStation の 3D モデリングデータ形式である TMD フォーマットのファイル(*.tmd)を与えると、高速版モデリングデータ形式であるPMD ファイル(*.pmd)を生成します。
引数にワイルドカードが使用できます。複数のファイルを与え一度に変換することも可能です。この場合、与えられたそれぞれのファイル名について、拡張子を ".pmd" に変換したファイルが、現在のディレクトリに生成されます。

↑3 オプション

-o output-file

出力ファイル名を指定します。デフォルトでは入力ファイルの拡張子を".pmd"に変換したものを現在のディレクトリに生成します。入力ファイルを２個以上与えた場合、このオプションを使用することはできません。ワイルドカード指定で、２個以上のファイルが対象となる場合にも、このオプションはエラーとなります。

-h

指定できるオプションの一覧と、簡単な使い方を表示します。

-v

変換に関する詳細な情報を表示します。

-s

生成される PMD ファイル内の頂点データを共有頂点モードにします。

+s

生成される PMD ファイル内の頂点データを独立頂点モードにします。(デフォルト)

-l

生成される PMD ファイル内の光源計算フラグを ON にします。

+l

生成される PMD ファイル内の光源計算フラグを OFF にします。(デフォルト)

-b

生成される PMD ファイル内の Back clip フラグを ON にします。(デフォルト)

+b

生成される PMD ファイル内の Back clip フラグを OFF にします。

-notge

生成される PMD ファイル内の全てのパケットの TGE フラグを OFFにします。

+notge

生成される PMD ファイル内のパケットの TGE フラグは、入力 TMD ファイルのものがコピーされます。(デフォルト)

↑4 備考

TMD ファイルに含まれる、光源計算ありのテクスチャポリゴンには、色に関する情報が含まれていません。tmd2pmd では、このようなデータはR, G, B ともに明るさ 0x80 として、PMD ファイルを生成します。
