mimesort

↑1 概要

TMD ファイルの頂点情報をソートします。mimefilt 後の MIMe 用差分ファイルを小さくし、MIMe アニメーションを高速化するために用います。
DOS版とSGI版があります。ここでは、1996/Jun/13付けの Version 2.1 に関する内容を記述しています。

↑2 使い方

mimesort [options] [base-model.tmd model1.tmd [model2.tmd [model3.tmd ...]]]

mimefilt で生成される MIMe 用差分ファイルが小さくなるようにTMD ファイル中の頂点情報をソートします。これにより、MIMe アニメーションに必要なランタイムの計算時間も軽減されます。
mimesort は、頂点情報の順番を入れ換えるので、mimefilt にかけるすべてのファイルを同時に mimesort にかける必要があります。一部のファイルだけを mimesort にかけた場合には、TMD ファイル間で頂点の対応が取れなくなり、正しい差分ファイルが作成できません。
引数にワイルドカードが使用できます。
変形モデルファイル（base-model を除く model の TMD ファイル) は最大32個まで指定することができます。ただし、変形モデルファイルが 14個を越えた場合、15番目以降に指定されたモデルはソートの際に用いられません。1番目から14番目までに指定されたモデルのみをソートのための情報として用いるため、15番目以降のモデルについては、頂点情報の並べ替えだけが行なわれます。すなわち、15番目以降の変形モデルファイルは、出力時に非効率化されている可能性が高くなります。（できるだけ良い結果を得るために、備考欄をお読みください。）

↑3 オプション

-d directory

ソート済みの TMD ファイルを置く出力用ディレクトリを指定します。デフォルトは "..\STMD" です。出力用ディレクトリはあらかじめ作成しておかなければなりません。

-v

ソート前後の頂点の並びを標準出力へ出力し、ソートの様子を確認できます。
デフォルトでは出力しません。出力の意味は以下のとおりです。

        file: (vertex: a/b)
        file: ファイル名
        a : 差分ファイルに含まれる頂点数
        b : 総頂点数
        
        .....*****++*++++++++++++++*****................
        . : 差分がなく、差分ファイルに含まれない頂点
        + : 差分はないが差分ファイルに含まれてしまう頂点
        * : 差分があり、差分ファイルに含まれる頂点

-stdin

モデルファイル名を標準入力から読み込みます。改行のみ入力すると読み込みを終了します。

例１：手でファイル名を入力する場合
        C:\> mimesort -stdin
        原形モデル： md1.tmd[RET] 	←原形モデルファイル名を入力
        変形モデル #1： md2.tmd[RET]	←変形モデル１のファイル名を入力
        変形モデル #2： md3.tmd[RET]	←変形モデル２のファイル名を入力
        変形モデル #3： [RET]		←入力終了
        （以下略）

例２：自動的に入力させる。さらに -v オプションと併用する。
        C:\> type list
        md1.tmd
        md2.tmd
        md3.tmd
        ←最後に空行が必要
        C:\> mimesort -stdin -v < list > kekka
        （以下略）

-m sorttable

sorttableファイルの指定にしたがって頂点をソートします。変形モデルファイル数が多い場合にはこのオプションを使用してください。
sorttableのファイルには、新しい頂点番号の順に古い頂点番号を並べて記述します。頂点番号は0から始まります。区切り文字は1byteのスペース、改行、タブのいずれかです。#で始まる行はコメントとみなされます。
記述例を示します。

例１：sample1.tbl
#sample1.tbl
0 1 3 2 4
#end of file

sample1.tblファイルを頂点数5のモデルファイルに -mオプションで与えると、頂点番号2と3（３番目と４番目）の頂点が入れ替ります。

例２：sample2.tbl
#sample2.tbl
0
2 3 4 5 6
1
7 8
#end of file

sample2.tblファイルを頂点数９のモデルファイルに -mオプションで与えると、元の頂点番号1の頂点が５つ後ろへ移動します。

↑4 補足

差分ファイルが必ず小さくなるとは限りません。効果があったかどうかは -v オプションで出力される頂点情報で知ることができます。-vオプションで + と表示される頂点が少ないほどMIMeの速度およびメモリの両面で効率的なモデルです。
入力する TMD ファイルは、mimefilt にかけることが可能なものでなければなりません。また、mimesort は複数のオブジェクトを含む TMD ファイルには未対応です。
ファイル名にはワイルドカードを使用することができますが、必ず base ファイルが先頭に来るように指定して下さい。もしも変形モデルであるべきファイルが原形モデルファイルの位置で展開された場合、期待したソート結果が得られません。実行時に出力されるメッセージ "base files=" で、ワイルドカードが期待通りに展開されているかどうか、確認してください。
原形モデル、変形モデルのファイル名中にサブディレクトリを指定した場合でも、出力用ディレクトリの直下にファイルを作成します。そのため、入力に異なるディレクトリの同名ファイルを指定してはいけません。
出力用ディレクトリに "." など、カレントディレクトリを指定しないでください。もしも指定した場合には、入力ファイルを出力ファイルで上書きして破壊します。
MS-DOS のコマンドラインの文字数制限にご注意ください。
頂点データ以外（法線データなど）のソートは未対応です。

↑5 備考

多くの変形モデルファイルを扱う際の注意

それぞれのモデルをキイとしたキイフレームを時系列に並べた、いわゆるキイフレームアニメーションを MIMe を使っておこなうと、MIMe パラメータが膨大な数になりがちです。しかし、あまり多くのパラメータを一つのモデルに対して同時に適用すると、時間もメモリも多く消費してしまいます。キイフレームアニメーションでは、要所要所で base のモデルを入れ換えることによって効率を上げることが出来ます。（要所要所：キイフレーム間の相関の少ないところ）
それでもなお、変形モデルファイルが多い場合は、-mオプションを使用してください。また、mimesortの自動頂点ソートの結果に満足がいかない場合も、-mオプションを使用してください。
