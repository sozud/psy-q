pict2tim

↑1 概要

MacintoshイメージデータをPlayStationの画像データファイルに変換します。
ここでは、1994/Oct/17付けのVersion3.1に関する内容を記述しています。

↑2 使い方

pict2tim [options] PICT-files ...

MacintoshのPICT2形式のイメージデータファイルを与えると、PlayStationのTIMファイル(*.TIM)を生成します。引数にワイルドカードが使用できます。複数のファイルを与え一度に変換することも可能です。

↑3 オプション

-o output-file

出力ファイル名を指定します。デフォルトは入力ファイルの拡張子を".tim"に変換したものを現在のディレクトリに生成します。

-org x y

VRAM上でのイメージの原点を指定します。デフォルトは(0, 0)です。

-plt x y

VRAM上でのカラーパレットの位置を指定します。デフォルトは(0, 480)です。

-t

(0 0 0)以外の色に対して、透明制御ビットをONにします。(0 0 0)以外の色が半透明色になります。デフォルトでは、すべての色は不透明になります。

-b

(0 0 0)に対して、透明制御ビットをOFFにします。 (0 0 0)は透明になります。デフォルトでは、(0 0 0)は黒として表示されます。

-v

変換に関する詳細な情報を表示します。

↑4 制約

現バージョンは以下の制約を持っています。
  • 変換可能なPICTデータはPixmapに限られます。
  • 32 ビット PICT は変換できません。
