rsdcat

↑1 概要

複数の RSD フォーマットファイルを一つに連結します。
DOS版とSGI版があります。ここでは、1996/May/16付けの Version 1.04 に関する内容を記述しています。

↑2 使い方

rsdcat [options] [ARG-files ...] RSD-files ...

複数の RSD ファイルセットを連結し、新たな RSD ファイルセットを生成します。
引数にワイルドカードが使用できます。

↑3 オプション

-o output-file

出力ファイル名を指定します。デフォルトでは"out.rsd", "out.ply", "out.mat", "out.grp" を現在のディレクトリに生成します。
このオプションでファイル名を指定した場合、この名前から拡張子を省いた名前に、rsd, ply, mat, grp の各拡張子を付け加えたファイル名で、出力を生成します。

-h

指定できるオプションの一覧と、簡単な使い方を表示します。

-v

変換に関する情報を表示します。

ARG-files

rsdcat に対するオプションや入力ファイル名等を記述した 引数ファイルを指定します。ファイル名の拡張子が「.arg」の場合に、引数ファイルと解釈します。128 バイトを越えるコマンド引数が必要な場合にお使いください。「#」で始まる行はコメントとみなされ、rsdcat の実行に影響を与えません。

↑4 備考

  • 生成されるグループファイル(*.grp)には、入力の RSD ファイルごとに一つずつグループが追加されます。このグループは、入力 RSD ファイルの全ポリゴンをメンバーとして、入力 RSD ファイルから拡張子を取り除いたものをグループ名として作成されます。
  • 入力の複数の RSD ファイルを通して、テクスチャ、頂点、法線、グループなどの情報に重複があっても rsdcat は、これを圧縮しません。このため、rsdcat の出力するファイルは、若干手直しが必要になる場合があります。
  • 出力ファイル名が既に存在する場合、その内容は上書きされます。警告などは出力しませんので、ご注意ください。
  • 引数ファイルの中に、引数ファイル名を書いても展開されません。
  • 引数ファイルの中ではワイルドカードは使用できません。
