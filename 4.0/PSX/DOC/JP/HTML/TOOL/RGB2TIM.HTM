rgb2tim

↑1 概要

RGBイメージデータをPlayStationの画像データファイルに変換します。
DOS版とSGI版があります。ここでは、1996/Apr/1付けのVersion 2.1に関する内容を記述しています。

↑2 使い方

rgb2tim -size w h [options] input-file

RGB形式のイメージデータファイルを与えると、PlayStationのTIMファイルを生成します。-sizeで入力イメージの幅と高さをピクセル数で指定します。幅のみ正しく指定し、高さに0以下の値を与えると、高さを自動的に計算します。高さのみを正しく指定した場合も同様です。
入力は24ビットinterleave型のRGBデータです。引数にワイルドカードが使えます。複数のRGBデータを一括変換できますが、サイズやビットモードなどのオプションは共通になり、個々の出力ファイル名は指定できません。

↑3 オプション

-o output-file

出力ファイル名を指定します。デフォルトは入力ファイル名の拡張子を".tim"に変換したものを現在のディレクトリに生成します。

-org x y

VRAM上でのイメージの原点を指定します。デフォルトは(0, 0)です。

-plt x y

VRAM上でのカラーパレットの位置を指定します。x, yどちらかに負の数を指定すると、4または8bitのTIMであってもCLUTを生成しません。デフォルトは(0, 480)です。

-mode 4|8|16|24

出力するTIMデータの１ピクセルの大きさを指定します。デフォルトでは16ビットモードになります。

-t

(0 0 0)以外の色に対して、透明制御ビットをONにします。(0 0 0)以外の色が半透明色になります。デフォルトでは、すべての色は不透明になります。

-b

(0 0 0)に対して、透明制御ビットをOFFにします。(0 0 0)は透明になります。デフォルトでは、(0 0 0)は黒として表示されます。

-skip n

入力ファイルの先頭から読み飛ばすバイト数を指定します。デフォルトは 0 です。

-v

変換に関する詳細な情報を表示します。

↑4 前バージョンからの主な変更点

  • CLUTなしのTIMファイルを生成できるようになりました(-pltオプション参照)。
  • -sizeオプションで幅のみ正しく指定し、高さに0以下の値を与えると、高さを自動的に計算します。高さのみを正しく指定した場合も同様です。
  • 複数のRGBデータを一括変換できるようになりました。ただし、オプションは共通のものが適用されます。

↑5 補足

入力RGBデータの色数が多い場合、4および8ビットには変換できないことがあります("Color overflow!!"というエラーメッセージが出力されます)。この場合、あらかじめPhotoshopなどで色数を落としてください。
