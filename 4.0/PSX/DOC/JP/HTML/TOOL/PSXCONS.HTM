↑ 1 はじめに

1. 1 psxconsについて

psxcons は、IBM-PC/AT 互換機上で動作する、DTL-H2000 およびCOH-2000K の組み込みモニタプログラム操作用のユーザーインターフェースフロントエンドプログラムです。
動作環境は以下の通りです。

動作機種

IBM-PC/AT 互換機

動作ボード

DTL-H2000, COH-2000K

動作OS

DOS-5/V, DOS-6/V

必要ドライバ

ANSI.SYS

1. 2 表記上の約束について

本説明書では、次のようにフォントを使用しています。

  • ゴシック(等幅フォント) はスクリーンに表示されるテキストを示します。
  • Bold はシステムプロンプトで入力しなければならないテキストを示します。
  • italic は入力しなければならないテキストのうち特にユーザの選択によって変更が有り得る部分を示します。
  • (Return)はReturn key を押すことを示します。
  • (F1)～(F10)はキーボード上部のF1～F10 key を押すことを示します。
  • Ctrl-C はCtrl key を押しながらC key を押すことを示します。
  • Ctrl-Break はCtrl key を押しながらBREAK key を押すことを示します。

↑ 2 インストール

2. 1 ANSI.SYSの存在の確認

MSDOS の起動ディスクのルートディレクトリにあるCONFIG.SYS ファイルに以下の行があることを確認してください。
        
        DEVICE=C:"DOS"ANSI.SYS

無い場合には、CONFIG.SYS を編集して追加したのち、MSDOS を再起動してください。

2. 2 psxcons のインストール

実行PATH の通ったディレクトリにPSXCONS.EXE をコピーしてください。

2. 3 ポートアドレス等の設定

ボードに設定したポートアドレス、割り込み(IRQ) レベルを、環境変数DEX2000 に設定します。
MSDOS の起動ディスクのルートディレクトリにあるAUTOEXEC.BAT ファイルに以下の様な行を追加します。
        
        SET DEX2000=ポートアドレス等の設定値
環境変数DEX2000 の内容については次節で述べます。

2. 4 注意

PSXCONS.EXEはDEXBIOS.COMとは共存できませんので、DEXBIOS.COMの常駐を解除してから使ってください。

↑ 3 起動

3. 1 書式

psxcons [オプション] [バッチファイル名]

3. 2 オプション

現在有効なオプションは以下に示す一つだけです。

-p ポートアドレス[, ＩＲＱレベル[, ＤＭＡチャネル]]

DTL-H2000 ボードのI/O アドレスを指定します。
IRQ レベル、DMA チャネルの指定は省略可能で、省略した場合は割り込み機能、DMA 機能を使用しないことになります。-p オプションによる指定が無い場合は、環境変数DEX2000に設定された値が採用されます。環境変数DEX2000 が設定されていない場合は'0x1340,10'が採用されます。

3. 3 バッチファイル名

バッチファイル名を指定すると、指定したバッチファイルの内容を読み込み自動実行を行ないます。
バッチファイルの詳細は、「8 自動実行」で述べます。

3. 4 環境変数

参照する環境変数は以下の二つです。

DEX2000

前述したようにDTL-H2000 ボードのI/O アドレス等を指定します。

PSXCONSHIS

入力ヒストリを保存するファイル名を指定します。

3. 5 操作例

例１

        C:\>  psxcons  (Return) (F7) 2  (Return) (F9)  (F10)
        psxcons -- PlayStation debug system console program
          $Date: 1995/08/24 08:30:05 $
          type F1  ---> display help
          when hung up try type ctrl+BREAK
        I/O addr = 0x1340, IRQ=10(vect=0x0072,8259=A0)
        connect to COH-2000K
        (Return)
        PSX>

例２

        C:\>  psxcons -p0x300  (Return)  (F7) 2  (Return)  (F9) (F10)
        psxcons -- PlayStation debug system console program
          $Date: 1995/08/24 08:30:05 $
          type F1  ---> display help
          when hung up try type ctrl+BREAK
        I/O addr = 0x300
        connect to DTL-H2000
        (Return)
        PSX>

例３

        C:\>  set DEX2000=0x340  (Return)
        C:\>  psxcons  (Return)  (F7) 2  (Return)  (F9) (F10)
        psxcons -- PlayStation debug system console program
          $Date: 1995/08/24 08:30:05 $
          type F1  ---> display help
          when hung up try type ctrl+BREAK
        I/O addr = 0x340
        connect to DTL-H2000
        (Return)
        PSX>

↑ 4 基本動作

psxcons は、通常のキー入力はモニタプログラムに渡し、モニタプログラムから渡された文字を画面に表示します。ただし、フアンクションキー、カーソル移動キーなどはモニタプログラムに渡すことなくローカルに処理します。特に (F1) ～ (F8) 迄のキーは以下のようにローカルコマンドを起動します。

(F1)

ヘルプメッセージを表示します。

(F2)

DOS のコマンドを入力し、実行します

(F3)

バッチファイル名を入力し、バッチファイルを実行します。

(F4)

オブジェクトファイルのファイル名を入力し、ダウンロードします。

(F5)

操作の記録ファイル名を入力し、操作の記録を開始します。

(F6)

疑似LED の表示をします。

(F7)

疑似DIPSW のデータを入力し、設定します。

(F8)

ローカルラインエディット機能のON/OFF をします。

また、(F9) は、続けて以下のようなファンクションキーを入力することでローカルコマンドを起動します。

(F9) (F4)

バイナリファイルのファイル名を入力し、ダウンロードします。

(F9) (F5)

操作の記録を停止します。

(F9) (F9)

DTL-H2000 ／COH-2000K のユーザ割り込みをかけます。（現状無効）

(F9) (F10)

DTL-H2000 ／COH-2000K のリセットをかけます。

また、(F10) は、続けて以下のようなファンクションキーを入力することでローカルコマンドを起動します。

(F10) (F2)

psxcons プログラムを終了させます。

↑ 5 ローカルコマンド実行時のキー操作

前章のファンクションキーによりローカルコマンドを実行すると、コマンドによってはファイル名などの入力が必要になります。この入力時には、以下のキーにより編集操作を行うことが出来ます。

左矢印

カーソルを左に進めます。

Ctrl-s

カーソルを左に進めます。

右矢印

カーソルを右に進めます。

Ctrl-d

カーソルを右に進めます。

上矢印

ヒストリーバッファを遡ります。

Ctrl-e

ヒストリーバッファを遡ります。

下矢印

ヒストリーバッファを下ります。

Ctrl-x

ヒストリーバッファを下ります。

Ctrl-g

カーソル位置の文字に消去をします。

Ctrl-y

一行消去、または、ヒストリーバッファから抜けます。

Ctrl-k

カーソル位置から行末まで消去します。

TAB

現在の入力行と先頭部分が一致するまでヒストリーを遡ります。

Ctrl-j

現在の入力行と先頭部分が一致するまでヒストリーを下ります。

ESC

現在の入力行を実行せずにヒストリーバッファにプッシュします。

↑ 6 プログラムのダウンロード

(F4) キーによりローカルコマンドのdown2 コマンドを起動しS-format のオブジェクトデータ、PS-X EXE 形式のオブジェクトデータ、CPE 形式のオブジェクトデータ、COFF(a.out) 形式のオブジェクトデータのダウンロードができます。

        PSX>  (F4)
        Down2[x]:  filename  (Return)
        ld2
        
        S-format data load start
        xxx line			← 転送中転送行数が時々表示されます。
        "filename" send end
        GP:a00xxxxxx PC:a00xxxxxx
        PSX>
あるいは
        
        PSX>  (F4)
        Down2[x]:  filename  (Return)
        
        smon
        filename  address=80010000-80010fff size:00001000  00001000:    3sec.
        CCS Taregt mode
        reg[32]=80010000
        reg[29]=801ffff0
        Exit from CCS Target mode
        PSX>
(F9) (F4)キーによりローカルコマンドのbload コマンドを起動しバイナリデータをダウンロードすることもできます。bload コマンドの引数にはファイル名とアドレス（16 進数）のペアを複数指定することが出来ます。
        
        PSX>  (F9)  (F4)
        Bload[x]:  file1 address1 file2 address2   (Return)
        smon
        CCS Taregt mode
        file1  address:xxxxxxxx size:xxxxxx  xxxxxx: xxsec.
        file2  address:xxxxxxxx size:xxxxxx  xxxxxx: xxsec.
        Exit from CCS Target mode
        PSX>

↑ 7 psxcons の終了の仕方

(F10) (F2) キーによりローカルコマンドのquit コマンドを起動します。
        
        PSX>  (F10)  (F2)
        c:\>

↑ 8 自動実行

8. 1 自動実行の概要

psxcons.exe には、簡単な自動実行機能があります。キーボードから投入するコマンドを羅列したテキストファイルを作成しておき、 (F3) キーにより起動されるauto コマンドでそのファイル名を指定すると、モニタプログラムがプロンプトを表示するたびにファイルから一行ずつ読み込み実行します。
        
        PSX>  (F3)
        Auto[x]:  batchfile   (Return)
        バッチファイルの１行目
        PSX>バッチファイルの２行目
        PSX>バッチファイルの３行目
        	:
        PSX>

注意

このコマンドはバッチファイルの最初の一行を無条件で実行しますのでかならず、モニタプログラムのプロンプトが表示されている状態で起動して下さい。

8. 2 バッチファイルのコマンド

バッチファイル中には、モニタプログラムへ投入するコマンドをそのまま記述することができます。これらのコマンドは、モニタプログラムからのコマンドプロンプトが表示されるたびに１行づつDTL-H2000 ／COH-2000K に送り込まれます。

8. 3 バッチファイルでのローカルコマンド

バッチファイル中で、psxcons.exe のローカルコマンドを実行するには、
        
        local  local-command argument1 argument2...
という具合に、最初に'local' という語を前置して、次にコマンド名、そして引数を書きます。
使用できるローカルコマンドは以下の通りです。

help

ヘルプメッセージを表示します。

dos

引数に与えられたDOS のコマンドを実行します

auto

引数に与えられたファイル名のバッチファイルを実行します。バッチファイルのネストは16 レベルまで許されます。

bload

引数でファイル名とアドレスのペアで指定し、バイナリファイルをダウンロードします。

down2

引数に与えられたファイル名のS-format ファイルをダウンロードします。

log

引数に操作の記録ファイル名が与えられた場合、操作の記録を開始します。引数がない場合、操作の記録を停止します。

led

疑似LED の表示をします。

dipsw

引数に与えられた１６進データを疑似DIPSW に設定します。

reset

DTL-H2000 ／COH-2000K のリセットをかけます。

beep

ブザーを鳴らします。

pause

キー入力待ちになります。適当なキーを打つと続行します。

echo

引数で与えられた文字列を表示します。

sleep

引数で与えられた秒数だけ一時停止します。

auto-again

現在実行中のバッチファイルを先頭から繰り返します。（このコマンドは暫定仕様です。なくなる可能性があります。）

quit

psxcons プログラムを終了させます。

8. 4 バッチファイルの例 

        local dipsw 2
        local reset
        local sleep 1
        local bload  program 80080000
        local beep
        sr sp 801ffff0
        local echo type any key to execute program.
        local pause
        call  80080100

↑ 9 ROMモニタコマンド

開発機に搭載されるROMモニタでは、以下のコマンドを利用してデバッグを行うことができます。
表記凡例は次のとおりです。

表記凡例

表記説明
コマンド名
コマンド名＜引数＞
コマンド名 [＜引数＞]
コマンドのみ、引数はありません。
コマンドに続き、引数を指定します。
コマンドに続き、引数を指定します。
[ ] で括られた部分は省略可能です。

9. 1 コマンド一覧表示

help

本付録で解説しているコマンドの一覧を表示します。

help2

ハードウェアテストのためのコマンドの一覧を表示します。

9. 2 モニタのリセット

re

restart

exit

hot

モニタをリセット（ホットスタート）します。

start

quit

モニタをリセット（コールドスタート）します。

9. 3 レジスタ操作

dr[＜reg＞]

＜reg＞レジスタの値を表示します。
＜reg＞を省略した場合、全レジスタの値を表示します。

sr[＜reg＞]

＜reg＞レジスタに値をセットします。
＜reg＞を省略した場合、レジスタ名を問い合わせてきます。

ds

R3000のステータス、原因両レジスタの内容を表示します。

9. 4 プログラムの実行

ca[＜adr＞]

call[＜adr＞]

＜adr＞番地からプログラムを実行し、実行終了後、モニタに制御が戻ります。＜adr＞を省略した場合、
EPCレジスタの現在値から実行を開始します。
なお、このコマンドでは、ブレークポイントは無視されます。

go

＜adr＞番地からプログラムを実行します。＜adr＞を省略した場合、 EPCレジスタの現在値から実行を開始します。
このコマンドでは、ブレークポイントが設定されていれば、そこで処理が中断します。なお、実行終了後、
モニタに制御が戻ることはありません。

9. 5 メモリ操作

dw[＜adr＞[＜count＞]]

dh[＜adr＞[＜count＞]]

db[＜adr＞[＜count＞]]

＜adr＞番地のメモリの内容を、＜count＞バイト毎に16進表示します。dwはワード単位、dhはハーフワード単位、dbはバイト単位で表示します。
＜adr＞＜count＞は何れも省略可能です。＜adr＞を省略した場合、前回の続きの番地から表示します。
＜count＞を省略した場合、64バイトをまとめて表示します

sw＜adr＞

sh＜adr＞

sb＜adr＞

＜adr＞番地から順に値を設定します。swはワード単位、shはハーフワード単位、sbはバイト単位で入力します。終了はCTRL-Cです。
＜adr＞を省略することはできません。

fw＜adr＞[＜data＞[＜count＞]]

fh＜adr＞[＜data＞[＜count＞]]

fb＜adr＞[＜data＞[＜count＞]]

＜adr＞番地から＜count＞バイト分を、値＜data＞でクリアします。fwはワード単位、fhはハーフワード単位、fbはバイト単位でクリアします。
＜data＞、＜count＞は何れも省略可能です。＜data＞を省略した場合、0x00000000でクリアします。
＜count＞を省略した場合、16バイト分をクリアします。
＜adr＞を省略することはできません。

9. 6 デバッグ

di[＜adr＞]

dis[＜adr＞]

＜adr＞番地から逆アセンブルを行います。
＜adr＞を省略した場合、前回の続きの番地から逆アセンブルします。

ld2

Ｓ-format形式のファイルをメモリにロードします。EPCおよびGPレジスタの値も受け取ります。

smon[＜key＞]

高速転送モードに切り替わり、ダウンロードを受け付けます。

bp[＜adr＞]

＜adr＞番地にブレークポイントを設定します。ブレークポイントは最大10個まで設定できます。
＜adr＞を省略した場合、設定済みのブレークポイントが番号付きで表示されます。

ub＜num＞

＜num＞番のブレークポイントを解除します。＜num＞を省略するとすべてのブレークポイントを解除します。

cont

c

ブレークポイントにより中断したプログラム実行を再開します。

step

s

機械語レベルでのシングルステップ動作を行います。

Step

S

stepコマンドと同じです。ただし、サブルーチンコールを１ステップとみなします。

qdebug

｢リモートデバッガ｣のためのデバッグスタブモードに入ります。一旦このモードに入ったら、モニタに復帰することはできません。

9. 7 ユーザー定義コマンド

showcom

ユーザー定義モニタコマンド（最大２０個）の内容を表示します。

addcom＜name＞＜adr＞

ユーザー定義モニタコマンドを登録します。＜name＞にコマンド名、＜adr＞に実行開始アドレスを指定します。

delcom＜name＞

ユーザー定義モニタコマンド＜name＞の登録を解除します。

9. 8 カーネルとブート

boot＜drv＞

ドライブ＜drv＞からアプリケーションプログラムをブートします。PlayStation実機のブートシーケンスのうち、ローリングデモなどを除いたサブセットを実行します。

rc＜ev＞＜tcb＞

EVENT=＜ev＞、TCB=＜tcb＞という内容のシステム設定ファイルと同様にカーネルコンフィギュレーションを再設定します。

sc

現在のカーネルコンフィギュレーションを表示します。

load＜file＞＜sp＞

PS-X EVE形式ファイル＜file＞をメモリに読み込みます。初期値なしデータ領域をゼロクリアし、EPC、GPレジスタの値もファイル内のものに設定しますので、直ちにcaコマンドで実行することができます。

loadexec＜file＞＜sp＞

PS-X EVE形式ファイル＜file＞をメモリに読み込み、スタックポインタの初期値を＜sp＞に設定し、実行します。

mem＜mbyte＞

＜mbyte＞が、２･８･１６のいずれかの場合は有効メモリ容量をその値（メガバイト単位）に設定します。
＜mbyte＞指定がない場合は、その時点の設定値を表示します。
