mktod

↑1 概要

プロジェクト情報(PRJファイル)と階層定義情報(HRCファイル)を読み込み、レイアウトファイル(TODファイル)を生成します。
DOS版とSGI版があります。ここでは、1996/May/1付けの Version 1.4 に関する内容を記述しています。

↑2 使い方

mktod [options] hrc-file ...

mktodはプロジェクトディレクトリにおいて実行され、プロジェクトファイル(model.prjおよびobject.prj)と、引数で与えられたHRCファイルを読み込み、todディレクトリにTODファイルを生成します。現在のディレクトリにtodディレクトリがない場合、TODファイルは現在のディレクトリに生成されます。いずれの場合もプロジェクトファイルは現在のディレクトリに存在していなければなりません。
また、引数であるHRCファイルは、明示的にパスが指定されない場合、現在のディレクトリ(.\)または.\hrcに存在しなければなりません。mktodはこの順にHRCファイルを探します。拡張子の".hrc"は省略可能です。

↑3 オプション

-o output-file

出力TODファイル名を指定します。デフォルトでは引数のHRCファイル名の拡張子を".tod"に置き換えたものになります。

-tree

オブジェクト間の階層構造を標準出力に出力します。

-v

変換中の情報を標準出力に出力します。

↑4 前バージョン(ver.1.3)からの主な変更点

  • 一部オリジンが正しく出力されない場合がありましたが、これを修正しました。

↑5 制約

現バージョンは以下の制約を持っています。

  • HRCファイル中のシーケンスブロックは読み飛ばします。したがって、mktodで生成されるTODファイルは常に１フレーム分です。

↑6 注意

レイアウト/アニメーションツールおよびmktodが出力するTODファイルを利用したプログラムを作成する場合、rsdlinkで平行移動(-t)や拡大縮小(-s)オプションは使用しないで下さい。TODファイルにはRSDオブジェクトに対する移動量や倍率が格納されているため、RSDからTMDに変換する際に移動や拡大縮小を行なうと、整合がとれなくなります。前もって、rsdformを利用して、RSDデータのまま移動や拡大縮小を行なうようにしてください。

↑7 使用例

例1 -v オプションの表示例

通常、mktodは以下のようなサブディレクトリを持つディレクトリ(プロジェクトディレクトリ)において起動されます。このディレクトリ構造およびプロジェクトファイルはレイアウト/アニメーションツールが生成します。
        
        > cd \home\proj1
        > dir /w
        [.]        [..]        [ACT]        [CAM]        [HRC]
        [LHT]      [ORG]       [RSD]        MODEL.PRJ    OBJECT.PRJ
        [TIM]      [TMD]       [TOD]
        
        > mktod -v test.hrc
        Input file   : C:\HOME\PROJ1\HRC\test.hrc
        Output file  : C:\HOME\PROJ1\TOD\test.tod
        Reading ... C:\HOME\PROJ1\model.prj
        Reading ... C:\HOME\PROJ1\object.prj
        Reading ... C:\HOME\PROJ1\HRC\test.hrc
        Number of Frames  : 1
        Number of Objects : 21
        Number of Packets : 72
        Output file size  : 1096 bytes

-vオプションにより、入出力ファイル名と、生成されたTODファイルのフレーム数、オブジェクト数、パケット数およびファイルサイズが表示されます。

例2 -tree オプションの表示例

以下は-treeオプションを指定してオブジェクト間の親子関係を表示させた例です。HRCファイル中の階層構造記述部に書かれた全オブジェクトの名前とID番号(#...)が表示されますが、その際、子オブジェクトは親オブジェクトより一段インデントされます。
