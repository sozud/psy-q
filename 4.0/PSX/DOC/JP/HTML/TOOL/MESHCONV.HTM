meshconv

↑1 概要

RSD拡張ファイルであるMSHファイルを作成します。このファイルをRSDファイルに付加することによりポリゴンの連結情報を持つことが可能となります。また、作成されるMSHファイルは連結情報を含むHMDデータを作成する場合必要となります。
ここでは、Version 1.0に関する内容を記述しています。

↑2 使い方

meshconv [options] RSD-file

RSDフォーマットのファイルより、MSHファイルを作成します。出力されるMSHファイルは、デフォルトでは入力RSDファイルから拡張子を取り除いた名前に ".msh" をつけたファイル名になります。

↑3 オプション

-o output-file

出力ファイル名を指定します。デフォルトは入力ファイルの拡張子を".msh"に変換したものを現在のディレクトリに生成します。また、RSDファイル中にMSHファイルが指定されていた場合、そちらの方が有効になります。

-min X

最小連結数を指定します。デフォルトは2です。

-max X

最大連結数を指定します。デフォルトは∞です。

-help, -?

指定できるオプションの一覧と、簡単な使い方を表示します。

-ns

共有ポリゴンの連結を防ぎます。

↑4 備考

  • 使用される関係ファイルは同一ディレクトリに存在しなくてはなりません。別ディレクトリに存在する場合は、その相対パスあるいは絶対パスを指定して下さい。
  • 出力されるMSHファイルはRSDファイル中に示される情報を考慮しMSHファイルを作成します。連結は複数のマトリックスにまたがるものについてはHMDで表現できませんので、MSHファイル作成時は必ずCODファイルをインクルードしてください。CODファイルを指定しなかった場合、そのオブジェクトは1つのマトリックスのみ持つと認識されます。
  • 出力ファイル名が既に存在する場合、その内容は上書きされます。警告などは出力しませんので、ご注意ください。
  • 本プログラムはRSDフォーマットの以下のバージョンに対応しています。その他のバージョンのRSDファイルは使用することができませんので、あらかじめご了承下さい。

    RSDファイル version 3.0
    PLYファイル version 3.0
    MATファイル version 3.0
    GRPファイル version 3.0
    MSHファイル version 1.0 (出力ファイル)
    PVTファイル version 1.0
    CODファイル version 1.0
    OGPファイル version 1.0
    MOTファイル version 1.0

※meshconv (version 1.0)では、RSD、PLY、MAT、COD、OGPの５つのファイルを読み込みの対象としています。従って、これらの５つのファイル以外は現時点ではバージョンを問いませんが、将来読み込みの対象になる可能性も考えられますので、基本的に全てのバージョンを最新のものにするようにしてください。
