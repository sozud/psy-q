mimefilt

↑1 概要

複数のTMDファイルを読み込んでMIMe用差分ファイルを生成します。
DOS版とSGI版があります。ここでは、1996/Apr/1付けの Version 1.51 に関する内容を記述しています。

↑2 使い方

mimefilt [options] base.tmd variant1.tmd variant2.tmd...

mimefilt [options] tmds.arg...

複数のTMDファイルを与えると、２番目以降のTMDそれぞれに対して、最初に与えたTMDとの差分ファイルを出力します。デフォルトでは、頂点情報の差分ファイル(.vdf)のみ生成されます。

引数にワイルドカードが使用できます。ファイル名の".tmd"は省略可能です。

引数が多くなる場合など、引数をファイル(*.arg)に書いて与えることが可能です。ただし、引数ファイル名の".arg"は省略できません。

↑3 オプション

-o output-file

出力ファイル名を指定します。頂点差分ファイル名(.vdf)および法線差分ファイル名(.ndf)に用いられます。デフォルトでは、最初のTMDファイル名から拡張子を除いたものが用いられます。

-n

法線差分ファイル(.ndf)を生成します。デフォルトではOFFです。

-v

変換に関する詳細な情報を標準出力に出力します。デフォルトではOFFです。

↑4 前バージョン(v1.5)からの主な改良点

  • 引数にワイルドカードが使用できるようになりました(DOS版)。

↑5 補足

引数のTMDファイルはすべて頂点数が等しくなければなりません。
-nオプション使用時にはさらに法線数も等しくなければなりません。

各TMDファイルを作る際には、頂点数や頂点の順番が変わらないよう、注意が必要です。３Ｄモデラで、十分に細かいポリゴンで基本となるモデルを作成し、これを元に、面や頂点を移動させて他のモデルを作成してください。それぞれのモデルをDXF形式で保存し、dxf2rsdでRSD形式に変換し、その後それぞれ別個にrsdlinkを適用してTMDファイルを生成してください。

↑6 差分ファイル形式

mimefiltで生成される差分ファイルの形式は、オブジェクト毎にヘッダと差分情報を持ったブロックが、連結されたバイナリファイルです。(法線差分ファイルも全く同じ形式です。)

差分ファイル中に生成されるブロック数は、
        (引数のTMDファイルの数 - 1)×各TMDファイル中のオブジェクト数
です。

以下に
        > mimefilt m0.tmd m1.tmd m2.tmd
を実行した場合に生成されるファイルの形式を示します。
