mkvab

↑1 概要

aiff2vag.exe にて作成した VAG 形式の波形データ群と属性テーブルを作成する定義ファイルを元に音源バンク形式 VAB を構築します。
ここでは、1996/May/01付けの Version 2.0 に関する内容を記述しています。

↑2 使い方

mkvab [option] vag-files....

↑3 オプション

-f def_file

属性テーブルを作成する定義ファイル def_file を指定します。

-r vab_file

VAB ファイルを解析して、属性定義ファイルを出力します。

-o out_file

出力ファイルを指定します。

↑4 制約

現バージョンは以下の制約を持っています。

  • VAB ファイルサイズおよび各 VAG のサイズは自動的に計算されますので、指定した数値は無視されます。

↑5 属性定義ファイル

VabHdr (VAB 全体にわたる属性定義です。)

ラベル値解説
form'VABp'フォーマット識別子です。
ver7フォーマットバージョン番号です。
id0VAB id です。(常に 0)
fsize0ファイルサイズです。(mkvab が自動計算します。)
ps0～128VAB に含まれる全プログラム数です。
ts0～2048VAB に含まれる全トーン数です。
vs0～254VAB に含まれる全 VAG 数です。


ProgAtr (プログラム(楽器に相当)レベルの属性定義です。)

ラベル値解説
tones4プログラムに含まれるトーン数。
mvol0～127プログラムのボリューム値です。
mpan0～127プログラムのパンニング値です。


VagAtr (トーンレベルの属性定義です。)

ラベル値解説
prior0～127トーンの優先度です。大きい値ほど優先されます。
mode0,44 に設定するとリバーブの効果が得られます。※
vol0～127トーンのボリューム値です。
pan0～127トーンのパンニング値です。
center0～127センターノート(半音単位)です。
shift0～127センターノートのファインチューンです。
min0～127ノートリミットの最小値です。
max0～127ノートリミットの最大値です。
pbmin0～127下方向のピッチベンドの最大値(半音単位)です。
pbmax0～127上方向のピッチベンドの最大値(半音単位)です。
ar0～127アタックレートです。
dr0～15ディケイレートです。
sr0～127サステインレートです。
rr0～31リリースレートです。
sl0～15サステインレベルです。
prog0～127トーンが所属するプログラム番号です。
vag0～254使用する VAG です。

※リバーブ効果を得るには、別途サウンド関数にてリバーブの設定が必要です。

↑6 補足

ADSR(エンベロープ)、すなわち、アタック、ディケイ、サステイン、リリースに対して個別にレートが設定でき、その時間的変化には、リニアと指数関数的カーブとが指定できます。また、サステインについてはレベルも設定可能です。
