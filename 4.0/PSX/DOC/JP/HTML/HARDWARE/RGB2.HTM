RGB2


レジスタ番号： データ＃２２

アクセス： Ｒ／Ｗ

ビットパタン： 
 31bit                        16 15                             0
+---------------+---------------+---------------+---------------+
|      CD2      |       B2      |       G2      |       R2      |
+---------------+---------------+---------------+---------------+

フィールド： 
R2	(0.8.0)		固有色のＲ成分
G2	(0.8.0)		固有色のＧ成分
B2	(0.8.0)		固有色のＢ成分
CD2	(-.8.-)		任意の８ビットデータ

内部動作：
いくつかのＧＴＥ命令実行時に以下の順に代入が実行される。 

R0 = R1;
R1 = R2;
R2 = RGBレジスタのＲフィールド;
G0 = G1;
G1 = G2;
G2 = RGBレジスタのＲフィールド;
B0 = B1;
B1 = B2;
B2 = RGBレジスタのＲフィールド;
CD0 = CD1;
CD1 = CD2;
CD 2 = 実行中のGTE命令ビットパタン;
