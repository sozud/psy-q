高速リンカ PSYLINK

PSYLINK は、完全な機能をもったリンカです。複雑なプログラムを、別々の扱いやすいサブプログラムへ簡単に分割し、分割したサブプログラムを PSYLINK により再び結合して、最終的に１つのアプリケーションにすることができます。

↑ 1 書式

PSYLINK を実行するには、MS-DOS のプロンプトから次のように入力します。

        psylink [/option] <source file>,[output file],[symbol file],[map file],
        [libraries]

オプションは"/"（スラッシュ）に続けて指定します。複数指定する場合はスペースで区切ります。
オプションに続き、入出力ファイルを指定します。ファイル名は","（コンマ）で区切り連続して指定します。ファイル名は一部を除き省略することができます。但し、一連の途中のファイル名を省略する場合は、コンマを必ず指定してください。
以下、オプション及び各種ファイルについて解説していきます。

↑ 2 オプション

オプションは"/"（スラッシュ）に続けて指定します。複数指定する場合はスペースで区切ります。
オプションには次のものがあります。

・大文字／小文字の区別(/c)

"/c"を指定すると、大文字と小文字を区別してリンクします。このオプションを指定しない場合、すべてのシンボルは大文字に変換されます。

例

        psylink /c test.obj,test.cpe

・デバッグモードの指定(/d)

"/d"を指定するとデバッグモードとなり、リンクのみを行ないます。

例

        psylink /d test.obj,test.cpe

・マクロ定義(/e <symbol=value>)

"/e"に続き、定義したいマクロ symbol とその値 value を"="（イコール）で結んで指定します。"/e"と symbol との間はスペースで区切ります。また、<symbol=value> を";"（セミコロン）で区切り、複数指定することもできます。

例

        psylink /e DEBUG=1 test.obj,test.cpe

例

        psylink /e DEBUG=1;TEST=0 test.obj,test.cpe

・詳細情報の表示(/i)

"/i"を指定すると、リンクの詳細な情報をウィンドウ表示します。

例

        psylink /i test.obj,test.cpe

・マップファイルの生成(/m)

"/m"を指定すると、すべての外部シンボルをマップファイルに出力します。

例

        psylink /m test.obj,test.cpe

・ORG アドレスの指定(/o $<address>)

"/o"に続き、ORG アドレス address を 16 進数で指定します。address の先頭には"$"（ドルマーク）を付加します。

例

        psylink /o$80040000 test.obj,test.cpe

・バイナリコード出力(/p)

"/p"を指定すると、実行ファイルをバイナリコードで出力します。

例

        psylink /p test.obj,test.cpe

・実行開始アドレスの指定(/x $<address>)

"/x"に続き、実行開始アドレス address を 16 進数で指定します。address の先頭には"$"を付加します。

例

        psylink /x$80000000 test.obj,test.cpe

・オーバレイ情報付きSYMファイルの出力(/v)

DBUGPSXでのオーバレイサポート機能を使用する場合はこのオプションが必要です。

例

        psylink /v /o$80010000 test.obj,test.cpe,test.sym

・リンクモジュール数の最大数(/n[num])

デフォルトはnum=256になっています。リンク時に「Too many modules to link」のエラーが発生した時は、/n オプションで、リンク出来るモジュールの最大個数を増やして下さい。

例

        psylink /n2048 /o$80010000 test.obj,test.cpe,test.sym

・同名変数に関するワーニング(/wm)

リンクモジュール群の中で同名の変数が複数回定義されていた場合、
ワーニングメッセージを出力します。

例

        psylink /wm /o$80010000 test.obj,test.cpe,test.sym

↑ 3 入出力ファイル

入出力ファイルは、オプションに続き、","(コンマ)で区切って連続して指定します。指定順は以下の通りです。

        <source file>,[output file],[symbol file],[map file],[libraries]

ファイル名は一部を除き省略することができます。但し、一連の途中のファイル名を省略する場合は、コンマを必ず指定してください。

例 すべて指定

        psylink test.obj,test.cpe,test.sym,test.map,mylib.lib

例 シンボルファイル以降を省略した場合

        psylink test.obj,test.cpe

例 マップファイルのみを省略した場合

        psylink test.obj,test.cpe,test.sym,,mylib.lib

3. 1 ソースファイル

ASMPSX アセンブラによって出力されたオブジェクトファイル（.OBJ ファイル）を指定します。ソースファイル名は省略することはできません。
ファイルは複数指定することができ、この場合、スペースまたは"+"（プラス）によって区切ります。

例 ファイルが１つ

        psylink test.obj,test.cpe

例 ファイルが複数

        psylink test1.obj test2.obj,test.cpe （スペースで区切る）
        psylink test1.obj+test2.obj,test.cpe （"+" で区切る）
また、ファイル名の先頭に"@"（アットマーク）を付加することにより、「コマンドファイル」の機能を利用することができます。コマンドファイルについては「４コマンドファイルの利用」の項を参照してください。

例 コマンドファイル"test.cmd"を利用

        psylink @test.cmd,test.cpe

3. 2 出力ファイル

オブジェクトコードを出力するファイル（実行ファイル）を指定します。省略可能ですが、この場合、オブジェクトコードは作成されません。

3. 3 シンボルファイル

デバッガが使用するシンボルファイルの名前を指定します。省略可能です。

3. 4 マップファイル

マップファイル名を指定します。省略可能です。

3. 5 ライブラリファイル

使用するライブラリファイル名を指定します。省略可能です。

↑ 4 コマンドファイルの利用

ソースファイルが多い場合、DOS の制限により、コマンド行にこれが入り切らなくなる場合があります。この場合、「コマンドファイル」を作成し、これをソースファイルの代わりに指定することにより、この制限を回避することができます。
コマンドファイルを利用するには、次のように、ファイル名の先頭に"@"（アットマーク）を指定します。

例

        psylink @test.cmd,test.cpe

4. 1 コマンドファイルの記述

コマンドファイルには、ソースファイルの情報、及びソースファイルの構成方法などを、各種のコマンドを用いて記述します。これはアセンブラの文法に似ており、以下のコマンドを利用することができます。
各コマンドとその引数の間はスペースで区切ります。引数としてファイル名を指定する場合は、必ずダブルクォーテーションで囲みます。
なお、表中、コマンドあるいは引数を大文字で記述していますが、実際には小文字で指定しても構いません。

コマンド・引数内容
INCLUDE <filename>
読み込むオブジェクトファイルを指定します。
ファイルを複数指定する場合は、１行ずつ記述
します。
例: INCLUDE "test.obj"
INCLIB <filename>
使用するライブラリファイルを指定します。
ファイルを複数指定する場合は、１行ずつ記述
します。
例: INCLIB "test.lib"
ORG <address>
出力時の ORG アドレスを指定します。
例: ORG $80040000
WORKSPACE <address>
新しいターゲットのワークスペースアドレスを
指定します。
例: WORKSPACE $80000000
<name> EQU <value>
name に value を代入します。
例: debug EQU 1
REGS pc=<address>
pc の初期値を address に設定します。
例: REGS pc=__SN_ENTRY_POINT
<name> GROUP <attrib>
属性 attrib のグループ name を宣言します。
例: BSS GROUP BSS
<name> SECTION <attrib>
属性 attrib のセクション name を宣言します。
例: BSS SECTION BSS
SECTION <name>[,<group>]
セクション name を宣言し、オプションでその
グループを指定します。
例: SECTION text
<name> ALIAS <oldname>
シンボル oldname に別名 name を定義します。
例: mura ALIAS village
UNIT <number>
目的のユニット番号 number を指定します。
例: UNIT 1


また、グループの属性 attrib には以下のものが指定できます。

属性内容
BSSグループを初期化されていないデータとします。
ORG(<address>)グループの ORG アドレスを address に設定します。
OBJ(<address>)グループのオブジェクトアドレスを address に設定します。
OBJ()
グループのオブジェクトアドレスを、直前のオブジェクト
アドレスに続くアドレスに設定します。
FILE(<filename>)
グループの内容を filename に出力します。
例: BSS GROUP FILE("bss.txt")
SIZE(<maxsize>)最大サイズを maxsize に設定します。

4. 2 コマンドファイル記述上の注意

コマンドファイルの記述に際しては、以下の点に注意してください。
  • グループ内のセクションは、コマンドファイルまたはオブジェクト／ライブラリファイルで、セクション定義がなされた順番になっています。
  • 指定したグループに置かれていないセクションは、出力開始時に、いっしょにグルーピングされます。
  • グループは、コマンドファイルで宣言された順番、またはオブジェクトファイル及びライブラリファイルにある順番で、出力されます。
  • 属性付きで宣言されたセクション、つまり、グループ内になく、オブジェクトファイルまたはライブラリファイル内にあるセクションは、コマンドファイルで適切に宣言することにより、指定したグループに入れられます。

4. 3 コマンドファイルの例

この例では３つのオブジェクトファイルを読み込んでいます。

例

        org	$80010000
        comdata	group
        code	group
        bssdata	group	bss
        
        section	data1,comdata
        section	data2,comdata
        section	code1,code
        section	code2,code
        section	tables,bssdata
        section	buffers,bssdata
        
        include	"inp.obj"
        include	"sort.obj"
        include	"out.obj"
        
        regs	pc=progstart
