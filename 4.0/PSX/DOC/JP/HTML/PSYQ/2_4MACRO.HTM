マクロ

ASMPSX は、広範なマクロ機能を提供しています。マクロにより、一連のコードに名前を指定することができます。マクロは、既存のディテクティブと同様に使用することができます。

↑ 1 マクロの定義

マクロを定義するためのディレクティブとして下記のものがあります。

MACRO, ENDM, MEXIT


書式
<Label> MACRO [symbol][,symbol]...
...
MEXIT
...
ENDM

解説
マクロは、MACRO～ENDM 間のソース及び引数のプレースマーカから成っています。Label フィールドは、そのマクロのシンボル名です。オペランド symbol で、引数のデータ名の文字列を指定することができます。
アセンブラが、Label 及び任意の引数からなる命令を検出すると、ソースラインはメインプログラムに読み込まれ、プレースマーカが呼び出し引数に置換され、展開されます。マクロの展開は、アセンブラが MEXIT を検出すると停止されます。

参照
MACROS

備考
マクロのサイズは、呼び出し時にマクロ名に続いて"."（ドット）を付けて指定します。これには、".b"、".h"、".w"だけでなく、テキストを指定することもできます。
マクロ内の制御構造は、マクロ内で完結していなければなりません。マクロでスタートする構造は、ENDM の前で終わらなければなりません。同様に、マクロの外でスタートした構造は、マクロ内で終了してはなりません。別のアセンブラから簡単な制御構造を模造するには、ショートマクロが便利です。詳しくは MACROS の項を参照してください。

例 
remove	macro
	dh	-2,0,0
	endm
Form	macro
	if	strcmp('\1','0)
	dh	0
	else
	dh	\1-FormBase
	endif
	endm

↑ 2 マクロパラメータ

マクロパラメータは、下記のルールに従っています。

  • マクロディレクティブ行にリストされているパラメータは、MACRO～ENDM ステートメント間のコードであれば、任意の位置で使用できます。各パラメータは、"\"（バックスラッシュ）付きで表わされます。ただし、これらが、EQUS で指定したテキストと混同される可能性があるときは、パラメータの後にもバックスラッシュを付けてください。
  • パラメータは、32 個まで使用することができ、"\0"～"\31"で表わされます。"\0"は特殊パラメータで、マクロディレクティブが呼び出されたときの、その size フィールドの内容、つまり、"."（ドット）の後のテキストを表わします。これには、"b"、"h"、"w"だけでなく、テキストも含まれています。

例えば、次の例では NOP 命令が生成されます。

例

        zed	macro
        	\0
        	endm
        	...
        	zed.nop
  • パラメータを示すものとして、"\0"～"\31"といった形式の代わりに、MACRO ディレクティブのオペランドで指定したシンボル名を用いることもできます。必ずしも名前の前にバックスラッシュを付ける必要はありませんが、周囲のテキストと混同される可能性がある場合には、シンボル名の前に（必要に応じて後ろにも）、バックスラッシュを付け、式が正確に展開されるようにしてください

例

        Position	macro	A,B,C,Pos,Time
        		dh	\Time*(\A*\Pos,\B*\Pos,\C*\Pos)
        		endm
  • 呼び出し時にパラメータを"<"（大なり記号）及び">"（小なり記号）で囲むことにより、パラメータ内でコンマ及びスペースを使うことができます。但し、これは角カッコをアドレスモード指定子として使っているアセンブラには適用されません。このような場合には、バッククォートを使ってください。

例

        Credits	macro
        	dh	\1,\2
        	db	\3
        	db	0
        	even
        	endm
        	...
        	Credits	11,10,<Psy-Q, by Psygnosis>
  • マクロを呼び出すとき、パラメータリストが長くなり過ぎることがあります。これはどの命令ステートメントにも当てはまりますが、行末に"&"（アンパサンド）を付けることにより、行を分割することができます。

例

        chstr		macro
        		rept	narg
        		db	k_\1
        		shift
        		endr
        		db	0
        		even
        		endm
        		...
        cheatstring	chstr	i,c,a,n,b,a,r,e,l,y,&
        			s,t,a,n,d,i,t

↑ 3 特殊パラメータ

マクロには、多種の特殊パラメータフォーマットが使用できます。

3. 1 整数をテキストに変換するには

"\#"及び"\$"パラメータは、これに続くシンボルを、これが示す 10 進または 16 進数の数値文字列で置き換えます。これは一般的に、実行時の日付と時刻を表わすのに利用されます。

例

        	org	$1006
        RunTime	db	"\#_hours:\#_minutes:\#_seconds"

上の例は、hh:mm:ss のフォームに展開されます。

例

        RunTime	db	 "21:08:49"

3. 2 ユニークなラベルを生成するには

"\@"パラメータを、マクロのラベル名の最後の文字として使うことができます。マクロが呼び出されると、これは、下線と 10 進数の組み合わせに展開されます。この数字は、呼び出しがある度に増加するので、ユニークなラベルとなります。
例えば下の例では、Slots マクロが使われる度に、next_001 及び dun_001 といった形式の新たなラベルが生成されます。

例

        Slots	macro
        	add	r1,r0,r0
        	lw	r1,\1
        	beq	r1,r0,dun\@
        next\@	addiu	r3,r0,1
        	bge	r3,r0,next\@
        dun\@
        	endm
        	...
        	Slots 	freeob1\w,numslot1\w

3. 3 全パラメータ

マクロ呼び出しステートメントで指定されている全引数を表わす特殊パラメータとして、"\_"があります。例えば次の例では、"\_"が"1,2,3,4"に展開されます。

例

        All     macro
        	db	\_
        	endm
        	All	1,2,3,4

3. 4 コントロールキャラクタ

"\^<x>"（バックスラッシュとサーカムフレックスに続き、コントロールキャラクタｘを指定）により、コントロールキャラクタを生成することができます。

3. 5 マクロラベルを使うには

呼び出し行の行頭にあるラベルをマクロ内で使用するには、MACRO ディテクティブの最初のシンボルを"*"（アスタリスク）にし、ラベル自身を"\*"で置き換える必要があります。しかし、その結果生成されるラベルは、現在のプログラム位置では定義されていません。従って、プログラマがこれに値を代入しない限り、ラベルは未定義のままとなってしまいます。

3. 6 拡張パラメータ

ASMPSX は、"{}"（カーリーブラケット）で囲まれている要素のセットを、マクロパラメータに引き渡すものとして受け付けます。NARG 機能及び SHIFT 命令は、そのリストを処理するために使用できます。

例

        cmd	macro
        cc	equs	{\1}
        	rept	narg(cc)
        	\cc
        	shift	cc
        	endr
        	endm

↑ 4 パラメータの制御


SHIFT, NARG


書式
<directive> NARG
...
SHIFT

解説
これらの命令は、そのオペランドとして変数パラメータリストをもつマクロの要求に応えます。
NARG は、マクロ呼び出し行の引数の数です。SHIFT は、すべての引数を左にシフトし、一番左の引数を上書きします。

参照
拡張パラメータ

例 
routes	macro
	rept	narg
	if	strcmp('\1','0')
	dh	0
	else
	dh	\1-routebase
	endif
	shift
	endr
	endm
	...
	routes	0,gosouth_1

↑ 5 その他のディレクティブ


MACROS


書式
<Label> MACROS [symbol][,symbol]...

解説
１行のコードを、ENDM 命令なしでマクロ定義することができます（ショートマクロ）。
MACROS 命令は、複雑なコードの代役としても使用できます。ショートマクロにより、プログラマはしばしば、別のアセンブラから命令を合成することができます。

参照
MACRO

備考
ASMPSX の"/k"オプションにより、外部の命令をエミュレートする幾つかのマクロを生成することができます。

例 
	if	0
boom	macros   
	jal	boom\1
	else
boom	macros
	lw	r1,blowup-tactbase&
		slot_tatoc(\1)
	endif

PUSHP, POPP


書式
PUSHP <string>
POPP <string>

解説
文字列変数にテキストをプッシュ、あるいはポップします。

備考
PUSHP に対応する POPP 命令は、同じマクロに存在しなくても構いません。

例 
ifhid	macro
	dh	ibvis
	dh	\1
	pushp	"\@"
	dh	\@-2-*
	endm
	...
ifnot	macro
	popp	lab
	goto	\@
	pushp	"\@"
\lab
	endm

PURGE


書式
PURGE <macroname>

解説
PURGE 命令は、展開したマクロ macroname を内部テーブルから削除し、これが占有していたメモリを解放します。

備考
マクロの再定義が必要な場合でも、これを消去する必要はありません。既存マクロが再定義されている場合は、オリジナルのマクロはアセンブラにより消去されます。

例 
HugeM	macro
	dh	\1
	dh	\2
	...
	dh	\31
	endm
	HugeM	para1,103,faultlevel,&
	...
		40,50,para31
	purge	HugeM

TYPE


書式
TYPE(symbol)

解説
TYPE は、シンボルについての情報を提供する機能です。マクロと一緒に、そのパラメータの性質を決定するために頻繁に使われます。値はワードとして返されます。ビット設定の意味は下記の通りです。

ビット意味
Bit 0シンボルには絶対値があります。
Bit 1シンボルは、セクションの始めに関連しています。
Bit 2シンボルは、SET を使って定義されています。
Bit 3シンボルは、マクロです。
Bit 4シンボルは、String Equate(EQUS) です。
Bit 5シンボルは、EQU を使って定義されています。
Bit 6シンボルは、XREF ステートメントにあります。
Bit 7シンボルは、XDEF ステートメントにあります。
Bit 8シンボルは、関数です。
Bit 9シンボルは、グループ名です。
Bit 10シンボルは、マクロパラメータです。
Bit 11シンボルは、ショートマクロ (MACROS) です。
Bit 12シンボルは、セクション名です。
Bit 14シンボルは、Register Equate(EQUR) です。
