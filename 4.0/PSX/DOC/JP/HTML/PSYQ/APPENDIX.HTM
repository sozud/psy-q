↑ 1 エラーメッセージ一覧

ここでは、ASMPSX、PSYLINK、PSYLIB が出力するエラーメッセージの一覧をアルファベット順に掲載しています。
エラーメッセージに続いて、そのメッセージの意味、もしあればそのメッセージに関する補足説明、そしてそのメッセージを出力するプログラム名を記述しています。
また、メッセージ中の"%"で始まる文字は、変数を表しています。

表記意味
%s文字列に置き換えられます。
%c１つの文字に置き換えられます。
%d16 ビットの 10 進数に置き換えられます。
%l32 ビットの 10 進数に置き換えられます。
%h16 ビットの 16 進数に置き換えられます。
%n記号名に置き換えられます。
%t
たとえばセクション、記号、またはグループなどの、シンボルに
置き換えられます。


%t

1. 1 %t %n redefiend as section

意味　　　: %t %ｎはセクションとして再定義されます。
補足説明 : 以前に定義されたシンボルの新しい定義です。
プログラム: PSYLINK

1. 2 %t '%n' redefined as XDEF symbol

意味　　　: %t '%n'は XDEF シンボルとして再定義されます。
補足説明 : 以前に定義されたシンボルの新しい定義です。
プログラム: PSYLINK

1. 3 %t '%n' redefined as group

意味　　　: %t '%n'はグループとして再定義されます。
補足説明 : 以前に定義されたシンボルの新しい定義です。
プログラム: PSYLINK

'%n'

1. 4 '%n' can not be used in an expression

意味　　　: '%n'は式で使用できません。
補足説明 : %ｎは、マクロやレジスタなどの名前と思われます。
プログラム: ASMPSX

1. 5 '%n' is not a group

意味　　　: '%n'はグループではありません。
補足説明 : グループ名が必要です。
プログラム: ASMPSX

1. 6 '%n' is not a section

意味　　　: '%n'はセクションではありません。
補足説明 : セクション名が求められていますが、名前%ｎが見つかりました。
プログラム: ASMPSX

↑ 2 ファイルサーバー機能

以下の関数により、ターゲットボードマシンから、PC (DOS/V) 上のファイルをアクセスすることができます。ただし、１回に読み書きできるサイズは 65,534 バイトまでです。

PCinit


書式
int PCinit( void )

引数
なし

解説
PC ファイルシステムを初期化する。
現在オープンされているバッファをすべてフラッシュし、ファイルをすべてクローズする。
なお、オープンできるファイルの上限は CONFIG.SYS の FILES によって規定されている。デフォルトは 20 であり、より多くのファイルをオープンする場合は、CONFIG.SYS の FILES 行を変更する必要がある。

返り値
成功した場合は０、それ以外の場合はエラーコードを返す。

PCcreat


書式
int PCcreat(name, perms);
char *name;
int perms;

引数
name ファイル名
perms ファイル属性

解説
ファイル name を perms で指定された属性で作成する。

返り値
成功した場合はファイルハンドルを、それ以外の場合は -1 を返す。

PCopen


書式
int PCopen(name, flags, perms)
char *name;
int flags;
int perms;

引数
name ファイル名
flags オープンモード
perms ファイルパーミッション

解説
ファイル name を perms で指定されたパーミッションでオープンする。
permsは通常0を指定して下さい。
flagsの種類を以下に挙げます。なお、LIBAPIのopen()で使われるflagの値とは関係ありませんので注意して下さい。

flagsの値オープンモード
0リードオンリ
1ライトオンリ
2リード／ライト


返り値
成功した場合はファイルハンドルを、それ以外の場合は -1 を返す。

例 
#include "libsn.h"
/* read named file to memory          */
void read_in_file(char *name, char *buff)
{
int fd;
long len;
fd = PCopen(name, 0, 0);
if (fd == -1) {
	printf("Error opening file %s＼n", name);
	exit(1);
}
len = PClseek(fd, 0L, 2);	/* seek to end of file to get length */
PClseek(fd, 0L, 0);		/* back to the start */
if (PCread(fd, buff, len) != len) {
	printf("Failed to read all of file %s＼n", name);
	exit(1);
}
PCclose(fd);
}
main()
{
....
read_in_file("mat0", (char*)0xA0040000);
read_in_file("mat1", (char*)0xA0050200);
...
}

PCclose


書式
int PCclose(fd)
int fd;

引数
fd ファイルハンドル

解説
ファイル fdを閉じる。

返り値
成功した場合は０を、それ以外の場合は DOS のエラーコードを返す。

PCread


書式
int PCread(fd, buff, len)
int fd;
char *buff;
int len;

引数
fd ファイルハンドル
buff バッファを指すポインタ
len 読み込むバイト数

解説
ファイル fd から、データを len バイト読み込み、buff に格納する。
なお、len にファイルサイズより大きい値を指定してはならない。

返り値
成功した場合は読み込んだバイト数を、それ以外の場合は０を返す。

PCwrite


書式
int PCwrite(fd, buff, len)
int fd;
char *buff;
int len;

引数
fd ファイルハンドル
buff バッファを指すポインタ
len 書き込むバイト数

解説
ファイル fd に、バッファ buff からデータを len バイト書き込む。
また、fd に負の値を指定することにより、バッファの内容をデバッガのメッセージウィンドウに出力することができる。例えば -1 を指定すると １番目のウィンドウ、-2 を指定すると ２番目のウィンドウに出力される。この場合、ファイルをオープンする必要はない。デバッガが実行されていない場合でも、メッセージは内部のリングバッファ (4KB) にバッファリングされ、デバッガが起動されるとその内容が表示される。

返り値
成功した場合は書き込んだバイト数、それ以外の場合は０を返す。

PClseek


書式
int PClseek(fd, offset, mode)
int fd;
int offset;
int mode;

引数
fd1 ファイルハンドル
offset シークオフセット
mode ファイルシークモード

解説
ファイル fd のファイルポインタを、mode で指定された条件に従って、offset で指定された位置に移動する。
mode に指定できる値は次の通り。

pollhost


書式
void pollhost ( void )

引数
なし

解説
DBUGPSXからの要求に応じて情報を提供する。
DBUGPSXがデータを要求していない場合はすぐに戻る。データを要求している場合は、その転送にいくばくかの時間がかかる。DBUGPSXの更新時間はオプションで設定可能(DBUGPSXの項参照)。
また、ソースコードにpollhost()がないとデバッガは正常に動作しないので注意。通常、メインループの最後か、割り込み処理から呼ばれる。

返り値
なし
