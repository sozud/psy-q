プログラムの実行- RUN

作成したプログラムをターゲットにダウンロードし、実行するには、RUN.EXE を用います。

↑ 1 書式

RUN.EXE を実行するには、MS-DOS のプロンプトから次のように入力します。
        run [/option] <filename> [[/option] <filename>]...
オプションは"/"（スラッシュ）に続けて指定します。複数指定する場合はスペースで区切ります。
オプションに続き、実行可能ファイル名を指定します。拡張子が省略された場合、".CPE"が用いられます。次の例では、test.cpe をダウンロードし、ファイル記述された実行開始アドレスから実行します。

例

        run test.cpe （拡張子あり）
        run test     （拡張子なし）

ファイルは最大８個まで指定できます、この場合、左から順にダウンロードされていきます。ただし、実行開始アドレスは最後に指定されたファイルに記述されているものになります（下の例では test3.cpe に記述されたアドレス）。

例

        run test1 test2 test3

Ver.2.32より、バイナリファイルのダウンロードをサポートしました。ファイル名に続けてロードアドレスを設定します。ファイル名の拡張子は .binでなければなりません。

例

        run mydemo.bin,80010000 /e80011000

また、RUN.EXE を引数なしで起動すると、ターゲットボードとの通信のみを行ないます。成功した場合はターゲット ID を表示し、失敗した場合はエラーメッセージが表示されます。これにより、ターゲットボードが正常に動作しているかを確認することができます。

例

≪失敗時≫

        C:＼>run
        RUN.EXE Executable/Binary file downloader version 2.23
        	Copyright(C) 1992, 93 S N Systems Ltd.
        Cannot connect to target

≪成功時≫

        C:＼>run
        RUN.EXE Executable/Binary file downloader version 2.23
        	Copyright(C) 1992, 93 S N Systems Lted.
        Target () is R3000-SONY_PSX4.00
        No file to process

↑ 2 オプション

オプションは"/"（スラッシュ）に続けて指定します。複数指定する場合はスペースで区切ります。
オプションには次のものがあります。

ターゲット停止(/h)

"/h"を指定すると、ターゲットを停止します。すなわち、ダウンロードのみを行ない、実行はしません。

例

        run /h test.cpe

タイムアウト時間指定(/w##)

"/w"に続いて数字を指定する事によって、タイムアウト時間を設定できます。
バッチファイル等で resetpsやrunを連続して実行する際、ターゲット側の処理が
終了する前に次のrunが発行され、"Cannot connect to target" エラーが起きる事が
あります。そういった場合にはこのオプションで調整して下さい。

例

        resetps 1         # reset the PSX (this takes a while to complete)
        run /w4 patchx    # install new kernel (4 second timeout)
        run /w4 newdex    # install debug stub (4 second timeout)

実行開始アドレス指定(/e[address])

"/e"で実行開始アドレスが指定できます。

例

        run mydemo.bin,80010000 /e80011000

↑ 3 ファイルについて

RUN.EXE の引数として指定できるファイルは、Psy-Q システムによって作成された.CPE 形式の実行可能イメージです。
実行開始アドレスは、指定されたファイルに記述されたものとなります。ただし、複数指定した場合は、最後に指定されたファイルに記述されたアドレスとなりますのでご注意ください。
