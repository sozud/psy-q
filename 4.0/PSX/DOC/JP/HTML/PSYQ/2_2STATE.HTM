アセンブラステートメントの文法

アセンブラの実行を制御するために、ソースコードには、伝統的に、多くの追加ステートメント及び関数が記述されています。
これにより、プログラマは、コードの各部分が解析され、マシンリーダブルなフォーマットに変換されるように、アセンブラのフロー及び動作を管理することができます。
通常、アセンブラステートメントは、ホストの言語フォーマットを反映しており、ASMPSX もこの規定に従っています。

↑ 1 ステートメントのフォーマット

ASMPSX ステートメントのフォーマットは、次の通りです。

        <Name/Label>  <Directive>  <Operand>
ステートメントには、以下の規約が適用されます。
  • 各フィールドは、スペースまたは TAB で区切ります。
  • 長い行は、行末に"&"（アンパサンド）を付け、分割することができます。
  • "="（イコール）から始まる行は、CASE ステートメントの case 部とみなされます。詳しくは「一般ディレクティブ」の章の「CASE,ENDCASE」の項を参照してください。
  • コメントは";"（セミコロン）に続いて記述します。
  • スペースまたは TAB のみから成る行はコメントとして扱われます。
  • "*"（アスタリスク）から始まる行もコメントとして扱われます。

↑ 2 名前及びラベルのフォーマット

名前及びラベルは、英数字記号、すなわち"A～Z"、"a～z"、及び"0～9"により構成されています。また、次の記号は特別な意味を持ちます。

記号意味
:
コロンは、名前またはラベルの終端記号です。ただし、参照時
には使用できません。
?、 _ 、.
クエスチョンマーク、アンダースコア、及びドットは、しばし
ば視認性を向上させるために使用します。
@
アットマークは、ローカルラベルの開始記号です。なお、ロー
カルことができます。名前及びラベルには、次の規約が適用さ
れます。
数字及びクエスチョンマークで始まる名前を指定することは
できません。
ラベルは行頭に記述し、コロンで終端させます。但し、行頭
にスペースまたは TAB を挿入することは可能です。
名前／ラベルに英数字以外の文字があり、これにより解釈の
問題が発生している場合、その文字のをバックスラッシュで置
き換えるか、あるいは、名前／ラベル全体をカッコで囲んでく
ださい。

↑ 3 定数のフォーマット

ASMPSX アセンブラは、下記のタイプの定数をサポートしています。

3. 1 文字定数

ダブルクォーテーションで囲まれた文字列は文字定数として扱われ、ASCII 値で評価されます。文字定数は最大４文字まで指定可能で、その値は 32 ビット値となります。

例

        "A"    = 65
        "AB"   = (65*256)      + 66 = 16706
        "ABC"  = (65*65536)    + (66*256)   + 67 = 4276803
        "ABCD" = (65*16777216) + (66*65536) + (67*256) + 68 = 1094861636

3. 2 整数定数

以下の場合を除き、整数定数は 10 進数を基数として評価されます。
  • RADIX ディレクティブにより基数を変更した場合。
  • "$"で始まる数字は 16 進数、"%"で始まる数字は２進数を表わします。
  • "\^"（バックスラッシュとサーカムフレックス）で始まる文字は、これに続く文字が示すコントロールコードに置き換えられます。
  • OPT ディレクティプの AN オプションで、数値を Intel 及び Zilog 整数として定義することができます。すなわち、数値は、数字で始まり、下記のいずれかで終わる必要があります。

記号意味
D10 進数
H16 進数
B２進数

4. 1 時間及び日付定数について

時間及び日付を示す定数は、アセンブル開始時に設定されます。アセンブル中には更新されません。

例

        RunTime	db "\#_hours:\#_minutes:\#_seconds"

上の例は、次のように hh:mm:ss 形式に展開されます。

例

        RunTime db "21:08:49"
なお、この例にある特殊マクロパラメータ "\#"については、「マクロ」の章の「３特殊パラメータ」の項を参照してください。

4. 2 ロケーションカウンタ定数について

プログラムポインタの現行値を定数として使用することができます。現在位置のロケーションカウンタを表わすには、"*"（アスタリスク）を使用します。

例

        		section	Bss,g_bss
        Firstbss	equ	*

"*"は、行の始めのアドレスを示していますので、次のようにすると$100 を３回定義します。

例

        org	$100
        dw	*,*,*

また、"@"は、それ自身が定数として使用された場合、現在値が格納されているアドレスを指すロケーションカウンタの値に置換されます。次の例では、$100、$104、$108 を定義します。

例

        org	$100 
        dw	@,@,@

↑ 7 アセンブラ演算子

ASMPSX は、以下の式演算子を利用します。
なお、比較が真として評価される場合、その結果は、-１として返されます。また、偽として評価される場合、その結果は、０として返されます。

ASMPSX は、32 ビットアセンブラですので、マイナス符号ビットは bit 31 となります。従って、$FFFFFF 及び$FFFFFFF は正の数値、$FFFFFFFF は負の数値となります。

+単項+aａが正
-単項-aａが負(※1)
=２進a=bａにｂを割り当て、またはｂと等価にする
+２進a+bａにｂを加える
-２進a-bａからｂを引く
*２進a*bａにｂを掛ける
／２進a/bａをｂで割った商を求める

<<２進a<<bａをｂ回左にシフトする
>>２進a>>bａをｂ回右にシフトする
~単項~a論理補数または NOT a
&２進a&bａとｂの論理積 (AND) 演算を行う
^２進a^bａとｂの排他的論理和 (XOR) 演算を行う
!２進a!bａとｂの論理和 (OR) 演算を行う

7. 1 優先順位

ASMPSX では、式は以下の規約に基づいて評価されます。
  • カッコにより括られた内容は優先順が強制的に上げられ、最初に実行されます。
  • カッコ付きでない場合、各演算子は、所定の優先順位に従って実行されます。
  • 同様な手続きの演算子は、その結合規則に従って実行されます。通常、単項演算子を除き、左から右に実行されます。
    演算子方向内容
    ( )←一次演算子
    + - ~→単項演算子
    << >>→シフト演算子
    & ! ^→論理演算子
    * ／ %→乗除演算子
    + -→加減演算子
    > < <= >=→関連演算子
    = <>→等価演算子

↑ 8 ディレクティブ

ここでは、定数や関数に関連するディレクティブについて解説していきます。

RADIX


書式
RADIX <newbase>

解説
基数を newbase で指定された値に変更します。newbase に指定できる値は２～16 です。また、newbase は現在の基数に関係なく、常に 10 進数で評価されます。

備考
デフォルトの基数は 10 進数です。
個々の数値の前に"$"あるいは"%"を記述することにより、その数値を 16 進あるいは２進数とすることも可能です。
OPT ディレクティブの AN オプションは、デフォルトの基数が 10 より大きい場合、実行されません。これは、"B"及び"D"が、16 進数表記においては数値として扱われるためです。

例 
radix	8

ALIAS、DISABLE


書式
<newname> ALIAS <name>
DISABLE <name>

解説
ALIAS は、name を newname に変更します。また、DISABLE は、name を ASMPSX が使用しないようにします。これにより、プログラマは、ASMPSX に予約されている名前とプログラムで使用している名前とが衝突することを回避することができます。

備考
ASMPSX のディレクティブを使用不可能としてはなりません。

例 
_Offset	alias	offset
		disable	offset
		...
_Offset	dh	_Offset(Lab)
offset	dh	*-pointer
