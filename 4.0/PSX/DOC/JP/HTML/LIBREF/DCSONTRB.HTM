DsControlB

CdControlBの互換関数

形式 

int DsControlB (
u_char com,
u_char* param,
u_char* result
)
引数 
com		コマンドコード
param		コマンドに対する引数（u_char[ 4 ]）
result		コマンドに対する返り値（u_char[ 8 ]）
解説
CdControlBと同じインターフェイスを提供する関数。コマンドキューを使用しているため、実際のタイミングは多少異なる。

返り値
0： コマンド実行失敗
1： コマンド実行成功
