GsSortSpriteB

スプライトをOTに登録（アーケード用）

形式 

void GsSortSpriteB (
GsSPRITE * sp, 
GsOT * otp, 
unsigned short pri,
unsigned short flip;
)
引数 
sp		スプライトへのポインタ
otp		OTへのポインタ
pri		OTでの位置
flip		FLIPするかどうかのフラグ
		0:FLIPをおこなわない
		1:x方向の反転
		2:y方向の反転
		3:x方向およびy方向の反転
解説
sp で示されるスプライトを、otp で示されるオーダリングテーブルに割り付ける。
スプライトの表示位置等のパラメータは全て、sp のメンバで与える。
pri はそのスプライトのオーダリングテーブル上での優先順位。
優先順位は最高値が０で最低値はそのオーダリングテーブルの大きさに依存する。
オーダリングテーブルの大きさ以上の数値は、そのオーダリングテーブルの取り得る最大値にクリップされる。
flipは水平方向および、垂直方向の反転を行うかどうかのフラグである。

返り値
なし
