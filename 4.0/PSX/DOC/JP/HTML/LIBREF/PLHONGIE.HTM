PhongLine

フォンシェーディング

形式 

void PhongLine(
int istart_x,
int iend_x,
int p,
int q,
u_short **pixx,
int fs,
int ft,
int i4,
int det
)
引数 
isstat_x	開始点のＸ座標
iend_x		終点のＸ座標
p		fs値のX座標による微分
q		ft値のX座標による微分
pixx		ピクセルポインタ
fs		スタート地点における内挿係数
ft		スタート地点における内挿係数
i4		ディザリングのための (line数)%4
det		エッジ行列の行列式
解説
１ラインのフォンシェーディングを行なう。

返り値
なし
