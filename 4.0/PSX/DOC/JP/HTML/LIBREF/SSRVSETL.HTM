SsSetRVol

リバーブボリューム値設定

形式 

void SsSetRVol (
short voll,
short volr
)
引数 
voll		Lチャンネルボリューム値
volr		Rチャンネルボリューム値
解説
リバーブボリューム値を voll,volr にそれぞれ設定する。それぞれ0～127まで設定可能。

返り値
なし
