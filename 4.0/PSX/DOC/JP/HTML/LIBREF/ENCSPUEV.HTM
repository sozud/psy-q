ENCSPUENV

SPUエンコード環境属性構造体

構造 

typedef struct {
		short	*src;
		short	*dest;
		long	size;
		long	loop_start;
		char	loop;
		char	byte_swap;
		char	proceed;
		char	pad4;
} ENCSPUENV;
メンバ 
src		16-bit ストレート PCM データアドレス
dest		PlayStation オリジナル波形データ
size		16-bit ストレート PCM データサイズ (単位:byte)
loop_start	PCM データのループスタートポイント (単位:byte)
loop		ループ波形生成指定
byte_swap	PCM データの endian 指定
proceed		一括/分割エンコード指定
解説
EncSPU() のための SPU エンコード環境属性を指定する。

備考
使用法の詳細はEncSPU() を参照。
