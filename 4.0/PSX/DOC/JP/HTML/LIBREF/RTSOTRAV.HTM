RotTransSV

回転マトリックスで座標変換を行なう

形式 

void RotTransSV
SVECTOR *v0,
SVECTOR *v1,
long *flag
)
引数 
v0		入力：ベクトル
v1		出力：ベクトル
flag		出力：フラグ
解説
RotTransの出力ショートベクトル版。
v1 = RTM×v0

引数フォーマット：
v0->vx,vy,vz : (1,15,0)
v1->vx,vy,vz : (1,15,0)
flag : (0,32,0)

返り値
なし
