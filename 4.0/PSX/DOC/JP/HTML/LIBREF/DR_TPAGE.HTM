DR_TPAGE

テクスチャページ変更プリミティブ

構造 

typedef struct {
		u_long	tag;
		u_long	code[1];
} DR_TPAGE;
メンバ 
tag		次のプリミティブへのフック（予約）
code		プリミティブ ID
解説
DR_TPAGEプリミティブはカレントテクスチャページ設定を描画の途中で変更します。
内容の設定は、SetDrawTPage()で行う。
