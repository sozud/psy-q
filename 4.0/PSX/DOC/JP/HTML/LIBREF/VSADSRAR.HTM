SpuSetVoiceADSRAttr

ADSR と各モードの設定

形式 

void SpuSetVoiceADSRAttr (
int voiceNum,
unsigned short AR,
unsigned short DR,
unsigned short SR,
unsigned short RR,
unsigned short SL,
long ARmode,
long SRmode,
long RRmode
)
引数 
voiceNum	ボイス番号 (0 ～23)
AR		ADSR Attack Rate
DR		ADSR Decay Rate
SR		ADSR Sustain Rate
RR		ADSR Release Rate
SL		ADSR Sustain Level
ARmode		ADSR Attack Rate モード
SRmode		ADSR Sustain Rate モード
RRmode		ADSR Release Rateモード
解説
ボイスで使われる ADSR の個別の属性の設定を行う。
SpuSetVoiceAttr() の mask 指定
SPU_VOICE_ADSR_AR SPU_VOICE_ADSR_AMODE
SPU_VOICE_ADSR_DR
SPU_VOICE_ADSR_SR SPU_VOICE_ADSR_SMODE
SPU_VOICE_ADSR_RR SPU_VOICE_ADSR_RMODE
SPU_VOICE_ADSR_SL
に該当する処理を行う。
各 Rate及び各 Rateモードに指定する値に関しては SpuSetVoiceAttr() を参照のこと。

返り値
なし
