frexp

正規化小数部と２のべき乗部への分解

形式 

double frexp (
double x, 
int *n
)
引数 
x		浮動小数点値
n		２のべき乗部を格納するバッファへのポインタ
解説
x を[1/2,1)に正規化された小数部と２のべき乗部に分解する。
小数部は返り値となり、べき乗部は n に格納される。

返り値
正規化小数部 [1/2, 1)

備考
[]は閉区間、()は開区間を示す。
