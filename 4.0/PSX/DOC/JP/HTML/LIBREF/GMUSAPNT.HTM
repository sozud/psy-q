GsMapUnit

HMD データを実アドレスにマップ

形式 

void GsMapUnit (
unsigned long	*p
)
引数 
p		HMD データの先頭アドレス
解説
HMD データにはポインタで参照する部分が存在する。HMD データ作成時には、メモリのどこにロードされるか確定しないため、HMD データの先頭からのオフセットアドレスがワード数で格納されている。GsMapUnit() 関数は、このオフセットアドレスを実アドレスに変換するもので、HMD データを使用するにはこの実アドレス変換をまず最初に行わなければならない。

返り値
なし

備考
一度実アドレスに変換された HMD データにはフラグが立っているので、再度 GsMapUnit() を呼び出しても、副作用は起こらない。
