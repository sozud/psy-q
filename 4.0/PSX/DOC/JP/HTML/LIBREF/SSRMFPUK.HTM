SpuSetReverbModeFeedback

リバーブのフィードバックの設定

形式 

void SpuSetReverbModeFeedback (
long feedback
)
引数 
feedback	リバーブのフィードバック
解説
リバーブのフィードバックの設定を行う。
SpuSetReverbModeParam() の mask 指定
SPU_REV_FEEDBACK
に該当する処理を行う。
リバーブモードが SPU_REV_MODE_ECHO, SPU_REV_MODE_DELAY の場合のみ有効となる。他のモードが設定されていた場合は何も影響しない。
リバーブのフィードバック feedback に指定する値に関しては SpuSetReverbModeParam() を参照のこと。

返り値
なし
