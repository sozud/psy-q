拡張CD-ROMライブラリ（libds） 関数一覧
Release 4.0

DsRead

データを読み込む

形式 

int DsRead (
DslLOC* pos,
int sectors,
u_long* buf,
int mode
)
引数 
pos		データの開始位置
sectors		読み込むセクタ数
buf		データを格納するバッファの先頭アドレス
mode		データを読み込む際の動作モード
解説
CDのデータをメインメモリに読み込む。読み込みはセクタ単位で行われるため、bufの大きさは１セクタ＝２０４８バイト（５１２ワード）の倍数でなければならない。
データの読み込み処理は関数の実行終了後バックグラウンドで行われる。関数の実行の成功がデータの読み出しの成功ではないことに注意。

返り値
0： 関数の実行失敗
1： 関数の実行成功

備考
CdRead()とは引数が異なることに注意。DsRead()ではデータの開始位置を指定する。
