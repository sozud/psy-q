GetCr

原因レジスタ値の取得

形式 

unsigned long GetCr ( void )
引数 
なし
解説
制御レジスタのひとつである原因レジスタの値を取得する。

返り値
現行の原因レジスタの値を返す。各ビットに意味は次のとおり。

ビット内容
31-6システム予約
5-2例外コード
0000: 外部割り込み
0001: 未使用
0010: 同上
0011: 同上
0100: アドレスリードエラー
0101: アドレスライトエラー
0110: 命令バスエラー
0111: データバスエラー
1000: システムコール
1001: ブレークポイント
1010: 未定義命令
1011: 未装着コプロセッサ
1100: オーバフロー
1-0システム予約
