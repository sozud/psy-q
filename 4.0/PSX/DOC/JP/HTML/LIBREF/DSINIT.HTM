Release 4.0

DsInit

システムの初期化を行う

形式 

int DsInit ( void )
引数 
なし
解説
Libdsシステムの初期化を行う。プログラムの最初もしくはDsClose()で終了したシステムを再開する場合に１回だけ呼び出す。

返り値
成功した場合は１を、失敗の場合は０を返す。

備考
DsInit()をプログラムの途中で呼ぶと誤動作を起こすことがある。プログラムの途中で初期化の必要がある場合は、DsReset()を使用する。

関連項目
DsClose(),DsReset()
