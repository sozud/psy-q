SpuFree

サウンドバッファ内に確保されている領域を解放

形式 

void SpuFree (
unsigned long addr
)
引数 
addr		確保されている先頭アドレス(バイト単位)
解説
先頭アドレス addr によって示されるサウンドバッファ内に確保されている領域を解放し、管理用テーブルからその領域情報を削除する。

返り値
なし

関連項目
SpuInitMalloc(), SpuMalloc() SpuMallocWithStartAddr()
