GsMIMePrimHeader

GsMap....MIMe() 関数の返り型

構造 

typedef struct {
	u_long		*mimepr;
	u_long		mimenum;
	u_short		mimeid;
	unsigned	internal:1, mapped:1, r:14;
}	GsMIMePrimHeader;
メンバ 
mimepr		マイム係数領域へのポインタ
mimenum		マイムキーの数
mimeid		当該プリミティブの ID (ユーザー使用領域)
internal	マイム係数領域が HMD 内部にありライブラリがmimeprの値を書き込む場合 1
		マイム係数領域が HMD 外にあり、プログラマがmimeprの値を書き込む場合 0
mapped		mimepr に実アドレスがマップされている場合 1
		mimepr に実アドレスがマップされていない場合 0
r		0 reserved
解説
GsMap....MIMe() 関数が返すポインタの型。このポインタが示す実体はプリミティブヘッダセクション内の当該データである。
ユーザはこの構造体の要素 internal 及び mapped を検査して、必要であればmimepr にプログラムで確保したマイム係数領域の実アドレスを指定し、mapped フラグ を 1 にする。
mimeid は、ユーザが自由に使用できる領域である。たとえば一つの HMD で複数のマイム係数領域を使い分ける場合の判別に使う。
