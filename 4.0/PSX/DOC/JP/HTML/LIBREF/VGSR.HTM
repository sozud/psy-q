SpuGetVoiceSR

ADSR Sustain Rate の取得

形式 

void SpuGetVoiceSR (
int voiceNum,
unsigned short *SR
)
引数 
voiceNum	ボイス番号 (0 ～23)
SR		ADSR Sustain Rate
解説
ボイスで使われる ADSR Sustain Rate の取得を行う。
SpuGetVoiceAttr() における SpuVoiceAttr 構造体のメンバ sr の値の取得に該当する処理を行う。
ADSR Sustain Rate モードが SPU_VOICE_LINEARDecN (リニア減少) になっている場合のみ得られた値は有効となる。 他の ADSR Sustain Rate モードの場合は不定となる。
ADSR Sustain Rate と ADSR Sustain Rate モードを同時に取得したい場合はSpuGetVoiceSRAttr() を使用する。

返り値
なし
