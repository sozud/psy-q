メモリカード簡易レベルライブラリ (libmcrd) 関数一覧
Release 4.0

MemCardInit

メモリカードシステムの初期化

形式 

void MemCardInit (
long val
引数 
val		ROM内のコントローラルーチン使用(0:なし、1:使用する)
解説
メモリカードシステムを初期化する。以降MemCardStart()でシステムを稼働状態にすると、MemCardで始まる各関数が使用可能となる。
２重に実行してはならない。
処理完了に60～70VSYNCを要する。libtap,libgunを利用する場合は、引数を0にする。InitPAD、InitGUN()、InitTAP()よりも後に実行すること。

返り値
なし

備考
同期関数, ブロッキング時間60～70VSYNC。クリティカルセクションには入らない。

関連項目
MemCardEnd(), MemCardStart(), MemCardStop()
