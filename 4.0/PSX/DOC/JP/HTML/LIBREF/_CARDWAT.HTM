メモリカード ライブラリ (libcard) 関数一覧
Release 4.0

_card_wait

メモリカードBIOS処理完了待ち

形式 

long _card_status (
long drv
)
引数 
drv		差し込み口番号（0：向かって左、1：向かって右）
解説
drv で指定する差し込み口宛の登録処理がなくなるまで待つ。

返り値
常に1を返す。

関連項目
_card_status(), _card_chan()
