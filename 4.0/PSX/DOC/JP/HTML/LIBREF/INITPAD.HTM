InitPAD

コントローラの初期化

形式 

long InitPAD (
char *bufA,
long lenA, 
char *bugB,
long lenB
)
引数 
bufA, bufB	受信データバッファ
lenA, lenB	受信データバッファ長（バイト単位）
解説
コントローラの受信データバッファを登録する。内部でChangeClearPAD()は実行しない。

返り値
常に１

備考
受信バッファ長は、予期せぬコントローラを接続された場合に、不具合が起きる可能性がありますので、必ず34バイト確保しておいて下さい。
受信バッファに格納されるデータ形式は以下の通りです。

バイト内容
0受信結果 0x00:成功、0xff:失敗
1
上位4ビット：端末種別
0x1:マウス
0x2:16ボタンアナログ
0x3:ガンコントローラ
0x4:16ボタン
0x5:アナログジョイスティック
0x7:アナログコントローラ
0x8:マルチタップ
下位4ビット：受信データバイト数／２


マウス
3
ボタン状態 1:リリース、0:プッシュ
第2ビット：右、 第3ビット：左
4移動量 X方向 (-128～127)
5移動量 Y方向 (-128～127)
6移動量 Z方向 (-128～127)
7,8, -移動量 ?方向 (-128～127)


16ボタンアナログ、アナログジョイスティック、アナログコントローラ
2,3ボタン状態 1:リリース、0:プッシュ
4,5,6,7,-アナログチャネル値


ガンコントローラ、16ボタン
2,3ボタン状態 1:リリース、0:プッシュ


バッファの第1バイトの上位4ビットは端末種別、下位4ビットは端末からの受信データ（バッファの第3バイト以降に格納される。）のバイト数の半分の値、となります。ボタンやチャネルなどの物理的な配置や対応は各端末のドキュメントを参照してください。

*既存端末の型
標準コントローラは16ボタン型端末です。
弊社から商品化されているマウスは、XとYの２方向だけをサポートするマウス型端末。また株式会社ナムコ様の「ネジコン」は、4チャネル、つまりバッファ第1バイトの下位4ビットが3（（ボタン分2バイト＋4チャネル分4バイト）÷２ ）、の16ボタンアナログ型端末です。
マルチタップ をご利用の際は、InitTAP()を、ガンコントローラをご利用の際は、InitGUN()をお使いください。
