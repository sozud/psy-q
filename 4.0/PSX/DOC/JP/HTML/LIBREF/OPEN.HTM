open

ファイルのオープン

形式 

long open ( 
char *devname,
unsigned long flag
)
引数 
devname		ファイル名
flag		オープンモード
解説
低水準入出力の為にデバイスをオープンして、そのディスクリプタを返す。
flag は、デバイスに依存する。共通部分を以下に示す。

マクロオープンモード
O_RDONLY読み出し専用
O_WRONLY書き込み専用
O_RDWR読み書き兼用
O_CREATファイル新規生成
O_NOBUF非バッファモード
O_NOWAIT非同期モード


返り値
成功するとファイルディスクリプタを、以外は-1を返す。
