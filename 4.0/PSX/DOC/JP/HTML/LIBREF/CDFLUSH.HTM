CD-ROM ライブラリ (libcd) 関数一覧
Release 4.0

CdFlush

CD-ROMコマンドのフラッシュ

形式 

void CdFlush ( void )
引数 
なし
解説
発行中のCD-ROMサブシステムのコマンドをキャンセルする。現在発行中のコマンドは無効になり、サブシステムは、直ちにコマンド受け付け状態（CdlComplete）になる。

返り値
なし

備考
データ受信状態も一旦CdlDataReadyにリセットされるため、CD-ROMから読みだし中に使用する際には注意。
