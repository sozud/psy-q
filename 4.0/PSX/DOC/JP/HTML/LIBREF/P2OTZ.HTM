p2otz

デプスキューイング用の内挿値pからotzを求める

形式 

long p2otz (
long p,
long projection
)
引数 
p		内挿値（ 0 ≦ p ≦ 4096 ）
projection	視点とスクリーンの距離
解説
デプスキューイング用の内挿値 p からおおよそのスクリーン座標のＺ成分szの1/4の値otz を求める。

返り値
OTZ値

備考
フォグの設定によって誤差が大きくなることがあり、必ずしもRotTransPers系の関数と同じ結果にはならない。
p=0もしくはp=4096となるotzは原理的には一意に決まらないが、この関数では便宜的な値を返す。
