StSetMask

ストリーミングの再生をコントロールする

形式 

void StSetMask (
u_long mask,
u_long start,
u_long end
)
引数 
mask		ストリーミングを再生するかしないかのスイッチ
 		0:再生状態、1:停止状態
start		StSetStream()のstart_frame
end		StSetStream()のend_frame
解説
ストリーミング再生を瞬間的に止めたり再開させたりするには、CDROMをポーズしていてはメカ的なタイムラグがあり不可能である。
StSetMask()を使えば mask の値をライブラリに設定することで、瞬間的にストリーミング再生のON/OFFができる。
start,end はStSetStream()のトリガフレームの値を再設定するものである。

返り値
なし
