StRingStatus

リングバッファの状態を返す

形式 

void StRingStatus (
short *free_sectors,
short *over_sectors
)
引数 
free_sectors	リングバッファ上の未使用セクタ数を返す
over_sectors	CDROMのデータを読み込んでいるセクタ位置と現在処理
		しているセクタ位置の差分が返される
解説
リングバッファの状態を引数で与えられる二つの変数に値を返すことでリポートする。

第一引数の free_sectors はリングバッファ上でまだデータが入っていない未使用領域のセクタ数を返す。この値が大きいほどリングバッファに余裕がある。

第二引数の over_sectors はCDROMからデータを読み込んでいるセクタ位置から現在処理中のセクタ位置の差分である。この値が大きいほどリングバッファ上に処理していないデータが多く存在することになる。

free_sectors と over_sectors とを足すとリングバッファのサイズとほぼ等しくなる。感ぜんに一致しない場合があるのはリングバッファの最後の方は１フレーム分のデータが入りきらない場合途中で折り返すからである。

返り値
なし
