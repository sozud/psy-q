DsFlush

コマンドキューをフラッシュする

形式 

void DsFlush ( void )
引数 
なし
解説
コマンドキューに登録されている全てのコマンドを削除する。実行中のコマンドがある場合、実行は最後まで行われるが結果は保存されずコールバック関数も呼び出されない。

返り値
なし

備考
関数呼びだし時に実行中のコマンドがある場合、そのコマンドは最後まで実行されるため、以降のコマンドの実行は待たされる（キューに登録される）。
