CdComstr

コマンドのコードに対応する文字列を得る（デバッグ用）

形式 

char *CdComstr (
u_char com 
)
引数 
com		コマンド終了コード
解説
デバッグ用。処理状態コードから対応する文字列を得る。例えばコードに応じて以下のような文字列を得る。

コマンドコード文字列
CdlNopCdlNop
CdlSetlocCdlSetLoc
CdlPlayCdlPlay
CdlForwardCdlForward
CdlBackwardCdlBackward


返り値
文字列の先頭ポインタ
