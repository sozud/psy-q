SpuGetVoiceVolumeX

現在のボイス音量の取得

形式 

void SpuGetVoiceVolumeX (
int voiceNum,
short *volumeXL,
short *volumeXR
)
引数 
voiceNum	ボイス番号 (0 ～23)
volumeXL	現在の音量 (左)
volumeXR	現在の音量 (右)
解説
ボイスの現在の音量を取得する。
SpuGetVoiceAttr() における SpuVoiceAttr 構造体のメンバ volumex の値の取得に該当する処理を行う。

返り値
なし

関連項目
SpuGetVoiceAttr(), SpuNGetVoiceAttr(), SpuGetVoiceVolume(), SpuGetVoiceVolumeAttr()
