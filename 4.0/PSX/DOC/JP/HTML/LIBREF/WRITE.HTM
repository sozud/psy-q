write

ファイルにデータを書き込む

形式 

long write ( 
long fd,
void *buf,
long n
)
引数 
fd		ファイルディスクプリタ
buf		書き込みデータアドレス
n		書き込みバイト数
解説
fd で指定するディスクリプタから n バイトを buf で指定する領域へ書き込む。

返り値
正常終了時には実際に領域に書き込まれたバイト数を、それ以外は-1を返す。
