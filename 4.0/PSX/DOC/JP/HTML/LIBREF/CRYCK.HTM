CdReadyCallback

CdReadyコールバック関数を定義

形式 

CdlCB CdReadyCallback (
CdlCB func 
)
引数 
func		コールバック関数
解説
データレディ時に呼ばれるコールバックを定義する。セクタバッファのデータが確定した時点でfuncが呼び出される。funcに0を指定した場合は、コールバックは発生しない。
CdlCBは以下のコールバック関数の型を表す 
typedef void ( *CdlCB )( u_char, u_char* )
第一引数にはdata readyのステータスが渡される。ステータスには以下のものがある。
CdlDataReady セクタバッファ上のデータは正常
CdlDiskError セクタバッファ上のデータは誤っている

第二引数はCD-ROMサブシステムからのresult配列のポインタが渡される。resultは8byteである。 
char result[ 8 ];
resultの先頭には ステータスが入りそれ以降は直近に発行されたコマンドによって内容が異なる。

返り値
以前に設定されたコールバックのアドレス

備考
func内では以降の描画終了割り込みはマスクされる。従ってfuncは必要な処理を終了したらすみやかにリターンする必要がある。
