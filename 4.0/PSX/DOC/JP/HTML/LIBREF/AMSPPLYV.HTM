ApplyMatrixSV

ベクトルにマトリクスを乗算する

形式 

SVECTOR *ApplyMatrixSV (
MATRIX *m, 
SVECTOR *v0,
SVECTOR *v1
)
引数 
m		入力：被乗算マトリックス
v0		入力：ショートベクトル
v1		出力：ショートベクトル
解説
マトリックス m にショートベクトル v0 を右側から乗算し、結果をショートベクトル v1 に格納する。

引数フォーマット：
m->m[i][j] : (1,3,12)
v0->vx,vy,vz : (1,15,0)
v1->vx,vy,vz : (1,15,0)

返り値
v1

備考
回転マトリックスをこわす。
