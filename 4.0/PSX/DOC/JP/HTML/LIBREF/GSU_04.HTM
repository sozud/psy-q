GsU_04......

HMD 用マイムドライバ

形式 

unsigned long * GsU_04...... (
GsARGUNIT	*ap;
)
引数 
ap		引数受け渡し領域の先頭アドレス
		通常は高速化のためスクラッチパッドを使用する
解説
HMD のライブラリによるマイムアニメーションのためのドライバ群。
マイムカテゴリのドライバを使用する際には、あらかじめそれぞれの初期化関数によってデータの初期化をおこなう。(各初期化関数の項目参照)
引数 sp の型は GsARGUNIT だが、内部では異なる型として扱われる。
現在 libgs でサポートされているマイムカテゴリのドライバは以下の通り。
