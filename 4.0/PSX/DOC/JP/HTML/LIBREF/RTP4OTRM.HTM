RotTransPers4_nom

４頂点の座標変換と透視変換を行なう

形式 

void RotTransPers4_nom (
SVECTOR *v0,
SVECTOR *v1,
SVECTOR *v2,
SVECTOR *v3
)
引数 
v0,v1,v2,v3	入力：頂点座標ベクトル
解説
３つの座標ベクトル v0,v1,v2,v3 を回転マトリックスで座標変換したあと透視変換を行ない、３つのスクリーン座標(sz0),(sx1,sy1,sz1),(sx2,sy2,sz2), (sx3,sy3,sz3)v3 に対応するデプスキューイング用の内挿値pをGTE内部レジスタに保持する。

引数および内部データフォーマット：
v0,v1,v2->vx,vy,vz : (1,15,0)
sx0,sy0,sz0 : (1,15,0),(1,15,0),(0,16,0)
sx1,sy1,sz1 : (1,15,0),(1,15,0),(0,16,0)
sx2,sy2,sz2 : (1,15,0),(1,15,0),(0,16,0)
sx3,sy3,sz3 : (1,15,0),(1,15,0),(0,16,0)
p : (0,20,12)
flag : (0,32,0)

返り値
flag

備考
(sz0,sz1,sz2,sz3)はマクロread_sz_fifo4で、((sx1,sy1),(sx2,sy2),(sx3,sy3))はマクロread_sxsy_fifo3で、pはマクロread_pで読む。
(sx0,sy0)はレジスタ v1 に返る。
flagはレジスタv0に返る。
