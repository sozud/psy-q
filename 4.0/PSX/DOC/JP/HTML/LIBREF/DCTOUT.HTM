DecDCTout

画像処理サブシステムからデコードデータを受けとる

形式 

void DecDCTout (
u_long *buf, 
int size
)
引数 
buf		解凍後画像データ
size		受信するデータサイズ（ロングワード）
解説
ランレベルを解凍し size ワード分の結果を buf 以下に格納する。
解凍データのフォーマットは、DecDCTin()の引数によって24bit/16bitいずれかになる。
サイズ size は全解凍データサイズと等しいか小さい値を指定する。
全解凍データより小さい値を指定した場合は、送受信のデッドロックを防止するために、続くDecDCToutで残りのデータをすべて読み出す必要がある。
解凍画像は、マクロブロック（16x16矩形領域）単位で出力される。
データサイズはマクロブロックサイズ（16bitモードならば16x16x2 = 512byte = 128 word, 24bitモードならば、16x16x3 = 768 byte = 192 word)単位で指定する必要がある。

返り値
なし

備考
DecDCTout()はノンブロック関数であるため、実際の転送の終了はDecDCToutSync()で検出する必要がある。DecDCTout()の終了をまたずに、次のDecDCTout()を実行すると２回目の送信は１回目の送信が終了するまでブロックされる。
