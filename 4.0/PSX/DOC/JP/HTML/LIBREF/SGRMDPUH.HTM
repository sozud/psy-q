SpuGetReverbModeDepth

リバーブの深さの取得

形式 

void SpuGetReverbModeDepth (
short *depthL,
short *depthR
)
引数 
depthL		リバーブの深さ (左)
depthR		リバーブの深さ (右)
解説
リバーブの深さを取得する。
SpuGetReverbModeParam() において SpuReverbAttr 構造体のメンバ depth の値の取得に該当する処理を行う。

返り値
なし

関連項目
SpuSetReverbModeParam(), SpuGetReverbModeParam(), SpuSetReverbModeDepth()
