DsStatus

CDサブシステムのステータスを得る

形式 

u_char DsStatus ( void )
引数 
なし
解説
最後に報告されたCDサブシステムのステータスを得る。得られるステータスはライブラリのシステムが管理している値なので、まれに現在のCDサブシステムの状態と異なる場合がある。最新のステータスを取得する場合はDslNopを発行する。

返り値
CDサブシステムのステータス
