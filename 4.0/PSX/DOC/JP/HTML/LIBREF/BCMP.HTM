bcmp

メモリブロックを比較する

形式 

#include <memory.h>
long bcmp (
char *b1,
char *b2,
long n
)
引数 
b1		比較元1
b2		比較元2
n		比較バイト数
解説
b1 と b2 の最初の n バイトを比較する。

返り値
b1 と b2 の比較結果により次の値を返す。

結果戻り値
b1<b2<0
b1=b2=0
b1>b2>0
