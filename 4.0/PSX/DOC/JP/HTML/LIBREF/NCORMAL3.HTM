NormalColor3

３つの法線ベクトルから３つのローカルカラーを求める

形式 

void NormalColor3 (
SVECTOR *v0,
SVECTOR *v1,
SVECTOR *v2,
CVECTOR *v3,
CVECTOR *v4,
CVECTOR *v5
)
引数 
v0,v1,v2	入力：法線ベクトル
v3,v4,v5	出力：色ベクトル
解説
(LLV0 LLV1 LLV2) = LLM×(v0 v1 v2)
(v3 v4 v5) = BK+LCM×(LLV0 LLV1 LLV2)

引数フォーマット：
v0,v1,v2->vx,vy,vz : (1,3,12)
v3,v4,v5->r,g,b : (0,8,0)

返り値
なし
