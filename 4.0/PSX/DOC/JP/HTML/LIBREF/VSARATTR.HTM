SpuSetVoiceARAttr

ADSR Attack Rate / Attack Rate モードの設定

形式 

void SpuSetVoiceARAttr (
int voiceNum,
unsigned short AR,
long ARmode
)
引数 
voiceNum	ボイス番号 (0 ～23)
AR		ADSR Attack Rate
ARmode		ADSR Attack Rate モード
解説
ボイスで使われる ADSR Attack Rate / ADSR Attack Rate モードの設定を行う。
SpuSetVoiceAttr() の mask 指定
SPU_VOICE_ADSR_AR
SPU_VOICE_ADSR_AMODE
に該当する処理を行う。
ADSR Attack Rate AR、 及び ADSR Attack Rate モードARmodeに指定する値に関しては SpuSetVoiceAttr() を参照のこと。

返り値
なし
