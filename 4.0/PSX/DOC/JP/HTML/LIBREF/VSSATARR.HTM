SpuSetVoiceStartAddr

波形データのサウンドバッファ内先頭アドレスの設定

形式 

void SpuSetVoiceStartAddr (
int voiceNum,
unsigned long startAddr
)
引数 
voiceNum	ボイス番号 (0 ～23)
startAddr	波形データ先頭アドレス
解説
ボイスで使われる波形データのサウンドバッファ内先頭アドレスの設定を行う。
SpuSetVoiceAttr() の mask 指定
SPU_VOICE_WDSA
に該当する処理を行う。
波形データ先頭アドレス startAddr に指定する値に関しては SpuSetVoiceAttr() を参照のこと。

返り値
なし
