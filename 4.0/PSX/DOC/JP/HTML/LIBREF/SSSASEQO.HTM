SsSeqSetAccelerando

テンポを速くする

形式 

void SsSeqSetAccelerando (
short seq_access_num,
long tempo,
long v_time
)
引数 
seq_access_num		SEQアクセスナンバー
tempo			曲のテンポ
v_time			時間（tick単位）
解説
seq_access_num を持つSEQデータを v_time 内に tempo の分解能まで速くしていく。
ただし、指定した分解能が現在の分解能よりも小さい（遅い）場合、SsSeqSetRitardando と同じ動作をする。

返り値
なし
