LINE_F4

フラット２連結直線

構造 

typedef struct {
		u_long	tag;
		u_char	r0, g0, b0, code;
		short	x0, y0;
		short	x1, y1;
		short	x2, y2;
		short	x3, y3;
		u_long	pad;
} LINE_F4;
メンバ 
tag			次のプリミティブへのフック（予約）
code			プリミティブ ID
r0,g0,b0		プリミティブの輝度値
x0,y0,x1,y1..x3,y3	プリミティブの各頂点座標
解説
LINE_F4は、輝度値が (r0,g0,b0) で、(x0,y0)-(x1,y1)-(x2,y2)-(x3,y3)を結ぶ２連結直線を描画する。
