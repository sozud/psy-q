ExitCriticalSection

クリティカルセクションから脱出

形式 

void ExitCriticalSection ( void )
引数 
なし
解説
割り込みの発生を許可し、クリティカルセクションから出る。

返り値
なし

備考
内部でシステムコール命令を実行し、割り込みコンテキストを破壊する。

関連項目
EnterCriticalSection(), TCBH構造体, TCB構造体
