Release 4.0

StartPAD

コントローラの読みとりを開始

形式 

long StartPAD ( void )
引数 
なし
解説
垂直帰線区間割り込みをトリガとして行なわれるコントローラの読みとりを開始する。
内部でChangeClearPAD(1)を実行する。

返り値
成功すると1を、失敗すると0を返す。

備考
割り込みを許可した状態で返る。

関連項目
InitPAD(), ChangeClearPAD()
