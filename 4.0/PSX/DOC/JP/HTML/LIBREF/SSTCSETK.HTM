SsSetTickCallback

TICK毎に呼ばれる関数（Tick Callback関数）を設定する

形式 

int SsSetTickCallback (
void (*cb)()
)
引数 
cb		Tick 毎に呼ばれる関数（Tick Callback関数）
解説
Tick 毎に呼ばれる関数（Tick Callback 関数）を設定する。
SsSetTickMode() にて SS_NOTICK を設定しなかった場合のみ、SsStart() あるいは SsStart2() の呼び出し後、各 Tick毎に関数 cb が呼ばれる。
本関数にて Tick Callback関数が設定されなかった場合、そのデフォルトにはSsSeqCalledTbyT() が設定される。

返り値
以前設定されていたTick Callback 関数

関連項目
SsSetTickMode(), SsStart(), SsStart2(), SsSeqCalledTbyT()
