SpuSetKey

各ボイスに対してキーオン/キーオフを設定

形式 

void SpuSetKey (
long on_off, 
unsigned long voice_bit
)
引数 
on_off		SPU_ON（キーオン設定）またはSPU_OFF（キーオフ設定）
voice_bit	設定するボイス
解説
各ボイスに対してキーオン/キーオフを設定する。
voice_bit にはSPU_0CH, SPU_1CH,...,SPU_23CHのビット和で設定する。

返り値
なし

備考
サンプル：
ボイス0とボイス2にキーオンを設定する際には以下のようにしてSpuSetKeyを呼ぶ
SpuSetKey (SPU_ON, /*キーオン設定*/
SPU_0CH | SPU_2CH); /* 0chと2ch */
