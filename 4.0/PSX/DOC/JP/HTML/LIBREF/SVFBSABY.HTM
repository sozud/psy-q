SsVabFakeBody

サウンドバッファ上の音源データを、与えられたVABIDのデータとしてライブラリを設定する

形式 

short SsVabFakeBody (
short vabid
)
引数 
vabid		VAB ID
解説
SsVabFakeHead() で、ヘッダリストを認識させ、サウンドバッファ上の音源データを、与えられたVAB IDのデータとしてライブラリを設定する。VAB IDの認証は行うが、実際には転送せず、ライブラリ内部状態を「サウンドバッファへ転送した」という状態にする。本関数を呼んだ後にSsVabTransCompleted() を行う必要はない。

返り値
VAB識別番号
失敗したら-1を返す。
