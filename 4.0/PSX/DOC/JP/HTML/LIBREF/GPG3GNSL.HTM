GsPrstG3GNL

グーローグラデーション３角形（光源計算無し）

形式 

PACKET *GsPrstG3GNL (
TMD_P_G3G * op, 
VERT * vp, 
VERT * np, 
PACKET * pk,
int n, 
int shift, 
GsOT * ot, 
u_long * scratch
)
引数 
op		TMDデータのプリミティブ先頭アドレス
vp		TMDデータのバーテックス先頭アドレス
np		TMDデータのノーマル先頭アドレス
pk		GPUパケットのバッファの先頭アドレス
n		プリミティブの数
shift		OTにソートする際の shift するbit数
ot		GsOTへのポインタ
scratch		未使用のscratch padの先頭アドレス
解説
GsSortObject5J()の下位関数群。
使用するためにはGsFCALL5に下位関数として登録し使用します。
TMDデータ上の連続する n 個のグラデーション３角形について座標変換、透視変換、backface clip, (光源計算）を行い、pk 上にGPUパケットを作成し、ot にリンクします。
pk 上には１ポリゴンにつき２つのパケットがプリセットされているものとします。

返り値
未使用の packet 領域の先頭アドレス

備考
グラデーション３角形とは、TMDデータの3頂点にそれぞれ異なるRGBが割り当てられているポリゴンのことです。
