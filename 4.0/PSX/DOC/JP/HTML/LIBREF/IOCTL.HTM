ioctl

デバイスの制御

形式 

long ioctl ( 
long fd,
long com,
long arg 
)
引数 
fd		ファイルディスクリプタ
com		制御コマンド
arg		制御コマンド引数
解説
デバイスに各種制御コマンドを発行する。コマンドとその引数についての詳細はデバイス毎に規定する。

返り値
成功すると0を、それ以外は-1を返す。
