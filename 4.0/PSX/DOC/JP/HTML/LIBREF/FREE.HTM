free

割り当て済みのメモリブロックを開放する

形式 

#include <stdlib.h>
void free (
void* block 
)
引数 
block		開放する領域
解説
calloc()、malloc()、realloc()で確保したメモリブロックを開放する。

返り値
なし

関連項目
calloc(), malloc(), realloc()
