GsARGUNIT_ANIM

アニメーションドライバの引数領域

構造 

typedef struct {
	unsigned long 	*primp;
	GsOT		*tagp;
	int		shift;
	int		offset;
	PACKET		*out_packet;
	long		header_size;
	unginged long	*htop;
	unsinged long	*ctop;
	unsinged long	*ptop;
}  GsARGUNIT_ANIM;
メンバ 
primp		プリミティブの先頭アドレス
tagp		現在の先頭の GsOT_TAG へのポインタ
shift		OTにソートする際の shift するbit数
offset		OT のスクリーン座標系におけるＺ軸上のオフセット
out_packetp	未使用のパケットエリアへのポインタ
header_size	アニメーションで使用するプリミティブヘッダのサイズ
htop		補完関数テーブルセクションの先頭アドレス
ctop		シーケンスコントロールセクションの先頭アドレス
ptop		パラメータセクションの先頭アドレス
解説
GsSortUnit()からコールされるアニメーションプリミティブドライバへ渡される引数領域。
GsARGUNIT加え、プリミティブヘッダのサイズやアニメーションで必要な各セクションの先頭アドレスが渡される。通常はこの引数領域は高速化のためスクラッチパッドを使用する。

引数受け渡し領域はこのメンバの領域よりも大きい。GsARGUNIT_ANIMの下に書き換えを行うセクションの先頭アドレスがリストされる。header_sizeはこのリストの数とhtop,ctop,htopの３をあわせた数が入る。

書き換えセクションの先頭アドレスの次に補完関数用の引数受け渡し領域が取られる。


補完ドライバ用引数受け渡し領域は補完関数のtypeによって数と意味が変わるが、リニア補完では
以下の４つのパラメータが入る。

１：シーケンスポインタの先頭アドレス
２：補完元のパラメータのアドレス
３：補完先のパラメータのアドレス
４：補完後のパラメータを記憶させておくアドレス
