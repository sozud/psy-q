InitClip

クリップパラメータの初期化

形式 

void InitClip (
EVECTOR *evbfad,
long hw,
long vw,
long h,
long near,
long far
)
引数 
evbfad		クリップベクトル情報の配列（16個）address 
hw		窓の幅
vw		窓の高さ
h		視点からスクリーンまでの距離
near		NEARCLIP位置
far		FARCLIP位置
解説
クリップ演算に使用するパラメータを設定する。クリップベクトル情報の配列は16個分（176word=704byte）確保する。

返り値
なし
