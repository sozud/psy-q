CdGetSector

セクタバッファのデータをメインメモリへ転送する

形式 

int CdGetSector (
void *madr, 
int size
)
引数 
madr		転送先メインメモリアドレス
size		転送サイズ（ロングワード）
解説
セクタバッファ上のセクタデータをメインメモリ上に転送する。転送終了までブロックする。

返り値
発行に成功すれば1を、失敗すれば0を返す。

備考
セクタサイズはモードによって異なる。転送は複数回にわけて異なるメモリ領域へ転送することもできる。セクタバッファのポインタはCdReady割込みによって先頭にセットされるため、セクタデータがバッファに準備されてから、次のセクタデータが上書きされる前（次のCdReady割込みが発生する前）に読み出さないと、以前のセクタデータは失われる。
本関数はDMAの終了を待ってリターンするため、関数のリターン時には転送は終了している。

なお、現在のCdGetSector()ではReadyコールバックによってバッファの読み込みポインタがリセットされるため、ポインタを更新するためのダミーのデータ転送は不要。
