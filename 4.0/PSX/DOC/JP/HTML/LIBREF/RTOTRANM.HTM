RotTrans_nom

回転マトリックスで座標変換を行なう

形式 

void RotTrans_nom (
SVECTOR *v0
)
引数 
v0		入力：ベクトル
解説
v1 = RTM×v0

引数および内部データフォーマット：
v0->vx,vy,vz : (1,15,0)
v1->vx,vy,vz : (1,31,0)
flag : (0,32,0)

返り値
なし

備考
(v1->vx,v1->vy,v1->vz)はマクロread_mtで、flagはマクロread_flagで読む。
