SpuRead

サウンドバッファからメインメモリへの転送

形式 

unsigned long SpuRead (
unsigned char *addr,
unsigned long size
)
引数 
addr		転送されるメインメモリ内の先頭アドレス
size		転送するデータのサイズ(バイト単位)
解説
サウンドバッファからメインメモリへデータを転送する。
ただし転送されるメインメモリのアドレス addr は、

  • 大域変数として取られた変数へのアドレス
  • mallocなどでヒープ領域に取られた変数へのアドレスでなければならない
すなわち、
  • スタック領域へのアドレス（auto変数へのアドレス）であってはならない

呼び出し後、転送終了を確認するために SpuIsTransferCompleted() を呼ぶか、事前にSpuSetTransferCallback() にて DMA転送終了Callback関数を設定しておくこと。

返り値
転送されたデータサイズ
設定したデータサイズが512KBより大きければ、実際に転送されたサイズが返る。
