StGetNext

１FRAME分のデータをとり出す

形式 

unsigned long StGetNext (
unsigned long **addr,
unsigned long **header
)
引数 
addr		とり出された１FRAME分のデータのユーザデータ領域の先頭アドレス
header 		とり出された１FRAME分のデータのセクタヘッダ領域の先頭アドレス
解説
リングバッファにある１FRAME分のデータをとり出す。
StGetNext()は呼ばれると次の１FRAME分のデータが、リングバッファ上に用意されていればユーザデータとセクタヘッダの先頭アドレスを引数にいれ０を返す。
もし次の１FRAMEのデータが準備できないときは１を返す。
とり出された領域はStFreeRing()が呼ばれるまでロックされるため新たなデータで壊されることはない。
とり出された領域はアドレス的に連続でありデータの途中でリングバッファの折り返りはない。

返り値
１FRAME分のデータがリングバッファより取り出せれば０を用意されてなければ１を返す
