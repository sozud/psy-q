SpuGetTransferStartAddr

サウンドバッファの転送先/転送元先頭アドレスの診断

形式 

unsigned long SpuGetTransferStartAddr ( void )
引数 
なし
解説
現在設定されている、メインメモリからサウンドバッファへ転送する際、及び、サウンドバッファからメインメモリへ転送する際の先頭アドレスの値を返す。

返り値
現在設定されている先頭アドレスの値

関連項目
SpuSetTransferStartAddr(), SpuWrite(), SpuWrite0(), SpuWritePartly(), SpuRead(), SpuReadDecodedData()
