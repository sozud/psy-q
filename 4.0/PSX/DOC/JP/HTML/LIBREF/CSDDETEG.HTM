CdSetDebug

デバッグレベルを設定

形式 

int CdSetDebug (
int level
）
引数 
level		デバッグレベル
解説
CD-ROMサブシステムのデバッグレベルlevelに設定する。

値内容
0全てのチェックを行なわない
1プリミティブコマンドのチェックを行なう
2プリミティブコマンドの実行状況をプリントする


返り値
直前に設定されたデバッグモード。
