DivideFT3

フラットテクスチャ３角形の分割

形式 

u_long *DivideFT3 (
SVECTOR *v0,
SVECTOR *v1,
SVECTOR *v2,
u_long *uv0,
u_long *uv1,
u_long *uv2,
CVECTOR *rgbc,
POLY_FT3 *s,
u_long *ot,
DIVPOLYGON3 *divp
)
引数 
v0,v1,v2	入力：頂点座標ベクトル
uv0,uv1,uv2	入力：テクスチャ座標ベクトル(uv0:uv0+clut,uv1:uv1+tpage)
rgbc		入力：色ベクトル(+code)
s		GPUパケットバッファのアドレス
ot		ＯＴエントリ
divp		入力：デバイド用ワークエリア
解説
フラットテクスチャ３角形の分割処理プログラム。頂点座標ベクトルとテクスチャ座標ベクトルと色ベクトルで表されるフラットテクスチャ３角形を divp->ndivの値のもとに分割し、OTへ登録する。

ndiv=1: 2x2分割、ndiv=2: 4x4分割、
ndiv=3: 8x8分割、ndiv=4: 16x16分割、
ndiv=5: 32x32分割

返り値
更新されたGPUパケットバッファのアドレス

備考
divp->ndiv:分割数、divp->pih,piv:表示画面の解像度(クリップ用)、は設定されているものとする。ot はＯＴエントリ（libgpu参照）
