GsU_00......,GsU_01......,GsU_02......

GsSortUnit()のプリミティブドライバ群（Polygon,Shared Polygon,Image）

形式 

unsigned long * GsU_00...... (
GsARGUNIT	*ap;
)
unsigned long * GsU_01...... (
GsARGUNIT	*ap;
)
unsigned long * GsU_02...... (
GsARGUNIT	*ap;
)
引数 
ap		引数受け渡し領域の先頭アドレス
解説
GsSortUnit()のプリミティブドライバ群。名称の先頭２文字目がカテゴリとなる。
GsU_00......()は通常のポリゴンプリミティブドライバ。GsU_01......()は共有ポリゴンプリミティブドライバ。GsU_02......()はイメージプリミティブドライバである。
使用するためにはＨＭＤデータを初期化する際、GsScanUnit()で返されるGsTYPE構造体のtypeを調べ、そのポインタにこのプリミティブドライバのアドレスを埋め込む必要がある。
現在libgsでサポートされているカテゴリ00,01,02のプリミティブドライバは以下の通り。

備考
固定分割を行うプリミティブドライバを使用する場合、分割数を以下のように、プリミティブインデックスが格納されている領域の上位8bitに指定する必要がある。

また、分割数を指定するため、以下のようなマクロがlibgs.hに用意されている。

マクロ分割数
GsUNIT_DIV12x2分割
GsUNIT_DIV24x4分割
GsUNIT_DIV38x8分割
GsUNIT_DIV416x16分割
GsUNIT_DIV532x32分割
