SetFogNear

フォグパラメータを設定する

形式 

void SetFogNear (
long a,
long h
)
引数 
a		フォグ０％となるＺ値
h		視点とスクリーンの距離
解説
視点とスクリーンの距離が h のとき、フォグ０％となるＺ値を a に設定する。
フォグ１００％となるＺ値は5 * a に自動設定される。
0 < a < 65536 * 0.2

引数フォーマット：
a : (0,32,0)
h : (0,32,0)

返り値
なし
