SpuSetReverbModeDepth

リバーブの深さの設定

形式 

void SpuSetReverbModeDepth (
short depthL,
short depthR
)
引数 
depthL		リバーブの深さ (左)
depthR		リバーブの深さ (右)
解説
リバーブの深さの設定を行う。
SpuSetReverbModeParam() の mask 指定
SPU_REV_DEPTHL
SPU_REV_DEPTHR
に該当する処理を行う。
リバーブの深さ depthL 及び depthR に指定する値に関しては SpuSetReverbModeParam() を参照のこと。

返り値
なし
