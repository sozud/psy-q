CdReadBreak

CdReadを中断する

形式 

void CdReadBreak ( void )
引数 
なし
解説
CdRead()を途中で中断する場合に使用する。中断した場合、それまでに読み出されたデータは保証されない。

返り値
なし

備考
CdRead()実行直後（１セクタも読まれていない状態）でCdReadBreak()を実行するとエラーになる場合がある。
