SsSetNext

次SEQデータの指定

形式 

void SsSetNext (
short ac_no1,
short tr_no1,
short ac_no2,
short tr_no2
)
引数 
ac_no1		SEP/SEQアクセスナンバー
tr_no1		SEP内のSEQ番号（譜面データがSEQの時は0)
ac_no2		SEP/SEQアクセスナンバー
tr_no2		SEP内のSEQ番号（譜面データがSEQの時は0)
解説
ac_no1 の tr_no1 を持つSEQデータの次に演奏したい譜面データのSEP/SEQアクセスナンバー（ac_no2, tr_no2）を指定する。

返り値
なし
