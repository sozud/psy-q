strspn

指定した文字集合中の文字のみからなる最初の部分を探す

形式 

#include <strings.h>
size_t strspn (
const char * s1,
const char * s2
)
引数 
s1		検索対象文字列
s2		文字群
解説
文字列 s1 のうち文字群 s2 に含まれる文字のみからなる最初の部分の長さを返す。

返り値
見つかった部分文字列の長さを返す。
