StoreImage

フレームバッファからデータを転送

形式 

int StoreImage (
RECT *rect,
u_long *p
)
引数 
rect		転送元矩形領域
p		転送先メインメモリアドレス
解説
rect で指定されたフレームバッファの矩形領域をアドレス p 以下に転送する。

返り値
キューの数

備考
ノンブロック関数であるため、実際の転送の終了は DrawSync()で検出する必要がある。
転送領域は、描画環境（クリップ・オフセット）の影響を受けない。
転送領域は描画可能領域(0,0)-(1023,511)に収まる必要がある。
