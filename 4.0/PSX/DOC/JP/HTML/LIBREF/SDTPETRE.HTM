SetDrawTPage

テクスチャページ変更プリミティブの内容を初期化

形式 

void SetDrawTPage (
DR_TPAGE *p,
int dfe;
int dtd;
int tpage;
)
引数 
p		DR_TPAGEプリミティブ
dfe		表示エリアへの描画フラグ
		０：表示エリアには描画を行わない。
		１：表示エリアにも描画を行う。
dtd		ディザ処理フラグ
		０：ディザをかけない。
		１：ディザをかける。
tpage		テクスチャページ
解説
テクスチャページ変更プリミティブを初期化する。初期化ずみのテクスチャページ変更プリミティブをAddPrim()でOTに登録することにより、描画途中での描画環境の一部を変更できる。

返り値
なし
