基本グラフィックス ライブラリ (libgpu) 関数一覧
Release 4.0

setWH

プリミティブpのw,hメンバに値を設定

形式 

setWH ( p,w,h )
引数 
p		プリミティブのポインタ
w,h		プリミティブの幅と高さ
解説
w,h のメンバをもつプリミティブに対して w,h を指定する。

返り値
なし

備考
マクロであるためベクトルの型に依存しない。
w,h をメンバに持たないプリミティブには使用できない。
