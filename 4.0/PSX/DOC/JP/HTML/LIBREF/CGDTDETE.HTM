CD-ROM ライブラリ (libcd) 関数一覧
Release 4.0

CdGetDiskType

CD のフォーマットを得る

形式 

int CdGetDiskType ( void )
引数 
なし
解説
CDのフォーマットを得る。検出可能なフォーマットは現在CD-ROMフォーマットのみ。

返り値

返り値意味
CdlCdromFormatCD-ROMフォーマット
CdlOtherFormat他のフォーマット
CdlStatShellOpenプレイヤーのカバーが開いている
CdlStatNoDiskCDが入っていない


備考
デバッギングステーションではPlayStationディスク（ブラックディスク）、CD-Rおよび一般のCD-ROM （ISO9600フォーマットのもの）がCD-ROMとして認識されるが、PlayStation（実機）ではPlayStationディスクのみCD-ROMとして認識される。CD-DAは常にOtherFormatと認識される。CDの交換などプレイヤーのカバーが閉じられた直後にこの関数を使用する場合は、その前にCdDiskReady()を呼んでCDサブシステムが安定したことを確認する。
※この関数は、DTL-H2000では正常に動作しない。
