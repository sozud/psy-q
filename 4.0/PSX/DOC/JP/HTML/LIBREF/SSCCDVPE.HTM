SpuSetCommonCDVolume

CD 入力音量の設定

形式 

void SpuSetCommonCDVolume (
short cdvolL,
short cdvolR
)
引数 
cdvolL		CD 入力音量 (左)
cdvolR		CD 入力音量 (右)
解説
CD 入力音量の設定を行う。
SpuSetCommonAttr() の mask 指定
SPU_COMMON_CDVOLL
SPU_COMMON_CDVOLR
に該当する処理を行う。
CD 入力音量 cdvolL, cdvolR に指定する値に関しては SpuSetCommonAttr() を参照のこと。

返り値
なし

関連項目
SpuSetCommonAttr(), SpuGetCommonCDVolume()
