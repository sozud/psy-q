SpuSetVoiceADSR

ADSR の設定

形式 

void SpuSetVoiceADSR (
int voiceNum,
unsigned short AR,
unsigned short DR,
unsigned short SR,
unsigned short RR,
unsigned short SL
)
引数 
voiceNum	ボイス番号 (0 ～23)
AR		ADSR Attack Rate
DR		ADSR Decay Rate
SR		ADSR Sustain Rate
RR		ADSR Release Rate
SL		ADSR Sustain Level
解説
ボイスで使われる ADSR の個別の属性の設定を行う。
SpuSetVoiceAttr() の mask 指定
SPU_VOICE_ADSR_AR
SPU_VOICE_ADSR_DR
SPU_VOICE_ADSR_SR
SPU_VOICE_ADSR_RR
SPU_VOICE_ADSR_SL
に該当する処理を行う。
Attack, Sustain Relase の各 Rate について、 Rate モードはそれぞれ以下の通りになる。

RateRateモード
Attack Rate SPU_VOICE_LINEARIncN (リニア増加)
Sustain Rate SPU_VOICE_LINEARDecN (リニア減少)
Release Rate SPU_VOICE_LINEARDecN (リニア減少)


各 Rate モードを同時に指定したい場合は SpuSetVoiceSRAttr() を使用する。
各 Rate に指定する値に関しては SpuSetVoiceAttr() を参照のこと。

返り値
なし
