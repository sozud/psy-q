printf

書式化された出力を標準出力stdoutへ行なう

形式 

#include <stdio.h>
long printf (
const char * fmt [,argument ...]
)
引数 
fmt		入力書式文字列
解説
入力書式の詳しい解説についてはＣ言語の各種参考書を参照のこと。
変換指定子「f」「e」「E」「g」「G」には対応していない。
浮動小数点表示には数学ライブラリのprintf2()を使用。

返り値
出力した文字列の長さを返す。エラーが発生するとNULLを返す。

関連項目
sprintf(), printf2()
