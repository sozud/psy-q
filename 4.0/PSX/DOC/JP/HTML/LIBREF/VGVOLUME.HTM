SpuGetVoiceVolume

ボイス音量の取得

形式 

void SpuGetVoiceVolume (
int voiceNum,
short *volumeL,
short *volumeR
)
引数 
voiceNum	ボイス番号 (0 ～23)
volumeL		音量 (左)
volumeR		音量 (右)
解説
ボイス音量を取得する。
SpuGetVoiceAttr() における SpuVoiceAttr 構造体のメンバ volume の値の取得に該当する処理を行う。
音量モードが [ダイレクトモード] になっている場合のみ得られた値は有効となる。 他の音量モードの場合は不定となる。
音量モードが [ダイレクトモード] でない場合、あるいは音量と音量モードを同時に取得したい場合は SpuGetVoiceVolumeAttr() を使用する。

返り値
なし
