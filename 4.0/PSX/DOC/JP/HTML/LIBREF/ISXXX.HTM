isXXX

文字のテストを行なう

形式 

#include <ctype.h>
long isXXX (
long c 
)
引数 
c		文字
解説
文字 c のテストを行う。すべてマクロである。テスト条件は以下のとおり。

関数名条件
isalnumisalpha(c) || isdigit(c)
isalphaisupper(c) || islower(c)
isasciiASCII文字
iscntrl制御文字
isdigit10進数
isgraph空白以外の印刷可能文字
islower小文字
isprint空白を含む印刷可能文字
ispunct空白、英字、数字以外の印刷可能文字
isspace空白、改頁、改行、復帰、タブ
isupper大文字
isxdigit16進数


返り値
入力値 c が条件を満たす場合は0でない値、条件を満たさない場合は0を返す。
