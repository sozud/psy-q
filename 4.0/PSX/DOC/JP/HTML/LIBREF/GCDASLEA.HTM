GsClearDispArea

画面をクリアする

形式 

void GsClearDispArea (
unsigned char r, 
unsigned char g, 
unsigned char b
)
引数 
r,g,b		バックグラウンドカラーのRGB 値
解説
IOで描画領域をクリアする

備考
GsSortClearと異なりGsClearDispArea()は この関数を呼んだ時点でクリア命令が発行される。
