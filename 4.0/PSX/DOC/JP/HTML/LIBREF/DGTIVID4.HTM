DivideGT4

グーローテクスチャ４角形の分割

形式 

u_long *DivideGT4 (
SVECTOR *v0,
SVECTOR *v1,
SVECTOR *v2,
SVECTOR *v3,
u_long *uv0,
u_long *uv1,
u_long *uv2,
u_long *uv3,
CVECTOR *rgb0,
CVECTOR *rgb1,
CVECTOR *rgb2,
CVECTOR *rgb3,
POLY_GT4 *s,
u_long *ot,
DIVPOLYGON4 *divp
)
引数 
v0,v1,v2,v3		入力：頂点座標ベクトル
uv0,uv1,uv2,uv3		入力：テクスチャ座標ベクトル(uv0:uv0+clut,uv1:uv1+tpage)
rgb0,rgb1,rgb2,rgb3	入力：色ベクトル(rgb0:rgb0+code)
s			GPUパケットバッファのアドレス
ot			ＯＴエントリ
divp			入力：デバイド用ワークエリア
解説
グーローテクスチャ４角形の分割処理プログラム。頂点座標ベクトルとテクスチャ座標ベクトルと色ベクトルで表されるグーローテクスチャ４角形を divp->ndivの値のもとに分割し、OTへ登録する。

ndiv=1: 2x2分割、ndiv=2: 4x4分割、
ndiv=3: 8x8分割、ndiv=4: 16x16分割、
ndiv=5: 32x32分割

返り値
更新されたGPUパケットバッファのアドレス

備考
divp->ndiv:分割数、divp->pih,piv:表示画面の解像度(クリップ用)、は設定されているものとする。ot はＯＴエントリ（libgpu参照）
