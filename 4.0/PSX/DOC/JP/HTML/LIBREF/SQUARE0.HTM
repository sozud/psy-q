Square0

ベクトルの２乗を求める

形式 

VECTOR *Square0 (
VECTOR *v0,
VECTOR *v1
)
引数 
v0		入力：ベクトル(L1,L2,L3)
v1		出力：ベクトル(L1^2,L2^2,L3^2)
解説
ベクトル v0 の各項の２乗のベクトルを v1 に返す。

引数フォーマット：
v0->vx,vy,vz : (1,31,0)
v1->vx,vy,vz : (1,31,0)

返り値
v1
