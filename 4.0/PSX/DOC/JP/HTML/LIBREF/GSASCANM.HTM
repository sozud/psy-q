GsScanAnim

HMDのアニメーション用専用SCAN関数

形式 

unsigned long 	*GsScanAnim (
unsigned long 	*p
GsTYPEUNIT	*ut,
)
引数 
p		アニメーションセクションの最初のtypeが存在するアドレス
		p が 0 の時は、前回 GsScanAnim() がコールされた次のタイプを調べる。
ut		タイプとそのアドレスを格納する領域へのポインタ
解説
HMD データのSCANは全てのセクションで共通なSCAN（global SCANと呼ぶ）を行うGsScanUnit()と、セクション毎にローカルなSCAN(local Scanと呼ぶ)を行う専用のSCAN関数とに分けられる。GsScanAnim()は後者でありHMDアニメーションセクション専用のSCAN関数である。

SCANを行うタイミングはアニメーションタイプが最初にglobal SCANされた時が良い。オーサリングレベルで最初にglobal SCANされるアニメーションtypeのINIフィールドにビットを立てるため、そのビットを見張ることでlocal SCANを行うタイミングをつかむことができる。

アニメーションセクションのすべてのtypeをスキャンするには以下の手順でGsScanAnim()を呼び出す。

(1) global SCANで選られたtypeのカテゴリが３（アニメーションカテゴリ）でかつINIが１であるならばlocal SCANをかけるタイミングである。type=0x03800000
(2) GsScanAnim()を上記typeのアドレスをpとして発行する。
(3) 返り値を検査し０であったならばデータ異常
(4) 1ならば、もう一度GsScanAnim()を発行する。
(5) 選られたut.typeからそのタイプに相当する補完プリミティブドライバの関数のポインタをut.ptrに代入する。
(6) 4)に戻って０が返ってくるまで繰り返す。

返り値
０ SCANするべきtypeが存在しない
１ SCAN成功 typeが存在した

備考
一度タイプがプリミティブドライバのポインタに上書きされたＨＭＤデータは、再度GsScanAnim()を呼び出しても、副作用は起こらない。
