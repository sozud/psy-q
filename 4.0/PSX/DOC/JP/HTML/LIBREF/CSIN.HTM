csin

正弦

形式 

int csin (
int a
)
引数 
a		PlayStation フォーマットによる角度
解説
PSX formatの角度（4096=2pai）のsinを固定小数点（4096=1.0）で求める。

フォーマット：
a : PSX format (4096=2pai radian)
返り値 : (1,19,12)

返り値
sin(a)
