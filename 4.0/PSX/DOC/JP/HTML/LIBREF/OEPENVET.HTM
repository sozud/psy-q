OpenEvent

イベントのオープン

形式 

long OpenEvent ( 
unsigned long desc
long spec
long mode
long *func()
)
引数 
desc		原因ディスクリプタ
spec		イベント種別
mode		モード
func		ハンドラ関数へのポインタ
解説
ディスクリプタ desc、イベント種別 spec のイベントのためのイベント管理ブロックを確保する。

返り値
成功するとイベントディスクリプタを、失敗すると-1を返す。

備考
クリティカルセクションで実行すること。

関連項目
EvCB構造体, CloseEvent(), DeliverEvent()
