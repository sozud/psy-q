DecDCTvlcSize2

一回のVLCの解凍の最大サイズを設定

形式 

int DecDCTvlcSize2 (
int size
)
引数 
size		デコードされたランレベルの最大値（ロングワード）
解説
ビットストリームを解凍する際の一回のデコードの最大値を与える。
DecDCTvlc2()は size ワードを越えて最初のブロックのランレベルをデコードするとデコードを中断する size に0を指定すると中断は発生しない。
デフォルトの値は0。

返り値
直前に設定されたランレベルの最大値

備考
ブロック関数。DecDCTin()を実行する前に必ずDecDCTvlc2()で一旦ビットストリームをランレベルに変換しておく必要がある。
DecDCTvlc()と組み合わせて使用することはできない。
