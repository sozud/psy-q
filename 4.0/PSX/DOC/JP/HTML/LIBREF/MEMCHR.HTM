memchr

メモリブロック中で文字を探す

形式 

#include <memory.h>
void * memchr (
const void * s,
long c,
size_t n
)
引数 
s		検索対象格納先
c		検索文字
n		検索バイト数
解説
s から始まるn バイトのメモリブロック中の、文字 c の最初の出現に位置付けする。

返り値
位置付けられた文字へのポインタを返す。 c が発見できなかった時はNULLを返す。
