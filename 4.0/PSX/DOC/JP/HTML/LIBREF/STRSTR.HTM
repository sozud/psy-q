strstr

指定の部分文字列が現れる位置を探す

形式 

#include <strings.h>
char * strstr (
const char * s1,
const char * s2
)
引数 
s1		検索対象文字列
s2		検索文字列
解説
文字列 s1 を調べ、文字列 s2 が最初に現れる位置を探す。

返り値
見つかった位置のアドレスを返す。見つからない場合はNULLを返す。
