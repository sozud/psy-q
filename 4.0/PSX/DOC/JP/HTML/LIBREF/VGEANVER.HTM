SpuGetVoiceEnvelopeAttr

現在のエンベロープ値とキーオン/キーオフの状態を取得

形式 

void SpuGetVoiceEnvelopeAttr (
int voiceNum,
long *keyStat,
short *envx
)
引数 
voiceNum	ボイス番号 (0 ～23)
keyStat		キーオン/キーオフ/エンベロープの状態
envx		現在のエンベロープ値
解説
ボイスのキーオン/キーオフ/エンベロープの状態、及び現在のエンベロープ値を取得する。
キーオン/キーオフ/エンベロープの状態 keyStat の取り得る値に関しては SpuGetKeyStatus() を参照のこと。

返り値
なし
