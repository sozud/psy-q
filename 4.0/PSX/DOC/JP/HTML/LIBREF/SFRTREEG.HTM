StFreeRing

リングバッファを解放する

形式 

unsigned long StFreeRing (
unsigned long *base
）
引数 
base		解放する１FRAMEのユーザデータ領域の先頭アドレス
解説
StGetNext()で取り出された領域はロックされる。StFreeRing()はこのロックされた領域を解放する。
解放する領域は base をユーザ領域の先頭アドレスとして与えられる１FRAME分の領域である。連動してセクタヘッダ領域も解放される。
StGetNext()でロックした領域は使い終わったならば解放しないとリングバッファすぐあふれストリーミングは止まってしまう。

返り値
解放に成功すると０失敗すると（例えばロックしていないのに解放しようとした）１を返す
