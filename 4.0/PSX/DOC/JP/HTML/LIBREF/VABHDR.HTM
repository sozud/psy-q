VabHdr

バンクヘッダ

構造 

struct VabHdr {
		long form;
		long ver;
		long id;
		unsighned long fsize;
		unsigned short reserved0;
		unsigned short ps;
		unsigned short ts;
		unsigned short vs;
		unsigned char mvol;
		unsigned char pan;
		unsigned char attr1;
		unsigned char attr2;
		unsigned long reserved1;
};
メンバ 
form		フォーマットネーム (常に VABp)
ver		フォーマットバージョン番号
id		バンク (VAB) 番号
fsize		バンクファイルサイズ
reserved0	システム予約
ps		バンクに含まれる全プログラム数
ts		バンクに含まれる全 VAG 属性セット数
vs		バンクにまれる VAG 数
mvol		マスタボリューム
pan		マスタパンレベル
attr1		ユーザ定義可能なバンク属性１
attr2		ユーザ定義可能なバンク属性２
解説
VAB バンクヘッダは、実行時に扱われる音源データセットのファイルサイズ、含まれる音源の数などの情報が含まれている。

SsVabOpenHead()およびSsVabTransBody() 関数が呼ばれたときにシステムに読み込まれ、SPUのローカルメモリに波形データが展開される。また、ボイスアロケーション時にボリューム設定やパンニング設定などが参照される。

VAB、プログラム、VAG の各ヘッダ情報は、ユーザが実行時に変更することも可能で、変更した属性値は次のキーオン時からボイスアロケーションに反映される。
