メモリカード簡易レベルライブラリ (libmcrd) 関数一覧
Release 4.0

MemCardAccept

カードの状態を取得

形式 

long MemCardAccept (
long chan
)
引数 
chan	ポート番号 + カード番号
	ポート番号(Ａポート:0x00、Ｂポート:0x10)
	カード番号(通常 0)
解説
chanで指定したメモリカードの接続をテストし、接続されている場合はさらに詳細な情報を取得する。
新規カードの場合は _card_clear(), _card_load()を実行し、以降のファイルアクセス関数を使用可能にする。
MemCardOpen() などファイルアクセス関数の使用に先立って実行する必要がある。カードが入れ替わらない限り反復して実行する必要はない。
関数自体は非同期処理のため直ちに終了する。多重の処理登録は行なえない。
処理の完了はMemCardSync() または完了コールバックにより確認する。
所用時間は最大 76VSYNC。カードが存在しない場合は約4VSYNC。
取得結果はMemCardSync() または完了コールバックの result 値として通知される。
新規カード(McErrNewCard)の検出は１回のみで、２回目以降はMcErrNone が返る。

result値
値マクロ状態
0x00McErrNone接続されている
0x01McErrCardNotExist接続されていない
0x02McErrCardInvalid不良カード
0x03McErrNewCard新規カード（カードが交換された）
0x04McErrNotFormatフォーマットされていない


返り値
処理登録に成功すると 1を、以外は 0を返す。

備考
非同期関数, 所要時間 4～76VSYNC
