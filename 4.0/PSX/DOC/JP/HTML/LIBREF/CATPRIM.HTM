CatPrim

プリミティブリストを連結

形式 

void CatPrim (
void *p0,
void *p1
)
引数 
p0, p1		連結するプリミティブの先頭アドレス
解説
プリミティブ p0 にプリミティブ p1 を連結する。

返り値
p0 の先頭アドレス

備考
AddPrim()は一つのプリミティブをプリミティブリストに挿入するの対して、CatPrim()
は単純に２つのプリミティブを連結する。
