GsLinkAnim

GsSEQ構造体の配列とHMDデータとを関連付ける

形式 

int GsLinkAnim (
GsSEQ		*seq,
unsigned long	*p
)
引数 
seq		GsSEQ構造体の配列の先頭アドレス
p		アニメーションセクションの最初のtypeが存在するアドレス
解説
GsSEQ構造体は一つのシーケンスを管理するのに十分な情報を保持する。既にＨＭＤデータ中に存在し、GsLinkAnim()によってGsSEQ構造体の配列がHMD中のシーケンスポインタをアクセスできるよう値が入れられる。GsLinkAnim()はGsScanAnim()と同様にglobal SCANの時に起動しなければならない。

プログラマはアニメーションの再生をseqを通じてリアルタイムにコントロールすることができる。GsLinkAnim()をした後は、seq[3]->aframe = 100; という感じで特定のシーケンスの特定のメンバを操作することができるようになる。

sehには選択できるシーケンスの個々の情報にアクセスできる。例えば５番目のシーケンスに、１０のシーケンスが定義されていたとするとその４番目を再生するには、
seq[5]->ti = ((GsSEH *)(&seq[5].start)+3)->idx;
というように、４番目の先頭インデックスをシーケンスポインタに伝えれば良い。

返り値
リンクした数を返す
