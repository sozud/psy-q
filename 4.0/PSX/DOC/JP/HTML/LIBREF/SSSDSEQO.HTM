SsSeqSetDecrescendo

デクレッシェンド

形式 

void SsSeqSetDecrescendo (
short seq_access_num,
short vol,
long v_time
)
引数 
seq_access_num		SEQアクセスナンバー
vol			ボリューム値
v_time			時間（tick単位）
解説
seq_access_num を持つSEQデータのメインボリュームを、v_time 内に vol 値だけ下げる。なお、各ボイスの音量が最小値の場合は効果なし。

返り値
なし
