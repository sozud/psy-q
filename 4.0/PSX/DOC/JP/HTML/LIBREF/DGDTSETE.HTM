拡張CD-ROMライブラリ（libds） 関数一覧
Release 4.0

DsGetDiskType

CDの種類を得る

形式 

int DsGetDiskType ( void )
引数 
なし
解説
現在セットされているCDの種類を得る。得られる種類はPlayStation用ディスク（ブラックディスク）かそれ以外のCDの２通り。
本関数は、システムステータス（DsSystemStatus()で得られるステータス）がDslReadyになるまで処理をブロックする。

返り値
DslCdromFormat PlayStation用ディスク
DslOtherFormat それ以外のCD
DslStatNoDisk CDがセットされていない
DslStatShellOpen CDのカバーが開いている

備考
デバッギングステーションでは、ISO9660規格のCD（CD-Rを含む）をDslCdromFormatと認識する。また、本関数はDTL-H2000およびDTL-H5000では正常に動作しない。
