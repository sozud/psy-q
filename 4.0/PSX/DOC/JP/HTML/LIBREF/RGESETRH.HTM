ResetGraph

描画エンジンを初期化

形式 

int ResetGraph (
int mode
)
引数 
mode		セットモード
 		0: オールリセット。描画環境・表示環境を初期化する。
 		1: 現在の描画をキャンセルしてコマンドキューをフラッシュする。
		3: コールバックや描画環境・表示環境を初期化し、コマンドリセットを行う。
解説
グラフィックシステムを mode で指定したモードでリセットする。

返り値
