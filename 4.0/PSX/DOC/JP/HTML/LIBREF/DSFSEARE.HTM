Release 4.0

DsSearchFile

CD-ROM上のファイル名から位置とサイズを獲得

形式 

DslFILE* DsSearchFile (
DslFILE* fp,
char* name
)
引数 
fp		CD-ROMファイル構造体のポインタ
name		ファイル名
解説
CD-ROM上のファイル名から絶対位置（分・秒・セクタ）とサイズを知る。結果は *fp に格納される。

返り値
0： ファイルが見つからない
-1： サーチに失敗
以外： 獲得されたCD-ROMファイル構造体のポインタ

備考
ファイル名は全て絶対パスでかかれなくてはいけない。fpで指定されたファイルと同じディレクトリにあるファイルの位置情報はメモリにキャッシュされる。そのため同一ディレクトリ内のファイルに続けてDsSearchFile()を行なう場合は２回目以降のアクセスは高速になる。
返り値が-1の場合は何らかの理由でディレクトリのリードに失敗したことを示す。
