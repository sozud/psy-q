SpuGetVoiceADSRAttr

ADSR と各モードの取得

形式 

void SpuSetVoiceADSRAttr (
int voiceNum,
unsigned short *AR,
unsigned short *DR,
unsigned short *SR,
unsigned short *RR,
unsigned short *SL,
long *ARmode,
long *SRmode,
long *RRmode,
)
引数 
voiceNum	ボイス番号 (0 ～23)
AR		ADSR Attack Rate
DR		ADSR Decay Rate
SR		ADSR Sustain Rate
RR		ADSR Release Rate
SL		ADSR Sustain Level
ARmode		ADSR Attack Rate モード
SRmode		ADSR Sustain Rate モード
RRmode		ADSR Release Rateモード
解説
ボイスで使われる ADSR の個別の属性及びモードの取得を行う。
SpuGetVoiceAttr において SpuVoiceAttr 構造体のメンバ ar, dr, sr, rr, sl, a_mode, s_mode, r_mode の値の取得に該当する処理を行う。

返り値
なし
