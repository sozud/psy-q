DsIntToPos

絶対セクタ番号から分・秒・セクタを得る

形式 

DslLOC* DsIntToPos (
int i,
DslLOC* p
)
引数 
i		絶対セクタ番号
p		結果を格納するバッファのアドレス
解説
絶対セクタ番号から、DslLOC形式の分・秒・セクタを得る。

返り値
結果を格納したバッファのアドレス
