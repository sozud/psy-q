GsSortUnit

object をオーダリングテーブルに割り付け

形式 

void GsSortUnit (
GsUNIT		*objp,
GsOT		*otp,
unsigned long	*scratch
)
引数 
objp		オブジェクトへのポインタ
otp		OT へのポインタ
scratch		スクラッチパッドのアドレスを指定
解説
GsUNIT でハンドルされる 3 次元オブジェクトに対して透視変換及び光源 計算を行い、描画コマンドを GsSetWorkBase() で指定されるパケットエリアに生成する。続いて、生成された描画コマンドを Z ソートし、otp で示される OT に割り付ける。
scratch は下位関数を呼び出すさいに、変数を受け渡すのに使用される。使用量は以下の通り。

種類scratch エリアの使用量（単位 Byte)
独立ポリゴン32
共有ポリゴン40
固定分割独立3角形568
固定分割独立4角形852
