RotMeshH

座標変換と透視変換を行なう

形式 

void RotMeshH (
short *Yheight,
DVECTOR *Vo,
u_short *sz,
u_short *flag,
short Xoffset,
short Zoffset,
short m,
short n,
DVECTOR *base
)
引数 
Yheight			入力：頂点Ｙ座標
Vo			出力：スクリーン座標
sz			出力：SZ値
flag			出力：フラグ
Xoffset,Zoffset		入力：ＸＺオフセット
m,n			入力：頂点数
base			base address
解説
m * n 個の四角形メッシュ頂点に対して座標変換と透視変換を行なう。

引数および内部データフォーマット：
*Yheight : (1,15,0)
Vo->vx,vy : (1,15,0)
sz : (0,16,0)
flag : (0,16,0)
Xoffset,Zoffset: (1,15,0)
m,n: (1,15,0)
base: (1,15,0)

返り値
なし

備考
flag は通常の３２ビットflagの２７ビット目から１２ビット目まで。
