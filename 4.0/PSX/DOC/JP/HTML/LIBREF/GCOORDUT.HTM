GsCOORDUNIT

マトリックス型座標系

構造 

typedef struct _GsCOORDUNIT {
	unsigned long		flg;
	MATRIX			coord;
	MATRIX			workm;
	SVECTOR			rot;
	struct _GsCOORDUNIT	*super;
} GsCOORDUNIT;
メンバ 
flg		coord が書き換えられたかどうかのフラグ
coord		マトリックス
workm		この座標系から WORLD 座標系までの掛けた結果
rot		coord を生成する回転ベクトル
super		親座標へのポインタ
解説
GsCOORDUNIT は親座標をもち、MATRIX 型の coord により定義される。
workm には、GsGetLwUnit() 関数や GsGetLsUnit() 関数で WORLD 座標からGsCOORDUNITの各ノードでマトリックスをかけ算していくときに、その結果が保持される。ただし、WORLD 座標系に直接つながっている座標系の workm には結果を格納 しない。
flg は GsGetLwUnit()、GsGetLsUnit() 計算時に、すでに計算しているノードについての計算を省くために参照される。1 でセット、0 でクリアされる。プログラマは coord の内容を変更した場合は責任持ってこのフラグをクリアしなければならない。さもないと GsGetLwUnit()、GsGetLsUnit() 関数が誤動作することになる。
