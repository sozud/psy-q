LINE_F2

フラット非連結直線

構造 

typedef struct {
		u_long	tag;
		u_char	r0, g0, b0, code;
		short	x0, y0;
		short	x1, y1;
} LINE_F2;
メンバ 
tag		次のプリミティブへのフック（予約）
code		プリミティブ ID
r0,g0,b0	プリミティブの輝度値
x0,y0,x1,y1	プリミティブの右端点頂点座標
解説
LINE_F2は、輝度値が (r0,g0,b0) で、(x0,y0)-(x1,y1) を結ぶ非連結直線を描画する。
