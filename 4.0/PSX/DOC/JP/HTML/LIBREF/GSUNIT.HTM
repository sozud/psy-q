GsUNIT

３次元オブジェクトハンドラGsSortUnit用

構造 

typedef struct {
		GsCOORDUNIT	*coord;
		unsigned long	*primtop; 
} GsUNIT;
メンバ 
coord		ローカル座標系へのポインタ
primtop		プリミティブブロックの先頭へのポインタ
解説
GsUNITはHMDデータのプリミティブブロックごとに存在し、このGsUNIT構造体を通じて３次元モデルを操作することができる。
GsUNITをオーダリングテーブルに登録するにはGsSortUnit()を用いる。
coordはそのプリミティブブロック固有の座標系へのポインタである。オブジェクトの位置、傾き、大きさは coordでポイントされる座標系にマトリックスを設定することで反映される。
primtopには、プリミティブブロックの先頭アドレスが渡される。
