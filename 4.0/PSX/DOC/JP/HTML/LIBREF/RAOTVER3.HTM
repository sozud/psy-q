RotAverage3

３点の座標変換と透視変換を行ないデプスキューイング用の内挿値とＺ値の平均値を求める

形式 

long RotAverage3 (
SVECTOR *v0,
SVECTOR *v1,
SVECTOR *v2,
long *sxy0,
long *sxy1,
long *sxy2
long *p,
long *flag
)
引数 
v0,v1,v2		入力：ベクトル
sxy0,sxy1,sxy2		出力：座標
p			出力：内挿値
flag			出力：フラグ
解説
ローカル座標ベクトル v0,v1,v2 を回転マトリックスで座標変換したあと透視変換を行ない、３つのスクリーン座標を sxy0,sxy1,sxy2 に返す。
また v2 に対応するデプスキューイング用の内挿値を p に返す。
また３つのスクリーン座標のＺ値の平均値を返り値とする。

引数フォーマット：
v0,v1,v2->vx,vy,vz : (1,15,0)
sxy0,sxy1,sxy2 : (1,15,0),(1,15,0)
p : (0,20,12)
flag : (0,32,0)

返り値
OTZ値
