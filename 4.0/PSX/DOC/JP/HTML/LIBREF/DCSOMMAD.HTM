DsCommand

プリミティブコマンドをコマンドキューに登録する

形式 

int DsCommand (
u_char com,
u_char* param,
DslCB cbsync,
int count
)
引数 
com		コマンドコード
param		コマンドに対する引数（u_char[ 4 ]）
cbsync		コールバック関数のポインタ
count		リトライ回数（0：リトライなし、-1：無限リトライ）
解説
プリミティブコマンドをコマンドキューに登録する。登録されたコマンドは、実行可能であれば即座に実行されるが、既に他のコマンドが実行されている場合は登録のみ行われる。コマンドは全てバックグラウンドで実行される。
コマンドの実行が失敗した場合はcountの回数だけリトライされ、count回リトライしても成功しなかった場合はエラーとなる。count=0はリトライなしで、count=-1は無限回リトライである。
コールバック関数は各コマンド毎に設定が可能で、コマンドが終了した（エラーになった）場合にキックされる。また、DsSync()によってコマンドの実行状況を獲得することができる。

返り値
コマンドの発行が成功した場合はコマンドID（>0）が返される。失敗した場合は０。
