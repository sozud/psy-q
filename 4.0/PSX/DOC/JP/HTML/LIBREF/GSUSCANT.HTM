GsScanUnit

HMD データ内のタイプを調べる

形式 

int GsScanUnit (
unsigned long	*p,
GsTYPEUNIT	*ut,
GsOT		*ot,
u_long		*scratch;
)
引数 
p		ブロックの先頭アドレス
		p が 0 の時は、前回 GsScanUnit() がコールされた次のタイプを調べる。
ut		タイプとそのアドレスを格納する領域へのポインタ
otp		OT へのポインタ
scratch		スクラッチパッドのアドレスを指定
解説
HMD データは、タイプ毎に別れており、そのタイプに従って、プリミティブドライバをコールする。タイプが置かれている領域にプリミティブドライバへのポインタを上書きすることにより、GsSortUnit() が呼ばれたときに、プリミティブドライバがコールされる。プリミティブドライバへのポインタは、GsScanUnit() で返される GsTYPEUNIT の内容をみて、ユーザが自分で使用するプリミティブドライバへのポインタを代入する。
GsScanUnit()は、内部でタイプに対応するヘッダをscratchにコピーする。このscratchをプリミティブドライバの引数として渡すことにより、プリミティブドライバを起動できる。一般に一度しか起動しないイメージ用のプリミティブなど(GsUIMG0,GsUIMG1)は、この初期化のときに起動する。

最初に p にそのブロックの先頭アドレスを入れてコールし、その後は、p に 0 を入れてコールしてやるだけで、そのブロックの終端まで自動的にスキャンされる。この操作をそれぞれのブロックに対しておこなう。

返り値
0 そのブロックの終端に達し、タイプが存在しない
1 タイプが存在する

備考
一度タイプがプリミティブドライバへのポインタに上書きされた HMD データにはフラグが立っているので、再度 GsScanUnit() を呼び出しても、副作用は起こらない。
