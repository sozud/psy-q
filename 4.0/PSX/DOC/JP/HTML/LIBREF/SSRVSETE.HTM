拡張サウンド ライブラリ (libsnd) 関数一覧
Release 4.0

SsSetReservedVoice

libsndライブラリが割り当てるボイス数を宣言する

形式 

char SsSetReservedVoice (
char voices
)
引数 
voices		ボイス数
解説
libsndライブラリがアロケーションに利用するボイス数を宣言する。
それ以外のボイスは、libspuでユーザが利用可能。（必ず、all key offの状態でコールすること）

返り値
成功したら設定したボイス数
失敗したら-1を返す。

関連項目
SsSeqPlay(), SsSepPlay()
