MulMatrix

２つのマトリックスの積をとる

形式 

MATRIX *MulMatrix (
MATRIX *m0,
MATRIX *m1
)
引数 
m0,m1		入出力：マトリックス
解説
２つのマトリックスの積をとる。値は m0 に格納する。

引数フォーマット：
m0,m1->m[i][j] : (1,3,12)

返り値
m0

備考
回転マトリックスをこわす。
