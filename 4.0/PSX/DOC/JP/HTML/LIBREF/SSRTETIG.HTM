Release 4.0

StSetRing

リングバッファを設定する

形式 

void StSetRing (
unsigned long  *ring_addr;
unsigned long  ring_size
)
引数 
ring_addr	リングバッファの先頭アドレス
ring_size	リングバッファの大きさ（セクタ単位）
解説
リングバッファを設定する。ring_addr で先頭アドレスを ring_size で大きさを設定する。
ただし現状サポートされているCDROMのセクタはフォーム１のみ。よって１セクタのデータ領域は2048byteである。領域の確保はメインプログラムで行なう。
ストリーミングライブラリを使うには必ず最初に１回呼ぶ必要がある。

返り値
なし
