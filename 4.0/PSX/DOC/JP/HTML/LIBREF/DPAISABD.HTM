Release 4.0

DisablePAD

コントローラとの通信を中断する。

形式 

void DisablePAD ( void )
引数 
なし
解説
コントローラとの通信を一時中断する。
StopPAD()は、Vsync割り込みにより起動されているコントローラのハンドラを削除するが、
この関数は、単にフラグの操作だけでコントローラの通信をスキップする。
返り値
なし

備考
通常コントローラはVsyncの割り込みで通信を行うが、1/60secより長いタイミングでしかコントローラの状態を必要としない場合に利用される。
