SsSepStop

SEPデータ読みとり停止（ストップ）

形式 

void SsSepStop (
short sep_access_num,
short seq_num
)
引数 
sep_access_num		SEPアクセスナンバー
seq_num			SEPデータ内のSEQナンバー
解説
sep_access_num を持つSEPデータの seq_num 番目のSEQデータの読みとり（演奏）を終了する。

返り値
なし
