GsIMAGE

イメージデータ構成情報

構造 

struct GsIMAGE {
		short pmode;
		short px, py;
		unsigned short pw, ph;
		unsigned long * pixcel;
		short cx, cy;
		unsigned short cw, ch;
		unsigned long * clut;
}
メンバ 
pmode		ピクセルモード
 		0: 4bit CLUT
 		1: 8bit CLUT
 		2: 16bit DIRECT
 		3: 24bit DIRECT
 		4: 多モード混在
px, py		ピクセルデータの格納位置
pw, ph		ピクセルデータの横幅／高さ
pivel		ピクセルデータへのポインタ
cx, cy		CLUT データの格納位置
cw, ch		CLUT データの横幅／高さ
clut		CLUT データへのポインタ
解説
GsGetTimInfo() 関数によって TIM フォーマットデータの情報が格納される構造体。
