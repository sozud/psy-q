SpuStEnv

SPUストリーミング環境属性

構造 

typedef struct {
		long		size;
		long		low_priority;
		SpuStVoiceAttr	voice [24];
} SpuStEnv;
メンバ 
size		ストリームバッファのサイズ
low_priority	ストリーム処理の優先度
voice		各ストリームの属性
解説
SPU ストリーミングライブラリにて、ストリーミング環境、及び各ストリームの属性設定に用いられる。

関連項目
SpuStVoiceAttr, SpuStInit()
