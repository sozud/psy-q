strcmp

文字列同士を比較する

形式 

#include <strings.h>
long  strcmp (
const char * s1,
const char * s2
)
引数 
s1		比較元1
s2		比較元2
解説
s1 と s2 の各文字をunsigned charとして比較する。

返り値
比較結果により次の値を返す。

結果戻り値
s1<s2<0
s1=s2=0
s1>s2>0
