setjmp

非局所的ジャンプの着地点を定義

形式 

#include <setjmp.h>
int setjmp (
jmp_buf p
)
引数 
p		環境退避変数
解説
非局所的ジャンプの着地点情報を p に格納する。longjmp(p,val) が実行されると、setjmp()からリターンすることになる。

返り値
直接呼び出しでは0を返す。
ジャンプ実施時にlongjmp()の第２引数に与えられた値を返す。
