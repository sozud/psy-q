SpuSetVoiceRRAttr

ADSR Release Rate / Release Rate モードの設定

形式 

void SpuSetVoiceRRAttr (
int voiceNum,
unsigned short RR,
long RRmode
)
引数 
voiceNum	ボイス番号 (0 ～23)
RR		ADSR Release Rate
RRmode		ADSR Release Rate モード
解説
ボイスで使われる ADSR Release Rate / ADSR Release Rate モードの設定を行う。

SpuSetVoiceAttr() の mask 指定
SPU_VOICE_ADSR_RR
SPU_VOICE_ADSR_RMODE
に該当する処理を行う。

ADSR Release Rate RR、 及び ADSR Release Rate モードRRmodeに指定する値に関しては SpuSetVoiceAttr() を参照のこと。

返り値
なし
