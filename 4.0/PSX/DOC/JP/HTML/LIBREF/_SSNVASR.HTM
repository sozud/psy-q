解説
SEQ/SEPにNRPNデータが含まれている場合、_SsSetControlChange, _SsContDataEntry,_SsContNrpn1,_SsContNrpn2 と併せて、この下位関数を呼び出す必要がある。各設定データによって、下位関数が異なるので、以下を参照のこと。

・_SsSetNrpnVabAttr0 … Priority (CC 98 が 0)
・_SsSetNrpnVabAttr1 … Mode (CC 98 が 1)
・_SsSetNrpnVabAttr2 … Limit Low (CC 98 が 2)
・_SsSetNrpnVabAttr3 … Limit high (CC 98 が 3)
・_SsSetNrpnVabAttr4 … ADSR (AR-L) (CC 98 が 4)
・_SsSetNrpnVabAttr5 … ADSR (AR-E) (CC 98 が 5)
・_SsSetNrpnVabAttr6 … ADSR (DR) (CC 98 が 6)
・_SsSetNrpnVabAttr7 … ADSR (SL) (CC 98 が 7)
・_SsSetNrpnVabAttr8 … ADSR (SR-L) (CC 98 が 8)
・_SsSetNrpnVabAttr9 … ADSR (SR-E) (CC 98 が 9)
・_SsSetNrpnVabAttr10 … ADSR (RR-L) (CC 98 が 10)
・_SsSetNrpnVabAttr11 … ADSR (RR-E) (CC 98 が 11)
・_SsSetNrpnVabAttr12 … ADSR (SR-±) (CC 98 が 12)
・_SsSetNrpnVabAttr13 … Vibrate time (CC 98 が 13)
・_SsSetNrpnVabAttr14 … Portamento depth (CC 98 が 14)
・_SsSetNrpnVabAttr15 … Reverb type (CC 98 が 15)
・_SsSetNrpnVabAttr16 … Reverb depth (CC 98 が 16)
・_SsSetNrpnVabAttr17 … Echo feed back (CC 98 が 17)
・_SsSetNrpnVabAttr18 … Echo delay time (CC 98が18)
・_SsSetNrpnVabAttr19 … Delay delay time(CC 98が19)

なし
