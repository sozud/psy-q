strcpy

文字列を他の文字列に複写する

形式 

#include <strings.h>
char * strcpy (
char * dest,
const char * src
)
引数 
dest			複写先文字列
src			複写元文字列
解説
文字列 dest へ src を複写する。

返り値
dest を返す。

関連項目
strncpy()
