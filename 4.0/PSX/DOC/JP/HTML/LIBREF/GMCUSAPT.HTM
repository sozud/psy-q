GsMapCoordUnit

HMD データ内の COORDINATE を実アドレスにマップ

形式 

GsCOORDUNIT *GsMapCoordUnit (
unsigned long	*base,
unsigned long	*p,
)
引数 
base		HMD データの先頭アドレス
p		INI(init) ビットが立っているタイプのアドレス
解説
HMD データ内に COORDINATE が存在する場合、GsScanUnit() を行ったときに、GsTYPEUNIT の type において、INI ビットが立っているタイプが一つ存在する。その場合、そのタイプのアドレスを GsMapCoordUnit() に渡すことにより、データ内の COORDINATE TOP および、COORDINATE 内の super が実アドレスに変換される。

返り値
COORDINATE 部の先頭アドレス

備考
なし
