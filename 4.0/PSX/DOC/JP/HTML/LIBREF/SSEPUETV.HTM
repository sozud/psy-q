SpuSetEnv

基本サウンドライブラリの環境設定

形式 

void SpuSetEnv (
SpuEnv  *env
)
引数 
env		基本サウンドライブラリ環境属性
解説
基本サウンドライブラリの環境を設定する。
env.mask に、下記の設定したい属性のビット和を与えることで各属性のみの設定が可能 (現在 1 つの属性のみ設定可能なのでその値を指定する)。

属性ビット内容
SPU_ENV_EVENT_QUEUEINGイベントをキューに溜める


env.mask が 0 の場合は全属性を設定する。
以下に個々の設定条件を説明する。

(1) イベントをキューに溜める
env.queueing に下記の値を指定することにより、キーオン/オフ、ピッチ LFO ボイス設定、ノイズボイス設定、およびリバーブボイス設定のそれぞれのイベントをキューに溜めるかを設定する。

指定値内容
SPU_ONイベントをキューに溜める
SPU_OFFイベントをキューに溜ない (既定値)


既定値はキューに溜めずに即座に設定を行う。

返り値
なし
