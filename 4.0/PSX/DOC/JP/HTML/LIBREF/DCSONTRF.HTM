DsControlF

CdControlFの互換関数

形式 

int DsControlF (
u_char com,
u_char* param
)
引数 
com		コマンドコード
param		コマンドに対する引数（u_char[ 4 ]）
解説
CdControlFとほぼ同じインターフェイスを提供する関数。実際のタイミング等は異なり、内部的にはコマンドキューにコマンドを登録するだけである。返り値がコマンドIDとなる点に注意。

返り値
コマンドの登録が成功した場合はコマンドID（>0）を返す。失敗した場合は０。

備考
CdControlFでは前のコマンドの実行の終了を待ってコマンドを発行するが、DsControlFでは前にコマンドが実行されている場合はコマンドキューにコマンドを登録する。
