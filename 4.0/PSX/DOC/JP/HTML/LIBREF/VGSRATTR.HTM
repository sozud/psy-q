SpuGetVoiceSRAttr

ADSR Sustain Rate / Sustain Rate モードの取得

形式 

void SpuGetVoiceSRAttr (
int voiceNum,
unsigned short *SR,
long *SRmode
)
引数 
voiceNum	ボイス番号 (0 ～23)
SR		ADSR Sustain Rate
SRmode		ADSR Sustain Rate モード
解説
ボイスで使われる ADSR Sustain Rate / ADSR Sustain Rate モードの取得を行う。
SpuGetVoiceAttr() における SpuVoiceAttr 構造体のメンバ sr, s_mode の値の取得に該当する処理を行う。

返り値
なし
