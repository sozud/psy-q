SpuSetMute

サウンドのミュートオン/オフ

形式 

long SpuSetMute (
long on_off
)
引数 
on_off		SPU_ON（ミュートオン設定）またはSPU_OFF（ミュートオフ設定）
解説
サウンドのミュートのオン/オフを設定する。
但し、CD入力、及び外部デジタル入力はこのミュートオン/オフによってミュートされない。

返り値
設定された値

返り値意味
SPU_ONミュートオン
SPU_OFFミュートオフ
