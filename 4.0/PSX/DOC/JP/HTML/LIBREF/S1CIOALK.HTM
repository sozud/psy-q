シリアル入出力ライブラリ (libsio) 関数一覧
Release 4.0

Sio1Callback

SIO割り込みコールバック関数を設定する

形式 

int Sio1Callback( 
void (* func)() 
)
引数 
func		コールバック関数
解説
_sio_control(1, 1, param)で設定された割り込み要因(CR_DSRIEN, CR_RXIEN, CR_TXIEN)により割り込みが発生した場合に、関数funcが呼び出される。
funcに 0を指定した場合は、コールバックは発生しない。

返り値
なし

備考
割り込み発生時には、_sio_control(2,1,0)または_sio_control(1,1, CR_ERRRST)を用いて割り込みフラグをクリアする必要がある。割り込みフラグがクリアされていない状態では、次のSIO割り込みは発生しない。
