SpuSetCommonMasterVolumeAttr

マスタ音量/マスタ音量モードの設定

形式 

void SpuSetCommonMasterVolumeAttr (
short mvolL,
short mvolR,
short mvolModeL,
short mvolModeR
)
引数 
mvolL		マスタ音量 (左)
mvolR		マスタ音量 (右)
mvolModeL	マスタ音量モード (左)
mvolModeR	マスタ音量モード (右)
解説
マスタ音量/マスタ音量モードの設定を行う。
SpuSetCommonAttr() の mask 指定
SPU_COMMON_MVOLL
SPU_COMMON_MVOLR
SPU_COMMON_MVOLMODEL
SPU_COMMON_MVOLMODER
に該当する処理を行う。
音量モード mvolModeL, mvolModeR 、及び音量 mvolL, mvolR に指定する値に関しては SpuSetCommonAttr(), SpuSetVoiceAttr() を参照のこと。

返り値
なし
