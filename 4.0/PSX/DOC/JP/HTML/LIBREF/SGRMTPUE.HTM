SpuGetReverbModeType

リバーブモードタイプの取得

形式 

void SpuGetReverbModeType (
long *type
)
引数 
type		リバーブモードタイプ
解説
リバーブモードタイプを取得する。
SpuGetReverbModeParam() において SpuReverbAttr 構造体のメンバ mode の値の取得に該当する処理を行う。

返り値
なし

関連項目
