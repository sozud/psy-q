DivideF3

フラット３角形の分割

形式 

u_long *DivideF3 (
SVECTOR *v0,
SVECTOR *v1,
SVECTOR *v2,
CVECTOR *rgbc,
POLY_F3 *s,
u_long *ot,
DIVPOLYGON3 *divp
)
引数 
v0,v1,v2	入力：頂点座標ベクトル
rgbc		入力：色ベクトル(+code)
s		GPUパケットバッファのアドレス
ot		ＯＴエントリ
divp		入力：デバイド用ワークエリア
解説
フラット３角形の分割処理プログラム。
頂点座標ベクトルと色ベクトルで表されるフラット３角形を divp->ndivの値のもとに分割し、OTへ登録する。

ndiv=1: 2x2分割、ndiv=2: 4x4分割、
ndiv=3: 8x8分割、ndiv=4: 16x16分割、
ndiv=5: 32x32分割

返り値
更新されたGPUパケットバッファのアドレス

備考
divp->ndiv:分割数、divp->pih,piv:表示画面の解像度(クリップ用)、は設定されているものとする。
ot はＯＴエントリ（libgpu参照）
