Release 4.0

SelectGUN

ガンを選択する

形式 

void SelectGUN (
int ch,
unsigned char mask
)
引数 
ch		ガンのチャネル（0 または 1）
mask		割り込みマスクの設定（0:割り込み禁止、1:割り込み許可）
解説
ガンに対して割り込みマスクのオンオフを知らせる。
同時に２つ以上のマスクの解除はできない。

関連項目
InitGUN(),StartGUN(),StopGUN(),SelectGUN(),RemoveGUN()
