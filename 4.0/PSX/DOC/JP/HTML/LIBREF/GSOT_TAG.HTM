GsOT_TAG

オーダリングテーブルの単位

構造 

struct GsOT_TAG {
		unsigned p : 24;
		unsigned char num : 8;
};
メンバ 
p		OT リングポインタ
num		パケットのワード数
解説
オーダリングテーブルの配列はこの GsOT_TAG の配列となる。
オーダリングテーブルは、次々にアドレスをポイントする「リスト構造」となっている。アドレスは 32bit 中下位 24bit が p で表わせる。
オーダリングテーブルをメモリ上に取る時は、GsOT のメンバである length 設定された大きさの GsOT_TAG の配列を確保する。
