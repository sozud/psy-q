SpuGetCommonCDMix

CD 入力オン/オフの取得

形式 

void SpuGetCommonCDMix (
long *on_off
)
引数 
on_off		CD 入力オン/オフ
解説
CD 入力オン/オフの状態を取得する。
SpuGetCommonAttr() において SpuCommonAttr 構造体のメンバ cd.mix の値の取得に該当する処理を行う。

返り値
なし

関連項目
SpuGetCommonAttr(), SpuSetCommonCDMix()
