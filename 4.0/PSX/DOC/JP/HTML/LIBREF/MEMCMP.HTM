memcmp

メモリブロックの比較を行なう

形式 

#include <memory.h>
long memcmp (
const void * s1,
const void * s2,
size_t n
)
引数 
s1		比較元1
s2		比較元2
n		比較バイト数
解説
s1 と s2 の最初の n バイトを比較する。

返り値
s1 と s2 の比較結果により次の値を返す。

結果返り値
s1<s2<0
s1=s2=0
s1>s2>0
