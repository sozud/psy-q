ratan2

逆正接をもとめる(２引数、大テーブル使用、高速)

形式 

long ratan2 (
long y,
long x
)
引数 
x,y		任意の値
解説
arctan (-pai...pai)をPSX format (4096=2pai)で求める。

フォーマット：
返り値 : (1,19,12)

返り値
atan2(y,x)

備考
x か y のどちらかが-2147483648 (0x80000000 =longの負の最大値)は返り値が不定になる。
