DecDCTin

ランレベルを画像処理サブシステムに送信

形式 

void DecDCTin (
u_long *buf, 
int mode
)
引数 
buf		入力ランレベル
mode		デコードモード
解説
ランレベル buf 以下をダイレクトカラー画像に解凍する。
解凍結果は、DecDCTout()で取り出す。
デコードモードは mode の下位２ビットで指定する。

bit 0出力モード
016bitダイレクトカラー
124bitダイレクトカラー


bit 1STP
00
11


出力のピクセルの深さは、24bit/16bitのどちらかを選択できる。
16bitモードの場合、解凍後のピクセルの15bit目(STPビット）は、mode のbit1で設定できる。

返り値
なし

備考
DecDCTin()で解凍された結果生じる画像の幅・高さに関する情報は、ランレベルやビットストリームには保持されていない。これらのパラメータは、より上位の階層のデータ形式(STRフォーマットなど）で定義される。
送受信のデッドロックを防止するために、送信したランレベルに対応するサイズのデータはDecDCTout()によって必ず受信しなくてはならない。
しかし、その際に一回のDecDCTin()で送信したデータを複数回のDecDCTout()で読み出してもよいし、その逆もできる。
DecDCTin()はノンブロック関数であるため、実際の転送の終了はDecDCTinSync()で検出する必要がある。DecDCTin()の終了をまたずに、次のDecDCTin()を実行すると２回目の送信は１回目の送信が終了するまでブロックされる。
