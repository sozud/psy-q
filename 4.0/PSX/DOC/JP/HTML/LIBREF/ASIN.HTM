asin

逆正弦

形式 

double asin (
double x
)
引数 
x		逆正接を計算する値。範囲は [-1, 1]。
解説
x の逆正弦関数を求める。

返り値
x の逆正弦関数。範囲は [-pai/2, pai/2]。
エラー処理は次の通り。

条件返り値エラー
fabs(x)>10領域エラー


備考
[]は閉領域を示す
