DR_ENV

描画環境変更プリミティブ

構造 

typedef struct {
		u_long	tag;
		u_long	code[15];
} DR_ENV;
メンバ 
tag		次のプリミティブへのフック（予約）
code		プリミティブ ID
解説
DR_ENV プリミティブはその時の描画環境を描画環境構造体DRAWENV から変換された描画環境に強制的に変更する。
内容の設定は SetDrawEnv() で行なう。

備考
DRAWENV と DR_ENV は表現形式が異なる。
