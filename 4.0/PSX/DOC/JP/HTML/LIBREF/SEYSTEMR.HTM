SystemError

システムエラー画面の表示

形式 

void SystemError ( 
char c, 
long n 
)
引数 
c		エラー識別文字（英文字のみ）
n		エラー識別コード（0～999）
解説
画面表示によりシステムエラー発生をオペレータに通報する。
ゲーム実機ではexit()の内部でコールする。
成功すると返らない。

返り値
なし
