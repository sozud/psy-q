GsWORKUNIT

共有プリミティブの計算結果格納領域

構造 

typedef struct {
	DVECTOR		vec; 
	short		otz:
	short		p;
} GsWORKUNIT;
メンバ 
vec		3次元の座標値を透視変換後の2次元座標値を格納する領域
otz		vecを求めたときに得られるOTZの値を格納する領域
p		vecを求めたときに得られる内挿値を格納する領域
解説
共有プリミティブを使用した場合には、まずそれぞれのマトリックスで3次元の座標値を透視変換し、2次元の座標に変換する。すべてのマトリックスで透視変換が終わった後で、共有プリミティブはその変換後の2次元座標を参照して、パケットを作成する。その計算結果を格納するための領域である。
