strncpy

文字列を他の文字列に複写する

形式 

#include <strings.h>
char  *strncpy (
char * dest,
const char * src,
size_t n
)
引数 
dest		複写先配列
src		複写元文字列
n		複写バイト数
解説
文字列 dest へ src を n バイト分複写する。複写文字数が n になると複写を打ち切る。

返り値
dest を返す。
