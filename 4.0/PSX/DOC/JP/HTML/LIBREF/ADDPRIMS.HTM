AddPrims

描画するプリミティブをまとめてＯＴに登録

形式 

void AddPrims (
void *ot,
void *p0,
void *p1
)
引数 
ot		ＯＴエントリ
p0		プリミティブリストの先頭プリミティブのアドレス
p1		プリミティブリストの最後尾プリミティブのアドレス
解説
ＯＴのエントリ* ot にアドレス* ps で始まるプリミティブリストを登録する。
プリミティブリストは、AddPrim() で接続された複数のプリミティブのリスト、あるいは、ローカルオーダリングテーブルによって作成されたリスト。

返り値
なし
