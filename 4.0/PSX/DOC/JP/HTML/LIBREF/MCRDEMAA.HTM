メモリカード簡易レベルライブラリ (libmcrd) 関数一覧
Release 4.0

MemCardReadData

メモリカードからデータを読み込む

形式 

long MemCardReadData (
long chan,
unsigned long* adrs,
long offset,
long bytes
)
引数 
chan		ポート番号 + カード番号
		ポート番号(Ａポート:0x00、Ｂポート:0x10)
		カード番号(通常 0)
adrs		読み込むメインメモリアドレス
offset		ファイルの先頭を 0とした読み込みオフセットバイト数
bytes		読み込むバイト数(128の倍数)
解説
メモリカード上のファイルからデータを読み込む。
MemCardOpen() によって事前にファイルをオープンしておく必要がある。
関数自体は非同期処理のため直ちに終了する。多重の処理登録は行なえない。
処理の完了はMemCardSync() または完了コールバックにより確認する。
実行結果はMemCardSync() または完了コールバックの result 値として通知される。
bytesは128単位で指定する。128単位でない数値を指定した場合、処理登録は行われず、戻り値に 0を返し終了する。

result値
値マクロ状態
0x00McErrNone正常終了
0x01McErrCardNotExistカードが接続されていない
0x02McErrCardInvalid通信エラー発生
0x03McErrNewCard新規カード（カードが交換された）


返り値
処理登録に成功すると 1を、以外は 0を返す。

備考
非同期関数, 所要時間 オーバーヘッド 約1VSYNC ＋ 1ブロック(8192バイト) あたり約130VSYNC
