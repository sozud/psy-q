EnterCriticalSection

クリティカルセクションに入る

形式 

int EnterCriticalSection ( void )
引数 
なし
解説
割り込みを停止し、クリティカルセクションに入る。
カーネル起動直後はこの状態にある。

返り値
クリティカルセクションで本関数を呼び出した場合０を、それ以外では１を返す。

備考
内部でシステムコール命令を実行し、割り込みコンテキストを破壊する。

関連項目
ExitCriticalSection(), TCBH構造体, TCB構造体
