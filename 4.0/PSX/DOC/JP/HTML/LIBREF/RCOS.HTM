rcos

余弦

形式 

int rcos (
int a
)
引数 
a		PlayStationフォーマットによる角度
解説
PSX formatの角度（4096=2pai）のcosを固定小数点（4096=1.0）で求める。

フォーマット：
a : PSX format (4096=2pai radian)
返り値 : (1,19,12)

返り値
cos(a)
