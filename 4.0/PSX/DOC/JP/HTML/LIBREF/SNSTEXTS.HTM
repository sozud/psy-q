Release 4.0

StNextStatus

次のフレームの状態を返す

形式 

unsigned short StNextStatus (
unsigned long **addr,
unsigned long **header
)
引数 
addr		次に取り出されるユーザデータ領域の先頭アドレス
header		次に取り出されるデータのセクタヘッダ領域の先頭アドレス
解説
リングバッファにある次の１フレームのステータスを得る。この関数を呼んでも内部状態は変化しない。

ステータスは以下の通り

ステータス内容
StFREE次のフレームはリングバッファ上にない
StCOMPLETE次のフレームはリングバッファ上にそろった
StBUSY次のフレームはリングバッファ上にそろいつつある
StLOCK
次のフレームは処理中（つまりStGetNext()で
引き上げているが、まだStFreeRing()していない）


返り値
次のフレームのステイタス
