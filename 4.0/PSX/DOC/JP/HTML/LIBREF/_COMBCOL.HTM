_comb_control

対戦ケーブルドライバの制御

形式 

long _comb_control (
unsigned long cmd,
unsigned long arg,
unsigned long param
)
引数 
cmd		コマンド
arg		サブコマンド
param		引数
解説
対戦ケーブルドライバの詳細な制御を行います。
※詳細はoverview/comb.docの「ＢＩＯＳ」を参照してください。

返り値
各コマンド／サブコマンドによる、それぞれの値を返します。
