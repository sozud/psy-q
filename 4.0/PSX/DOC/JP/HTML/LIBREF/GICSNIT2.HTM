GsInitCoordinate2

ローカル座標系の初期化（GsCOORDINATE2用）

形式 

void GsInitCoordinate2 (
GsCOORDINATE2 * super，
GsCOORDINATE2 * base
)
引数 
super		親座標系へのポインタ
base		（初期化する）座標系へのポインタ
解説
base->coord は単位行列に、base->superは引数で指定される座標系に各々初期化される。

返り値
なし
