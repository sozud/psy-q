GsARGUNIT_SHARED

共有プリミティブドライバの引数領域

構造 

typedef struct {
	unsigned long	*primp;
	GsOT		*tagp;
	int		shift;
	int		offset;
	PACKET		*out_packetp;
	unsigned long	*primtop;
	SVECTOR		*vertop; 
	GsWORKUNIT	*vertop2;
	SVECTOR		*nortop;
	SVECTOR		*nortop2;
} GsARGUNIT_SHARED;
メンバ 
primp		プリミティブの先頭アドレス
tagp		現在の先頭の GsOT_TAG へのポインタ
shift		OTにソートする際の shift するbit数
offset		OT のスクリーン座標系におけるＺ軸上のオフセット
out_packetp	未使用のパケットエリアへのポインタ
primtop		POLYGONセクションの先頭へのポインタ
vertop		共有VERTEXセクションの先頭へのポインタ
vertop2		共有VERTEXセクションの計算結果を格納する領域へのポインタ
nortop		共有NORMALセクションの先頭へのポインタ
nortop2		共有NORMALセクションの計算結果を格納する領域へのポインタ
解説
GsSortUnit()からコールされる共有プリミティブドライバへ渡される引数領域。
GsARGUNITに加え、HMDデータ内のPOLYGONセクションやVERTEXセクションや、NORMALセクションの先頭へのポインタや、その計算結果を格納する領域へのポインタなどが渡される。
通常高速化のため、スクラッチパッドを使用する。
