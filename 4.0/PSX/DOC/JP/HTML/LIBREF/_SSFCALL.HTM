_SsFCALL

SsSeqOpenJ(), SsSepOpenJ() で参照する関数テーブルの型

構造 

typedef struct {
		void (*noteon)();
		void (*programchange)();
		void (*pitchbend)();
		void (*metaevent)();
		void (*control[13])();

} _SsFCALL;

解説
SsSeqPlay(), SsSepPlay()は MIDI の status data を解析して下位関数を呼び出している。この下位関数はかなりの数にのぼり、1 つのアプリケーションでは全ての下位関数を使わない場合がほとんどである。これらの下位関数群は、SsSeqOpen(), SsSepOpen() を CALL することでセットされる。

そこで、不要な下位関数をリンクしないことでコードを小さくするために SsSeqOpenJ(),SsSepOpenJ()という、それぞれSsSeqOpen(),SsSepOpen()コンパチで下位関数をジャンプテーブル化し、必要な関数群をユーザが設定出来るようにした。

_SsFCALLは、この関数テーブルを定義した構造体である。それぞれの要素に適切な下位関数のポインタを入れることで、その関数はリンクされる。逆にポインタを入れず extern宣言もしないことでリンクを切ることができる。ただしポインタのない関数が呼ばれた場合は、BUS ERRORが発生するので注意が必要である。これは下位関数の頭に dmy をつけたダミー関数を設定することで回避することが出来る。
