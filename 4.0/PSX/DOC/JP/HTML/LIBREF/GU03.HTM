GsU_03000000

HMDアニメーションのフレームアップデートドライバ

形式 

unsigned long 	*GsU_03000000(
GsARGUNIT_ANIM *sp
)
引数 
sp		引数受け渡し領域
		通常は高速化のためスクラッチパッドを指定する。
sp上に構築されている引数の情報は以下の通り





色のついている部分は必ずセットされている。
色のついていない部分はプリミティブヘッダがそのままコピーされるので
ヘッダの形が変われば変化する。
アニメーションヘッダサイズはアニメーション用の情報がいくつ引数領域へ
コピーされたかの数を保持する。上記例の場合は６である。
解説
フレームアップデートドライバとはシーケンス記述子を解釈し適当な補完関数を呼び出す働きをする関数である。シーケンスのジャンプやリバースなどはこのフレームアップデートドライバによって実現されている。フレームアップデートドライバの内部状態は、全てシーケンスポインタ領域に保持されるためプログラマが実行時にこの領域を書き換えることでシーケンスのリアルタイム制御が可能である。
シーケンスポインタの詳細はGsSEQの解説を参照のこと。

フレームアップデートドライバはＨＭＤのプリミティブブロックのPRE-PROCESSにリンクされる。
GsSortUnit()で最初のプリミティブブロックを処理する際(PRE-PROCESS)に呼び出される。フレームアップデートドライバはシーケンスポインタにより参照すべきシーケンス記述子を特定し、それを解釈することでシーケンスの進行を制御する。最終的にキーフレームを参照するシーケンス記述子を解釈し適当な補完ドライバをSRC FRAME,DST FRAMEをつけて呼び出す。

返り値
次のプリミティブドライバの先頭アドレスが格納されている領域
サンプルプログラム参照のこと（PS-X/sample/grapihcs/hmd/pdriver/GsU_00000008.c）
