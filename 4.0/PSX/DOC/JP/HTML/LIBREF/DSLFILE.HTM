DslFILE

9660ファイルディスクリプタ

構造 

typedef struct {
	DslLOC pos;
	u_long size;
	char name[ 16 ];
} DslFILE;
メンバ 
pos		ファイルポジション
size		ファイルサイズ（バイト単位）
name		ファイル名
解説
9660形式CD-ROMファイルの位置・サイズを取得する。
