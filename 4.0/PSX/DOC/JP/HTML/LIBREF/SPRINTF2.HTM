sprintf2

配列への書式出力（float,double型対応）

形式 

long sprintf2 (
char *s,
const char *fmt[,argument...]
)
引数 
s		変換文字列の格納先
fmt		入力書式文字列
解説
変換指定子「f」「e」「E」「g」「G」が使用できる。
スタック消費量はsprintfより多い。

返り値
出力した文字の長さを返す。
