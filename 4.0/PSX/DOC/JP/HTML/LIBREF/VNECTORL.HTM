VectorNormal

ベクトルを正規化する

形式 

long VectorNormal (
VECTOR *v0,
VECTOR *v1
)
引数 
v0		入力：ベクトル
v1		出力：ベクトル
解説
ベクトル v0 を正規化し v1 に返す。

引数フォーマット：
v0->vx,vy,vz : (1,31,0)
v1->vx,vy,vz : (1,19,12)

返り値
v0 の成分の２乗和

備考
v0 の成分の２乗和が2^31-1を超えると正しく計算できない。
v0の各成分の下位16bitを符号付き16bit整数としてきりだしたものの2乗和が2^31-1を超えるとオーバーフロー例外を発生する。
