ストリーミング ライブラリ (libcd) 関数一覧
Release 4.0

StSetStream

ストリーミングのパラメータを設定する

形式 

void StSetStream (
unsigned long mode,
unsigned long start_frame,
unsigned long end_frame,
int (*func1)(),
int (*func2)()
)
引数 
mode		モードの設定
 		色モード指定 (16bit mode: 0、24bit mode:1)
start_frame 	ストリーミングをスタートさせるFRAME
 		0 を指定するとフレーム番号にかかわらずスタート。
end_frame	ストリーミングを終了するFRAME
 		0 を指定するとリングバッファの最後までデータが入ると自動的に終了、
		十分大きな数を指定するとCDROMのデータの最後まで再生して終了。
func1		1FRAME分のデータができる毎にコールバックされる関数のアドレス。
		0 を指定するとコールバックされない。
func2		ストリーミングが終了するとコールバックされる関数のアドレス。
		0 を指定するとコールバックされない。
解説
StSetStream()はストリーミングのためのパラメータをセットする。
start_frame, end_frame で指定する frame 番号はSTRデータに書かれている frame 番号である。
start_frame はストリーミングを再生させるトリガをかけるフレームのことである。
ストリーミングライブラリはこのトリガフレームがこない限り再生を始めない。
よってストリーミングデータの途中から再生をしたい場合は start_frame も１ではなく適正な値にセットしなければならない。
ストリーミングのスタートポイントを厳密に定めなくてもよいならば0を指定することでどのフレームがきても再生するようにできる。
end_frame は０を設定するとリングバッファに入り切る最大のFRAMEが入ったところで終了するのでリングバッファを大きくとり、メモリーから再生する時に便利。

返り値
なし

備考
ストリーミングのアプリケーションを正常にexitするにはストリーミングの終了は end_frame で指定しない方が望ましい。
end_frame には0xffffffffを設定しておきアプリケーションのループ中で最適なexitポイントをコーディングすべきである。
