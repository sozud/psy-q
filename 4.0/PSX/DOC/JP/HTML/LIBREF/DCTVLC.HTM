DecDCTvlc

VLCの解凍を行なう

形式 

int DecDCTvlc (
u_long *bs, 
u_long *buf
)
引数 
bs		入力ビットストリーム
buf		出力ランレベル
解説
ビットストリーム bs を解凍し、中間形式であるランレベルを buf 以下に生成する。
解凍後のランレベルの大きさは、DecDCTBufSize() で取得できる。
ランレベルが DecDCTvlcSize() で指定された値を越えると、DecDCTvlc() は一旦処理を中断し制御をアプリケーションに戻す。
中断したVLCデコードは、DecDCTvlc(0, 0) を実行することで再開できる。

返り値

返り値意味
0全ビットストリームのデコードが終了
1未デコードのビットストリームを残して復帰
-1デコード失敗


備考
ブロック関数。DecDCTin()を実行する前に必ずDecDCTvlc()で一旦ビットストリームをランレベルに変換しておく必要がある。
途中結果のランレベルをDecDCTin()に入力として与えることはできない。
