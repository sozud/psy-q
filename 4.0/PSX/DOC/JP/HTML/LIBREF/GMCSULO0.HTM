GsMulCoord0

MATRIXの乗算

形式 

void GsMulCoord0 (
MATRIX * m1, 
MATRIX * m2, 
MATRIX * m3
)
引数 
m1, m2, m3	マトリックス
解説
translation も考慮した MATRIX の乗算を行なう。
結果は m3 に 格納される。

m3 ＝ m1 × m2

返り値
なし
