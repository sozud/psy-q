メモリカード簡易レベルライブラリ (libmcrd) 関数一覧
Release 4.0

MemCardStart

メモリカードシステムの稼動開始

形式 

void MemCardStart ( void )
引数 
なし
解説
MemCardInit()で初期化したメモリカードシステムを稼働状態に移行する。
内部でHwCARD及びSwCARDなど、8個のイベントをオープンする。

返り値
なし

備考
同期関数, 即時終了する

関連項目
MemCardInit(), MemCardStop()
