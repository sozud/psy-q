SendPAD

コントローラの送信データバッファの初期化

形式 

void SendPAD (
char *bufA,
long  lenA,
char *bugB,
long  lenB
)
引数 
bufA, bufB	送信データバッファ
lenA, lenB	送信データバッファ長（バイト単位）
解説
コントローラの送信データバッファを登録する初期化関数で、PadInit(),InitPAD()の後に１度呼ぶ。以後は、垂直同期割り込み毎のコントローラとの通信時にバッファにセットされたターゲットデバイスＩＤおよびデータが送信されるので、必要な値を、バッファに書き込むことで、コントローラの振動等を制御することになる。


バイト内容
０
バッファのデータが有効か無効かを指定するフラグ
0x00で無効、0x01で有効。その他の値での動作は未定義。
１
ターゲットデバイスＩＤ
(上位２ビットを利用、他のビットはシステム予約)
２～送信データ(データ長は受信データ長と同じ)


返り値
なし

備考
振動装置搭載の新型アナログコントローラにおけるバッファ設定と注意事項は以下のとおり。

バイト内容
ターゲットデバイスＩＤ
上位2bit：0x01
下位6bit：動作未定義（振動装置）
送信データ（第１バイト）
bit0:1 = 振動ON、 0 = 振動OFF
その他(bit7～1)：動作未定義
送信データ（第２バイト以降）常に0x00。その他：動作未定義


注意事項：
振動装置へのオン操作はコントローラとの通信が行われ、次にコントローラとの通信が行われるまでの１垂直同期期間の間のみ有効。装置を動作させる期間中、垂直同期割り込み毎に送信データバッファにターゲットデバイスＩＤおよび振動オンをセットしかつバッファを有効状態にし続けること。ターゲットデバイスＩＤは上位２ビットが01のときに有効となるが、他のビットはシステム予約となっており、すべて0として下さい。また、送信データ第１バイトも下位１ビットが1のとき有効となり、他のビットは、0として下さい。
