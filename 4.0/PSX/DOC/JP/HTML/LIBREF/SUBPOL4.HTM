SubPol4

４頂点ポリゴンを細分割する

形式 

void SubPol4 (
POL4 *p,
SPOL *sp,
int ndiv
)
引数 
p		４頂点ポリゴン
sp		細分割頂点配列
ndiv		分割数(0:分割なし,1:2x2,2:4x4)
解説
４頂点ポリゴン p を分割数2**ndiv で細分割し、その細分割頂点座標やテクスチャー座標やＲＧＢ値を sp のさす配列に返す。


引数フォーマット：
p->sxy : (1,15,0),(1,15,0)
p->sz : (0,16,0)
p->uv : (1,15,0),(1,15,0)
p->rgb : (0,8,0),(0,8,0),(0,8,0)
p->code : (0,32,0)
sp->xy : (1,15,0),(1,15,0)
sp->uv : (1,15,0),(1,15,0)
sp->rgb : (0,8,0),(0,8,0),(0,8,0)

返り値
なし
