GsARGUNIT_JntMIMe

関節マイムプリミティブドライバの引数領域

構造 

typedef struct {
	unsigned long	*primp;
	GsOT		*tagp;
	int		shift;
	int		offset;
	PACKET		*out_packetp;
	GsCOORDUNIT	*coordtop;
	long		*mimepr;
	u_long		mimenum;
} GsARGUNIT_JntMIMe;
メンバ 
primp		プリミティブの先頭アドレス
tagp		現在の先頭の GsOT_TAG へのポインタ
shift		OTにソートする際の shift するbit数
offset		OT のスクリーン座標系におけるＺ軸上のオフセット
out_packetp	未使用のパケットエリアへのポインタ
coordtop	COORDINATE セクションの先頭へのポインタ
mimepr		マイム係数領域へのポインタ
mimenum		マイムキーの数
解説
GsSortUnit()からコールされる関節マイムプリミティブドライバへ渡される引数領域。
GsARGUNITに加え、HMDデータ内のCOORDINATEセクション先頭へのポインタ、マイム係数領域へのポインタ、マイムキーの数が渡される。
通常高速化のため、スクラッチパッドを使用する。
