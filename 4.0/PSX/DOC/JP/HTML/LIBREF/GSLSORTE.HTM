GsSortLine

直線をOTへ登録

形式 

void GsSortLine (
GsLINE * lp, 
GsOT * otp, 
unsigned short pri
)
引数 
lp		GsLINEへのポインタ
otp		OTへのポインタ
pri		OTでの位置
解説
lp で示される直線を、otp で示されるオーダリングテーブルに割り付ける。
GsSortLine()では単一色の直線をOTに登録する。

返り値
なし
