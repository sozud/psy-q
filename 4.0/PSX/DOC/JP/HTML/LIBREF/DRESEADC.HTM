Release 4.0

DsReadExec

実行可能ファイルを読み込む

形式 

DslFILE* DsReadExec (
char* file
)
引数 
file		ファイル名
解説
fileで指定される実行可能ファイルをCD-ROMよりメインメモリの適切なアドレスにロードする。読み込みはバックグラウンドで行われ、読み込み終了判定はDsReadSync()を使用する。ロードされたファイルはExec()を使用して子プロセスとして実行される。

返り値
読み込まれた実行可能ファイルの持つEXEC構造体

備考
実行可能ファイルのロードアドレスが親プロセスの使用領域と重複してはならない。
