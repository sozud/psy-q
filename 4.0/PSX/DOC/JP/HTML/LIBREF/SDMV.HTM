SetDrawMove

プリミティブの内容を初期化

形式 

void SetDrawMove (
DR_MOVE *p,
RECT *rect,
int x,y
)
引数 
p		矩形領域複写オフセット設定プリミティブ
rect		転送する矩形領域
x,y		転送先矩形領域左上端点
解説
矩形領域複写プリミティブを初期化する。初期化済みのプリミティブを、AddPrim()でＯＴに登録することにより、MoveImage() 関数と同等の処理（矩形領域の複写）を行なうことができる。

返り値
なし
