SpuGetVoiceAR

ADSR Attack Rate の取得

形式 

void SpuGetVoiceAR (
int voiceNum,
unsigned short *AR
)
引数 
voiceNum	ボイス番号 (0 ～23)
AR		ADSR Attack Rate
解説
ボイスで使われる ADSR Attack Rate の取得を行う。
SpuGetVoiceAttr() における SpuVoiceAttr 構造体のメンバ ar の値の取得に該当する処理を行う。
ADSR Attack Rate モードが SPU_VOICE_LINEARIncN (リニア増加) になっている場合のみ得られた値は有効となる。 他の ADSR Attack Rate モードの場合は不定となる。
ADSR Attack Rate と ADSR Attack Rate モードを同時に取得したい場合はSpuGetVoiceARAttr() を使用する。

返り値
なし
