GsCOORD2PARAM

GsCOORDINATE2用パラメータフォーマット

構造 

typedef struct {
	VECTOR			scale;
	SVECTOR			rotate;
	VECTOR			trans;
} GsCOORD2PARAM;
メンバ 
scale		座標のscaling情報を保持する
rotate		座標の回転情報を保持する
trans		座標の平行移動情報を保持する
解説
GsCOORD2PARAMはTODアニメーションの際、GsCOORDINATE2のSRT情報を保持しておくために用いられる。
