ReadSZfifo3

ＳＺ値を読み出す

形式 

void ReadSZfifo3 (
long *sz0,
long *sz1,
long *sz2
)
引数 
sz0,sz1,sz2	出力：値
解説
RotTransPers3などで計算したスクリーンＺ値を読み出す。

RotTransPers3(v0,v1,v2,..)
または
RotTransPers(v0,..)
RotTransPers(v1,..)
RotTransPers(v2,..)
を実行したとき
v0->sz0
v1->sz1
v2->sz2
という対応になる。

引数フォーマット：
(sz0,sz1,sz2) : (0,16,0)

返り値
なし
