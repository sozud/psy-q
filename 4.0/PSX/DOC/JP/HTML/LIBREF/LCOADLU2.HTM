LoadClut2

テクスチャCLUTをロード

形式 

u_short LoadClut2 (
u_long *clut,
int x,
int y 
)
引数 
clut		テクスチャカラー先頭アドレス
x, y		転送先フレームバッファアドレス
解説
メインメモリ上の clut 以下のテクスチャカラーデータ(CLUT)をフレームバッファ( x,y )以下にロードし、ロードしたテクスチャCLUTに対するテクスチャCLUT IDを計算する。

返り値
ロードしたCLUTに対するCLUT ID

備考
256色分転送するLoadClut()に対し、この関数は16色分のデータを転送する。
LoadClut2() は、内部でLoadImage()を起動する。
