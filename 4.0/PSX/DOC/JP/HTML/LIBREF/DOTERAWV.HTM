DrawOTagEnv

描画環境を設定し、ＯＴに登録されたプリミティブを描画

形式 

void DrawOTagEnv (
u_long * p,
DRAWENV * env 
)
引数 
p		ＯＴの先頭ポインタ
env		描画環境
解説
描画オフセット・描画クリップエリアなど、描画に関する基本的なパラメータを設定し、ＯＴに登録されたプリミティブをまとめて実行する。

返り値
なし

備考
DrawOTagEnv() によって指定された描画環境は次にPutDrawEnv()かDrawOTagEnv() が実行されるか、DR_ENVプリミティブが実行されるまで有効。
