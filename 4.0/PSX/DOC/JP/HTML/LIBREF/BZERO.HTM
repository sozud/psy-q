bzero

メモリブロックをゼロで埋める

形式 

#include <memory.h>
void * bzero (
unsigned char * p,
int n 
}
引数 
p		書き込み開始位置へのポインタ
n		書き込みバイト数
解説
p の指すアドレスから、n バイト分の0を書き込む。

返り値
書き込みを開始したアドレスへのポインタを返す。

関連項目
bcopy(), bcmp()
