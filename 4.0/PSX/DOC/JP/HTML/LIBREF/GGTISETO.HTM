GsGetTimInfo

TIMフォーマットのヘッダを調べる

形式 

void GsGetTimInfo (
unsigned long * tim, 
GsIMAGE * im
)
引数 
tim		TIM データへのポインタ
im		イメージ構造体へのポインタ
解説
引数 tim で指定された TIM フォーマットの情報が im に格納される。
TIMデータの先頭とは IDをスキップしたアドレスである。
つまり TIMファイルをロードしたらその先頭から４byteオフセットしたものである。

返り値
なし
