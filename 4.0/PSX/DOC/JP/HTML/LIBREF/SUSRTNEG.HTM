StUnSetRing

ストリーミングライブラリで使う割り込みを解放する

形式 

void StUnSetRing ( void )
引数 
なし
解説
StSetRing()でフックされた2つの割り込み関数をはずし初期状態に戻す。
2つの割り込み関数とは
CdDataCallback
CdReadyCallback
のことである。
ストリーミングを終了し ストリーミングライブラリを使用しない他のプログラムに移行する場合はこの関数を呼んで、割り込みのフックを初期状態に戻す必要がある。

返り値
なし
