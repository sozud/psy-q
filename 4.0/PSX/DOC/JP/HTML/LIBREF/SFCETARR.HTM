SetFarColor

ファーカラーベクトルを設定する

形式 

void SetFarColor (
long rfc,
long gfc,
long bfc
)
引数 
rfc,gfc,bfc	入力：ベクトル
解説
ファーカラーベクトル(rfc,gfc,bfc)を設定する。
カラー値は０～２５５（ＭＡＸ）である。

引数フォーマット：
(rfc,gfc,bfc) : (0,32,0)

返り値
なし
