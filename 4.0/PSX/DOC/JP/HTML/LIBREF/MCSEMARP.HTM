メモリカード簡易レベルライブラリ (libmcrd) 関数一覧
Release 4.0

MemCardStop

メモリカードシステムの停止

形式 

void MemCardStop ( void )
引数 
なし
解説
MemCardStartで稼動状態にした、メモリカードシステムを停止する。
同時に各イベントをクローズする。

返り値
なし

備考
同期関数, 即時終了する

関連項目
MemCardInit(), MemCardStart()
