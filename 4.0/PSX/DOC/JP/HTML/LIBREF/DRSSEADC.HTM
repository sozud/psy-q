DsReadSync

DsRead()の終了を待つ

形式 

int DsReadSync (
u_char* result
)
引数 
result		実行結果の格納バッファ（u_char[ 8 ]）
解説
DsRead()の終了を待つ。関数が呼び出された時点のDsRead()の実行状況を返す。

返り値
0： DsRead()が終了した
-1： エラーが発生した（DsRead()は中断された）
正数； 残りのセクタ数
