CdlATV

オーディオアッテネータ

構造 

typedef struct {
		u_char val0;
		u_char val1;
		u_char val2;
		u_char val3;
} CdlATV;
メンバ 
val0		CD (L) → SPU (L) への減衰量
val1		CD (L) → SPU (R) への減衰量
val2		CD (R) → SPU (R) への減衰量
val3		CD (R) → SPU (L) への減衰量
解説
CDの音量を設定するための構造体。
CDの音量はCD-DAおよびCD-XAの音量のことである。
val0～val3の値は最小音量0から最大音量128を設定する。
通常のステレオの音量を調整するためにはval0にＬチャンネル、val1にＲチャンネルの音量を指定しval1、val3には0を指定する。
