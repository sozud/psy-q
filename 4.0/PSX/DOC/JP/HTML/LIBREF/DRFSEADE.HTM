拡張CD-ROMライブラリ（libds） 関数一覧
Release 4.0

DsReadFile

CD-ROM上のファイルを読み込む

形式 

int DsReadFile (
char* file,
u_long* addr,
int nbyte
)
引数 
file		ファイル名
addr		読み込むメインメモリアドレス
nbyte		読み込むサイズ
解説
CD-ROM上のファイルをnbyte読み込む。nbyteは、２０４８の倍数でなくてはいけない。nbyteに０が指定された場合は、ファイルすべてを読み込む。fileにNULLを指定した場合は、直前のDsReadFile()で読み込んだ最後の位置から読み込みを開始する。

返り値
0： 読み込みエラー
以外： 読み込まれたデータの数（バイト）

備考
ファイル名は全て絶対パスでかかれなくてはいけない。小文字は自動的に大文字へ変換される。読み込みはバックグラウンドで行われ、読み込み終了の判定は、DsReadSync()を使用する。
