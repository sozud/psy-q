strncat

文字列を他の文字列に追加する

形式 

#include <strings.h>
char  *strncat (
char * dest,
const char * src,
size_t n
)
引数 
dest		連結先配列
src		連結元文字列
n		連結文字数
解説
文字列 dest の最後に src から最大 n 文字を追加する。

返り値
dest を返す。
