SquareSS12

ショートベクトルの２乗を求める

形式 

VECTOR *SquareSS12 (
SVECTOR *v0;
SVECTOR *v1;
)
引数 
v0		入力：ショートベクトル(L1,L2,L3)
v1		出力：ショートベクトル(L1^2,L2^2,L3^2)
解説
ショートベクトルv0の各項の2乗を4096で割ったショートベクトルをv1に返す。

引数フォーマット：
v0->vx,vy,vz: (1,3,12)
v1->vx,vy,vz: (1,3,12)

返り値
v1
