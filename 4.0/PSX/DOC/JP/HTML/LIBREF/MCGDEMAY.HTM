MemCardGetDirentry

メモリカードのディレクトリ情報を取得

形式 

long MemCardGetDirentry (
long chan,
char* name,
struct DIRENTRY* dir,
long* files,
long ofs,
long max
)
引数 
chan		ポート番号 + カード番号
		ポート番号(Ａポート:0x00、Ｂポート:0x10)
		カード番号(通常 0)
name		検索するファイル名( ワイルドカード指定 )
dir		検索できたファイルに関する情報を格納するバッファ
files		検索されたファイル数を格納するバッファ
ofs		エントリのオフセット
		検索されたファイル群の先頭から、いくつスキップして、バ
		ッファに格納するかを指定する。( 0～14 )
max		バッファに格納する最大エントリ数
解説
ファイル名パターン name に該当するファイルを検索し、それに関する情報を dir に格納し、総検索数を files へ格納する。
格納バッファはユーザアプリ側で用意する。

返り値
result値
値マクロ状態
0x00McErrNone正常終了
0x01McErrCardNotExistカードが接続されていない
0x02McErrCardInvalid不良カード
0x04McErrNotFormatフォーマットされていない


備考
同期関数
ブロッキング時間: 正常終了の時は1～2VSYNC、それ以外は4～76VSYNC。
ファイル名パターンにはワイルドカード文字として?（任意の1文字）*（任意長のすべての文字列）を使うことができる。*以降の文字指定は無視される。
