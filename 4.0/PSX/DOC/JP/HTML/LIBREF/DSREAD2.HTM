DsRead2

ムービーの再生を開始する

形式 

int DsRead2 (
DslLOC* pos,
int mode
)
引数 
pos		データの先頭位置
mode		再生時の動作モード
解説
ムービーの再生を開始する。実際にはストリーミングライブラリ用のコールバック（ライブラリで提供）を設定し、DslReadSでデータの読み出しを開始する。

返り値
成功した場合はコマンドID（>0）を返す。失敗した場合は０。

備考
CdRead2()とは引数が異なることに注意。DsRead2()はデータの先頭位置を設定する。
