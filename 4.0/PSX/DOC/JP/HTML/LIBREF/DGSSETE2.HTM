DsGetSector2

セクタバッファのデータをメインメモリに転送する（ノンブロック型）

形式 

int DsGetSector2 (
void* madr,
int size
)
引数 
madr		転送先メインメモリアドレス
size		転送サイズ（ロングワード）
解説
セクタバッファ上のデータをメインメモリ上に転送する。転送はサイクルスチールモードで行われるため、転送中に割込みが入ることができる。本関数は転送を開始してリターンするノンブロック型であるため、転送の終了はDsDataSync()もしくはDsDataCallback()で監視する必要がある。
なお、サイクルスチールモードでの転送中は、割込みは入ることができるが普通のプログラムはデータバスを使用できないため、バスを通してメモリなどにアクセスする命令があるとその時点で処理がブロックされる。

返り値
実行に成功すれば１を、失敗すれば０を返す。

備考
サイクルスチールモードでのデータ転送は、ブロックモード（DsGetSector()で使用されるモード）に比べて時間がかかる。
