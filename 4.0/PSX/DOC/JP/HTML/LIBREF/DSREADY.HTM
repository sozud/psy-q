DsReady

データの到着を確認する

形式 

int DsReady (
u_char* result
)
引数 
result		結果格納バッファのポインタ（u_char[ 8 ]）
解説
データリード（DslReadS/DslReadN）で読み出されたデータの到着を確認する。もしくはレポートモードでのDA再生時のレポートの到着を監視する。

返り値
データの到着状態
DslDataReady： 新しいデータがセクタバッファに到着した
DslNoIntr： 新しいデータは到着していない
DslDataEnd： 最終セクタが確認された（DA再生のみ）

備考
セクタバッファの値はデータリードでのみ意味を持つ。
