Release 4.0

DsSync

プリミティブコマンドの終了を監視する

形式 

int DsSync (
int id,
u_char* result
)
引数 
id		コマンドID
result		結果格納バッファのポインタ（u_char[ 8 ]）
解説
プリミティブコマンドの終了を監視する。呼び出された時点でのコマンドIDに対応するコマンドの実行状況を返す。resultの値はDslCompleteもしくはDslDiskErrorの場合のみ有効となる。
なお、idに0を指定するとコマンドの種類を問わず最新の結果を得ることができる。またidに-1を指定するとコマンドと対応が取れていない結果（カバー開閉エラーなど）を得られる。

返り値
コマンドの実行状況
DslComplete： コマンドは既に正常終了している
DslDiskError： コマンドの実行は失敗した
DslNoIntr： まだ実行されていない
DslNoResult： 実行は終了したが結果は既に抹消されている

備考
コマンドの実行結果はある程度の個数まで保存されているが、それ以前のものについては抹消される。保存される結果の最大数はマクロ定数DslMaxRESULTSに定義されている。
