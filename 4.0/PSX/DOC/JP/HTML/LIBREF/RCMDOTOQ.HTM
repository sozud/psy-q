RotColorMatDpq

座標変換と透視変換とデプスキューイングを行なう

形式 

long RotColorMatDpq (
SVECTOR *v0,
SVECTOR *v1,
CVECTOR *v2,
long *sxy,
CVECTOR *v3,
long matc,
long *flag
)
引数 
v0		入力：ベクトル
v1		入力：法線ベクトル
v2		入力：原色ベクトル
sxy		出力：座標値
v3		出力：色ベクトル
matc		入力：材質
flag		出力：フラグ
解説
点 v0 を回転マトリックスで座標変換したあと透視変換を行ない、スクリーン座標を sxy に返す。またこのとき求められるデプスキューイング用内挿値 p を以下の計算で使う。

LLV = LLM×v1
LLV = LLV^(2^matc)
LC = BK+LCM×LLV
v3 = (1-p)×v2×LC+p×FC

引数フォーマット：
v0->vx,vy,vz : (1,15,0)
v1->vx,vy,vz : (1,3,12)
v2->r,g,b : (0,8,0)
sxy : (1,15,0),(1,15,0)
v3->r,g,b : (0,8,0)
matc : (0,32,0)
flag : (0,32,0)

返り値
sz/4
