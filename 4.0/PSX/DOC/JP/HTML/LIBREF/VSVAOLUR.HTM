SpuSetVoiceVolumeAttr

ボイス音量/音量モードの設定

形式 

void SpuSetVoiceVolumeAttr (
int voiceNum,
short volumeL,
short volumeR,
short volModeL,
short volModeR
)
引数 
voiceNum	ボイス番号 (0 ～23)
volumeL		音量 (左)
volumeR		音量 (右)
volModeL	音量モード (左)
volModeR	音量モード (右)
解説
ボイスの音量/音量モードの設定を行う。
SpuSetVoiceAttr() の mask 指定
SPU_VOICE_VOLL
SPU_VOICE_VOLR
SPU_VOICE_VOLMODEL
SPU_VOICE_VOLMODER
に該当する処理を行う。
音量モード volModeL, volModeR、及び音量 volumeL, volumeRに指定する値に関しては SpuSetVoiceAttr() を参照のこと。

返り値
なし
