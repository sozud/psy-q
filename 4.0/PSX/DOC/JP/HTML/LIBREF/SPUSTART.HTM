SpuStart

SPU処理の開始

形式 

void SpuStart ( void )
引数 
なし
解説
SPU処理の開始を行う。 SpuInit でも呼ばれているため、初期化時に呼ぶ必要はないが、SpuQuit の呼出し後、 SpuQuit でオフされた機能を使用する場合に呼ばれる。
現在の仕様では、呼び出し後、以下のような処理が行われる。

  • DMA転送の初期化設定

返り値
なし

関連項目
SpuQuit(), SpuInit(), SpuInitHot()
