GsARGUNIT_NORMAL

独立プリミティブドライバの引数領域

構造 

typedef struct {
	unsigned long	*primp;
	GsOT		*tagp;
	int		shift;
	int		offset;
	PACKET		*out_packetp;
	unsigned long	*primtop;
	SVECTOR		*vertop; 
	SVECTOR		*nortop;
} GsARGUNIT_NORMAL;
メンバ 
primp		プリミティブの先頭アドレス
tagp		現在の先頭の GsOT_TAG へのポインタ
shift		OTにソートする際の shift するbit数
offset		OT のスクリーン座標系におけるＺ軸上のオフセット
out_packetp	未使用のパケットエリアへのポインタ
primtop		POLYGONセクションの先頭へのポインタ
vertop		VERTEXセクションの先頭へのポインタ
nortop		NORMALセクションの先頭へのポインタ
解説
GsSortUnit()からコールされる独立プリミティブドライバへ渡される引数領域。
GsARGUNITに加え、HMDデータ内のPOLYGONセクションやVERTEXセクションや、NORMALセクションの先頭へのポインタが渡される。
通常高速化のため、スクラッチパッドを使用する。
