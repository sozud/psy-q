SsVabTransfer

音源データを認識、転送する

形式 

short SsVabTransfer (
unsigned char *vh_addr,
unsigned char *vb_addr, 
short vabid,
short i_flag
)
引数 
vh_addr		VHデータの先頭アドレス
vb_addr		VBデータの先頭アドレス
vabid		VAB認識番号
i_flag		= SS_IMMEDIATE ...すぐ返り値(VAB認識番号)を返す
		= SS_WAIT_COMPLETED ... 転送が終了するまで待つ
解説
vh_addrで指定された音源ヘッダリスト (VH データ) を認識し、vb_addrで指定された音源データ(VBデータ) をSPUサウンドバッファへ転送する。vabidにVAB認識番号を指定する。vabidが -1の場合、空いているVAB認識番号 (0-15) を探して割り付ける。i_flagにて本関数が転送終了するまで待つか、転送開始後すぐに抜ける（その後SsVabTransCompletedでチェックする）かを指定する。

返り値
VAB識別番号
失敗した場合には、その要因によって以下の値を返す。
-1 VAB ID割り当て不可能or VH異常
-2 VB異常
-3以上 その他の異常

関連項目
SsVabOpenHead(), SsVabTransBodyPartly(), SsVabTransCompleted()
