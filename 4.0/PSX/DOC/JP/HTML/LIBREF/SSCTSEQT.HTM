SsSeqCalledTbyT

1Tick毎に呼ばれ、SEQ/SEPデータを解釈し演奏を行う

形式 

void SsSeqCalledTbyT (void)
引数 
なし
解説
1 Tick毎にこの関数が呼ばれ、SEQ / SEPデータを解釈し演奏を行う。
TickはSsSetTickMode() によって設定されるが、このTickはSEQ / SEPデータで指定されている速度、及び分解能には依存せず、単にサウンドシステム内部の分解能を規定する。
SsSetTickMode() での指定で、tick_modeがSS_TICK60, SS_TICK120,SS_TICK240,及び任意の分解能の指定を行った場合は、 SS_NOTICKを指定した場合はユーザ・プログラム側で垂直帰線（Vsync()）のタイミング（1/60秒間隔{NTSC}あるいは 1/50秒間隔{PAL}）あるいは指定した間隔（SS_NOTICKと「ビットor」で指定した間隔）でこの関数を呼び出す必要がある。SS_NOTICK以外を指定した場合は指定された分解能でサウンドシステム側がこの関数を呼び出す。
SsSetTickCallback() で Tick Callback関数が指定された場合で SEQ/SEPデータを解釈し、演奏を行わせたい場合には、指定したTick Callback関数の中でこの関数を呼び出す必要がある。

返り値
なし
