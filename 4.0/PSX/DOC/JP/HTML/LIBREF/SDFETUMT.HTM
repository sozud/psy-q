SetDumpFnt

オンスクリーンダンプのためのストリームを定義

形式 

void SetDumpFnt (
int id 
)
引数 
id		プリントストリームID
解説
デバッグプリントのためのプリントストリームを設定する。これ以降、デバッグプリント関数の出力は、id に指定される。ストリームに対して行なわれる。実際の表示は、FntFlush()関数で実行される。

返り値
なし
