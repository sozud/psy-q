qsort

クイックソートを行なう

形式 

#include <stdlib.h>
void qsort (
void *base,
size_t n,
size_t w,
long (* fcmp )(const void *, const void *)
)
引数 
base		ソートする配列の格納先
n		要素の個数
w		要素１個のサイズ
fcmp		比較関数
解説
fcmp を比較関数として base から始まる項目数 n （項目サイズは w ）のテーブルをソートする。
内部でmalloc() をコールしているので、ヒープの空き領域に注意すること。

返り値
なし
