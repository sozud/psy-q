SpuSetCommonCDMix

CD 入力オン/オフの設定

形式 

void SpuSetCommonCDMix (
long on_off
)
引数 
on_off		CD 入力オン/オフ
解説
CD 入力オン/オフの設定を行う。
SpuSetCommonAttr() の mask 指定
SPU_COMMON_CDMIX
に該当する処理を行う。
CD 入力オン/オフ on_off に指定する値に関しては SpuSetCommonAttr() を参照のこと。

返り値
なし

関連項目
SpuSetCommonAttr(), SpuGetCommonCDMix()
