SwEnterCriticalSection

割り込みの禁止

形式 

void SwEnterCriticalSection (void)
引数 
なし
解説
割り込みを禁止する。内部でシステムコール割り込みを発生しないので、イベントハンドル関数やコールバック関数中で呼び出すことができる。
クリティカルセクションで実行すること。

返り値
なし

関連項目
EnterCriticalSection(), SwExitCriticalSection()
