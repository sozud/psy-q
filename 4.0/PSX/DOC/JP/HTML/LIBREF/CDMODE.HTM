CD-ROM ライブラリ (libcd) 関数一覧
Release 4.0

CdMode

直近のCD-ROMのモードを獲得

形式 

int CdMode ( void )
引数 
なし
解説
最後に設定されたCD-ROMのモードを獲得する。

返り値
CD-ROMモード

備考
メインメモリ内のバッファを参照するだけなので高速。モードバッファはCdlSetModeコマンドを発行した場合、およびCdRead()など引数でモードを指定した場合に更新される。
