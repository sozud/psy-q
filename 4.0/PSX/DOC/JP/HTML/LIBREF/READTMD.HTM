ReadTMD

TMDプリミティブの内容を解析

形式 

TMD_PRIM * ReadTMD (
TMD_PRIM * tmdprim 
)
引数 
tmdprim		TMD情報構造体
解説
TMDのプリミティブ情報を順番にとりだし、構造体TMD_PRIM* tmdprim に格納する。

返り値

返り値意味
0失敗
その他tmdprim の先頭アドレス


備考
TMDのタイプによっては構造体の全てのメンバが有効とは限らない。
