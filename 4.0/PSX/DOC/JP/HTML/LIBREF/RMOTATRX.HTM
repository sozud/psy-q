RotMatrixX

Ｘ軸まわりの回転マトリックスを求める

形式 

MATRIX *RotMatrixX (
long r,
MATRIX *m
)
引数 
r		入力：回転角
m		入出力：回転マトリックス
解説
マトリックス m に、回転角 r によるＸ軸まわりの回転行列をかけたマトリックスを与える。回転角は4096を360度としてあたえ、マトリックス成分は4096が1.0として与えられる。マトリックスは次のものである。


引数フォーマット：
m->m[i][j] : (1,3,12)
r : (1,3,12) （ただし360度を1.0とする）

返り値
m
