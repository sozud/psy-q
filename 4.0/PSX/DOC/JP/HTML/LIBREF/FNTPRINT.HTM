FntPrint

プリントストリームに出力

形式 

int FntPrint (
int id, *format,...
)
引数 
id		プリントストリームID
format		プリントフォーマット
解説
printf()インターフェースでプリントストリームに文字列sを送る。
文字列中に '~' が現れた場合は、続く3文字が文字の輝度値（RGB）として解釈される。
輝度値は0-15の16段階で表示される。

例：
FntPrint("~c800This is red\n")
FntPrint("~c080This is green\n")
FntPrint("~c444This is half tone\n")

返り値
ストリーム内の文字数

備考
実際に文字列が表示されるのは、FntFlush()が実行された時となる。
