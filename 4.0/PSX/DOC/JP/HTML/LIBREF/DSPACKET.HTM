DsPacket

一連のコマンド列をキューに登録する

形式 

int DsPacket (
u_char mode,
DslLOC* pos,
u_char com,
DslCB* cbsync,
int count
)
引数 
mode		動作モード
pos		ターゲットポジション
com		最後に実行されるコマンド
cbsync		コマンドがすべて終了したときにキックされるコールバック関数
count		リトライ回数（0：リトライなし、-1：無限リトライ）
解説
データリード（再生）に関する一連のコマンドをキューに登録する。キューに登録されるコマンドは以下の通り。

DslPause
DslSetmode mode
DslSetloc pos
comで指定されたコマンド

comには以下のコマンドを指定することができる。

  • DslPlay
  • DslReadN
  • DslReadS
  • DslSeekP
  • DslSeekL

DslPlay、DslReadN、DslReadSを指定した場合はデータリード（再生）まで実行される。
DslSeekP、DslSeekLを指定した場合は、シーク実行後にポーズ状態で終了する。

一連のコマンドのいずれかがエラーになった場合は、先頭のコマンドからリトライされる。リトライする回数はcountで指定する。count=0の場合はリトライなし、count=-1の場合は無限回リトライされる。count回リトライしても成功しなかった場合はエラーとなる。
一連のコマンドが全て成功するかエラーとなった場合は、cbsyncで指定されたコールバック関数がキックされる。また、DsSync()によって実行状況を獲得することができる。

返り値
登録した場合はコマンドID（>0）が返される。失敗した場合は０。

備考
キューに一連のコマンドを登録するだけの空きがない場合はエラーとなる。
