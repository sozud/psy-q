ProgAtr

プログラムヘッダ

構造 

struct ProgAtr {
		char tones;
		char mvol;
		char prior;
		char mode;
		short attr;
		short reserved0;
		unsigned long reserved1;
		unsigned long reserved2;
};
メンバ 
tones		プログラムに含まれる VAG 属性セットの数
mvol		プログラムのマスタボリューム
prior		プログラムの優先度（0 ～ 15）
mode		音源モード
attr		プログラム属性
reserved0	システム予約
reserved1	システム予約
reserved2	システム予約
