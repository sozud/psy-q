ContinueDraw

BreakDrawで中断したOTを描画続行する

形式 

void ContinueDraw (
unsigned long *ins_ot,
unsigned long *cont_ot,
)
引数 
ins_ot		途中で割り込ませるOTのアドレス
cont_ot		ins_otを描画直後に、描画させるOTのアドレス
解説
ins_otで与えられたOTをキューに入れず(*1)に即時実行させる。ins_otを描画終了後続けてcont_otを描画する。ただし、GPUが即時実行可能な状態でなければいけないため、BreakDraw()等と併用する必要がある。
あるタイミングで、特定のOTを最優先で描画させたい場合に使用する。その場合、BreakDraw()で描画中のOTを中断し、その返り値をcont_otとして実行することにより実現できる。

返り値
なし

備考
GPUが描画を実行中に、ContinueDraw()だけを呼ぶとハングすることがある。（必ずBreakDraw()かDrawSync(0)を直前に呼び出さねばならない。）

*1) DrawOTga()等のノンブロッキング関数は、GPUが即時実行可能の状態にない場合は、実行キューの中にエントリしてしまうため、即時に実行することを保証しない。
