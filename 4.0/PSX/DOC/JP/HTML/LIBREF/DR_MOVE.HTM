DR_MOVE

矩形領域複写プリミティブ

構造 

typedef struct {
		u_long	tag;
		u_long	code[5];
} DR_MOVE;
メンバ 
tag		次のプリミティブへのフック（予約）
code		プリミティブ ID
解説
DR_MOVE は、矩形領域の転送を行なう。速度は、MoveImage() と同等。16bit SPRT プリミティブと異なり、半透明・透明色制御を行なわない。 また描画環境に依存しない。
