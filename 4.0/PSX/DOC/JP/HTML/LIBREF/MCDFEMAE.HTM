メモリカード簡易レベルライブラリ (libmcrd) 関数一覧
Release 4.0

MemCardDeleteFile

メモリカード上のファイルを削除する

形式 

long MemCardDeleteFile (
long chan,
char* file
)
引数 
chan		ポート番号 + カード番号
		ポート番号(Ａポート:0x00、Ｂポート:0x10)
		カード番号(通常 0)
file		ファイル名
解説
メモリカード上のファイルを削除する。

返り値

値マクロ状態
0x00McErrNone正常終了
0x01McErrCardNotExistカードが接続されていない
0x02McErrCardInvalid通信エラー発生
0x04McErrNotFormatフォーマットされていない
0x05McErrFileNotExistファイルが見つからない


備考
同期関数
ブロッキング時間: 正常終了のときは1～4VSYNC、それ以外は4～76VSYNC。
クリティカルセクションには入らない。
