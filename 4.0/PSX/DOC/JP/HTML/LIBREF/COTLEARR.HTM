ClearOTagR

逆順ＯＴを初期化

形式 

u_long *ClearOTagR (
u_long *ot,
int n 
)
引数 
ot		ＯＴの先頭ポインタ
n		ＯＴのエントリ数
解説
n 個のNextPrim(ot+i) = ot+i-1の形式の逆順ＯＴを生成する。

返り値
なし

備考
ClearOTag() で初期化されたＯＴを実行する場合には、DrawOTag(ot+n-1)を実行する。
大きなOTをクリアする場合は ClearOTag() よりも高速。
