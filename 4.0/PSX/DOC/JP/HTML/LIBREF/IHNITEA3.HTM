InitHeap3

ヒープ領域の初期化

形式 

void InitHeap3 ( 
unsigned long *head,
unsigned long size 
)
引数 
head		ヒープ先頭アドレス
size		ヒープサイズ（8の倍数、バイト単位）
解説
メモリ管理関数群を初期化する。
以降、malloc3()などが使用可能となる。
ただし、オーバヘッドがあるのでsize バイトすべてが利用可能とはならない。

返り値
なし

備考
多重に実行するとそれまで保持していたメモリ管理情報が失われる。
InitHeap2()系よりも高速でサイズも小さい。
sizeに8の倍数でない数字を指定した場合は、8で割り切れない余りを
切り捨てた分だけが確保される。
InitHeap(),InitHeap2()系との違いは overview\api.docの「10 メモリ管理関数について」を参照の事。
