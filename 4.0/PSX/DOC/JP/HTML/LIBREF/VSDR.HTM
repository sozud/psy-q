SpuSetVoiceDR

ADSR Decay Rate の設定

形式 

void SpuSetVoiceDR (
int voiceNum,
unsigned short DR
)
引数 
voiceNum	ボイス番号 (0 ～23)
DR		ADSR Decay Rate
解説
ボイスで使われる ADSR Decay Rate の設定を行う。
SpuSetVoiceAttr() の mask 指定
SPU_VOICE_ADSR_DR
に該当する処理を行う。
ADSR Decay Rate DR に指定する値に関しては SpuSetVoiceAttr() を参照のこと。

返り値
なし

関連項目
SpuSetVoiceAttr(), SpuNSetVoiceAttr()
