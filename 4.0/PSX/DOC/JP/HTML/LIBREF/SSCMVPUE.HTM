SpuSetCommonMasterVolume

マスタ音量の設定

形式 

void SpuSetCommonMasterVolume (
short mvolL,
short mvolR
)
引数 
mvolL		マスタ音量 (左)
mvolR		マスタ音量 (右)
解説
マスタ音量の設定を行う。
SpuSetCommonAttr() の mask 指定
SPU_COMMON_MVOLL
SPU_COMMON_MVOLR
に該当する処理を行う。
音量モードは [ダイレクトモード] となり、 音量 mvolL, mvolR に指定できる値の範囲は SpuSetVoiceAttr() における [ダイレクトモード] と同等である。
音量と音量モードを同時に指定したい場合は SpuSetCommonMasterVolumeAttr() を使用する。
音量 mvolL, mvolR に指定する値に関しては SpuSetCommonAttr(), SpuSetVoiceAttr() を参照のこと。

返り値
なし
