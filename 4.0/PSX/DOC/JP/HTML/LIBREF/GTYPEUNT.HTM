GsTYPEUNIT

タイプ格納領域

構造 

typedef struct {
	unsigned long	type;
	unsigned long	*ptr; 
} GsTYPEUNIT;
メンバ 
type		プリミティブのタイプ
ptr		タイプが格納されている領域のアドレス
解説
GsTYPEUNIT は、GsScanUnit() 関数において、そのタイプとタイプが格納されている領域を格納する。
ユーザはその情報を見て、そのタイプに対応した下位関数を ptr に代入することにより、type が下位関数へのポインタに上書きされる。GsSortUnit() は、その下位関数をコールする。

タイプは以下の通り。


DEV ID
DEV ID(Developper ID)
0000: SCE Reserved

CATEGORY
CATEGOR(Category)
0000: ポリゴンドライバ
0001: Shared Primitive データ
0010: イメージデータ
0011: アニメーション

DRIVER
INI(init) 0: なし
1: COORDINATE 初期化が必要
CLP(clip) 0: クリップなし
1: 画面左と上のクリップなし
STP(Semi-trans) 0: 不透明
1: 半透明
BOT(both-side) 0: 片面ポリゴン
1: 両面ポリゴン
BCL(back-clip) 0: バッククリップ 正論理
1: バッククリップ 負論理
LGT(light) 0: 光源計算あり
1: 光源計算なし
FOG(fog) 0: FOG off
1: FOG on
DIV(divide) 0: 分割なし
1: 分割あり

PRIMITIVE TYPE
MIM(MIMe) 0: Built-in MIMe なし
1: Built-in MIMe あり
TILE 0: 繰り返しテクスチャのための情報なし
1: 繰り返しテクスチャのための情報あり
PST(preset) 0: プリセットなし
1: プリセットあり
MIP(mip-map) 0: mip-map なし
1: mip-map あり
LMD(light-mode) 0: 法線あり
1: 法線なし
CODE 000: 直線
001: 三角形
010: 四角形
011: strip mesh
100: スプライト
IIP 0: フラット
1: グーロー
COL(colored) 0: 同一ポリゴン内で 1 材質カラー
1: 頂点ごとにカラーがある
TME 0: テクスチャマッピング OFF
1: テクスチャマッピング ON
