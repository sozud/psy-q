DsSyncCallback

Syncコールバック関数を設定する

形式 

DslCB DsSyncCallback (
DslCB func
)
引数 
func		コールバック関数のポインタ
解説
Syncコールバック関数を設定する。設定されたコールバック関数は、全てのコマンドの終了割込み、および全てのエラー割込みで呼び出される。
エラーになったコマンドがキューによってリトライされる場合、コマンドに設定されたコールバック関数は呼び出されないが、ここで設定したコールバック関数は呼び出されることに注意。

返り値
以前のコールバック関数のポインタ
