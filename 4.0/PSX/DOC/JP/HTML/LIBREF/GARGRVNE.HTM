GsARGUNIT_RstVNMIMe

頂点法線マイムリセットプリミティブドライバの引数領域

構造 

typedef struct {
	unsigned long	*primp;
	GsOT		*tagp;
	int		shift;
	int		offset;
	PACKET		*out_packetp; 
} GsARGUNIT_RstVNMIMe;
メンバ 
primp		プリミティブの先頭アドレス
tagp		現在の先頭の GsOT_TAG へのポインタ
shift		OTにソートする際の shift するbit数
offset		OT のスクリーン座標系におけるＺ軸上のオフセット
out_packetp	未使用のパケットエリアへのポインタ
解説
GsSortUnit()からコールされる頂点法線マイムプリミティブドライバへ渡される引数領域。
GsARGUNIT と同じ構成をとる。
通常高速化のため、スクラッチパッドを使用する。
