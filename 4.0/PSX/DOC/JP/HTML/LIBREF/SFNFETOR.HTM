SetFogNearFar

フォグパラメータを設定する

形式 

void SetFogNearFar (
long a,
long b,
long h
)
引数 
a		フォグ０％となるＺ値
b		フォグ１００％となるＺ値
h		視点とスクリーンの距離
解説
視点とスクリーンの距離が h のとき、フォグ０％となるＺ値を a に設定する。
フォグ１００％となるＺ値を b に設定する。
0 < a,b < 65536
( b - a ) >= 100

引数フォーマット：
a : (0,32,0)
b : (0,32,0)
h : (0,32,0)

返り値
なし
