CdlFILE

9660 ファイルディスクリプタ

構造 

typedef struct {
		CdlLOC pos;
		u_long size;
		char name[16];
} CdlFILE;
メンバ 
pos		ファイルポジション
size		ファイルサイズ（バイト単位）
name		ファイル名
解説
9660 CD-ROMファイルの位置・サイズを取得する。
