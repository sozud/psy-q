LoadExec

実行ファイルのロードと実行

形式 

void LoadExec ( 
char *name,
unsigned long s_addr,
unsigned long s_size
)
引数 
name		PS-X EXE形式実行ファイル名（19文字以内）
s_addr		スタック領域先頭アドレス
s_size		スタック領域バイト数
解説
内部でLoad()とExec()を呼びだし、ファイル name をメモリ上に読み込み、それを実行する。s_addr と s_size はExec()に引き渡されるEXEC構造体に設定される。正常に実行されると返らない。

返り値
なし
