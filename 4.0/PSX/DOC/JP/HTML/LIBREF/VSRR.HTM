SpuSetVoiceRR

ADSR Release Rate の設定

形式 

void SpuSetVoiceRR (
int voiceNum,
unsigned short RR
)
引数 
voiceNum	ボイス番号 (0 ～23)
RR		ADSR Release Rate
解説
ボイスで使われる ADSR Release Rate の設定を行う。
SpuSetVoiceAttr() の mask 指定
SPU_VOICE_ADSR_RR
に該当する処理を行う。
ADSR Release Rate モードは SPU_VOICE_LINEARDecN (リニア減少) となる。 ADSR Release Rate と ADSR Release Rate モードを同時に指定したい場合は SpuSetVoiceSRAttr() を使用する。
ADSR Release Rate RR に指定する値に関しては SpuSetVoiceAttr() を参照のこと。

返り値
なし
