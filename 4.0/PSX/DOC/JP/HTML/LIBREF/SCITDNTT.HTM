StCdInterrupt

CDROMからの割り込みハンドラ（内部関数）

形式 

void StCdInterrupt ( void )
引数 
なし
解説
この関数は通常はStSetStream(),StStartEmulate()でCDROMの割り込みにフックされるため、ユーザプログラムで呼ぶ必要はない。
ただし mode bit 1の２４ビットモードにすると割り込みでは、StCdInter Flagがセットされるだけなのでユーザプログラムでこの関数を呼ぶ必要がある。

返り値
なし
