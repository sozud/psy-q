LoadAverageShort0

２つのベクトルの荷重平均を求める

形式 

void LoadAverageShort0 (
SVECTOR *v0,
SVECTOR *v1
long p0,
long p1,
SVECTOR *v2
)
引数 
v0,v1		入力：ベクトル
p0,p1		入力：重み
v2		出力：ベクトル
解説
２つのベクトル v0,v1 の重み p0,p1 による荷重平均を v2 に返す。

引数フォーマット：
v0,v1->vx,vy,vz : (1,15,0)
p0,p1 : (1,15,0)
v2->vx,vy,vz : (1,30,0)

返り値
なし
