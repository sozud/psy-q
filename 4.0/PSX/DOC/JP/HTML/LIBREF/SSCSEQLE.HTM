SsSeqClose

SEQデータをクローズする

形式 

void SsSeqClose (
short seq_access_num
)
引数 
seq_access_num		SEQアクセスナンバー
解説
必要がなくなった seq_acces_num を持つSEQデータをクローズする。
この関数実行前に、該当するSEQをSsSeqStop() すること。

返り値
なし
