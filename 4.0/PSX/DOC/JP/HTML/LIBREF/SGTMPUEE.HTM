SpuGetTransferMode

サウンドバッファの転送モードの診断

形式 

long SpuGetTransferMode ( void )
引数 
なし
解説
現在設定されている、メインメモリからサウンドバッファへ転送する際のモードを返す。

返り値
現在設定されている転送モード

返り値意味
SPU_TRANSFER_BY_DMADMA転送の指定
SPU_TRANSFER_BY_IOI/O転送の指定


関連項目
SpuSetTransferMode(), SpuWrite(), SpuWrite0(), SpuWritePartly()
