GsSetAmbient

アンビエントカラーの設定

形式 

void GsSetAmbient (
long r, 
long g, 
long b 
)
引数 
r, g, b		アンビエントカラーの RGB 値 (0～4095)
解説
周囲光を設定する。設定は r, g, bごとに光の当たっていない部分が光の当たっている部分の何分の１になるかで行なう。
1/1は4096、1/8は4096/８となる。

返り値
なし
