bsearch

バイナリサーチ（二分探索）を行なう

形式 

#include <stdlib.h>
void *bsearch (
const void *key,
const void *base,
size_t n,
size_t w,
long(*fcmp)(const void *, const void *)
)
引数 
key		検索の対照となる値の格納先
base		検索する配列の格納先
n		要素の個数
w		要素１個のサイズ
fcmp		比較関数
解説
fcmp を比較関数として base から始まる項目数 n （項目サイズはw ）のテーブルを対象として、 key と一致する項目を二分探索する。

返り値
検索キーと一致した最初の項目のアドレスを返す。一致する項目がなかった場合は0を返す。
