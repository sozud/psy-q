RotTransPers_nom

座標変換と透視変換を行なう

形式 

void RotTransPers_nom (
SVECTOR *v0
)
引数 
v0		入力：頂点座標ベクトル
解説
座標ベクトル v0 を回転マトリックスで座標変換したあと透視変換を行ない、スクリーン座標sx,sy,sz、デプスキューイング用の内挿値pをGTE内部レジスタに保持する。

引数および内部データフォーマット：
v0->vx,vy,vz : (1,15,0)
sx : (1,15,0)
sy : (1,15,0)
sz : (0,16,0)
p : (0,20,12)
flag : (0,32,0)

返り値
なし

備考
szはマクロread_sz2で、(sx,sy)はマクロread_sxsy2で、pはマクロread_pで、flagはマクロread_flagで読む。
