ストリーミング ライブラリ (libcd) 関数一覧
Release 4.0

StSetChannel

ストリーミングのチャンネルを指定する

形式 

int StSetChannel (
u_long ch
）
引数 
ch		ストリーミングチャンネル
解説
ストリーミングライブラリにはSTRデータの一部だけを選択して再生するという機能がある。選択するデータはチャンネルにより識別される。
チャンネルはSTRデータに入っておりオーサリングレベルでおこなわれる。
StSetChannelはストリーミングで再生するチャンネルを設定する。
チャンネルは、0から31までである。

返り値
チャンネルが設定できれば０が返り失敗すれば１が返る
