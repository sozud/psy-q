Release 4.0

MemCardSync

非同期関数の終了を待つ

形式 

long MemCardSync (
long mode,
unsigned long* cmds,
unsigned long* result
)
引数 
mode		0: 非同期関数の終了を待つ
		1: 現在の状態を調べて即座にリターンする
cmds		終了した非同期関数
result		非同期関数の実行結果
解説
MemCardAccept(), MemCardReadFile()などの非同期関数の終了を待つ。
cmdsには終了した非同期関数のコード番号が入る。

cmds値
値マクロ関数
0x01McFuncExistMemCardExist
0x02McFuncAcceptMemCardAccept
0x03McFuncReadFileMemCardReadFile
0x04McFuncWriteFileMemCardWriteFile
0x05McFuncReadDataMemCardReadData
0x06McFuncWriteDataMemCardWriteData

result値は各関数の項目を参照

返り値

返り値内容
0処理中
1終了
-1登録処理なし


備考
同期関数, modeが 1の場合は即時終了する、 0の場合は各非同期関数の所要時間に準ずる。
