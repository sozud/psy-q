ResetRCnt

ルートカウンタのリセット

形式 

long ResetRCnt ( 
unsigned long spec
)
引数 
spec		ルートカウンタ指定
解説
ルートカウンタ spec をリセットする。

返り値
成功すると1を、失敗すると0を返す。
RCntCNT3の場合は設定できないので、必ず０を返す。

関連項目
GetRCnt(), SetRCnt(), StartRCnt(), StopRCnt()
