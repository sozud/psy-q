Krom2RawAdd

漢字フォントパタンアドレスの取得

形式 

long Krom2RawAdd ( 
unsigned long sjiscode
)
引数 
sjiscode	シフトJISコード
解説
sjiscode が指定する漢字に対応するフォントパタンのカーネル中の先頭アドレスを取得する。

返り値
漢字フォントパタンの先頭アドレスを返す。
指定された漢字に対応するフォントデータが用意されていない場合は-1を返す。
