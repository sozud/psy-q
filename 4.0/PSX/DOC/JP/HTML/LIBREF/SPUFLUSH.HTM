SpuFlush

キューに溜めたイベントをフラッシュする

形式 

unsigned long SpuFlush (
unsigned long ev
)
引数 
ev		フラッシュするイベント
解説
キューに溜めたイベントをフラッシュする。
ev に、下記のフラッシュしたいイベントのビット和を与えることで各イベントのみのフラッシュが可能。

属性ビット内容
SPU_EVENT_KEYキーオン/オフ
SPU_EVENT_PITCHLFOピッチ LFO ボイス指定
SPU_EVENT_NOISEノイズボイス指定
SPU_EVENT_REVERBリバーブボイス指定


ev が SPU_EVENT_ALL の場合は全イベントをフラッシュする。

返り値
フラッシュされたイベントのビット和
