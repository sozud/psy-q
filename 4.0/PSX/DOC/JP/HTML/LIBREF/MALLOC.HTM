malloc

主記憶を割り当てる

形式 

#include <stdlib.h>
void *malloc (
size_t s
)
引数 
s		確保するメモリブロックのサイズ
解説
ヒープメモリから s バイトのブロックを確保する。

返り値
確保されたメモリブロックへのポインタを返す。
確保に失敗するとNULLを返す。

備考
ユーザプログラム起動時に、ヒープメモリは次のように定義される。
最下位アドレス： モジュールの最上位アドレス + 4
最上位アドレス： 実装メモリ - 32KB
free()で領域が完全に開放されないというバグあり。LIBAPIのmalloc2(),malloc3()で代用できる。詳しくはoverview\api.docの「10 メモリ管理関数について」を参照のこと。

関連項目
