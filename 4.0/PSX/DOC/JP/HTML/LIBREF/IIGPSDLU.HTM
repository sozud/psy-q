IsIdleGPU

BreakDrawで中断した描画の終了を検知する

形式 

int IsIdleGPU {
int maxcount; 
)
引数 
maxcount		カウント値
解説
BreakDrawで描画を中断しても、その瞬間に実行中に描画が終了するまで、GPUは停止しない。そのため、この関数を用いてBreakDraw中断した描画が完全に終了したことを検知する。
maxcountで与えられたカウントを越えても、GPUがアイドル状態にならない場合、-1を返す。

返り値
0 : GPUがアイドル状態
-1 : GPUが描画中

関連項目
BreakDraw(), ContinueDraw()
