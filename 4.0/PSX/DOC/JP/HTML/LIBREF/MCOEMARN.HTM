メモリカード簡易レベルライブラリ (libmcrd) 関数一覧
Release 4.0

MemCardOpen

ファイルを開く

形式 

long MemCardOpen (
long chan,
char* file,
long flag
)
引数 
chan		ポート番号 + カード番号
		ポート番号(Ａポート:0x00、Ｂポート:0x10)
		カード番号(通常 0)
file		ファイル名
flag		オープン形式指定
		(リードオープン: O_RDONLY、ライトオープン: O_WRONLY)
解説
指定形式でメモリカード上のファイルをオープンし、MemCardReadData(),MemCardWriteData() を使用可能とする。
形式の併用( O_RDONLY|O_WRONLY )はできない。
複数ファイルのオープンはできない。

返り値

値マクロ状態
0x00McErrNone正常終了
0x01McErrCardNotExistカードが接続されていない
0x02McErrCardInvalid不良カード
0z04McErrNotFormatフォーマットされていない
0x05McErrFileNotExistファイルが見つからない


備考
同期関数
ブロッキング時間: 正常終了のときは即時終了する、それ以外は4～76VSYNC。
