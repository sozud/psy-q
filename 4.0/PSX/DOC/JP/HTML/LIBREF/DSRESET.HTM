拡張CD-ROMライブラリ（libds） 関数一覧
Release 4.0

DsReset

システムをリセットする

形式 

int DsReset ( void )
引数 
なし
解説
システムをリセットする。

返り値
成功した場合は１、それ以外の場合は０が返される。

備考
プログラムの途中でシステムを初期化する場合は必ずDsReset()を使用する。DsInit()を途中で使用することはできない。
