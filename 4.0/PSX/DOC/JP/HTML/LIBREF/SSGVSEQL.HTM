SsSeqGetVol

SEQボリューム値を得る

形式 

void SsSeqGetVol (
short access_num,
short seq_num,
short *voll,
short *volr
)
引数 
access_num	SEQ/SEPアクセスナンバー
seq_num		SEPデータ内のSEQナンバー
voll		SEQのLボリューム値
volr		SEQのRボリューム値
解説
SEQの現在のボリューム値をL,Rそれぞれを voll, volr に返す。
SEQデータにこの関数を使用する時は、seq_numは0を設定し、SEPデータに使用する時は、値を獲得したいSEQの番号を設定する。この関数でSsSepSetVolで設定したボリューム値も得ることができる。

返り値
なし
