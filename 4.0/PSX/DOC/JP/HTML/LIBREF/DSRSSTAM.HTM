Release 4.0

DsStartReadySystem

簡易レディシステムを開始する

形式 

int DsStartReadySystem (
DslRCB func,
int count
)
引数 
func		コールバック関数のポインタ
count		リトライ回数（-1：無限リトライ）
解説
簡易レディシステムを開始する。簡易レディシステムが開始されると、DslDiskErrorが発生した場合に最後に発行されたコマンドによってリトライが行われる。リトライの回数はcountで指定する。count=-1の場合は無限回リトライとなる。リトライ回数はシステムスタート時からの総回数である。
funcで指定されたコールバック関数は、通常はデータリードが成功したときのみキックされる。エラーでキックされるのは、カバーが開けられた場合かリトライ回数を超えてエラーが発生した場合に限られる。

リトライが行われた場合、再リードされるポジションはライブラリによって決定されるが、コールバック関数は前回呼び出された次のセクタからキックされる。よって、コールバック関数の中でリトライを意識する必要はない。

返り値
1： 成功
0： 失敗（既にシステムが開始されている）

備考
本関数は必ず対応するデータリード（再生）コマンドのコールバック内で実行する。それ以外の場所で実行した場合、エラーハンドリングシステムが破壊されることがある。
