SpuGetVoiceRRAttr

ADSR Release Rate / Release Rate モードの取得

形式 

void SpuGetVoiceRRAttr (
int voiceNum,
unsigned short *RR,
long *RRmode
)
引数 
voiceNum	ボイス番号 (0 ～23)
RR		ADSR Release Rate
RRmode		ADSR Release Rate モード
解説
ボイスで使われる ADSR Release Rate / ADSR Release Rate モードの取得を行う。
SpuGetVoiceAttr においてSpuVoiceAttr 構造体のメンバ rr, r_mode の値の取得に該当する処理を行う。
返り値
なし

関連項目
SpuGetVoiceAttr(), SpuNGetVoiceAttr(), SpuGetVoiceSR()
