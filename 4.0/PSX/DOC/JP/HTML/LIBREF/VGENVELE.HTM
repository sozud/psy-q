SpuGetVoiceEnvelope

現在のエンベロープ値の取得

形式 

void SpuGetVoiceEnvelope (
int voiceNum,
short *envx
)
引数 
voiceNum	ボイス番号 (0 ～23)
envx		現在のエンベロープ値
解説
ボイスの現在のエンベロープ値の取得を行う。
SpuGetVoiceAttr() における SpuVoiceAttr 構造体のメンバ envx の値の取得に該当する処理を行う。

返り値
なし

関連項目
SpuGetVoiceAttr(), SpuNGetVoiceAttr()
