GsDrawOtIO

OTに割り付けられた描画コマンドの実行（Ｉ/Ｏ版）

形式 

void GsDrawOtIO(
GsOT * otp
)
引数 
otp		OTへのポインタ
解説
otp で示されるOTに登録された描画コマンドの実行を開始する。
GsDrawOt()と違い、描画処理はフォアグラウンドで行われるため、描画が終わるまでこの関数はリターンしない。

返り値
なし

主としてデバッグ用に用いられる。
