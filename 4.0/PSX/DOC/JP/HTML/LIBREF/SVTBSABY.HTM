SsVabTransBody

音源データを転送する

形式 

short SsVabTransBody (
unsigned char *addr, 
short vabid
)
引数 
addr		VABデータの先頭アドレス
vabid		VABID
解説
SsVabOpenHead() で、ヘッダリストを認識させてメインメモリ上の音源データ（VABボディ）をSPUローカルメモリへ転送を開始する。

返り値
VAB識別番号
失敗したら-1を返す。

関連項目
