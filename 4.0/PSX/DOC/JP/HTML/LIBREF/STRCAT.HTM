strcat

文字列を他の文字列に追加する

形式 

#include <strings.h>
char * strcat (
char * dest,
const char *src
)
引数 
dest		連結先文字列
src		連結元文字列
解説
文字列 dest の最後に src を追加する。

返り値
dest を返す。

関連項目
strncat()
