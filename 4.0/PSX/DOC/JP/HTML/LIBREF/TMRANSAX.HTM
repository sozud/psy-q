TransMatrix

平行移動量を与える

形式 

MATRIX *TransMatrix (
MATRIX *m,
VECTOR *v
)
引数 
m		出力：マトリックス
v		入力：移動ベクトル
解説
マトリックス m に、v で表される平行移動量を与える。

引数フォーマット：
m->m[i][j] : (1,3,12)
m->t[i] : (1,31,0)
v->vx,vy,vz : (1,31,0)

返り値
m
