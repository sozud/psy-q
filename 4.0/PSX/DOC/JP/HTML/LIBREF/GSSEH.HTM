GsSEH

HMDアニメーション　シーケンスヘッダ

構造 

typedef struct 	{
	short	idx;
	unsigned char 	sid;
	unsigned char	pad;
} GsSEH;
メンバ 
idx		シーケンスの先頭のシーケンスコントロール記述子をインデックスする。
		シーケンスコントロールセクション内のインデックスで表現される。
sid		シーケンスID
pad		システム予約
解説
GsSEHはシーケンスの情報を保持し、複数のシーケンスがある場合はGsSEHの配列としてシーケンスポインタに続けて格納される。
idxはシーケンスの再生開始のシーケンスコントロール記述子へのインデックスを与える。このインデックスをGsSEQのtidxにセットし、GsSEHのSIDをGsSEQのSIDにセットすることでそのシーケンスの再生を開始させることができる。
複数のシーケンスがある場合は、GsSEHの配列から一つを選んでGsSEQへ値を更新する。
