SsSeqPlay

SEQデータ読みとり（演奏）

形式 

void SsSeqPlay (
short seq_access_num,
char play_mode,
short l_count
)
引数 
seq_access_num		SEQアクセスナンバー
play_mode		演奏モード
l_count			曲の繰り返し回数
解説
play_mode の値によって、即座にSEQデータを読みとり始める（演奏する）か、またはSEQデータの先頭（曲の先頭）でのpause状態にするかの選択を行うことが出来る。
この時、l_count にこの曲の繰り返し回数を指定する。無限回演奏の場合はSSPLAY_INFINITYを指定する。

play_mode動作
SSPLAY_PAUSEpause状態にする
SSPLAY_PLAY即座に演奏する


返り値
なし
