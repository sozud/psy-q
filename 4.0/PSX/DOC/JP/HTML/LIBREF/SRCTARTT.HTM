StartRCnt

ルートカウンタの起動

形式 

long StartRCnt ( 
unsigned long spec
)
引数 
spec		ルートカウンタ指定
解説
ルートカウンタ spec を起動する。割り込み許可を行う。
RCntCNT3の場合は設定できないので、必ず０を返す。

返り値
成功すると1を、失敗すると0を返す。

関連項目
GetRCnt(), SetRCnt(), StopRCnt(), ResetRCnt()
