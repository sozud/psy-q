pers_map

透視変換テクスチャマッピング

形式 

void pers_map (
int abuf ,
SVECTOR **vertex,
int tex[4][2],
u_short *dtext
)
引数 
abuf		表示している方のバッファＩＤ
vertex		４頂点の３次元座標
tex		４頂点のテクスチャアドレス
dtext		ダイレクトカラーに変換されたテクスチャの格納場所
解説
歪みのないテクスチャマッピングを行なう。

返り値
なし

備考
フラットテクスチャ、光源計算なしのみ。
４頂点は正方形、長方形、平行四辺形の位置のみ。
ＯＴによるＺソートはできない。
