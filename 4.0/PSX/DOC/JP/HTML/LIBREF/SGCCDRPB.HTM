SpuGetCommonCDReverb

CD 入力リバーブオン/オフの取得

形式 

void SpuGetCommonCDReverb (
long *on_off
)
引数 
on_off		CD 入力リバーブオン/オフ
解説
CD 入力リバーブオン/オフの状態を取得する。
SpuGetCommonAttr() において SpuCommonAttr 構造体のメンバ cd.reverb の値の取得に該当する処理を行う。

返り値
なし

関連項目
SpuGetCommonAttr(), SpuSetCommonCDReverb()
