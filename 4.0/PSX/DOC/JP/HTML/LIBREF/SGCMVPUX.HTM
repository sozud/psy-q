SpuGetCommonMasterVolumeX

現在のマスタ音量の取得

形式 

void SpuGetCommonMasterVolumeX (
short *mvolXL,
short *mvolXR
)
引数 
mvolXL		現在のマスタ音量 (左)
mvolXR		現在のマスタ音量 (右)
解説
現在のマスタ音量を取得する。
SpuGetCommonAttr() において SpuCommonAttr 構造体のメンバ mvolx の値の取得に該当する処理を行う。

返り値
なし
