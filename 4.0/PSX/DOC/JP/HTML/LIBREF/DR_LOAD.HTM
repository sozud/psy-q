DR_LOAD

矩形領域転送プリミティブ

構造 

typedef struct {
		u_long	tag;
		u_long	code[3];
		u_long	p[13];
} DR_LOAD;
メンバ 
tag		次のプリミティブへのフック（予約）
code		プリミティブ ID
p		転送データ
解説
DR_LOAD は、配列 p 以下のデータをフレームバッファへ転送する。LoadImage() と同様に半透明・透明色制御を行なわない。 また描画環境に依存しない。
