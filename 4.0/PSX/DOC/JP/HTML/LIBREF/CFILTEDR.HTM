CdlFILTER

ADPCM チャンネル

構造 

typedef struct {
		u_char file;
		u_char chan;
		u_short pad;
} CdlFILTER;
メンバ 
file		ファイル番号
chan		チャネル番号
pad		システム予約
解説
再生するADPCMのセクタチャネルを設定する。
