Release 4.0

DsSystemStatus

キューの状態を得る

形式 

int DsSystemStatus ( void )
引数 
なし
解説
キューの状態を得る。コマンドが実行されていない場合はDslReady、何かコマンドが実行されているかカバー開きなどコマンドが実行できない状態ではDslBusy、CDがセットされていない場合はDslNoCDとなる。
DslReadyでない時に発行されたコマンドは、全てキューに登録される。

返り値
DslReady： コマンドは実行されていない
DslBusy： コマンド実行中、もしくはコマンド実行できない状態にある（カバー開きなど）
DslNoCD： CDがセットされていない
