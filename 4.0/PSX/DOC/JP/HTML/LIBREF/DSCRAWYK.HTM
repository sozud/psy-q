DrawSyncCallback

描画終了コールバック関数を設定

形式 

u_long DrawSyncCallback (
void (*func )()
)
引数 
func		コールバック関数
解説
描画終了時に呼ばれるコールバックを定義する。キューに登録された全てのリクエストが完了した時に関数 func が呼び出される。 func に0を指定した場合は、コールバックは発生しない。

返り値
なし

備考
func 内では以降の描画終了割り込みはマスクされる。従って func は必要な処理を終了したらすみやかにリターンする必要がある。
