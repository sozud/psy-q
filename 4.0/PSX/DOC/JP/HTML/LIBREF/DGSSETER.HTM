DsGetSector

セクタバッファのデータをメインメモリへ転送する

形式 

int DsGetSector (
void* madr, 
int size
)
引数 
madr		転送先メインメモリアドレス
size		転送サイズ（ロングワード）
解説
セクタバッファ上のセクタデータをメインメモリ上に転送する。関数の実行は転送終了までブロックする。

返り値
発行に成功すれば１を、失敗すれば０を返す。

備考
セクタサイズはモードによって異なる。セクタバッファのデータは複数回にわけて異なるメモリ領域へ転送することもできる。セクタデータがバッファに準備されてから、次のセクタデータが上書きされる前に読み出さないと、以前のセクタデータは失われる。
関数のリターン時には転送は終了している。
