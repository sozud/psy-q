SsGetSerialAttr

Serialの属性値を得る

形式 

char SsGetSerialAttr (
char s_num,
char attr
)
引数 
s_num		Serial番号
attr		属性
解説
指定したSerialの属性値を返す。

s_num = SS_SERIAL_A(SS_CD)…Serial A（CD入力）
s_num = SS_SERIAL_B(SS_EXT)…Serial B（外部デジタル入力）
attr = SS_MIX…ミキシング
attr = SS_REV…リバーブ

返り値
属性値：onなら1を、offなら0を返す。

関連項目
SsSetSerialAttr()
