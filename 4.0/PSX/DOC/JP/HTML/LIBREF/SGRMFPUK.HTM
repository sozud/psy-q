SpuGetReverbModeFeedback

リバーブのフィードバックの取得

形式 

void SpuGetReverbModeFeedback (
long *feedback
)
引数 
feedback		リバーブのフィードバック
解説
リバーブのフィードバックを取得する。
SpuGetReverbModeParam() において SpuReverbAttr 構造体のメンバ feedbackの値の取得に該当する処理を行う。

返り値
なし

関連項目
