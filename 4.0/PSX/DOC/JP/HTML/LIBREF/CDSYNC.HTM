CdSync

プリミティブコマンドの終了を待つ

形式 

int CdSync (
int mode, 
u_char *result 
)
引数 
mode		0: コマンドの終了を待つ
 		1: 現在の状態を調べて即座にリターンする
result		最も最近に終了したコマンドのステータス(8byte)
解説
コマンドの終了を待つ。

返り値

返り値意味
CdlCompleteコマンド終了
CdlDiskErrorエラー検出
CdlNoIntrコマンド実行中


関連項目
