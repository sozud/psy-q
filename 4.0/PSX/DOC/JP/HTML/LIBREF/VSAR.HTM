SpuSetVoiceAR

ADSR Attack Rate の設定

形式 

void SpuSetVoiceAR (
int voiceNum,
unsigned short AR
)
引数 
voiceNum	ボイス番号 (0 ～23)
AR		ADSR Attack Rate
解説
ボイスで使われる ADSR Attack Rate の設定を行う。
SpuSetVoiceAttr() の mask 指定
SPU_VOICE_ADSR_AR
に該当する処理を行う。
ADSR Attack Rate モードは SPU_VOICE_LINEARIncN (リニア増加) となる。 ADSR Attack Rate と ADSR Attack Rate モードを同時に指定したい場合は SpuSetVoiceARAttr() を使用する。
ADSR Attack Rate AR に指定する値に関しては SpuSetVoiceAttr() を参照のこと。

返り値
なし
