setRGB1

プリミティブのRGBメンバを設定

形式 

setRGB1 ( p,r1g1,b1 )
引数 
p		プリミティブのポインタ
r1,g1,b1	プリミティブのRGBメンバ
解説
プリミティブ p のRGBメンバに値を設定する。

返り値
なし

備考
マクロであるためプリミティブの型に依存しない。
また、
a) setRGB1 ((POLY_FT4 *) p, r1, g1, b1 )
b) setRGB1 ((POLY_F4 *) p, r1, g1, b1 )
では動作が異なる。
