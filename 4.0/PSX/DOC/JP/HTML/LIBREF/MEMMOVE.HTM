memmove

メモリブロックの複写を行なう

形式 

#include <memory.h>
void  * memmove (
void * dest,
const void * src,
size_t n
)
引数 
dest		複写先
src		複写元
n		複写バイト数
解説
dest に、src の最初の n バイトを複写する。
重複したオブジェクト間でも正確に複写される。

返り値
dest を返す。
