SsStart2

サウンドシステムを開始する(VSyncCallback版)

形式 

void SsStart2 ( void )
引数 
なし
解説
サウンドシステムの開始処理を行う。
SsSetTickMode() にて TickCallback関数が自動で呼ばれるモードを設定した場合は、この関数の呼出し後、各Tick毎にTick Callback関数が呼ばれる。
以下の条件が満たされた場合にのみTick Callback 関数をVSyncCallback() にて設定する。

  • SsSetTickMode() にてSS_TICKVSYNC を設定
  • SsSetTickMode() にてSS_TICK60 を設定し、SsSetVideoMode() にてMODE_NTSC を設定。
  • SsSetTickMode() にてSS_TICK50 を設定し、SsSetVideoMode() にてMODE_PAL を設定。

他のモードにおける Tick Callback 関数の設定はSsStart() と同様。

返り値
なし
