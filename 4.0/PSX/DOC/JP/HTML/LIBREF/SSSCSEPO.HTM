SsSepSetCrescendo

クレッシェンド

形式 

void SsSepSetCrescendo (
short sep_access_num,
short seq_num,
short vol,
long v_time
)
引数 
sep_access_num		SEPアクセスナンバー
seq_num			SEPデータ内のSEQナンバー
vol			ボリューム値
v_time			時間（tick単位）
解説
sep_access_num を持つSEPデータの seq_num 番目のSEQデータのメインボリュームを、v_time 内に vol 値だけ上げる。なお、各ボイスの音量が最大値の場合は効果なし。

返り値
なし
