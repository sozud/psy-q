ReadRGBfifo

RGBcd値を読み出す

形式 

void ReadRGBfifo (
CVECTOR *v0,
CVECTOR *v1,
CVECTOR *v2
)
引数 
v0,v1,v2	出力：ベクトル
解説
RGBcd0,RGBcd1,RGBcd2値を v0,v1,v2 に読み出す。

引数フォーマット：
v0,v1,v2->r,g,b,cd : (0,8,0)

返り値
なし
