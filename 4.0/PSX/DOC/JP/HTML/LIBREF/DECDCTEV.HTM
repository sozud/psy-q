DECDCTENV

DCT デコード環境

構造 

typedef struct {
		u_char	iq_y[64];
		u_char	iq_c[64];
		short	dct[64];
} DECDCTENV;
メンバ 
iq_y		輝度成分量子化テーブル
iq_c		色差成分量子化テーブル
dct		システム予約
解説
DCT デコードのパラメータを設定する。
デフォールトの iq_y, iq_c 両テーブルの値は同じで、以下の通り。

u_char iq_y[64] = {
2, 16, 19, 22, 26, 27, 29, 34,
16, 16, 22, 24, 27, 29, 34, 37,
19, 22, 26, 27, 29, 34, 34, 38,
22, 22, 26, 27, 29, 34, 37, 40,
22, 26, 27, 29, 32, 35, 40, 48,
26, 27, 29, 32, 35, 40, 48, 58,
26, 27, 29, 34, 38, 46, 56, 69,
27, 29, 35, 38, 46, 56, 69, 83
};

注意：テーブル中の各値は、小数部４ビットの固定小数点表現である。

備考
iq_y, iq_c はジグザグスキャン順序で並べられていることに注意。
