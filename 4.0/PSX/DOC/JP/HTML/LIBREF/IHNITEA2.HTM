InitHeap2

ヒープ領域の初期化

形式 

void InitHeap2 ( 
unsigned long *head,
unsigned long size 
)
引数 
head		ヒープ先頭アドレス
size		ヒープサイズ（4の倍数、バイト単位）
解説
メモリ管理関数群を初期化する。
以降、malloc2()などが使用可能となる。
ただし、オーバヘッドがあるのでsize バイトすべてが利用可能とはならない。
返り値
なし

備考
多重に実行するとそれまで保持していたメモリ管理情報が失われる。
オンメモリ関数なのでプログラムのサイズは大きくなる。
InitHeap(),InitHeap3()系との違いは overview\api.docの「10 メモリ管理関数について」を参照の事。
