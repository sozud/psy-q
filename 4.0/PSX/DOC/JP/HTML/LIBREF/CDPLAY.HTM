CdPlay

CD-DAトラックを再生する

形式 

int CdPlay (
int mode,
int *tracks,
int offset
)
引数 
mode		モード
tracks		演奏するトラックを指定した配列。0で終端していること
offset		演奏を開始するtracksのインデックス
解説
配列tracksで指定された複数のトラックをバックグラウンドに順に演奏する。配列の最後のトラックまで演奏したらモードに応じて繰り返し演奏するか、演奏を終了する。
modeに指定できる値は次の通り。

mode内容
0演奏を停止する。
1
tracksで指定されたトラックを順に演奏し、指定されたトラックを
すべて演奏したら、演奏を停止する。
2
tracksで指定されたトラックを順に演奏し、指定されたトラックを
すべて演奏したら、最初に戻って繰り返し演奏する。
3現在の演奏中のトラックに対応するtracksのインデックスを返す。


返り値
現在演奏中のトラック。これはトラック番号ではなく配列tracksのインデックスが返される。-1が返された場合は、演奏は終了していることを表す。

備考
演奏はトラック単位で行われ、トラックの途中からの演奏や停止はできない。
