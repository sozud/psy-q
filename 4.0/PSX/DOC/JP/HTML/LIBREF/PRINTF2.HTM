printf2

書式化された出力を標準出力stdoutへ行なう（float,double型対応）

形式 

long printf2 (
const char *fmt[,argument...]
)
引数 
fmt		入力書式文字列
解説
変換指定子「f」「e」「E」「g」「G」が使用できる。
スタック消費量はprintfより多い。

返り値
出力した文字の長さを返す。

関連項目
sprintf2()
