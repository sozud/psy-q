malloc3

主記憶を割り当てる

形式 

#include <stdlib.h>
void *malloc3 (
size_t s
)
引数 
s		確保するメモリブロックのサイズ
解説
ヒープメモリから s バイトのブロックを確保する。
InitHeap3()に対応している。

返り値
確保されたメモリブロックへのポインタを返す。
確保に失敗するとNULLを返す。

備考
前もってInitHeap3()を実行しておく必要がある。
InitHeap(),InitHeap2()とペアでは使用できない。
malloc(),malloc2()系との違いは overview\api.docの「10 メモリ管理関数について」を参照の事。

関連項目
InitHeap3(), calloc3(), realloc3(), free3()
