free2

割り当て済みのメモリブロックを開放する

形式 

#include <stdlib.h>
void free2 (
void* block 
)
引数 
block		開放する領域
解説
calloc2()、malloc2()、realloc2()で確保したメモリブロックを開放する。

返り値
なし

関連項目
calloc2(), malloc2(), realloc2()
