GsLINE

直線ハンドラ

構造 

struct GsLINE {
		unsigned long attribute;
		short x0, y0;
		short x1, y1;
		unsigned char r, g, b;
};
メンバ 
attribute	属性
x0, y0		描画開始点の位置
x1, y1		描画終了点の位置
r, g, b		描画色
解説
GsLINE は、直線を描画するために必要な情報を持つ構造体である。
GsLINE をオーダリングテーブルに登録するには、GsSortLine() 関数を使用する。
attribute は 32 ビットで、ここで表示のためのさまざまな属性を設定する。

ビット意味
28-29
半透明レート
0：0.5 x Back + 0.5 x Forward
1：1.0 x Back + 1.0 x Forward
2：1.0 x Back - 1.0 x Forward
3：1.0 x Back + 0.25 x Forward
30
半透明 ON/OFF
0: 半透明 OFF
1: 半透明 ON
31
表示 ON/OFF
0: 表示
1: 非表示


bit30 で半透明を ON にした場合に、ピクセルをブレンディングする方式を設定する。
０のときは通常の半透明処理 １のときはピクセル加算、２のときはピクセル減算、３のときは25%加算となる。
