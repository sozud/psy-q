Release 4.0

GetRCnt

ルートカウンタの取得

形式 

long GetRCnt (
unsigned long spec
)
引数 
spec		ルートカウンタ指定
解説
ルートカウンタ spec の現行値を返す。

返り値
成功すると32ビットに符号拡張したカウンタ値を、失敗すると-1を返す。
RCntCNT3の場合は、0を返す。

関連項目
SetRCnt(), StartRCnt(), StopRCnt(), ResetRCnt()
