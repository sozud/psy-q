DslLOC

CD-ROMロケーション

構造 

typedef struct {
	u_char minute;
	u_char second;
	u_char sector;
	u_char track;
} DslLOC;
メンバ 
minute		分
second		秒
sector		セクタ
track		トラック盤号
解説
CD-ROMの位置指定構造体。各要素はBCDで設定する。

備考
trackは現在使用されていない。
