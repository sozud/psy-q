StSetEmulate

ストリーミングのエミュレーションのためのパラメータを設定する

形式 

void StStartEmulate (
unsigned long *addr,
unsigned long mode,
unsigned long start_frame,
insigned long end_frame,
int (*func1)(),
int (*func2)()
)
引数 
addr		エミュレーションデータの先頭アドレス
 		その他の引数はStSetStream()と同じ
解説
エミュレーションのためのパラメータを設定する。
エミュレーションとはメモリーにCDROMのデータを入れておき、実際のCDからはデータレディのタイミングだけをもらって、CDROMからではなくメモリーからデータをひっぱってきてストリーミングを再生する機能である。
もちろんメモリ容量には限りがあるため再生時間は数秒に限られるがCDROMエミュレータを使うよりも容易にエミュレーションをすることができる。
あらかじめ addr にSTRフォーマットのデータをロードしておく必要がある。

返り値
なし
