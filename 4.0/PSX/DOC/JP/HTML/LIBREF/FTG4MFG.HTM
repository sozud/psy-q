GsTMDfastTG4MFG

グーローテクスチャ４角形（光源計算＋FOG＋マテリアル減衰）

形式 

PACKET * GsTMDfastTG4MFG (
TMD_P_TG4 * op, 
VERT * vp, 
VERT * np, 
PACKET * pk, 
int n, 
int shift, 
GsOT * ot, 
u_long * scratch
)
引数 
op		TMDデータのプリミティブ先頭アドレス
vp		TMDデータのバーテックス先頭アドレス
np		TMDデータのノーマル先頭アドレス
pk		GPUパケットのバッファの先頭アドレス
n		プリミティブの数
shift		OTにソートする際の shift するbit数
ot		GsOTへのポインタ
scratch		未使用のscratch padの先頭アドレス
解説
GsSortObject4J()の下位関数群。
使用するためにはGsFCALL4に下位関数として登録し使用します。
lighting modeがmaterial ON時のみ、光源計算時にGsDOBJ2のattributeで与えられたパラメータにしたがい輝度を減衰させます。

返り値
未使用の packet 領域の先頭アドレス
