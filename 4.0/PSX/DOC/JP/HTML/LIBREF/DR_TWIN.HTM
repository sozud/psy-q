DR_TWIN

テクスチャウィンドウ変更プリミティブ

構造 

typedef struct {
		u_long	tag;
		u_long	code[2];
} DR_TWIN;
メンバ 
tag		次のプリミティブへのフック（予約）
code		プリミティブ ID
解説
DR_TWIN プリミティブは現在の描画環境のうちテクスチャウィンドウだけを描画の途中で変更する。
内容の設定は SetTexWindow() で行なう。
