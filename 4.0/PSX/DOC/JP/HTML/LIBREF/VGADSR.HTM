SpuGetVoiceADSR

ADSR の取得

形式 

void SpuGetVoiceADSR (
int voiceNum,
unsigned short *AR,
unsigned short *DR,
unsigned short *SR,
unsigned short *RR,
unsigned short *SL
)
引数 
voiceNum	ボイス番号 (0 ～23)
AR		ADSR Attack Rate
DR		ADSR Decay Rate
SR		ADSR Sustain Rate
RR		ADSR Release Rate
SL		ADSR Sustain Level
解説
ボイスで使われる ADSR の個別の属性の取得を行う。
SpuGetVoiceAttr() における SpuVoiceAttr 構造体のメンバ ar, dr, sr, rr, sl の値の取得に該当する処理を行う。
Attack, Sustain Relase の各 Rate について、 Rate モードはそれぞれ以下の通りとなっている場合のみ得られた値は有効となる。他の各 Rate モードの場合は不定となる。

RateRateモード
Attack Rate SPU_VOICE_LINEARIncN (リニア増加)
Sustain Rate SPU_VOICE_LINEARDecN (リニア減少)
Release Rate SPU_VOICE_LINEARDecN (リニア減少)


各 Rate モードを同時に取得したい場合は SpuGetVoiceADSRAttr() を使用する。

返り値
なし
