SsSeqOpenJ

SEQ データをオープンする(関数 Table 版)

形式 

short SsSeqOpenJ (
unsigned long* addr,
short vab_id
)
引数 
addr		SEQ データの主記憶内の先頭アドレス
vab_id		VAB id
解説
全ての下位関数を登録した場合の機能は SsSeqOpen() と同等。加えてテーブルに登録する関数をプログラマが制御できるため、不必要な下位関数を呼ばないようにしてコード効率をあげることができる。
SsFCALL の登録しないスロットには 取り敢えず dmy を先頭につけた関数名を書いておけば、万が一その下位関数が呼ばれたとしても BUS ERRORを起こすことはなく、最初にその関数が呼ばれた時、関数名をプリントアウトするので、dmy をとって登録すれば良い。
この関数で指定するVABデータIDのVBデータが SsVabTransCompleted() にて、転送が終了
したことが確認されてから行なうこと。


返り値
SEQアクセスナンバー: SEQ データアクセス関数中で使用するための番号で、内部で持つSEQデータ管理テーブルの番号。
