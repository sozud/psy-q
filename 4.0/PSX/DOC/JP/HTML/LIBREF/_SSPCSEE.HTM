_SsSetProgramChange

SsSeqOpen(SsSepOpen)の下位関数群

形式 

void _SsSetProgramChange(
short num1, 
short num2, 
unsigned char data
)
引数 
num1		SEQ/SEP アクセスナンバー
num2		SEP データ内の SEQ ナンバー
data		ステータスメッセージデータ
解説
SEQ/SEP に Program Change データが含まれる場合、この下位関数を呼び出す必要がある。

返り値
なし

関連項目
SsSeqOpenJ(), SsSepOpenJ()
