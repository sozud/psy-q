gets

標準入力ストリームから文字列を読み込む

形式 

#include <stdio.h>
char * gets (
char * s
)
引数 
s		入力文字列の格納先
解説
標準入力ストリーム（stdin）から改行文字で終了する文字列を読み込んで s に格納する。

返り値
成功すると文字列引数 s を返す。ファイルエンドまたはエラーの場合はNULLを返す。

関連項目
getc(), getchar()
