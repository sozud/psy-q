SpuGetVoiceSL

ADSR Sustain Level の取得

形式 

void SpuGetVoiceSL (
int voiceNum,
unsigned short *SL
)
引数 
voiceNum	ボイス番号 (0 ～23)
SL		ADSR Sustain Level
解説
ボイスで使われる ADSR Sustain Level の取得を行う。
SpuGetVoiceAttr において SpuVoiceAttr 構造体のメンバ sl の値の取得に該当する処理を行う。

返り値
なし

関連項目
SpuGetVoiceAttr(), SpuNGetVoiceAttr()
