RotMeshPrimQ_T

２次元メッシュ

形式 

void RotMeshPrimQ_T (
QMESH *msh,
POLY_FT4 *prim,
u_long *ot,
u_long otlen,
long dpq,
long backc,
SCLIP *sclip,
LINE_BUF *line_sxy
)
引数 
msh		メッシュ型データへのポインタ
prim		生成すべきGPUパケットへのポインタ
ot		オーダリングテーブルのポインタ
otlen		オーダリングテーブルの長さ
dpq		デプスキューイングをするかしないか
backc		バッククリップをするかしないか
sclip		スクリーンクリップ領域
line_sxy	内部処理のための１ライン分のバッファ
解説
下記のような２次元メッシュ(qmesh)データの座標変換、透視変換、法線クリップ、スクリーン座標によるクリッピング(X,Y,Z)、ＯＴへのリンクを行なう。
Ｈ方向の頂点の数は３の倍数でなければならない。( msh->lenh = 3 * n )


テクスチャをそのまま書き込む（フォグはかかるが光源計算しない）。
テクスチャ座標は設定されているものとする。

返り値
なし

備考
以下の構造体を使う。ラインバッファは(１Ｈ＋３頂点)以上確保する。
ラインバッファとしてスクラッチパッドを使うと高速である。

typedef struct {
long sminX
long smaxX
long sminY
long smaxY
long sminZ
long smaxZ
} SCLIP;

typedef struct {
long sxy
long code
} LINE_BUF;
