SpuNGetVoiceAttr

ボイス属性の取得

形式 

void SpuNGetVoiceAttr (
int voiceNum,
SpuVoiceAttr *attr
)
引数 
voiceNum	ボイス番号 (0 ～23)
attr		ボイス属性
解説
ボイス属性を取得する。
voiceNum に取得するボイス番号を明示的に設定する。
attr の構造体メンバについては、mask 以外全ての属性が返る。それぞれの属性の詳細については、SpuSetVoiceAttr() を参照。

返り値
なし
