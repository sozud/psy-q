SpuSetReverbModeType

リバーブモードタイプの設定

形式 

long SpuSetReverbModeType (
long type
)
引数 
type		リバーブモードタイプ
解説
リバーブモードタイプの設定を行う。
SpuSetReverbModeParam() の mask 指定
SPU_REV_MODE
に該当する処理を行う。
リバーブモードタイプ type に指定する値に関しては SpuSetReverbModeParam() を参照のこと。

返り値
リバーブのワークエリアが SpuMalloc() / SpuMallocWithStartAddr() によって他の領域として使われている場合は SPU_ERROR を返し指定されたリバーブ属性は全て設定されない。他の領域として使われていなければ、指定されたリバーブ属性が設定され、0 を返す。
