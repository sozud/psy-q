RotTransPers4

４頂点の座標変換と透視変換を行なう

形式 

long RotTransPers4(
SVECTOR *v0,
SVECTOR *v1,
SVECTOR *v2,
SVECTOR *v3,
long *sxy0,
long *sxy1,
long *sxy2,
long *sxy3,
long *p,
long *flag
)
引数 
v0,v1,v2,v3		入力：ベクトル
sxy0,sxy1,sxy2,sxy3	出力：座標値
p			出力：内挿値
flag			出力：フラグ
解説
４つの座標ベクトル v0,v1,v2,v3 を回転マトリックスで座標変換したあと透視変換を行ない、４つのスクリーン座標を sxy0,sxy1,sxy2,sxy3 に返す。
また v3 に対応するデプスキューイング用の内挿値を p に返す。
v3 に対応するスクリーン座標のＺ成分szの１／４を返り値とする。

引数フォーマット：
v0,v1,v2,v3->vx,vy,vz : (1,15,0)
sxy0,sxy1,sxy2,sxy3 : (1,15,0),(1,15,0)
p : (0,20,12)
flag : (0,32,0)

返り値
sz/4
