_card_format

メモリカードのフォーマット

形式 

int _card_format(
long chan
)
引数 
chan		ポート番号＊１６＋カード番号
 		ポート番号（Ａポート:０、Ｂポート:１）
 		カード番号（通常０）
解説
メモリカードをフォーマットする。
同期関数、約144VSYNCの間、ブロッキングされる。
クリティカルセクションには入らない。

返り値
フォーマットに成功すると1を、以外は0を返す。
