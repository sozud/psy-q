SPRT

任意サイズスプライト

構造 

typedef struct {
		u_long	tag;
		u_char	r0, g0, b0, code;
		short	x0, y0;
		u_char	u0, v0;
		u_short	clut;
		short	w, h;
} SPRT;
メンバ 
tag		次のプリミティブへのフック（予約）
code		プリミティブ ID
r0,g0,b0	プリミティブの輝度値
x0,y0		プリミティブの左上端点頂点座標
u0,v0		プリミティブの左上端点テクスチャ座標
clut		CLUT ID (4bit/8bit モード時のみ）
w, h		プリミティ幅・高さ
解説
SPRT は、矩形領域を等倍でのテクスチャマッピングつきで描画する。

備考
描画速度は、POLY_FT4 プリミティブよりも高速。
スプライトプリミティブは、 tpage メンバを持たないため、テクスチャページは直前に指定されたもの（カレントテクスチャページ）がそのまま使用される。
u0,w は偶数の指定のみ。スプライトプリミティブでは、描画を高速に行なうために 2pixel 単位で処理をおこなっているため、u0 座標は 2 の倍数しか指定できない。
u に奇数を指定した場合

4bit テクスチャ 16 pixel
8bit テクスチャ 8 pixel
16bit テクスチャ 4 pixel

の間隔で誤ったテクスチャピクセルが使用される。
