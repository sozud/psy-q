RotMeshPrimS_F3

ストリップメッシュ

形式 

void RotMeshPrimS_F3 (
TMESH *msh,
POLY_F3 *prim,
u_long *ot,
u_long otlen,
long dpq,
unsigned long backc
)
引数 
msh		メッシュ型データへのポインタ
prim		生成すべきGPUパケットへのポインタ
ot		オーダリングテーブルのポインタ
otlen		オーダリングテーブルの長さ
dpq		デプスキューイングをするかしないか
backc		バッククリップをするかしないか
解説
下記のようなストリップ型メッシュ(smesh)データの座標変換、透視変換、ＯＴへのリンクを行なう。


頂点色の一つでフラットシェーディングを行なう（光源計算する）

返り値
なし
