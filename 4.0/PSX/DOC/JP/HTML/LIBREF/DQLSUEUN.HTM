DsQueueLen

コマンドキューに登録されているコマンドの数を得る

形式 

int DsQueueLen ( void )
引数 
なし
解説
コマンドキューに登録されているプリミティブコマンドの数を得る。DsPacket()で発行したコマンドは、全てが成功するまでキューから削除されないため、実行中は常に変化しない。

返り値
キューに登録されているコマンドの数

備考
実行中のコマンドも数えられる。なお、キューに登録可能な最大コマンド数はマクロ定数DslMaxCOMMANDSに定義されている。
