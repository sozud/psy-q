GsSortGLine

直線をOTへ登録

形式 

void GsSortGLine (
GsGLINE * lp, 
GsOT * otp, 
unsigned short pri
)
引数 
lp		GsGLINEへのポインタ
otp		OTへのポインタ
pri		OTでの位置
解説
lp で示される直線を、otp で示されるオーダリングテーブルに割り付ける。
GsSortGLine() ではグラデーションのかかった直線をOTに登録する。

返り値
なし
