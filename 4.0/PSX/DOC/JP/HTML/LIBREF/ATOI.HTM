atoi

文字列を整数に変換する

形式 

#include <stdlib.h>
long atoi (
const char *s
)
引数 
s		文字列
解説
(long)strtol(s,(char**)NULL)と同じ。本システム上では、atol() と等価な関数となる。

返り値
入力値 s を整数に変換した結果を返す。

関連項目
atol(), strtol()
