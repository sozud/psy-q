CD-ROM ライブラリ (libcd) 関数一覧
Release 4.0

CdLastPos

最後にアクセスしたCD-ROMの位置を獲得

形式 

CdlLOC *LastPos( void )
引数 
なし
解説
最後に実行されたCdlSetloc/CdlPlay/CdlSeekL/CdlSeekP/CdlRead/CdlReadSサブコマンドで指定された位置を返す。

返り値
CD-ROMの位置を表すCdlLOC構造体のポインタ
