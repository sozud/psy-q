シリアル入出力ライブラリ (libsio) 関数一覧
Release 4.0

_sio_control

SIOBIOS

形式 

long _sio_control( 
unsigned long cmd
unsigned long arg
unsigned long param 
)
引数 
cmd		コマンド
arg		サブコマンド
param		引数
解説
SIOドライバ制御および情報取得。
ＰＣとの細かい通信処理に利用する。
ライブラリ等の標準出力によるデバッグデータを抑制したい場合に利用する。

返り値
