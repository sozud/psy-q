POLY_F4

フラット４角形プリミティブ

構造 

typedef struct {
		u_long	tag;
		u_char	r0, g0, b0, code;
		short	x0, y0;
		short	x1, y1;
		short	x2, y2;
		short	x3, y3;
} POLY_F4;
メンバ 
tag			次のプリミティブへのフック（予約）
code			プリミティブ ID
r0,g0,b0		プリミティブの輝度値
x0,y0,x1,y1..x3,y3	プリミティブの各頂点座標
解説
POLY_F4 は (x0,y0)-(x1,y1)-(x3,y3)-(x2,y2) で囲まれた領域を (r0,g0,b0) の輝度値で塗りつぶす。

４角形プリミティブの場合頂点の指定順序は以下の通り。
これは、テクスチャマップ４角形における、(u,v) および、グーローシェーディング４角形における、(r,g,b) の指定についても同様。
