getc

ストリームから１文字取得する

形式 

#include <stdio.h>
char getc (
FILE * stream
)
引数 
stream		入力ストリーム
解説
入力ストリームstreamから１文字取得する。

返り値
ファイルが終わりである場合や、エラーが発生するとEOFを返す。

関連項目
getchar(), gets()
