AverageZ3

３つの値の平均値を求める

形式 

long AverageZ3 (
long sz0,
long sz1,
long sz2
)
引数 
sz0,sz1,sz2		入力：値
解説
３つの値 sz0,sz1,sz2 の平均値を返す。

引数フォーマット：
sz0,sz1,sz2 : (0,16,0)

返り値
( sz0 + sz1 + sz2 ) / (3 * 4)
