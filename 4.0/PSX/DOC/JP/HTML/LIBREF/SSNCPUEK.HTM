SpuSetNoiseClock

ノイズ音源のクロックの設定

形式 

long SpuSetNoiseClock (
long n_clock
)
引数 
n_clock		ノイズ音源のクロック
解説
ノイズ音源のクロックの値を設定する。ただしそのクロックの値は 0x00～0x3f でなければならない。

返り値
設定されたノイズ音源のクロックの値

関連項目
