applyVector

ベクトルの演算

形式 

applyVector (v,x,y,z,op )
引数 
v		ベクトルへのポインタ
x, y, z		座標値
op		演算子
解説
ベクトル v に x,y,z に op で指定された操作を行う
applyVector(v, 2, 4, 8, +=)
は、
v－>vx += 2, v－>vx+= 4, v－>vx += 8
に等しい。

返り値
なし

備考
マクロであるためベクトルの型に依存しない。
