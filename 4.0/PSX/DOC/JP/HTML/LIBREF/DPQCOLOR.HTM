DpqColor

原色ベクトルとファーカラーとの内挿を行なう

形式 

void DpqColor (
CVECTOR *v0,
long p,
CVECTOR *v1
)
引数 
v0		入力：原色ベクトル
p		入力：内挿値
v1		出力：カラーベクトル
解説
v1 = (1-p)×v0+p×FC

引数フォーマット：
v0->r,g,b : (0,8,0)
p : (0,20,12)
v1->r,g,b : (0,8,0)

返り値
なし
