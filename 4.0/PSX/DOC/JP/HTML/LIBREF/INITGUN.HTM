InitGUN

ガンを初期化する

形式 

void InitGUN ( 
char *bufA, *bugB,
long  lenA, lenB
char *buf0,
char *buf1,
long len
)
引数 
bufA, bufB	コントローラ受信データバッファ
lenA, lenB	コントローラ受信データバッファ長（バイト単位）
buf0,buf1	水平・垂直位置受信バッファ(バッファのサイズは、len*4+2 バイト必要)
len		ガンによる１ Vsyncあたりの割り込み数(最大20)
解説
コントローラの受信データバッファおよび水平・垂直位置受信バッファを登録する。
ガンによる割り込みをトリガーとした、垂直および水平位置の取り込みをおこなう。
InitPAD(),InitTAP()との併用はできません。
ライブラリのバージョン4.0から、ガンの精度を上げるために割り込み処理内部でDMAと割り込みをブロックしています。1Vsyncあたりの割り込みの数を大きく設定しますと１回あたり1Hsyncの時間を消費しますので、この値は小さめに設定してください。
水平方向のカウンタの値は、システムクロックの値を返していますので、ピクセル値を得るためには、水平方向の解像度に応じて下記の係数を乗算してください。
