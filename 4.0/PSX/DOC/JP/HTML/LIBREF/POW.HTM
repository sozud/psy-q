pow

xのy乗

形式 

double pow (
double x, 
double y
)
引数 
x		数値
y		べき乗
解説
x の y 乗を計算する。

返り値
x の y 乗（xy）

備考
エラー処理は次の通り。

条件返り値エラー
x==0 && y>00
x==0 && y<=01領域エラー
x<0 && 「yが整数値でない」0領域エラー
