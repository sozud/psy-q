CompMatrixLV

座標変換の合成を行なう

形式 

MATRIX *CompMatrixLV (
MATRIX *m0,
MATRIX *m1,
MATRIX *m2
)
引数 
m0		入力：マトリックス
m1		入力：マトリックス
m2		出力：マトリックス
解説
平行移動を含む座標変換マトリックスの合成を行なう。

[m2->m] = [m0->m]×[m1->m]
(m2->t) = [m0->m]×(m1->t)+(m0->t)

引数フォーマット：
m0->m[i][j] : (1,3,12)
m0->t[i] : (1,31,0)
m1->m[i][j] : (1,3,12)
m1->t[i] : (1,31,0)
m2->m[i][j] : (1,3,12)
m2->t[i] : (1,31,0)

返り値
m2

備考
回転マトリックスをこわす。
