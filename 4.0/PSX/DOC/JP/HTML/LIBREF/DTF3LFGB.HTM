GsTMDdivTF3LFGB

両面フラットテクスチャ３角形 (光源計算＋FOG)

形式 

u_long *GsTMDdivTF3LFGB (
TMD_P_TF3 *primtop,
SVECTOR *vertop,
SVECTOR *nortop,
POLY_FT3 *s,
u_long n,
u_long shift,
GsOT *otp,
DIVPOLYGON3 *divp
)
引数 
primtop		TMD PRIMITIVEのスタートアドレス
vertop		TMD VERTEXの先頭アドレス
nortop		TMD NORMALの先頭アドレス
s		GPUパケットバッファのアドレス
n		処理ポリゴン数
shift		OTへの割り付け時にZの値を何ビット右にシフトさせるかを設定
otp		OTへのポインタ
divp		デバイド用ワークエリア
解説
TMDファイル上の連続する n 個のフラットテクスチャ３角形について divp->ndivの値のもとに分割し,分割ポリゴンに対し、座標変換、透視変換、表示画面clip、(光源計算)を行ない、ＧＰＵパケットをバッファ上に完成し、ＯＴにリンクする。 backface clipをおこなわない。

ndiv=1: 2x2分割、ndiv=2: 4x4分割、
ndiv=3: 8x8分割、ndiv=4: 16x16分割、
ndiv=5: 32x32分割

返り値
更新されたGPUパケットバッファのアドレス

備考
divp->ndiv:分割数、divp->pih,piv:表示画面の解像度(クリップ用)、は設定されているものとする。libgs参照
