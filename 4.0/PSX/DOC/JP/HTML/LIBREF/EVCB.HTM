EvCB

イベント管理ブロック

構造 

struct EvCB {
		unsigned long desc;
		long status;
		long spec;
		long mode;
		long ( *Fhandler )();
		long system [2];
};
メンバ 
desc		原因ディスクリプタ
status		ステータス
spec		イベント種別
mode		モード
FHandler	関数型ハンドラ
system		システム予約
解説
