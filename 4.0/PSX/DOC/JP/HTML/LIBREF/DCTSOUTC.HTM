DecDCToutSync

画像処理サブシステムへの受信の終了を待つ

形式 

int DecDCToutSync (
int mode
)
引数 
mode		モード
解説
DecDCTout()関数の終了を検出する
モードに指定できる値は次の通り。

mode内容
0終了までブロックする
1状態の通知のみを行なう


返り値
画像処理サブシステムの状態
0:受信が行なわれていない
1:受信中
