DR_AREA

描画領域変更プリミティブ

構造 

typedef struct {
		u_long	tag;
		u_long	code[2];
} DR_AREA;
メンバ 
tag		次のプリミティブへのフック（予約）
code		プリミティブ ID
解説
DR_AREA プリミティブは現在の描画環境のうち描画領域だけを描画の途中で変更する。
内容の設定は SetDrawArea() で行なう。
