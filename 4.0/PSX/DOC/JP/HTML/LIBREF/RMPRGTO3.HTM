RotMeshPrimR_GT3

ラウンドメッシュ

形式 

void RotMeshPrimR_GT3 (
TMESH *msh,
POLY_GT3 *prim,
u_long *ot,
u_long otlen,
long dpq,
unsigned long backc
)
引数 
msh		メッシュ型データへのポインタ
prim		生成すべきGPUパケットへのポインタ
ot		オーダリングテーブルのポインタ
otlen		オーダリングテーブルの長さ
dpq		デプスキューイングをするかしないか
backc		バッククリップをするかしないか
解説
下記のようなラウンド型メッシュ(rmesh)データの座標変換、透視変換、ＯＴへのリンクを行なう。


頂点色でグーローシェーディングしたものとテクスチャを掛け合わせる（光源計算する）

返り値
なし
