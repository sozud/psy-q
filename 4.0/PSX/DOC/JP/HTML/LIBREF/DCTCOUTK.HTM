DecDCToutCallback

受信終了時に呼ばれるコールバックを設定

形式 

int DecDCToutCallback (
void (*func)()
)
引数 
func		コールバック関数のアドレス
解説
受信終了時に呼ばれるコールバック func を設定する。
コールバックが設定されると、受信の終了時に関数 func が呼び出される。
func に0を指定した場合は、コールバックは発生しない。

返り値
なし

備考
func 内では以降の受信終了割り込みはマスクされる。従って func は必要な処理を終了したらすみやかにリターンする必要がある。
