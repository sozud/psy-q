NormalColor_nom

法線ベクトルからローカルカラーを求める

形式 

void NormalColor_nom (
SVECTOR *v0
)
引数 
v0		入力：法線ベクトル
解説
LLV = LLM×v0
v1 = BK+LCM×LLV

引数フォーマット：
v0->vx,vy,vz : (1,3,12)
v1->r,g,b : (0,8,0)

返り値
なし

備考
(v1->r,v1->g,v1->b)はマクロread_rgb2で読む。
