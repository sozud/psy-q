ChangeTh

実行スレッドの変更

形式 

ChangeTh ( 
long thread
)
引数 
thread		スレッドディスクリプタ
解説
スレッド thread に実行を移す。現行スレッドはこの関数を実行中の状態でTCBに待避される。実行が再開されるとこの関数から返って来る。

返り値
成功し再実行されると1を、それ以外は0を返す。
再実行時の返り値は他スレッドにより変更される可能性がある。

関連項目
TCBH構造体, TCB構造体, OpenTh()
