ClearImage

フレームバッファ高速塗りつぶし

形式 

int ClearImage (
RECT *rect,
u_char r,
u_char g,
u_char b
)
引数 
rect		塗りつぶす矩形領域
r, g, b		塗りつぶすピクセル値
解説
rect で指定されたフレームバッファの矩形領域を( r,g,b )の輝度値で塗りつぶす。

返り値
キューの数

備考
ノンブロック関数であるため、実際の転送の終了はDrawSync()で検出する必要がある。
描画領域は、描画環境（クリップ／オフセット）の影響を受けない。
