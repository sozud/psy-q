SpuGetCommonCDVolume

CD 入力音量の取得

形式 

void SpuGetCommonCDVolume (
short *cdvolL,
short *cdvolR
)
引数 
cdvolL		CD 入力音量 (左)
cdvolR		CD 入力音量 (右)
解説
CD 入力音量を取得する。
SpuGetCommonAttr() において SpuCommonAttr 構造体のメンバ cd.volume の値の取得に該当する処理を行う。

返り値
なし

関連項目
SpuGetCommonAttr(), SpuSetCommonCDVolume()
