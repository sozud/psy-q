TransposeMatrix

転置行列を与える

形式 

MATRIX *TransposeMatrix (
MATRIX *m0,
MATRIX *m1
)
引数 
m0		入力：マトリックス
m1		出力：マトリックス
解説
マトリックス m0 の転置行列を m1 に与える。

引数フォーマット：
m0->m[i][j] : (1,3,12)
m1->m[i][j] : (1,3,12)

返り値
m1
