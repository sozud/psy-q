GsSetFlatLight

平行光源の設定

形式 

void GsSetFlatLight (
int id，
GsF_LIGHT * lt 
)
引数 
id		光源番号 (0,1,2)
lt		光源情報
解説
平行光源を設定する。光源は３つ（ID = 0, 1, 2）まで設定可能。
光源の情報は GsF_LIGHT 構造体によって与えられる。

返り値
なし

備考
GsF_LIGHT 構造体の内容を書き替えても、この関数を呼ばなければ設定が libgs に反映されないので注意。
