ChangeClearPAD

コントロールドライバの設定

形式 

void ChangeClearPAD ( 
long val
)
引数 
val		垂直帰線割り込みクリアフラグ
解説
垂直帰線割り込みで起動されるコントローラドライバの中で割り込み処理を完了するか、完了せずにより低い優先度の割り込みモジュールに処理を許すかを設定する。
val が1の場合は前者、0の場合は後者の設定となる。

返り値
なし
