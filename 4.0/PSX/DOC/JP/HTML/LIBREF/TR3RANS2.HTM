TransRot_32

RotTransの回転平行移動を逆順に行なう

形式 

void TransRot_32 (
VECTOR *v0,
VECTOR *v1,
long *flag
)
引数 
v0		入力：ベクトル
v1		出力：ベクトル
flag		出力：フラグ
解説
v0 に32bitの平行移動量を足したあと定数回転マトリックスで回転を行なう。

引数フォーマット：
v0->vx,vy,vz : (1,31,0)
v1->vx,vy,vz : (1,31,0)
flag : (0,32,0)

返り値
なし
