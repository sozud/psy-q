Release 4.0

CdReset

CD-ROMサブシステムの初期化

形式 

int CdReset (
int mode
）
引数 
mode		リセットモード
解説
CD-ROMサブシステムを初期化する。CdInit()の下位関数。CdInit()と異なりCD-ROMに関するイベント環境を初期化しない。
リセットモードには以下の値を指定できる。

mode内容
0CDサブシステムのみ初期化
1CDサブシステムとCDオーディオ（CD-DA、ADPCM）の音量の初期化


modeに0が指定された場合は、CDオーディオの音量の初期化を行なわないため、それ以前にサウンドライブラリで指定された音量の設定が保存される。

返り値
初期化に成功すれば1を、失敗すれば0を返す。

備考
リトライは行なわない。
