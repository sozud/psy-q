RECT

フレームバッファ矩形領域

構造 

typedef struct {
		short x, y;
		short w, h;
} RECT;
メンバ 
x, y		矩形領域の左上点 
w, h		矩形領域の幅・高さ
解説
アクセスするフレームバッファの領域を指定する。負の値およびフレームバッファの大きさ (1024x512) を越える値は指定できない。
