RotTransPers3N

座標変換と透視変換を行なう

形式 

void RotTransPers3N (
SVECTOR *v0,
DVECTOR *v1,
u_short *sz,
u_short *flag,
long n
)
引数 
v0		入力：頂点座標ベクトル
v1		出力：頂点座標ベクトル
sz		出力：SZ値
flag		出力：フラグ
n		頂点数
解説
n 個の三角形に対してRotTransPers3を行なう

引数および内部データフォーマット：
v0->vx,vy,vz : (1,15,0)
v1->vx,vy : (1,15,0)
sz : (0,16,0)
flag : (0,16,0)

返り値
なし

備考
flag は通常の３２ビットflagの２７ビット目から１２ビット目まで
