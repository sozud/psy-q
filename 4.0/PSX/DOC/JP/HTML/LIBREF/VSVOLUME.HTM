SpuSetVoiceVolume

ボイス音量の設定

形式 

void SpuSetVoiceVolume (
int voiceNum,
short volumeL,
short volumeR,
)
引数 
voiceNum	ボイス番号 (0 ～23)
volumeL		音量 (左)
volumeR		音量 (右)
解説
ボイス音量の設定を行う。
SpuSetVoiceAttr() の mask 指定
SPU_VOICE_VOLL
SPU_VOICE_VOLR
に該当する処理を行う。
音量モードは [ダイレクトモード] となり、 音量 volumeL, volumeR に指定できる値の範囲はSpuSetVoiceAttr() における [ダイレクトモード] と同等である。
音量と音量モードを同時に指定したい場合は SpuSetVoiceVolumeAttr() を使用する。
音量 volumeL, volumeR に指定する値に関しては SpuSetVoiceAttr() を参照のこと。

返り値
なし

関連項目
SpuSetVoiceAttr(), SpuNSetVoiceAttr(), SpuSetVoiceVolumeAttr()
