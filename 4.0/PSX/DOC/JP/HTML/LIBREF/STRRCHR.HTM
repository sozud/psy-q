strrchr

指定した文字が文字列に最後に現れる位置を探す

形式 

#include <strings.h>
char * strrchr (
const char * s,
long c
)
引数 
s		検索対象文字列
c		検索文字
解説
文字列 s に文字 c が最後に出現する位置を探す。

返り値
c の出現位置のアドレスを返す。c が現れない場合はNULLを返す。
