SsVoKeyOn

キー・オン

形式 

void SsVoKeyOn (
long vab_pro,
long pitch,
unsigned short voll,
unsigned short volr
)
引数 
vab_pro		VABデータ id，プログラム番号
pitch		ピッチ
voll		Lチャンネルボリューム値
volr		Rチャンネルボリューム値
解説
vab_pro の下位16bit中、上位8bitはvab_id、下位8bitはプログラム番号を指定する。
pitch の下位16bit中、上位8bitは、MIDI規格の鍵番号を指定し、さらに細かいピッチを指定したい場合は pitch の下位8bitに1/128半音単位で指定する。
この vab_pro と pitch で指定された音を voll, volr で指定された音量でキーオンする。

返り値
なし
