DecDCTvlcBuild

VLCテーブルを生成する

形式 

void DecDCTvlcBuild (
DECDCTTAB table
)
引数 
mode		VLC バッファ
解説
DecDCTvlc2() で使用する VLC テーブルを生成する。
生成されるサイズは sizeof(DECDCTTAB) であらかじめ知ることができる。
構造体DECDCTTABに関しては、libpress.hを参照のこと。

返り値
なし

備考
VLCテーブルは、圧縮された（4KB) 形式で保持され、ムービー再生時にのみこれをワーク領域に解いて (64KB)解凍に使用される。
この場合は、ムービー再生時でのメモリ削減にはならないが、ムービー未使用時には不必要なテーブル領域を削減することができる。
