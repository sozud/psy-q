GsDrawOt

OTに割り付けられた描画コマンドの実行

形式 

void GsDrawOt (
GsOT * otp 
)
引数 
otp		OTへのポインタ
解説
otp で示されるOTに登録された描画コマンドの実行を開始する。
描画処理はバックグラウンドで行なわれるためGsDrawOt()はすぐにリターンする。

返り値
なし

備考
GPUが描画中の場合、この関数はうまく動作しないのでResetGraph(1)で描画を打ち切ってから呼ぶ必要がある。
