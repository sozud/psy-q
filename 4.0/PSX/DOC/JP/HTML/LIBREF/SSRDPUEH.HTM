SpuSetReverbDepth

リバーブの深さパラメータを設定

形式 

long SpuSetReverbDepth (
SpuReverbAttr *attr
)
引数 
attr		リバーブ属性
解説
リバーブの深さのパラメータの属性を設定する。
attr.mask に、下記の設定したい属性のビット和を与えることで各属性のみの設定が可能。

属性ビット内容
SPU_REV_DEPTHLリバーブの深さ(左)
SPU_REV_DEPTHRリバーブの深さ(右)


attr.mask が0の場合は左右の属性を同時に設定する。

リバーブの深さ
リバーブの深さを -0x8000～ 0x7fffの範囲で attr.depth に、左右独立に設定する。
設定された値が負の場合はリバーブ音(wet)の位相が反転する。

返り値
常に0を返す。

関連項目
