SsSepOpenJ

SEP データをオープンする(関数 Table 版)

形式 
short SsSepOpenJ (
unsigned long* addr,
short vab_id,
short num2
)
引数 
addr		SEQ データの主記憶内の先頭アドレス
vab_id		VAB id
num2		SEP に含まれる SEQ の数
解説
全ての下位関数を登録した場合の機能は SsSepOpen() と同等。加えてテーブルに登録する関数をプログラマが制御できるため、不必要な下位関数を呼ばないようにしてコード効率をあげることができる。

SsFCALL の登録しないスロットには 取り敢えず dmy を先頭につけた関数名を書いておけば 万が一その下位関数が呼ばれたとしても BUS ERRORを起こすことはなく、最初にその関数が呼ばれた時、関数名をプリントアウトするので、dmyをとって登録すれば良い。
この関数で指定するVABデータIDのVBデータが SsVabTransCompleted() にて、転送が終了
したことが確認されてから行なうこと。

返り値
SEP アクセスナンバー：SEQ アクセスナンバーと同様の性格を持つナンバーで、内部で持つ SEPデータ管理テーブルの番号。
