RVECTOR

分割頂点ベクトル情報

構造 

typedef struct {
		SVECTOR v;
		u_char uv[2];
		u_short pad;
		CVECTOR c;
		DVECTOR sxy;
		u_long sz;
} RVECTOR;
メンバ 
v		ローカルオブジェクトの３次元頂点
uv, pad;	テクスチャマッピングデータ
c		頂点の色成分
sxy		スクリーンの２次元頂点
sz		クリップのZ値
