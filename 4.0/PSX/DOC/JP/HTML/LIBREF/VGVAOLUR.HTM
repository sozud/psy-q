SpuGetVoiceVolumeAttr

ボイス音量/音量モードの取得

形式 

void SpuGetVoiceVolumeAttr (
int voiceNum,
short *volumeL,
short *volumeR,
short *volModeL,
short *volModeR
)
引数 
voiceNum	ボイス番号 (0 ～23)
volumeL		音量 (左)
volumeR		音量 (右)
volModeL	音量モード (左)
volModeR	音量モード (右)
解説
ボイスの音量/音量モードを取得する。
SpuGetVoiceAttr() における SpuVoiceAttr 構造体のメンバ volume およびメンバ volmode それぞれの値の取得に該当する処理を行う。

返り値
なし
