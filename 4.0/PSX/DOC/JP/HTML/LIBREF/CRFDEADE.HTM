CD-ROM ライブラリ (libcd) 関数一覧
Release 4.0

CdReadFile

CD-ROM 上のファイルを読み込む

形式 

int CdReadFile (
char *file,
u_long *addr,
int nbyte
)
引数 
file		ファイル名
addr		読み込むメインメモリアドレス
nbyte		読み込むサイズ
解説
CD-ROM上のファイルをnbyte読み込む。nbyteは、2048の倍数でなくてはいけない。nbyteに0が指定された場合は、ファイルすべてを読み込む。fileにNULLを指定した場合は、直前のCdReadFileで読み込んだ最後の位置から読み込みを開始する。

返り値

返り値意味
0読み込みエラー
それ以外読み込まれたデータの数（バイト）


備考
ファイル名は全て絶対パスでかかれなくてはいけない。小文字は自動的に大文字へ変換される。読み込みはバックグラウンドで行われ、読み込み終了の判定は、CdReadSync()を使用する。
