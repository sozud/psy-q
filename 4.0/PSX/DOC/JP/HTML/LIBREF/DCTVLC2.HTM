DecDCTvlc2

VLCの解凍を行なう

形式 

int DecDCTvlc2(
u_long *bs, 
u_long *buf, 
DECDCTTAB *table
)
引数 
bs		入力ビットストリーム
buf		出力ランレベル
table		VLC テーブル
解説
ビットストリーム bs を table に従って解凍し、中間形式であるランレベルを buf 以下に生成する。解凍後のランレベルの大きさは、DecDCTBufSize() で取得できる。ランレベルが DecDCTvlcSize2() で指定された値を越えると、DecDCTvlc2() は一旦処理を中断し制御をアプリケーションに戻す。中断したVLCデコードは、DecDCTvlc2(0, 0, table)を実行することで再開できる。
返り値

返り値意味
0全ビットストリームのデコードが終了
1未デコードのビットストリームを残して復帰
-1デコード失敗

備考
ブロック関数。DecDCTin()を実行する前に必ずDecDCTvlc2()で一旦ビットストリームをランレベルに変換しておく必要がある。
途中結果のランレベルをDecDCTin()に入力として与えることはできない。
VLCテーブルはあらかじめDecDCTBuild() で解凍しておくこと。
