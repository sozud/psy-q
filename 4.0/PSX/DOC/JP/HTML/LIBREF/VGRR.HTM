SpuGetVoiceRR

ADSR Release Rate の取得

形式 

void SpuGetVoiceRR (
int voiceNum,
unsigned short *RR
)
引数 
voiceNum	ボイス番号 (0 ～23)
RR		ADSR Release Rate
解説
ボイスで使われる ADSR Release Rate の取得を行う。
SpuGetVoiceAttr において SpuVoiceAttr 構造体のメンバ rr の値の取得に該当する処理を行う。
ADSR Release Rate モードが SPU_VOICE_LINEARDecN (リニア減少) になっている場合のみ得られた値は有効となる。 他の ADSR Release Rate モードの場合は不定となる。
ADSR Release Rate と ADSR Release Rate モードを同時に取得したい場合はSpuGetVoiceRRAttr() を使用する。

返り値
なし
