InvSquareRoot

１／平方根を求める

形式 

void InvSquareRoot (
long a,
long *b,
long *c
)
引数 
a		入力：値
b		出力：仮数部
c		出力：指数部
解説
値 a の１／平方根を返す。

引数フォーマット：
a : (0,32,0)
b : (0,20,12)
c : (0,32,0)

返り値
なし
