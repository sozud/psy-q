メモリカード簡易レベルライブラリ (libmcrd) 関数一覧
Release 4.0

MemCardCallback

完了コールバック関数定義

形式 

MemCB MemCardCallback (
MemCB func
)
引数 
func		コールバック関数
解説
非同期関数の終了時に呼ばれるコールバックを定義する。
非同期関数が終了した時に func が呼び出される。
func に 0を指定した場合は、コールバックは発生しない。

MemCBは以下のコールバック関数の型を表す
typedef void (*MemCB)( unsigned long cmds, unsigned long result )

cmds 終了した非同期関数
result 非同期関数の実行結果

cmds値
値マクロ関数
0x01McFuncExistMemCardExist
0x02McFuncAcceptMemCardAccept
0x03McFuncReadFileMemCardReadFile
0x04McFuncWriteFileMemCardWriteFile
0x05McFuncReadDataMemCardReadData
0x06McFuncWriteDataMemCardWriteData

result値は各関数の項目を参照

返り値
以前に設定されたコールバックのアドレス

備考
同期関数, 即時終了する

関連項目
