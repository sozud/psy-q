CdSyncCallback

CdSyncコールバック関数を定義

形式 

CdlCB CdSyncCallback (
CdlCB func
)
引数 
func		コールバック関数
解説
コマンド終了時に呼ばれるコールバックを定義する。コマンドが終了した時にfuncが呼び出される。funcに0を指定した場合は、コールバックは発生しない。
CdlCBは以下のコールバック関数の型を表す。 
typedef void ( *CdlCB )( u_char, u_char* )
第一引数にはCD-ROMサブシステムのステータスが渡される。
ステータスには以下のものがある。

CdlAcknowledgeコマンドが受けつけられた
CdlCompleteコマンドの実行が終了した
CdlDiskErrorコマンドが受けつけられなかったorコマンドが異常終了した


第二引数はCD-ROMサブシステムからのresult配列のポインタが渡される。resultは8byteである。 
char result[ 8 ];
resultの先頭にはステータスが入り，それ以降は発行したコマンドによって内容が異なる。

返り値
以前に設定されたコールバックのアドレス

備考
func内では以降の描画終了割り込みはマスクされる。従ってfuncは必要な処理を終了したらすみやかにリターンする必要がある。
