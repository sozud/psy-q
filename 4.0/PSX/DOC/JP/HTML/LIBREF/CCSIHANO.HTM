ChangeClearSIO

ドライバ内で拡張 SIO からの割り込みをクリアする

形式 

void ChangeClearSIO ( 
long val 
)
引数 
val		割り込み要因クリアフラグ
解説
val に非 0を指定するとドライバ内で拡張 SIO からの割り込みをクリアします。他の拡張 SIO ドライバと共存する場合にのみ使用します。

返り値
なし
