SsSeqReplay

SEQデータ読みとりを再開する（リプレイ）

形式 

void SsSeqReplay (
short seq_access_num
)
引数 
seq_access_num		SEQアクセスナンバー
解説
SsSeqPauseで一旦中断した seq_access_num を持つSEQデータ読みとりを再開する。

返り値
なし

関連項目
SsSeqPause()
