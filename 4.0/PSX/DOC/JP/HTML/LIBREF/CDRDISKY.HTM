CD-ROM ライブラリ (libcd) 関数一覧
Release 4.0

CdDiskReady

Cdの状態をチェックする

形式 

int CdDiskReady (
int mode
)
引数 
mode		チェックモード（0: ブロック型、1: ノンブロック型）
解説
CDの状態をチェックし、コマンドが発行できるかどうかを調べる。CDのカバーを閉めた直後は、数秒間コマンドが発行できない状態が続くが、これをチェックする。ブロック型は安定していない場合は安定するまでホールドしてリターンする。ノンブロック型の場合はステータスを見てリターンする。

返り値

返り値意味
CdlCompleteコマンドを発行できる状態にある
CdlDiskError
ブロック型：ディスクが入っていないか不良ディスク
ノンブロック型：まだ安定していない、
もしくはディスクが入っていない、
もしくは不良ディスク
CdlStatShellOpenプレイヤーのふたが開いている



備考
CDの交換などでプレイヤーがカバーを閉めた直後は、この関数を使用してCDの安定を待つ必要がある。その後CdGetDiskType()でCDのフォーマットを確認してからコマンドを発行する。
ブロック型をコールした場合、関数がリターンするまでに最大で以下の時間を要する。

デバッギングステーション
CD-R 最大約１２秒
CD-DA 最大約１２秒
ディスクなし 約５秒
PlayStation
Black CD 最大約３秒
CD-DA 最大約５秒
ディスクなし 約５秒

ノンブロック型の場合は、ステータスを見てすぐにリターンするが、CDが安定していない状態と、ディスクなしの状態を区別できない。よって、上記の時間を参考にしてプログラム側でタイムアウトを管理する必要がある。
※この関数はDTL-H2000では正常に動作しない。
