SpuGetVoicePitch

音程 (ピッチ指定) の取得

形式 

void SpuGetVoicePitch (
int voiceNum,
unsigned short *pitch
)
引数 
voiceNum	ボイス番号 (0 ～23)
pitch		音程 (ピッチ指定)
解説
ボイスの音程 (ピッチ指定) を取得する。
SpuGetVoiceAttr() における SpuVoiceAttr 構造体のメンバ pitch の値の取得に該当する処理を行う。

返り値
なし

関連項目
SpuGetVoiceAttr(), SpuNGetVoiceAttr()
