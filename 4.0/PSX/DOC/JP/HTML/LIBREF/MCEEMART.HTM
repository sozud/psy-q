メモリカード簡易レベルライブラリ (libmcrd) 関数一覧
Release 4.0

MemCardExist

カードの接続状態を取得

形式 

long MemCardExist (
long chan
)
引数 
chan		ポート番号 + カード番号
		ポート番号(Ａポート:0x00、Ｂポート:0x10)
		カード番号(通常 0)
解説
chanで指定したメモリカードの接続をテストする。
MemCardAccept() と異なり、カードの存在のみのテストを行うため所要時間が少なくなっている。
従って、未フォーマットの確認など、より詳細なカード情報が必要な場合はMemCardAccept() を実行する必要がある。
また、カードが交換された場合も、MemCardOpen() などファイルアクセス関数の使用に先立ってMemCardAccept() を実行する必要がある。
関数自体は非同期処理のため直ちに終了する。多重の処理登録は行なえない。
処理の完了はMemCardSync() または完了コールバックにより確認する。
所用時間は約4VSYNC。
取得結果はMemCardSync() または完了コールバックの result 値として通知される。
新規カード(McErrNewCard)の検出は、MemCardAccept() を行わない限り、何度も通知される。

result値
値マクロ状態
0x00McErrNone接続されている
0x01McErrCardNotExist接続されていない
0x02McErrCardInvalid不良カード
0x03McErrNewCard新規カード（カードが交換された）


返り値
処理登録に成功すると 1を、以外は 0を返す。

備考
非同期関数, 所要時間 約 4VSYNC
