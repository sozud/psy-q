setVector

ベクトルに値を設定

形式 

setVector ( v,x,y,z )
引数 
v		ベクトルへのポインタ
x, y, z		座標値
解説
VECTOR/SVECTORに値 ( x, y, z ) を設定する

返り値
なし

備考
マクロであるためベクトルの型に依存しない。また、
a) setVector ((SVECTOR *)v, x, y, z )
b) setVector ((VECTOR *)v, x, y, z )
では動作が異なる。
