SetDrawLoad

矩形領域転送プリミティブの内容を初期化

形式 

void SetDrawLoad (
DR_LOAD *p,
RECT *rect
)
引数 
p		DR_LOADプリミティブ
rect		転送先矩形領域
解説
矩形領域転送プリミティブを初期化する。初期化ずみの矩形領域転送プリミティブをAddPrim()でOTに登録することにより、構造体DR_LOADの配列p以下のデータをフレームバッファに転送することができる。

返り値
なし
