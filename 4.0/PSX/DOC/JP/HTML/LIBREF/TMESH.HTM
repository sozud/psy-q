TMESH

三角形メッシュ

構造 

typedef struct {
		SVECTOR *v;
		SVECTOR *n;
		SVECTOR *u;
		CVECTOR *c;
		u_long len;
} TMESH;
メンバ 
v		共有頂点座標列へのポインタ
n		共有法線列へのポインタ
u		共有テクスチャ座標列へのポインタ
c		共有色情報列へのポインタ
len		頂点の長さ
