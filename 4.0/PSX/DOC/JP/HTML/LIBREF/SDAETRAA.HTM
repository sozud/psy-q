SetDrawArea

描画範囲設定プリミティブの内容を初期化

形式 

void SetDrawArea (
DR_AREA *p,
RECT *r
)
引数 
p		描画範囲設定プリミティブ
r		描画範囲
解説
描画範囲設定プリミティブを初期化する。初期化済みの描画環境変更プリミティブを、AddPrim()でＯＴに登録することにより、描画途中での描画環境の一部を変更できる。

返り値
