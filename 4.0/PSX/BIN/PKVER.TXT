名前
     pkver - ライブラリのバージョン情報の取り出し

形式
     pkver [ -h | -help ] file ...

機能説明
     pkver コマンドは、与えられたライブラリファイルを検索し、それらの
     ファイルが持つバージョン情報を全て出力します。

     ライブラリファイル file に複数の入力ファイルが指定された場合には、
     それぞれのライブラリについて情報を出力します。

     コマンド行オプションは以下の通りです。

     -h
     -help
	  簡単なヘルプメッセージを表示します。

出力フォーマット
     pkver の出力にはライブラリ名、コンパイルされた日付、時間、及びそ
     のライブラリファイルのバージョン番号が示されます。

使用例
     libc.lib のバージョン情報を取り出します (以下の例で示されているコ
     ンパイルされた日付、時間、バージョン番号は偽の情報です)。

	c:> pkver libc.lib
        libc     -- Apr 30, 00:00, 1997  [4.0]

     libsnd.lib および libspu.lib のバージョン情報を取り出します。

	c:> pkver libsnd.lib libspu.lib
        libsnd   -- Apr 30, 01:00, 1997  [4.0]
        libspu   -- Apr 30, 02:00, 1997  [4.0]

注意
     ライブラリファイル file の指定に正規表現を使用することはできません。

     バージョン情報の取り出しにつきましては version 3.6 のライブラリ 
     (一部のライブラリファイルについては未対応のものあり) 以降で対応し
     ています。

     ライブラリファイルからバージョン情報を検索するうえで、.lib の内部
     配置によっては誤ったバージョン情報が出力される可能性があります。
