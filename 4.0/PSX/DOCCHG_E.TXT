Overview and Notes
---------------------------------------------------------------------------
This file contains summaries concerning the additions and changes made to 
the document. Please refer to respective documents for details. Following 
are the newly-added document files:


<Overview>
	Extended CD-ROM Library (ds.doc)
	Memory Card Easy Access Library (mcrd.doc)
<Library Reference>
	Extended CD-ROM library (libds.doc)
	Memory card Easy Access Library (libmcrd.doc)
<Format>
	Compressed Image Data Format (bs.doc)
	Integrated Graphics Format (hmd.doc)
<Converter(Tool)>
	MSH File Creation  (meshconv.doc)
	Conversion of RSD Format to HMD Format(rsd2hmd.doc)

Notes:
The hmd.doc describing the HMD format is distributed only as a WORD file in 
release 4.0. There is no text version for bs.doc.

Basic Graphics Library (gpu.doc)
---------------------------------------------------------------------------
• The descriptions of "5. Graphics System Synchronization and Reset" 
  section has been changed.
						
• "Asynchronous Double Buffer" article has been added to "6. Double buffer".
	
• "Texture Pattern Format" article of "7. Texture Mapping" has been deleted,
  and the descriptions of "Texture Cache" article has been changed.

• The descriptions of "9. Cautionary Programming Notes" section of release 
  3.7 have been partially removed, and the removed portions were reorganized
  independently as "8. Primitive Rendering Speed".

• "9. Primitive Division" section has been added.

• "VSync Synchronization in Interlace Mode" article has been added to 
  "11. Cautionary Programming Notes".

	"15. HMD Animation"
