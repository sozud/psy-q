ガンコントローラのサンプルプログラム
=====================================

・libgunの関数を使用して、ガンコントローラが向いているＴＶ画面の
　位置を検出して、画面上に表示するプログラムです。

・実行方法
	psymake
	resetps
	run main


・ファイルの説明
	makefile.mak	メイクファイル
	main.cpe	実行ファイル

	main.c		メインルーチン

・ガンコントローラの操作は以下の通り。

	トリガーボタン：	ガンの向いている位置を表示

	SELECTボタン：	終了
