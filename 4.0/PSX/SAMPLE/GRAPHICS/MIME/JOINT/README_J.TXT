axes-MIMe (回転軸の多重内挿) サンプルプログラム

階層構造をもったオブジェクトを、座標に対する MIMe (多重内挿法) によっ
て操作するサンプルです。axes-MIMe とロール・ピッチ・ヨー角 MIMe の二種
類の内挿法をデモします。


・プログラムのコンパイル

	> psymake all

・プログラムのロード

	> psymake load
	> run main

・このサンプルの使い方

1. まず起動したら、A 側のパッドをもち、L/R キーをゆっくり押してみてく
	ださい。画面左のモデルが base, 画面右の4つが MIMe1-MIMe4 、画
	面中央が内挿されたモデルです。


             +-----------------------------+
             |                             |
             |                    MIMe1-key|
             |                             |
             |base  内挿された  MIMe2-key  |
             |         モデル              |
             |                    MIMe3-key|
             |                             |
             |                  MIMe4-key  |
             +-----------------------------+

                    画面の様子


2. A パッドの左十字キーの左右を押すと、次のプリセット状態へ移ります。

3. A パッドの start ボタンを押すと、ロール・ピッチ・ヨー角による内挿と、
	回転軸による内挿の切替ができます。現在の内挿方法は画面左上２行目
	に表示されています。

4. B パッドを使うと、自分で好きな状態を作ることができます。左十字キー
	で操作対象を変更し、右十字キーと R1/R2 キーで回転／移動をさせ
	ることができます。回転と移動のどちらを操作するのかは
	select/start キーで変更します。現在の操作対象は画面上に表示さ
	れています。編集中に A パッドの左十字キーの左右を押すと、プリ
	セット状態へ復帰します。

・パッドボタンのわりあて

	A パッド: プリセットモデルや、独自に変形したモデルを使って
		 MIMe 動作のようすを見るのに使います。
	B パッド: モデルの変形に使います。



	A パッド:
		L1/L2/R1/R2	MIMe パラメータ操作
			L1	MIMe 動作 1
			L2	MIMe 動作 2
			R1	MIMe 動作 3
			R2	MIMe 動作 4
				(画面に MIMe パラメータ表示)

		左十字右 次のプリセット状態へ移る
		左十字左 前のプリセット状態へ移る

		start	内挿方法の変更
				axes-MIMe (回転軸の多重内挿) と
				RPY-MIMe (ロール・ピッチ・ヨー角の多重内挿)
				のトグル (画面に状態を表示)

	
		select	現在のモデルの状態をダンプする
			preset.c へ追加するとプリセットとして利用できます。
			printf() 出力が出せない環境では、プログラムが
			出力待ちの状態で止まってしまいますので注意してください。


	B パッド:
		R1/R2/右十字キー
			回転 もしくは 移動

		start	回転を操作するモードへ (画面に "ROTATION" と表示)
		select	移動を操作するモードへ (画面に "TRANSLATION" と表示)

		左十字キー	操作対象の変更 (明るい部分が操作対象)
			上下	操作モデルの変更 (MIMe1/MIMe2/MIMe3/MIMe4/ALL)
			左右	操作オブジェクト(胴、足、二の足、など)の変更
