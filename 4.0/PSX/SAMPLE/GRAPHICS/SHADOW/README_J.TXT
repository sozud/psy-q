        ドロップシャドーサンプルプログラムの動かし方:

        PADL1    		.... 物体が動く
        PADR1    		.... 光源が動く
        PADRup/down/left/right	.... 全体が回転する
	PADR2/L2		.... 全体が回転する

------------------------------------------------------------------

        How to execute the sample program to drop the shadow:

        PADL1    		.... The object moves.
        PADR1    		.... The light source moves.
        PADRup/down/left/right	.... All rotates.
	PADR2/L2		.... All rotates.
