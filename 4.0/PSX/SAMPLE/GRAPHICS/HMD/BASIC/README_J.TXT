tuto0: 汎用的な HMD ビューワ

【起動方法】
	psymake tuto0	コンパイル
	psymake load0	必要なデータをダウンロード
	run tuto0	実行

【操作方法】
	○△□× 	： オブジェクトの回転
	→←↑↓ 	： オブジェクトの XY 軸平行移動
        L１ R１  	： オブジェクトの Z 軸平行移動
        L２ R２  	： 影響を受ける COORDINATE の変更

	START		： 影響を受ける COORDINATE を 0 番にする
	SELECT		： 影響を受ける COORDINATE を COORDINATE の数 -1 番
			   にする

	START & SELECT	： 終了

【モデリングデータ】
	tri.hmd		： トリケラトプス
	dino.hmd	： 恐竜（ティラノザウルス）
	cube.hmd	： 立方体
	tile.hmd	： 立方体（繰り返しテクスチャ）

【説明】
	HMD データフォーマットを使用した汎用的なビューワです。
	現在サポートされている全てのタイプのプリミティブドライバをサポート
	しています。


tuto1: 共有ポリゴンを使用した HMD ビューワ

【起動方法】
	psymake tuto1	コンパイル
	psymake load1	必要なデータをダウンロード
	run tuto1	実行

【操作方法】
	○△□× 	： オブジェクト全体の回転
	→←↑↓ 	： オブジェクト全体の XY 軸平行移動
        L１ R１  	： オブジェクト全体の Z 軸平行移動

	START を押しながら
	○△□× 	： オブジェクト１の回転
	→←↑↓ 	： オブジェクト１の XY 軸平行移動
        L１ R１  	： オブジェクト１の Z 軸平行移動

	SELECT を押しながら
	○△□× 	： オブジェクト２の回転
	→←↑↓ 	： オブジェクト２の XY 軸平行移動
        L１ R１  	： オブジェクト２の Z 軸平行移動

	START & SELECT	： 終了

【モデリングデータ】
	flag.hmd	： フランス国旗

【説明】
	HMD データフォーマットの共有ポリゴンを使用したビューワです。
	共有ポリゴンとは、複数のマトリックスにまたがるポリゴンのことです。
	
	この共有ポリゴンを関節などに使用することにより、ワンスキンモデルが
	可能になります。


tuto2: HMD を使用したシャトルビューワ

【起動方法】
	psymake tuto2	コンパイル
	psymake load2	必要なデータをダウンロード
	run tuto2	実行

【操作方法】
	○△□× 	： オブジェクトの回転
	→←↑↓ 	： オブジェクトの XY 軸平行移動
        START SELECT  	： オブジェクトの Z 軸平行移動
        L１ R１  	： ハッチの開閉
        L２ R２  	： 衛星の送出

	START & SELECT	： 終了

【モデリングデータ】
	shuttle.hmd	： シャトル

【説明】
	HMD データフォーマットの階層構造を使用したビューワです。

	データ作成時にあらかじめ親子関係やマトリックスをデータの中に埋め込む
	ことが出来るため、プログラムとデータを独立して扱うことが出来ます。

	このデータの中では、オブジェクトの使い回しを行っています。（ハッチや
	衛星の羽根など）


tuto3: 固定分割を使用した HMD ビューワ

【起動方法】
	psymake tuto3	コンパイル
	psymake load3	必要なデータをダウンロード
	run tuto3	実行

【操作方法】
	○△□× 	： オブジェクトの回転
	→←↑↓ 	： オブジェクトの XY 軸平行移動
        L１ R１  	： オブジェクトの Z 軸平行移動
        L２ R２  	： 分割のオンオフ

	START & SELECT	： 終了

【モデリングデータ】
	jimen.hmd	： 地面

【説明】
	HMD データフォーマットの固定分割を使用したビューワです。
	HMD では分割を行う場合は、プリミティブドライバを付け替えることで
	行います。さらに分割数を、データ内のプリミティブインデックスの上位 
	8 bit に指定します。

		+---------------------------------+
		|              TYPE               |
		+----------------+----------------+
		|   ポリゴン数   |     サイズ     |
		+-------+--------+----------------+
		|分割数 |        PRIM IDX         |
		+-------+--------+----------------+

	分割数を指定するマクロ（GsUNIT_DIV1～DIV5）は libgs.h にあります。
